# Systems

This directory contains system maps and authority maps.

Use the [feature review ledger](../reviews.md) to find current source and dated
architecture records. Each system map keeps its stated scope and source date;
it is not a current whole-editor ranking.

Use it for larger structures:

- editor-behavior authority models
- package or subsystem maps
- cross-editor comparison surfaces

Current editor-architecture pages include:

- [editor-architecture-landscape.md](editor-architecture-landscape.md)
- [slate-v2-overlay-architecture.md](slate-v2-overlay-architecture.md)
