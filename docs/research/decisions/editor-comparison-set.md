# Select external editors by the decision

Stop the universal editor ranking and any engine-replacement inference from it. The [review](../../plans/2026-10-13-editor-comparison-review.md) keeps Plate and Plite's existing owners. The research expands the comparison evidence without adopting another runtime.

Choose the comparison set by the question. Current additions include Wordgard for independent changes and mapping, ProseKit and Lexical Extensions for framework composition, BlockSuite and Blok for shared blocks, Portable Text for schema and behavior specifications, Meowdown and MDXEditor for Markdown editing, and OpenDoc for experimental document layout. Milkdown, Lexxy, canvas-editor and Proof SDK add narrower lifecycle, focus, rendering and agent-integration scenarios.

Keep mature baselines when they answer the question. BlockNote is active. ProseMirror's canonical source moved from GitHub. Quill's history contracts remain useful despite quiet activity. Neither age nor a GitHub archive flag alone settles relevance.

Treat source ownership and proof scope as part of each claim. A ProseMirror wrapper is distinct product evidence but not another engine confirmation. SuperDoc's public packages do not expose the entire current proprietary DOCX Engine. Premirror's older Pretext calls are a freshness concern, not a reproduced runtime failure. Desktop browser engines, touch emulation, a user-agent override and CDP composition do not establish native-device correctness.

The [current comparison](../sources/editor-architecture/current-comparison.md) compiles the findings. The run's ledgers preserve every discovered identity, exact source read, accepted invariant, rejected inference and reopening condition. Twenty-seven promotions are documentation packets. None is an accepted implementation, browser or performance result.

An adoption needs a concrete user job, a native Plate or Plite owner and a failing or discriminating proof at that owner. A scale-sensitive proposal also needs a current-owner versus target measurement. A source comparison can choose the next test or design question. It cannot settle those gates by itself.

Unresolved evidence stays with the feature-specific comparison it could change. Owner: that comparison's lead. The gap closes when the missing current implementation, provider, native gesture, layout-fidelity vector or measured cost is inspected and proved. The broad discovery pass requires no further shard because every declared corpus has an explicit disposition.
