# Decisions

For repeated architecture questions, start with the [feature review ledger](../reviews.md)
and [review-history contract](../schema.md#review-history). A decision page owns
the current conclusion; linked immutable records preserve prior reviews,
rejected alternatives and proof limits. A source match or an accepted decision
does not certify implementation.

This directory contains normalized choices and policy calls.

Each decision page should answer:

- what question was decided
- what answer won
- why it won
- what it overruled
- what sources support it
