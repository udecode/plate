### 2026-09-13: 2026-09-13-clipboard-transfer-convergence

[Immutable record](../review-records/2026-09-13-clipboard-transfer-convergence.json) — review; pursue; observation stale.

Question: What does transfer preserve across schemas and editor instances, and can one content-fitting owner replace feature-specific paste repair?

- Keep/configure: existing handler and export hooks cannot fix callers that bypass them or reconstruct incomplete slices; insufficient.
- Local repair: patching each rewrite or fallback fixes individual cases but preserves duplicate transfer policy; use only as adoption steps toward the durable owner.
- Change API: separate edge closure, root preservation/pruning and destination identity remapping in the existing complete-slice contract; pursue detailed design.
- Add primitive: a new public clipboard plugin or transfer object has no proven independent job beyond DOM transfer, ContentSlice and exact target replacement; reject speculative machinery.
- Delete ContentSlice/get-fragment distinction: reject bare-node interchange because it loses open edges and referenced roots; keep getFragment for its distinct node-array query job.
- Delete projected extraction: reject collapsing authored retained fragments, visible segment order and repeated root owners to one canonical range; keep the exact-view target adapter.
- Merge/move: cut projected payload decoding, handler termination and fallback policy; share DOM interpretation/export rules and apply exact target replacement atomically. Strongest candidate, still provisional pending design and measurement.
- Move all feature repair into the fitter: reject blanket consolidation; keep neutral fitting below table placement and external-format policy, and centralize only complete-slice mechanics.
- Replace architecture: no evidence justifies replacing the compiled fitter, frontier, provenance mapping or all clipboard layers. Preserve their independent jobs.

Proof limits: 241 existing tests pass in 10 files: 87 core slice/fitting, 98 clipboard/DOM boundary, 11 projected clipboard and 45 projected command tests. A direct source public-call diagnostic records original/preserved slice success and maxLength/closed-rewrite missing-root exceptions, with zero commits in both failures. The initial test-only preload invocation failed before probe execution and was corrected. These baseline passes do not prove newly identified combinations. Projected replacement-data, export-policy and failed-insertion paths plus root-bearing table/static consumers are source findings; no actual browser, native/device, Plate package or performance replay. No runtime target is accepted: the Task design/plan must resolve dispatch, root ownership, exact target replacement, adoption, doctrine repair and matched scale proof.
