Question: What is the smallest React integration for canonical editor state, rendering and component lifetime?

- Keep/configure: ordinary EditorRoot already hosts multiple roots, but retaining Runtime duplicates setup vocabulary and leaves invalid editor/root combinations to runtime.
- Change API: make EditorRoot's editor/view modes explicit and inferred, including independent authored projections.
- Add primitive: reuse core editor/view identity; no independent current job establishes another public Runtime or ViewManager.
- Delete/merge/inline: remove the peer forwarding handle and creation-or-context hook; fold its public setup job into EditorRoot while retaining necessary private coordination.
- Move ownership: keep document authority below React, mounted registration/effects in React, and Plate's passive control provider distinct from mounting.
- Replace architecture: removing every context forces scoped controls/callbacks to reconstruct ownership; global view state or a document per Editable loses independence or sharing.

Proof limits: Source and existing assertions inspected only. No tests, browser, scale probe or adoption executed. The exact multi-projection mount grammar remains design work. Any changed private coordination/subscription topology remains provisional under the scale gate.
