# Milkdown: autocomplete and triggers

## Slash menu

- Milkdown's slash menu keeps no range or decoration. `SlashProvider` reads the paragraph text before the caret and by default shows when the last character is the trigger (`Milkdown/milkdown@6a4db480b:packages/plugins/plugin-slash/src/slash-provider.ts:132-144`, `:153-183`). Crepe treats the whole block text after a leading `/` as the filter, and only when the caret is at the end of a paragraph or heading (`Milkdown/milkdown@6a4db480b:packages/crepe/src/feature/block-edit/menu/index.ts:79-112`). `shouldShow` re-runs on every debounced view update (20 ms in Crepe, 200 ms by default), so paste, undo or a remote edit can open the menu (inferred). The provider skips updates while composing, but Crepe's Enter handler has no `isComposing` or 229 guard, so an IME commit Enter can run the item (inferred). Crepe's menu has no ARIA and no input-rule guard. A window-level capture-phase keydown handles Escape, the arrows and Enter while the editor keeps focus. Completion clears the block text and then sets the block type. Source: `docs/plite/research/2026-10-02-autocomplete-query-representation/shards/001-prosemirror-family.md:65-77`, read on 2026-10-02 at that commit of the local fork.
