# Slate: model and schema

## Model proposals in Slate history

- Legacy Slate's model is open element objects with `children` and text leaves `{ text }`, with discriminators left to the app (`ianstormtaylor/slate@ec793483:packages/slate/src/interfaces/element.ts:17-21`, `ianstormtaylor/slate@ec793483:packages/slate/src/interfaces/text.ts:11`). Plate keeps this direct editing shape and adds schema compilation. Source: `c70bacbd4a:docs/plite/research/2026-08-17-editor-node-model-standards/README.md:99`, `read-log.tsv:11`, `lead-ledger.tsv:2`.

- Legacy Slate considered and declined several standard-model proposals. Issue #4378 proposed renaming `text` to `value` and adding `type: 'text'` for UNIST compatibility; it has been open since 2021 with no landed PR, and its comments showed that UNIST requires `type` on every node and that a configurable text key would infect every read and transform or become editor-global policy. Issue #1486 considered MDAST-style nested mark nodes and kept self-contained split text leaves, because marks are unordered formatting while inlines have structural identity. Issue #3482 tried Portable Text as the native value: text blocks worked, but voids and inlines broke Slate's required text children and text-point selection; it is still open, and #5253 only asks to parse Portable Text. Issue #1024 proposed a MIME `contentType` to reject clipboard fragments from incompatible schemas; open and unimplemented. Issue #1959's versioned compact `slt1` storage was rejected to keep readable JSON, and #3272 rejected a core migration chain as app-owned. PR #3093, the 0.50 rewrite, moved to plain JSON with flat custom fields and briefly shipped `slate-schema`, which #3273 and PR #3291 removed five days later because imperative normalization was clearer. Issue #269 rejected Mobiledoc's indexed JSON. A keyword scan of 100 of 155 recent discussions found no later standards proposal, and Slate source at `ianstormtaylor/slate@ec793483` integrates none of UNIST, MDAST, Portable Text, Mobiledoc or content types.
