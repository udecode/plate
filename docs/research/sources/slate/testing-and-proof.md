## Android coverage

- **Slate's Android cases are manual.** Slate's `android-tests` example holds six manual cases, each an instruction with a starting value: split-join (Enter twice, then Backspace twice, around bold words), insertion (by tapping keys, glide typing, voice input and an IME), special characters, an empty editor, removal over a selection, and autocorrect, which PR #5901 added in 2025. Its `Editable` sets `spellCheck` and a placeholder. Slate's contributing guide asks contributors to run these cases by hand for changes that might affect Android, the page is hidden from the examples list, and no Playwright test drives it. Evidence: `ianstormtaylor/slate@945a484df2497e4c448b33f417b0de2a49840032:site/examples/ts/android-tests.tsx:14-196`, `:249-253`, `ianstormtaylor/slate@945a484df2497e4c448b33f417b0de2a49840032:docs/general/contributing.md:140-142`, `ianstormtaylor/slate@945a484df2497e4c448b33f417b0de2a49840032:site/constants/examples.ts:27`, read 2026-10-08 at the local fork, whose `playwright/integration/examples` holds no Android test.

- **Slate's only mobile automation is a Pixel 5 profile on desktop Chromium.** Slate's Playwright projects are `chromium`, `firefox`, `mobile` (Playwright's `Pixel 5` descriptor) and, on macOS hosts, `webkit`, and nothing in the repository drives a real Android device or soft keyboard. The Pixel 5 user agent contains `Android`, which is all Slate's `IS_ANDROID` tests, so the `mobile` project runs Slate's Android input manager and RestoreDOM on desktop Chromium, fed by input that Playwright synthesizes, as Plite's `mobile` project does. Evidence: `ianstormtaylor/slate@945a484df2497e4c448b33f417b0de2a49840032:playwright.config.ts:5-41`, `ianstormtaylor/slate@945a484df2497e4c448b33f417b0de2a49840032:packages/slate-dom/src/utils/environment.ts:10-11`, `ianstormtaylor/slate@945a484df2497e4c448b33f417b0de2a49840032:packages/slate-react/src/hooks/android-input-manager/use-android-input-manager.ts:25-29`, read 2026-10-08 at the local fork, which has no Appium, adb or emulator setup.
