# Yjs collaboration: selection and caret

## Relative positions

- **Relative positions.** y-prosemirror round-trips every ProseMirror position through a Yjs relative position, including positions between blocks. Its cases cover single and multiple paragraphs, hard breaks, headings, blockquotes, nested and ordered lists, code blocks and a horizontal rule. It also restores text and node selection bookmarks, including after a remote insert shifts them (`yjs/y-prosemirror@9200946f0e:tests/positions.test.js:90-539`). yjs encodes and decodes a relative position at every index with each association -1, 0 and 1 (`yjs/yjs@da05230083:tests/relativePositions.tests.js:25`). With association 0 a position follows an insert at its index, and with -1 it stays put (:111). A position into deleted text comes back after an `UndoManager` undo only on the doc that ran the undo; a peer that receives the update resolves it past the restored text (:128) (Yjs 14 prerelease; `docs/editor-test-harvester/yjs-collaboration/report.md:72`). Plite converts only text points: `pointToYjsRelativePosition` throws for a target that is not a `Y.XmlText`, and picks association -1 at the end of a text node and 0 elsewhere (`packages/plitejs/src/yjs/core/selection.ts:14-32`). `packages/plitejs/test/yjs/selection-contract.spec.ts` covers point and range round trips with direction kept, offset clamping, distinct adjacent leaf boundaries, rebasing across a concurrent insert, moved-node identity and a vanished target. It has no nested-list, hard-break or undo case (test names read 2026-10-08).
