- **Harvest sources and licenses.** The Yjs collaboration test harvest read four MIT-licensed sources: slate-yjs (`BitPhinix/slate-yjs@69f3e0eaec:LICENSE.md`), Lexical's `lexical-yjs` package (repository `LICENSE`, and `"license": "MIT"` in `facebook/lexical@dd5c41b131:packages/lexical-yjs/package.json`), y-prosemirror (`yjs/y-prosemirror@9200946f0e:LICENSE`) and yjs (`yjs/yjs@da05230083:LICENSE`). It extracted behavior invariants and copied no fixtures (`docs/editor-test-harvester/yjs-collaboration/report.md:22-30`, :56). The report pinned no commit. Its cited test lines match the local checkouts at the slate-yjs, y-prosemirror and yjs commits above (checked 2026-10-08), so those are probably the harvested revisions (inferred). At those commits yjs is 14.0.0-rc.2, and y-prosemirror is `@y/prosemirror` 2.0.0-2 on `@y/y` 14. Plite tests against yjs 13.6.30 (`packages/plitejs/package.json:210`), so the harvested tests use a newer Yjs API (`Y.Type`, `setAttr`, lib0 deltas) than the one Plite calls.

## Harness and fault-injection helpers

- **Harness files and the yjs fault-injection helper.** The harvest skipped files that hold no editor behavior: slate-yjs's ambient typings and fixture harness (`BitPhinix/slate-yjs@69f3e0eaec:packages/core/test/withTestingElements.ts`), y-prosemirror's runners and its cohort and schema helpers, and yjs's runner and its internal `IdMap`, `IdSet`, encoding and compatibility tests (`docs/editor-test-harvester/yjs-collaboration/report.md:79-88`). One helper is worth copying as a technique. yjs's `TestConnector` buffers each peer's updates, so a test can flush one random message, flush all of them, or disconnect and reconnect a random peer. `applyRandomTests` runs random edits across five peers under those faults, and then `compare` asserts that every peer converged (`yjs/yjs@da05230083:tests/testHelper.js:156`, :453, :568).
