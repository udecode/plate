# Portable Text: model and schema

## Containers and nested roots

- **Containers.** The harvest groups 30 Portable Text files (241 indexed test and describe names) on nested editable containers and reads one portable law from them: nested roots keep stable order, selection ownership, normalization boundaries and DOM projection, while which content a container admits stays schema policy (report.md:116). Under `portabletext/editor@ad2a52d13d9f:packages/editor`, schema resolution is tested in `src/schema/resolve-containers.test.ts`, `src/schema/get-block-object-schema.test.ts`, `src/selectors/selector.get-applicable-schema.test.ts` and `src/traversal/get-union-schema.test.ts`, and container editing in the nine `tests/container-*.test.tsx` files and their neighbours (source-routing.md). At that revision the editing tests pin concrete gestures: Backspace in an empty callout unwraps it; Backspace at the start of an empty block after a container lands at the end of the container's last content, or selects a trailing block object; Enter on an empty last line leaves the container only when the previous sibling is empty too; a range delete across containers merges outer text blocks that share a parent and keeps the shell of a container it starts or ends inside; a moved block lands before its destination inside or outside a container; and each container normalizes to a cursor-ready structure on its own (`tests/delete-empty-container.test.tsx`, `tests/backspace-before-container.test.tsx`, `tests/container-enter-escape.test.tsx`, `tests/cross-container-range-delete.test.tsx`, `tests/event.move.block.cross-container.test.tsx`, `tests/container-normalization.test.tsx`).

## Path, point, range and operation helpers

- **Core helpers.** The harvest groups 30 Portable Text files (374 indexed test and describe names) as pinning root-aware, deterministic core helpers (report.md:125). Under `portabletext/editor@ad2a52d13d9f:packages/editor` they cover path comparison and navigation (`src/engine/path/`), node traversal (all of `src/node-traversal/` but `get-highest-object-node.test.ts`, which sits in the object family), operation inversion (`src/engine/operation/inverse-operation.test.ts`), dirty paths and path serialization (`src/paths/get-dirty-paths.test.ts`, `src/paths/serialize-path.test.ts`), operation-to-patch translation (`src/internal-utils/operation-to-patches.test.ts`), and transforming a local operation against a remote patch, where keyed paths stay stable and an operation on a removed block is dropped (`src/internal-utils/transform-operation.test.ts`). The root-aware reading is the harvest's summary, drawn from test names rather than assertion bodies (report.md:70).

## Portable Text model

- Portable Text blocks use `_type: 'block'` and `style`; spans carry `marks` arrays that reference `markDefs`; and lists are flat, with `listItem` and `level` on blocks (`portabletext/portabletext@d17f7289:README.md:16-185`). Flat lists and portable annotations work, at the cost of mark-reference indirection. Source: `c70bacbd4a:docs/plite/research/2026-08-17-editor-node-model-standards/README.md:101`, `read-log.tsv:15`.
