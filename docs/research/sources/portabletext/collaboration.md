# Portable Text: collaboration

## Remote patches, selection and undo

- **Remote patches.** Six Portable Text files (54 indexed test and describe names) under `portabletext/editor@ad2a52d13d9f:packages/editor` pin how remote patches meet local state (report.md:122). A remote block insert or delete, text edit, span insert or unset, or split of the caret's block rebases the local caret (`tests/selection-after-remote-patches.test.tsx`). A remote patch that leaves the caret in place, or only re-spreads the selection range, emits no selection event, while a real move still emits one (`tests/selection-emit-dedup.test.tsx`, `tests/selection-emit-stability.test.tsx`). One user's undo after another user's unrelated change undoes only their own change, also out of order and with emoji or kanji text (`tests/undo-redo-collaboration.test.tsx`). Held-back local normalization patches are discarded when a remote patch conflicts with them, targets their parent path or a full value sync arrives, and survive remote patches on unrelated paths (`tests/collaborative-editing.test.tsx`). `gherkin-tests/undo-redo.test.tsx` holds the single-editor undo and redo scenarios, such as a selection change leaving the undo stack alone.
