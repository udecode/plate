# ProseKit: issues and regressions

## Issue corpus shape

- **Tracker themes.** On 2026-09-09 ProseKit's GitHub tracker (prosekit/prosekit) held 93 issues, 15 open and 78 closed. None was semantically checked, so the titles are leads, not confirmed defects, and the per-issue rows stay in `docs/editor-issue-harvester/prosekit/full/issues.md`. The largest cluster is block and table drag handles, 14 issues: #771, #895 (dragging an image fails in long documents), #940, #1066 (drag and drop with lists, open), #1121, #1122, #1141 (handles move while scrolling), #1153 (Safari drag preview), #1159, #1182, #1183, #1184 (table drag preview on Firefox), #1383 (slow code-block drag preview) and #1392 (tables with header cells cannot be dragged). Menus and autocomplete: #470, #689 (an empty selection should not open the inline menu), #839 (the popover shifts after a mark button click), #976 (autocomplete forgets a dismissal when the selection moves between nodes), #1062 (the slash menu opens when a selection contains /, open) and #1598. Keyboard and selection: #799 (cannot select a table cell's first character), #1001 (Shift+Enter newline without a new block), #1061, #1069, #1077 (the first Ctrl+A should select the block) and #1670 (wrong virtual selection after blur). Markdown export: #1125 (code block languages) and #1266 (task lists). Framework integration: #587, #607, #1026 (React Compiler), #1218, #1432 and #1439. Collaboration: #1219 (the commit viewer resets under streaming Loro updates, open). Feature requests open on that date: #877 (footnotes via ReactNodeView), #909 (virtual DOM rendering), #1076 (open a link on click), #1081 (block side menu example), #1118 (move-node command), #1322 (AI kits), #1444 (percentage sizes in ResizableRoot), #1498 (pages and formats) and #1500 (multi-column layout). The other open issues are #1 (the dependency dashboard), #1061, #1062, #1066, #1069 and #1219 (`docs/editor-issue-harvester/prosekit/full/issues.md:3-101`).
