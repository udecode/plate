# ProseMirror: collaboration

## Change tracking

- **prosemirror-changeset** turns a sequence of step maps into a flat set of insertions and deletions for a change-tracking display, and each span can carry caller data such as the user who made the change (`README.md:18-20`). The set is shaped by how it was built, though. `addSteps` re-minimizes the changes it touches by diffing content after every call, so adding steps one at a time can give a different set than adding them all at once (`src/changeset.ts:26-36`); the default token encoder compares node names and text by character and ignores marks and attributes (`src/changeset.ts:145-156`); and `simplifyChanges` widens mixed insertions and deletions to whole words for presentation (`src/simplify.ts:52-58`). A product that needs exact attribution records it where the change happens and uses the changeset to display it. Evidence: `ProseMirror/prosemirror-changeset@e215757276357b64cf74f536552f3a5ef292fa1a:src/changeset.ts`, `ProseMirror/prosemirror-changeset@e215757276357b64cf74f536552f3a5ef292fa1a:src/simplify.ts` and `ProseMirror/prosemirror-changeset@e215757276357b64cf74f536552f3a5ef292fa1a:README.md`, read slices recorded in `docs/plite/research/2026-09-10-structural-diff-oss/sources/source-identities.json`, verdict at `docs/plite/research/2026-09-10-structural-diff-oss/shards/001-structural-diff.md:13`. Limit: read in source, not run; the README was checked by the 2026-10-08 compile reader, not by the run.

- `simplifyChanges` decides word boundaries per character: ASCII letters and digits are word characters, and other characters are when they match `\p{Alphabetic}` or `_`, or, where the runtime lacks Unicode regex properties, when they change case or belong to common single-case scripts such as Hebrew, Arabic, kana, CJK ideographs and Hangul; leaf nodes and node boundaries count as spaces (`src/simplify.ts:4-45`). Changes less than 30 characters apart are merge candidates (`:47-49`), and single-character replacements are not widened (`:51-56`). So unspaced CJK text reads as one word, and a mixed edit inside it widens to the whole run; that consequence is inferred from the code, not run. Evidence: `ProseMirror/prosemirror-changeset@e215757276357b64cf74f536552f3a5ef292fa1a:src/simplify.ts`, read 2026-10-08.

## Track changes plugins

- Two ProseMirror track-changes plugins show how much rewriting a mark-based design keeps. Handle with Care's `prosemirror-suggest-changes` (MIT) rewrites transactions into insertion, deletion and modification marks with dedicated structural-step handling (`handlewithcarecollective/prosemirror-suggest-changes@653fba70:src/withSuggestChanges.ts:1-185`) and exposes range and ID decisions (`src/index.ts:1-40`); its issues, as read on 2026-09-10, report newline edits escaping review (#11, open), partial decisions on grouped suggestions (#23, closed) and AI change identity apart from neighbor grouping (#26, open). Atypon's `manuscripts-track-changes-plugin` (Apache-2.0 headers) tracks replace, replace-around, formatting and attribute steps with structural grouping and selection remapping by inverting and reapplying steps (`Atypon-OpenSource/manuscripts-track-changes-plugin@62f4d19d:src/tracking/trackTransaction.ts:1-155`). The issues were read, not replayed. Source: `docs/plite/research/2026-09-10-authored-changes/assessment.md:48-49`, `read-log.tsv:32-35`, `:49-51`.

## Central-authority collaboration

- prosemirror-collab keeps the steps the central authority has not confirmed in plugin state, each with its inverse (`ProseMirror/prosemirror-collab@19ad580996ba404d81cd51968c547665b5948e5c:src/collab.ts:29-55`). `receiveTransaction` treats the leading incoming steps that carry this client's ID as confirmations, applies the remaining remote steps, rebases the still-unconfirmed local steps over them with `rebaseSteps`, and marks the result `addToHistory: false` with the rebased count under the `rebased` meta key (`:102-150`). The plugin spec sets `historyPreserveItems: true` (`:93-95`), which makes prosemirror-history keep steps unmerged, exactly as they arrived, so its items can be rebased (`ProseMirror/prosemirror-history@768b74205ad59919ed54d75e197312964ddcf3c2:src/history.ts:345-360`). Source: `831f5e5da6a37f7d9095c1a81acc6b3de10bd3ba:docs/analysis/plite-plate-v2-architecture-research.md:253-267` (2026-04-03, unpinned), checked at these commits on 2026-10-08.
