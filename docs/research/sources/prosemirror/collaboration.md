# ProseMirror: collaboration

## Change tracking

- **prosemirror-changeset** turns a sequence of step maps into a flat set of insertions and deletions for a change-tracking display, and each span can carry caller data such as the user who made the change (`README.md:18-20`). The set is shaped by how it was built, though. `addSteps` re-minimizes the changes it touches by diffing content after every call, so adding steps one at a time can give a different set than adding them all at once (`src/changeset.ts:26-36`); the default token encoder compares node names and text by character and ignores marks and attributes (`src/changeset.ts:145-156`); and `simplifyChanges` widens mixed insertions and deletions to whole words for presentation (`src/simplify.ts:52-58`). A product that needs exact attribution records it where the change happens and uses the changeset to display it.
