# ProseMirror: testing and proof

## View test corpus

- ProseMirror's view browser tests are a harvest index for editing oracles. Composition (`test/webtest-composition.ts:87-305`): empty, end and start blocks, existing text, word replacement, marks, multi-child marks, cursor wrappers, decoration changes, cancellation by overlapping transactions, rapid consecutive and cross-paragraph compositions. Selection (`test/webtest-selection.ts:64-350`): DOM selection import and export, model-to-DOM sync, coordinate round trips, wrapped-line, node-boundary and RTL coordinates, selectable inline and block arrow movement, and the `Selection.extend` fallback. DOM change (`test/webtest-domchange.ts:147-205`, `:411-445`): selection adjustment after a native DOM mutation and step extraction for ambiguous deletions and replacements. Clipboard (`test/webtest-clipboard.ts:1-115`): node-selection serialization, text-selection context, open-node preservation, external HTML cleanup, paste transforms, table wrappers, comment-bounded fragments and custom parser and serializer hooks. Source: `docs/plite/research/2026-06-12-testing-oracles/sources/prosemirror-view-summary.md:10-24`, `read-log.tsv:9-12`. Limit: unpinned local checkout read on 2026-06-12.

- **ProseMirror's composition tests are synthetic.** `prosemirror-view`'s composition tests dispatch bare `CompositionEvent`s on the editor DOM and edit the text node's `nodeValue` directly, collapsing the selection after the edit, to simulate composition (`ProseMirror/prosemirror-view@ca4c78e9:test/webtest-composition.ts:7-16`). Plite's row 'commits IME composition inside bold markup' uses the same shape: it puts a DOM caret inside the bold text node and dispatches the composition events from page script (`apps/plite/tests/plite-browser/donor/examples/richtext.test.ts:1972`). Read 2026-10-08 at the local checkout; the 2026-10-02 run read `master` unpinned (`docs/plite/research/2026-10-02-agentic-e2e-testing/read-log.tsv:395`).

## Porting ProseMirror tests

- ProseMirror mechanisms are not port targets: string content expressions, numeric positions, Step JSON, the class model, mark objects, the step registry, PluginView, NodeView, MarkView, command dispatch, plugin bags and central OT. Only the portable behavior a ProseMirror test checks carries over, translated into Plite APIs and fixtures, and no browser, composition, geometry, clipboard or mobile claim closes on a synthetic package test alone. Source: `docs/editor-test-harvester/prosemirror/report.md:31-33`, `:173-177`.
