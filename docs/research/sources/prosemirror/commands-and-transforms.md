# ProseMirror: commands and transforms

## ProseMirror test families

- **PM-05 change algebra.** The harvest reads `model/test/test-diff.ts` and `transform/test/test-mapping.ts`, `test-replace_step.ts`, `test-step.ts`, `test-trans.ts` as checking that changes map, compose, invert and replay, and classify the ranges they touch across structural edits. Plite counterparts: `packages/plitejs/test/document-change-laws.test.ts`, `document-change-structural-transform.test.ts` and `anchor-mapping-contract.ts`; replace-around (wrap and unwrap) cases were the named gap. Source: `docs/editor-test-harvester/prosemirror/report.md:144`.

- **PM-16 and PM-17 keymaps and commands.** `keymap/test/test-keymap.ts` checks handler lookup by key name, modifier distinction, passing state, dispatch and view, the shift-key fallbacks and `keyCode` fallbacks with modifiers or non-ASCII characters (`ProseMirror/prosemirror-keymap@d60e2447d63374d7612121675e9e7fa9ccfb2eb0:test/test-keymap.ts:20-62`). The harvest reads `commands/test/test-commands.ts` as checking that delete, join, split, lift, select, mark and block-type commands respect atoms, isolating boundaries, bidi edges, schema legality and applicability. Plite counterparts: `packages/plitejs/test/dom/hotkeys.test.ts`, `hotkeys-no-navigator.test.ts`, `packages/plitejs/test/command-spec.test.ts`, `delete-contract.ts`, `transforms-contract.ts` and `editor-methods-contract.ts`; Plite does not use raw key strings as command identity. Source: `docs/editor-test-harvester/prosemirror/report.md:155-156`.

- **PM-19 list commands.** `schema-list/test/test-commands.ts` checks `wrapInList`, `splitListItem`, `liftListItem` and `sinkListItem`, including nested lists, empty sublists and joining adjacent lists of the same type (`ProseMirror/prosemirror-schema-list@d5515fe14169373c3f4ae73d2a82c13b50c6486e:test/test-commands.ts:24-142`). Plate counterparts: `packages/platejs/src/features/list/lib/BaseListPlugin.spec.tsx` and `apps/plite/tests/plite-browser/donor/examples/check-lists.test.ts`. Source: `docs/editor-test-harvester/prosemirror/report.md:158`.
