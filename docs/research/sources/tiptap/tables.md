# Tiptap: tables

## Table support

- Tiptap's open-source table support is built on prosemirror-tables: its `@tiptap/pm/tables` entry re-exports `prosemirror-tables`, and its table extension imports `CellSelection`, `columnResizing`, `fixTables` and `tableEditing` from it and wires commands such as `fixTables` and `setCellSelection` through them. Evidence: `ueberdosis/tiptap@91c51be53c4655ef07e29ec489471524debfa0ca:packages/pm/tables/index.ts:1` and `ueberdosis/tiptap@91c51be53c4655ef07e29ec489471524debfa0ca:packages/extension-table/src/table/table.ts:18-28`, `:426-496`, checked 2026-10-08.

## Table extension

- Tiptap's open-source table extension carries some table policy of its own on top of prosemirror-tables. At ueberdosis/tiptap@eb974ea2f6e6eae10d987bcba4d32f80ca4f1ca8 (read 2026-09-17 from a fetched bare clone, not run), in its extension-table package: `src/table/utilities/deleteTableWhenAllCellsSelected.ts` deletes the whole table when every cell is selected; `keepCursorInTable.ts` keeps the cursor in the mapped table; `createColGroup.ts` and `colStyle.ts` own the HTML colgroup width model and the minimum-width CSS; `src/cell/table-cell.ts` parses scalar or multiple `colwidth` values from HTML; `src/kit/index.ts` composes four table extensions; and `isCellSelection.ts` checks for the inherited `CellSelection`. The whole-table delete is already wired at the older local checkout: ueberdosis/tiptap@91c51be53c4655ef07e29ec489471524debfa0ca:packages/extension-table/src/table/table.ts:474-477 binds Backspace, Mod-Backspace, Delete and Mod-Delete to it (checked 2026-10-08). The 2026-09-17 read lists current tests for colgroup updates on resizable and non-resizable tables, programmatic changes while read-only, width retention, multi-cell deletion and row and column cursor retention. Tiptap's pm package then resolved prosemirror-tables 1.8.5 and prosemirror-state 1.4.4, up from 1.6.4 and 1.4.3 at 91c51be5 (ueberdosis/tiptap@eb974ea2:pnpm-lock.yaml:894-906,915-934; docs/plite/research/2026-09-17-table-substrate-ownership/read-log.tsv:22-70).

- Tiptap supplies its own `TableView` node view (ueberdosis/tiptap@eb974ea2f6e6eae10d987bcba4d32f80ca4f1ca8:packages/extension-table/src/table/TableView.ts:1-154; read 2026-09-17). Because its pm package re-exports prosemirror-tables, its table behavior is integration evidence for that engine, not independent validation, though application callers get semantic commands such as `setCellSelection` (docs/plite/research/2026-09-17-table-substrate-ownership/REPORT.md:47).
