# Tiptap: clipboard and paste

## Paste HTML transform order

- **Paste HTML transform order.** Tiptap composes `transformPastedHTML` in a fixed order. The editor's own `editorProps.transformPastedHTML` runs first, then each extension's hook by priority, higher first, with equal priorities kept in registration order. Each hook receives the previous hook's output, and extensions without the hook are skipped. Unit tests pin this in `ueberdosis/tiptap@91c51be53c:packages/core/src/__tests__/transformPastedHTML.test.ts:8-257`, and `ueberdosis/tiptap@91c51be53c:tests/cypress/integration/core/transformPastedHTML.spec.ts` repeats it in a browser. The composition is `ueberdosis/tiptap@91c51be53c:packages/core/src/ExtensionManager.ts:285-319`. The harvest would add this order to Plate only where a Plate paste owner chains HTML transforms (`docs/editor-test-harvester/tiptap/report.md:92`, and lines 133-135). Read at that commit on 2026-10-08; the 2026-05-10 harvest pinned no commit, but its cited lines match this one.

## Link paste

- Pasting a URL over a non-empty selection in Tiptap sets a link mark with that URL on the selected text, but only when the pasted text is exactly one link by `linkifyjs` and `shouldAutoLink`, when given, accepts it; an empty selection falls through to the ordinary paste (`ueberdosis/tiptap@91c51be5:packages/extension-link/src/helpers/pasteHandler.ts:15-45`). Source: `c70bacbd4a:docs/plite/research/2026-06-14-selection-paste-undo-oracles/read-log.tsv:14`; reread at the pinned commit on 2026-10-08.

- Tiptap's link extension links pasted text only over a selection. Its `handlePaste` returns false on a collapsed selection, and otherwise sets a link mark on the selection only when the whole pasted text is one URL that `linkify` finds and `shouldAutoLink` accepts (`ueberdosis/tiptap@91c51be53c:packages/extension-link/src/helpers/pasteHandler.ts:15-49`). Plate also links a URL pasted at a collapsed caret (`### Link` notes in `docs/editor-behavior/markdown-editing-spec.md`). The `transformPastedHTML` tests go beyond the order this page describes: the extension context and editor state each hook receives, empty, special-character, very long and malformed HTML, and practical chains that strip inline styles and dangerous attributes or normalize word-processor whitespace (`ueberdosis/tiptap@91c51be53c:packages/core/src/__tests__/transformPastedHTML.test.ts:258-545`). Source: `c70bacbd4a:docs/plite/research/2026-06-13-oss-rich-html-paste-clipboard-invariants/read-log.tsv:8-9`; both files read at that commit on 2026-10-08.
