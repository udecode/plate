# Meowdown: clipboard and paste

## Open fragments

- **Open fragments.** `prosekit/meowdown@5b9962982a1cb3d1732355c753ce76d9a5966af3:packages/core/src/extensions/clipboard/plain-text.test.ts`, `prosekit/meowdown@5b9962982a1cb3d1732355c753ce76d9a5966af3:packages/core/src/extensions/clipboard/clipboard.test.ts`, `prosekit/meowdown@5b9962982a1cb3d1732355c753ce76d9a5966af3:packages/core/src/extensions/clipboard/semantic-inline.test.ts`, `prosekit/meowdown@5b9962982a1cb3d1732355c753ce76d9a5966af3:packages/core/src/utils/selected-text.test.ts` and `prosekit/meowdown@5b9962982a1cb3d1732355c753ce76d9a5966af3:packages/core/src/utils/top-level-block-boundary.test.ts` pin that copying an open fragment, such as part of a heading, code block or list, never invents a block marker or fence for structure that was not selected, while rich HTML stays semantic. They include one-edge cases: a heading keeps its marker when its content start is selected and loses it when it is not, and a code block selection that starts at its content start drops the fences. Plate has the Markdown side in `packages/platejs/src/markdown/lib/MarkdownPlugin.spec.ts:634-738`: an open nested fragment keeps its inline marks, and open heading, code block, list and nested blockquote fragments get no marker or fence. Limit: every Plate case opens both edges by the same depth, so a fragment open at one edge only is untested, and the cases read only `text/markdown`, not HTML. Evidence: `docs/editor-test-harvester/meowdown/report.md:144, 156, 238-239`; the Plate file was read on 2026-10-08, not rerun.

## Plain paste

- **Plain paste.** `prosekit/meowdown@5b9962982a1cb3d1732355c753ce76d9a5966af3:packages/core/src/extensions/clipboard/plain-paste.test.ts` (lines 23-287) pins plain-text paste: a single newline becomes a soft break, one blank line adds no empty paragraph and two restore one gap paragraph, CRLF is normalized, tabs and spaces survive, and block Markdown is parsed into blocks. Pasted into the middle of a paragraph, a heading or list lands as a whole block that splits the paragraph, a pasted paragraph before or after it merges into the text at the caret, and a list pasted inside a list item nests under it; Shift+paste turns every newline run into a paragraph. Plate's `packages/platejs/src/markdown/lib/MarkdownPlugin.spec.ts:525-589` covers only which clipboard type wins: HTML before plain text, URL-only text passed through to link handling, text alongside files parsed, and plain text parsed as Markdown by default. The report's claim that Plate also covers lists, code and paragraph breaks on paste was not rechecked, and that file has no CRLF or insertion-context case. Evidence: `docs/editor-test-harvester/meowdown/report.md:145`; checked on 2026-10-08.
