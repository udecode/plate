# Meowdown: testing and proof

## What Meowdown's tests are good for

- **Specialist donor.** Meowdown (`prosekit/meowdown`, harvested at commit 5b9962982a1cb3d1732355c753ce76d9a5966af3 on 2026-08-21) is a hybrid Markdown editor built on ProseKit and ProseMirror (`prosekit/meowdown@5b9962982a1cb3d1732355c753ce76d9a5966af3:packages/core/package.json`). Its tests are the best donor source for hybrid-Markdown selection, clipboard boundaries, typed and browser text substitution, and touch-aware caret policy. Worth taking: open-fragment Markdown clipboard cases, seeded structural and Unicode round-trip stress, third-editor isolation in cross-editor drag, visual-line and document-edge browser cases, and engine skips that name exactly what an engine cannot synthesize. Not portable: ProseMirror steps, integer positions, plugin views, hidden-source decorations, the custom virtual caret, and smart-dash cancellation outside an editor that shows literal Markdown source. Evidence: `docs/editor-test-harvester/meowdown/report.md:10-15, 190-209`, a reading of the checked-in tests; the harvest did not run them.

- **Wiki links have no Plate owner.** Meowdown ships wiki links and wiki embeds, and 11 test files at the pinned commit are named for them. `prosekit/meowdown@5b9962982a1cb3d1732355c753ce76d9a5966af3:packages/markdown/src/wikilink.test.ts` and `prosekit/meowdown@5b9962982a1cb3d1732355c753ce76d9a5966af3:packages/markdown/src/wiki-embed.test.ts` parse `[[note]]`, `[[a|b]]` and `[[note#section]]` as a wiki link and `![[embed]]` as an embed. `prosekit/meowdown@5b9962982a1cb3d1732355c753ce76d9a5966af3:packages/core/src/extensions/wikilink.test.ts` and `prosekit/meowdown@5b9962982a1cb3d1732355c753ce76d9a5966af3:packages/core/src/extensions/wikilink-insert-caret.test.ts` render the link as one atom and pin arrow, Backspace and typing next to it. `prosekit/meowdown@5b9962982a1cb3d1732355c753ce76d9a5966af3:packages/core/src/extensions/wikilink-trigger.test.ts` turns a selection into an open wiki link on `[` or Mod-Shift-K. `prosekit/meowdown@5b9962982a1cb3d1732355c753ce76d9a5966af3:packages/core/src/extensions/wikilink-click.test.ts` and `prosekit/meowdown@5b9962982a1cb3d1732355c753ce76d9a5966af3:packages/core/src/extensions/wikilink-hover.test.ts` fire click and hover callbacks. `prosekit/meowdown@5b9962982a1cb3d1732355c753ce76d9a5966af3:packages/core/src/extensions/wiki-embed.test.ts` parses an embed's alias and size, and `prosekit/meowdown@5b9962982a1cb3d1732355c753ce76d9a5966af3:packages/core/src/extensions/wiki-embed-editor.test.ts` renders a resolved embed as an image, a file pill or a note chip and keeps an unresolved one literal. `prosekit/meowdown@5b9962982a1cb3d1732355c753ce76d9a5966af3:packages/react/src/components/wikilink-menu.test.tsx` and `prosekit/meowdown@5b9962982a1cb3d1732355c753ce76d9a5966af3:packages/react/src/components/wikilink-hover-card.test.tsx` pin a note menu opened by `[[` or `@` that inserts `[[Name]]`, and a hover card. Plate ships no wiki-link or wiki-embed feature: on 2026-10-08 a case-insensitive search for `wiki` in `packages/`, `apps/www/src/registry` and `content/` found only Wikipedia URLs and one test string. These tests therefore have no Plate owner until an application or a future Markdown-source product needs one, and the harvest inventory's `plate-owned` label on these files (`docs/editor-test-harvester/meowdown/inventory.md:89-95, 113-114, 131-132`) names no existing owner. Only the atom navigation carries over, as the Inline atoms entry in `docs/research/sources/meowdown/selection-and-caret.md` records. Evidence: `docs/editor-test-harvester/meowdown/report.md:160, 176`; the Meowdown files were read at the pinned commit, not run.

## Browser and device limits

- **Desktop engines, synthetic touch.** Meowdown's browser-backed core and React tests run Playwright through Vitest at a 900x600 viewport with `hasTouch: true` (`prosekit/meowdown@5b9962982a1cb3d1732355c753ce76d9a5966af3:packages/vitest/src/config.ts`). CI runs Linux Chromium, Linux Firefox, macOS Chromium, macOS desktop WebKit and Windows Chromium (`prosekit/meowdown@5b9962982a1cb3d1732355c753ce76d9a5966af3:.github/workflows/ci.yml`), strong coverage of desktop engines and operating systems. Touch is synthetic: `prosekit/meowdown@5b9962982a1cb3d1732355c753ce76d9a5966af3:packages/core/src/extensions/virtual-caret.test.ts` dispatches a `pointerdown` with `pointerType: 'touch'`, and `prosekit/meowdown@5b9962982a1cb3d1732355c753ce76d9a5966af3:packages/core/src/extensions/image.test.ts` builds `Touch` and `TouchEvent` objects but skips those cases on desktop WebKit, whose `Touch` constructor throws. None of it is proof for a real iPhone or iPad. Evidence: `docs/editor-test-harvester/meowdown/report.md:58-75`, rechecked against the checkout on 2026-10-08; the suite was not run.
