# Wordgard: performance

## Huge code blocks

The 2026-09-02 matched huge-code-block run compared Wordgard `b5ad0d057e2790c8cf971c85a9d2fb7e4a82da54` (0.5.1) with Plite's historical CodeLine renderer at base `a6afd55c30e97c74fe895d1ad005ca75413110f3`. On Apple M5 Max/macOS 26.3.1, Chromium 149.0.7827.55, 1280×720/DPR 1, each cohort used 48-character lines, full DOM, midpoint caret placement and trusted `XXXXX` input, with one discarded warmup and ten samples. At 5,000 lines, Wordgard/Plite p50 mount-to-paint was 62.4/885.7 ms and typing-to-paint 122.3/212.6 ms; p95 was 101.4/1255.9 and 140.3/260.6 ms. At 10,000 lines, p50 was 56.1/1294.2 and 99.2/284.1 ms; p95 was 57.5/1789.5 and 124.3/438.7 ms. A separate 20-sample Wordgard repeat put 10,000-line mount p50/p95 at 80.0/90.3 ms and typing at 156.9/181.7 ms, exposing substantial run noise.
