# Editor architecture: commands and transforms

## Typora and Milkdown evidence for structural keys

- **Global rules.** The audit rated four of the five global invariants as partly supported and expanded selections as unsupported, and locked only the empty-block rule (EDIT-GLOBAL-004). Typora documents block-local commands for quote, list, code, math and table, and its nested quotes and Indent and Outdent commands imply one structural step at a time. Milkdown's tests give table, list, code and math their own local behavior, and its list tests outdent one level at a time: a second Enter on an empty nested item leaves one list level, not all (`Milkdown/milkdown@6a4db480b:e2e/tests/input/bullet-list.spec.ts`). For deleting an empty block in place before any structural lift, Typora's Delete Range page says its Delete Line / Sentence command deletes an empty block, and `Milkdown/milkdown@6a4db480b:e2e/tests/transform/preserve-empty-line.spec.ts` leaves an empty document after Enter then Backspace; Typora's evidence is a menu command, not the Backspace key. Expanded selections (EDIT-GLOBAL-005) had no evidence in either reference. The spec now locks EDIT-GLOBAL-001 to EDIT-GLOBAL-005. Evidence: `docs/research/history/2026-04-02-markdown-editing-reference-audit.md:89-93`, `../raw/typora/pages/delete-range.json` (fetched 2026-04-02). Limit: docs and tests read, neither editor run; Milkdown is cited at the raw clone's 2026-04-02 head, since the audit pinned no commit.

- **Paragraph.** Typora's Markdown Reference and Shortcut Keys pages make Enter a new paragraph, and `Milkdown/milkdown@6a4db480b:e2e/tests/shortcut/system.spec.ts` gets two paragraphs from Enter; the audit counted that as agreement and locked EDIT-P-ENTER-001. For an empty paragraph, Typora's Delete Range command deletes the empty block and `Milkdown/milkdown@6a4db480b:e2e/tests/transform/preserve-empty-line.spec.ts` removes the last empty line on Backspace; the audit locked EDIT-P-BS-START-EMPTY-001 on that pair, though Typora's half is a menu command, not the Backspace key. Typora's Shortcut Keys bind Tab and Shift+Tab to Indent and Outdent, which Milkdown never tests on a plain paragraph, so EDIT-P-TAB-001 and EDIT-P-STAB-001 follow Typora alone and keep Tab inside the editor. Neither reference covers Backspace at the start of a non-empty paragraph (EDIT-P-BS-START-001). In the same Milkdown test, Enter in an empty document serializes as `<br />`, which left the empty-root Enter (EDIT-P-ENTER-EMPTY-001) unsettled. The spec now locks all six. Evidence: `docs/research/history/2026-04-02-markdown-editing-reference-audit.md:99-104`, `../raw/typora/pages/shortcut-keys.json` and `../raw/typora/pages/delete-range.json` (fetched 2026-04-02). Limit: docs and tests read, neither editor run; Milkdown is cited at the raw clone's 2026-04-02 head, since the audit pinned no commit.

- **Heading.** Typora's Markdown Reference creates a heading when the user types `#` and the title, then Return, and `Milkdown/milkdown@6a4db480b:e2e/tests/input/heading.spec.ts` presses Enter after a heading and types the next one in a new block; the audit locked Enter at a heading's end (EDIT-H-ENTER-END-001) on that. Neither reference documents or tests a split in the middle of a heading, which the spec now locks as well (EDIT-H-ENTER-001). The audit found reset-to-paragraph only as a command in both (Typora's is Cmd/Ctrl+0), never as Backspace at the start, so the spec's rule that one Backspace resets a heading to a paragraph before any merge is a Plate decision (EDIT-H-BS-START-001). For an empty heading, Typora's Delete Range implies deleting the block, and the spec instead resets it to an empty paragraph (EDIT-H-BS-START-EMPTY-001). Evidence: `docs/research/history/2026-04-02-markdown-editing-reference-audit.md:110-113`, `../raw/typora/pages/markdown-reference.json` and `../raw/typora/pages/shortcut-keys.json` (fetched 2026-04-02). Limit: docs and tests read, neither editor run; Milkdown is cited at the raw clone's 2026-04-02 head, since the audit pinned no commit.

- **List.** Typora's docs imply list continuation but spell out no split or exit rule. `Milkdown/milkdown@6a4db480b:e2e/tests/input/bullet-list.spec.ts` and `Milkdown/milkdown@6a4db480b:e2e/tests/input/ordered-list.spec.ts` press Enter at the end of a non-empty item to start the next item, and a second Enter on an empty nested item outdents it one level; the audit locked EDIT-LIST-ENTER-001 and EDIT-LIST-ENTER-EMPTY-001 on these. The same tests use Backspace in a fresh empty item to step out of the current list layer before typing a nested marker, which the audit took as partial support for two Plate decisions: Backspace at a non-empty item's start removes one list layer, and Backspace in an empty nested item outdents it one level (EDIT-LIST-BS-START-001, EDIT-LIST-BS-START-EMPTY-001). Neither reference covers an empty top-level item, so its exit to a paragraph on Enter or Backspace is a Plate decision (EDIT-LIST-ENTER-EMPTY-ROOT-001, EDIT-LIST-BS-START-EMPTY-ROOT-001). Typora's Shortcut Keys bind Indent and Outdent to Tab and Shift+Tab, while `Milkdown/milkdown@6a4db480b:e2e/tests/shortcut/list.spec.ts` sinks and lifts items with Mod-] and Mod-[. The audit locked the indent and outdent behavior and left the key binding to the kit; the spec now locks it on Tab and Shift+Tab (EDIT-LIST-TAB-001, EDIT-LIST-STAB-001). Evidence: `docs/research/history/2026-04-02-markdown-editing-reference-audit.md:119-126`, `../raw/typora/pages/shortcut-keys.json` (fetched 2026-04-02). Limit: docs and tests read, neither editor run; Milkdown is cited at the raw clone's 2026-04-02 head, since the audit pinned no commit.

- **Blockquote.** Typora's Markdown Reference says it inserts the proper `>` or line break as the user types a quote, and `Milkdown/milkdown@6a4db480b:e2e/tests/input/blockquote.spec.ts` keeps the paragraph after Enter inside the quote; the audit counted that as agreement and locked EDIT-BQ-ENTER-001. Neither reference documents or tests leaving a quote. Enter in an empty quote paragraph, top-level or nested, Backspace at the start of a quoted paragraph, and Shift+Tab in a quote are all Plate decisions that remove one quote level per keypress (EDIT-BQ-ENTER-EMPTY-001, EDIT-BQ-ENTER-EMPTY-NESTED-001, EDIT-BQ-BS-START-001, EDIT-BQ-BS-START-ONLY-001, EDIT-BQ-STAB-001). Typora's Delete Range gave partial support for deleting an empty non-first quoted paragraph in place (EDIT-BQ-BS-START-EMPTY-NONFIRST-001), and its generic Indent command for plain Tab indenting a quoted paragraph without changing quote depth (EDIT-BQ-TAB-001). Evidence: `docs/research/history/2026-04-02-markdown-editing-reference-audit.md:132-139`, `../raw/typora/pages/markdown-reference.json` (fetched 2026-04-02). Limit: docs and tests read, neither editor run; Milkdown is cited at the raw clone's 2026-04-02 head, since the audit pinned no commit.

- **Quote and list together.** Neither Typora's docs nor Milkdown's tests cover a list inside a quote. The spec's order, where the list takes the first exit or outdent step on Enter, Backspace or Shift+Tab and the quote takes the second, is a Plate decision (EDIT-BQ-LIST-ENTER-EMPTY-001, EDIT-BQ-LIST-BS-START-001, EDIT-BQ-LIST-STAB-001). Evidence: `docs/research/history/2026-04-02-markdown-editing-reference-audit.md:145-147`. Limit: docs and tests read, neither editor run.

- **Code block.** Typora's Delete Range treats a code block like a code editor, deleting the current line, and says an empty block is deleted. Its Code Fences page says that since version 1.5 Shift+Tab indents selected code lines by default, with an option to auto-indent them instead, so it gives no clean indent and outdent polarity. Milkdown's Crepe code blocks are code-editor surfaces, but no Milkdown test covers Enter indentation, Backspace in an empty code block, Tab or Shift+Tab. The audit therefore locked all six code-block rules as Plate decisions: Enter inserts a code line that keeps the indentation, Backspace stays inside the block until the block is empty, an empty block unwraps, and Tab and Shift+Tab indent and outdent the selected lines (EDIT-CB-ENTER-001, EDIT-CB-BS-START-001, EDIT-CB-BS-START-EMPTY-LINE-001, EDIT-CB-BS-START-EMPTY-001, EDIT-CB-TAB-001, EDIT-CB-STAB-001). Evidence: `docs/research/history/2026-04-02-markdown-editing-reference-audit.md:153-158`, `../raw/typora/pages/code-fences.json` and `../raw/typora/pages/delete-range.json` (fetched 2026-04-02). Limit: docs and tests read, neither editor run.

- **Math block.** Typora's Math page enters a math block on `$$` then Return and leaves editing with the Up or Down arrow or Cmd/Ctrl+Return. In `Milkdown/milkdown@6a4db480b:e2e/tests/crepe/latex.spec.ts`, `$$` then Enter opens a Crepe code block with a LaTeX preview, ArrowUp moves into it for typing, and Backspace in inline math stays inside the inline math editor. The audit counted entry as agreement and locked EDIT-MATH-ENTER-001. Backspace at the start staying inside math editing, and an empty math block exiting, rest on Typora treating math like code and on its Delete Range clause for empty blocks, and are Plate decisions (EDIT-MATH-BS-START-001, EDIT-MATH-BS-START-EMPTY-001). Neither reference documents Tab in math, so keeping Tab inside math editing is a Plate decision too (EDIT-MATH-TAB-001). Evidence: `docs/research/history/2026-04-02-markdown-editing-reference-audit.md:164-167`, `../raw/typora/pages/math.json` (fetched 2026-04-02). Limit: docs and tests read, neither editor run; Milkdown is cited at the raw clone's 2026-04-02 head, since the audit pinned no commit.

- **Toggle and details.** Neither reference has a native toggle block: the audit found none in Typora's Markdown docs or in Milkdown, and left toggle Enter, Backspace and Tab to app-kit policy. A search of `Milkdown/milkdown@6a4db480b` on 2026-10-08 found no `<details>` or `summary` handling under `packages/` or `e2e/`. The spec's Details section now takes Notion as primary reference and names Milkdown as secondary, which this evidence does not back; it locks Enter, Backspace and Delete for Details and states no Tab rule. Evidence: `docs/research/history/2026-04-02-markdown-editing-reference-audit.md:182-184`; the search was `git grep -i -E '<details|details_|summary' -- packages e2e` in the local raw clone. Limit: Milkdown's core repository only, not third-party plugins.

- **Thematic break and atoms.** Typora's Markdown Reference draws a horizontal rule when the user types `***` or `---` on a blank line and presses Return, and `Milkdown/milkdown@6a4db480b:e2e/tests/input/hr.spec.ts` creates one from typed `---`. Neither covers Enter next to an existing rule, and neither covers Backspace at an atomic block. The spec's rules that Enter creates an adjacent paragraph and that an atomic block's owner beats generic merge are Plate decisions (EDIT-HR-ENTER-001, EDIT-ATOMIC-BS-START-001). Evidence: `docs/research/history/2026-04-02-markdown-editing-reference-audit.md:190-191`, `../raw/typora/pages/markdown-reference.json` (fetched 2026-04-02). Limit: docs and tests read, neither editor run; Milkdown is cited at the raw clone's 2026-04-02 head, since the audit pinned no commit.

- **Expanded selections.** Neither Typora's docs nor Milkdown's tests cover Enter, Backspace or Shift+Tab on a selection that spans several blocks. The audit locked those rules from Plate's own protocol behavior: replace or delete the selection without corrupting structure, and outdent every selected block one owned level (EDIT-SEL-ENTER-001, EDIT-SEL-BS-001, EDIT-SEL-STAB-001). The spec's decision rules now count existing Plate behavior as evidence, not authority, so these three rules have no reference behind them. Evidence: `docs/research/history/2026-04-02-markdown-editing-reference-audit.md:197-199`. Limit: docs and tests read, neither editor run.
