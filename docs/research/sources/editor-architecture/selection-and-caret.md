# Editor architecture: selection and caret

## Drawn selection

- CodeMirror can hide the native selection and draw its own (`src/draw-selection.ts:33-56`), accepting layout work for code-editor affordances such as multiple cursors. Plite rejected that as the rich-text default and keeps native selection affordances unless a specific projected-selection lane, such as partial-DOM huge documents, proves otherwise. Source: `c70bacbd4a:docs/plite/research/2026-06-12-oss-input-selection-architecture/lead-ledger.tsv:6`, `rejected-ledger.tsv:3`, `read-log.tsv:14`. Limit: unpinned local `codemirror/view` checkout read on 2026-06-12.

- editablejs/editable avoids native contenteditable: a hidden textarea carries `beforeinput`, `input`, composition and paste, and a selection-drawing plugin keeps per-editor style and selection state and converts model ranges into relative DOM rectangles, drawn as shadow blocks with focus and blur colors and also used to place the caret. Evidence: `editablejs/editable@161179f3b7d8d1c325be63e375abbf9d76f71844:README.md:5-31`, `editablejs/editable@161179f3b7d8d1c325be63e375abbf9d76f71844:packages/editor/src/plugin/selection-drawing.ts:48-117`, `editablejs/editable@161179f3b7d8d1c325be63e375abbf9d76f71844:packages/editor/src/components/selection.tsx:15-39` and `editablejs/editable@161179f3b7d8d1c325be63e375abbf9d76f71844:packages/editor/src/components/input.tsx:74-130`, checked 2026-10-08 at the local clone (last commit 2023-09-05).

## Atomic ranges

- CodeMirror keeps pointer selection out of atomic ranges: a selection that a DOM change reports within 50 ms of a pointer selection goes through `skipAtomsForSelection` with the `atomicRanges` facet before dispatch (`codemirror/view@fbff59ba:src/domchange.ts:174-180`), and mouseup either selects from the last mouse event or prevents the native default before clearing the mouse-selection state (`src/input.ts:347-358`). A DOM change becomes a transaction through a default insert that `inputHandler` extensions may replace, after Android Enter, Backspace and Delete-shaped changes are turned back into key events (`src/domchange.ts:187-218`). Source: `c70bacbd4a:docs/plite/research/2026-06-14-firefox-inline-void-select-all-replacement/read-log.tsv:9-11`; lines reread at the pinned commit on 2026-10-08.
