# Repo mistake-proofing

Page: https://claude.ai/artifact/6uuSsgRoX5oowk5GomX9K1

Mistakes agents keep repeating in plate-2, and the checks that stop each one. Every `/pstack:correct` run is one iteration of this subject. `AGENTS.md`'s `## Rules and enforcement` table pairs each code rule with what enforces it.

## Main changes

- `tooling/scripts/check.mjs` owns the 22 blocking steps. `pnpm check` and the CI job run it, and `pnpm generate` runs each step's writer. CI runs on every push and pull request, generates barrels only on a push, and hands the push or pull request base to the baseline check.
- `tooling/scripts/ci-workflow.test.mjs` fails when `ci.yml` runs any other lint, test, typecheck or check command, and when a check, test or typecheck script in the root or www `package.json` is neither a step nor listed in `manualOnly` with its reason.
- `tooling/scripts/finding-baseline.mjs` owns shrink-only finding baselines. It lists each finding by rule, file and the trimmed text of the line it flags. A finding it does not list fails, `--check` also fails on a listed finding the tree no longer holds, and the copy at the base commit bounds each rule it lists.
- `tooling/oxlint/plate-plugin.mjs` holds 9 `plate/*` rules. Seven run through `tooling/oxlint/plate-baseline.json`, which lists 202 existing findings in 103 files. `plate/mock-spreads-module` fails a test that mocks a `platejs` or `@platejs/*` module without spreading the real module. An exception names its reason, an expiry at most 90 days out and an approver.
- The Plate schema adoption audit passes with its 46 findings from before 2026-10-05 listed in `tooling/scripts/plate-schema-adoption-baseline.json`, which contains that debt and fixes none of it.
- 61 of the 91 `as never` casts in plitejs and platejs source are gone, all type-only. The 10 annotated editor callbacks are gone; the untyped history helpers type their editor as `Editor<Value, readonly [HistoryPlugin]>`, and the hyperscript fixture reader narrows with `isEditor`.
- The two DOCX benchmarks keep their correctness and work-count assertions in the blocking lane. Their wall-clock and memory budgets, and the rewrite of their tracked results, run only under `pnpm bench:docx`.
- The slice fitter keeps an identical replacement whole instead of trimming it to an empty change, which the range guard refused when a paste filled a non-rectangular table fragment.
- `tooling/config/bunTestSetup.ts` sets `_FUMADOCS_MDX=1`, so no Bun test process runs fumadocs codegen into `apps/www/.source` while other test files read it.
- `tooling/config/bunTestSetup.ts` also wraps `mock.module`, `jest.mock` and `vi.mock`. A run fails when a later mock's object or function result adds an export that the module's exports in that Bun process lack. The message names the mocking file and whoever set those exports first, a real import or an earlier mock, and the fix that fits each. `tooling/scripts/bun-test-setup.test.mjs` runs fixture specs through it. `plate/mock-spreads-module` stays Plate-only, and `verify`'s testing reference says so and names the scripts that run each module-mocking file in its own process.
- Type-aware lint is clean, with unawaited `editor.api.history.undo()` and `redo()` promises marked `void`.
- Regenerated stale output: `packages/platejs/turbo.json`, `packages/test/turbo.json`, and `plugins.generated.ts` and `plugins.schema.json` under `apps/www/src/registry/components/editor/`.
- `tooling/scripts/review-ledger.mjs ship` gives each open scope's item a `run:<plan>` wait for each plan in the checkout that names the scope in `review_scopes` while that plan's `Status:` is active, held or planning, and chips cards the item's task only once that plan leaves those states. `.agents/playbooks/verdict.md` gives such a scope no second review.
- `.agents/pstack/decisions-check.mjs` refuses a new row whose evidence cites a missing run-directory path, and `append --from` writes a batch only when every row passes. `.agents/pstack/plan-open.mjs` refuses a newly closed box that cites a missing run-directory path or a `.log` with no `exit=<code>` line. Both judge lines since `HEAD`, or since `PSTACK_BASE`.
- Shared helpers `proof.mjs`, `mutate.mjs`, `reply.mjs` and `reread.mjs` write proof logs, revert a fix in a fresh worktree to show its test fails, copy a finished subagent reply, and print each changed instruction sentence. A SessionStart hook in `.claude/settings.json` runs `reread.mjs`.
- `tooling/scripts/proof-worktree.mjs` makes a clean detached worktree with linked `node_modules`, or an offline install with `--install`, and copied `.env` files. `--with` copies a candidate file in and labels the run a candidate, and after `--` it runs a command through `proof.mjs` and removes the worktree. `--expect-fail <text>` refuses a run in which that command passes or its output lacks a text, such as a case's failure line. A new case that passes at the base is refused even when other cases in its file fail, unless a longer case title that starts with the same text fails. Each text counts only on a line where a runner reports a failed case or an error, such as bun's `(fail)`, a TypeScript `error TS` line or an oxlint error. `verify`'s command recipes list every form. The log, not the match, ties a failure to its defect. Every write it makes into the worktree refuses a directory that resolves elsewhere and replaces a symlink at its own path. `AGENTS.md` pins a run's own baseline to its intake base, and the Plan playbook reads another plan's check at `HEAD`, not its Status.
- The pstack block gives each mechanism one replacement in a plan iteration's diff rounds. A later critical finding against it reverts it to its code from before the iteration changed it, narrows the claim and sends the revert to the next diff round, and a new plan iteration rebuilds it when the goal still needs it. The Build playbook revises the plan in the same file for that one replacement, with `verdict` first for a Plate or Plite API or architecture and neither `architect` nor a plan panel.
- Each panel round's fixes get their writing passes, and `decisions-check.mjs append` refuses a later round's `seats` row with no `writing` row after the previous one. comment-sicko only reports. `mutate.mjs` links each `node_modules` entry except `.cache`, `.vite` and `.vite-temp`.
- verify reads its command recipes before any probe or base run. benchmark reads each cohort's mode and workload back from the page, counts layout work with CDP `Performance.getMetrics`, runs base arms through `proof-worktree.mjs` and runs `pstack:benchmark-checklist` before any result is logged `verified`.
- Each www docs mode generates into its own directory, `.source`, `.source-dev` or `.source-async`, so a production build no longer turns a local `pnpm check` red.
- `CODING_STANDARDS.md`'s `## Rules and enforcement` table pairs 39 code rules with their enforcers.
- `freeze.mjs --parent` refuses a freeze that would reset to `HEAD` a path the parent changed, that holds uncommitted changes and that no named path covers.
- `plan-open.mjs` reads a closed box's artifact, owner and stop from the box line and the uncommitted lines indented under it, and a nested box starts its own entry.

- `tooling/scripts/review-ledger.mjs` derives a scope's dependents from imports. A dependent is a scope that owns non-test code outside `packages/plitejs` importing a file the scope owns, through a relative path or a workspace specifier. `lookup` and `show` list them. `check` refuses a review page that the base commit (`PLATE_BASELINE_BASE`, else `HEAD`) lacks until its `### Dependents` names each one beside a `review_inputs` path from it, or beside "unaffected" and a reason. It fails on a base or `review_commit` this checkout lacks.
- `apps/www/src/lib/docs-routes.ts` owns the rule that turns a docs source path into its URL and the rule that names a registry example's docs page. `apps/www/scripts/check-docs-source-parity.mts`, `apps/www/src/app/(app)/docs/[[...slug]]/doc-page.tsx` and the hand-drive helper import it instead of each keeping a copy.
- When www runs with `PLATE_WWW_DRIVE_DIR`, `next.config.ts` turns on a drive flag in the browser, and `apps/www/src/instrumentation-client.ts` starts the reporter in `apps/www/src/lib/drive-reporter.ts` before Next's client on every page, Next's error page included. The reporter keeps the page load's errors: window errors, unhandled rejections and every `console.error` call, at most 20, each cut to 300 characters. It posts a visit with `navigator.sendBeacon` to `POST /api/dev/drive` as each new error arrives, and the root layout's beacon asks it to post after each navigation, resize, theme change, pointer or key release and preview resize. The route appends each visit to `<dir>/visits.jsonl`: path, window width, painted theme, each docs preview's name and width, the errors with a rendered Not Found and the server's error status first, whether the page sits in a frame, `navigator.webdriver`, the time the server rendered the page and the time the page sent it. The render time comes from `DriveStamp`, which writes a script into the document's HTML that the browser runs once while the page loads, so a refresh or a remount cannot replace it. A visit `sendBeacon` refuses is lost. Without the variable nothing posts and the route answers 404.
- `tooling/scripts/hand-drive.mjs` derives the cells a change needs from `apps/www/src/__registry__/registry-metadata.json`, the `ComponentPreview` nodes in `content/docs/**/*.mdx`, the registry docs fallbacks and the Plite example loaders. It records a route for a file no owner maps (`route`) and judges the drive (`check`). A cell is covered by its page's latest top-level visit at that width and theme, not driven by webdriver, from a page the server rendered at least 5 s after the last write to every file of the cell, with no page error. A visit that reports an error fails every cell of its page. A `load` cell takes the agent's own latest visit, and a webdriver visit only when the agent never loaded the page.
- `hand-drive.mjs --hook` runs as a Stop hook in `.claude/settings.json` and `.codex/hooks.json`. It reads the files the session edited from Claude Code's Edit and Write calls and from the `FileChange` items Codex records for applied patches, and refuses to stop while a browser-visible one has open cells, unless background work is still running or the owner wrote "skip drive".

- A shared rule file, `.agents/pstack/rules/browser.md`, rendered from dotai's `skills/sync-pstack/assets/pstack/rules/browser.md`, holds the typing, frame and clipboard facts for Codex's browser, Claude Code's built-in browser and Claude in Chrome.
