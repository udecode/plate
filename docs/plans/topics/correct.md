# Repo mistake-proofing

Page: https://claude.ai/artifact/DaRPywazwSiM5gTxbnDMBT

Mistakes agents keep repeating in plate-2, and the checks that stop each one. Every `/pstack:correct` run is one iteration of this subject. `AGENTS.md`'s `## Rules and enforcement` table pairs each code rule with what enforces it.

## Main changes

- `tooling/scripts/check.mjs` owns the 22 blocking steps. `pnpm check` and the CI job run it, and `pnpm generate` runs each step's writer. CI runs on every push and pull request, generates barrels only on a push, and hands the push or pull request base to the baseline check.
- `tooling/scripts/ci-workflow.test.mjs` fails when `ci.yml` runs any other lint, test, typecheck or check command, and when a check, test or typecheck script in the root or www `package.json` is neither a step nor listed in `manualOnly` with its reason.
- `tooling/scripts/finding-baseline.mjs` owns shrink-only finding baselines. It lists each finding by rule, file and the trimmed text of the line it flags. A finding it does not list fails, `--check` also fails on a listed finding the tree no longer holds, and the copy at the base commit bounds each rule it lists.
- `tooling/oxlint/plate-plugin.mjs` holds 9 `plate/*` rules. Seven run through `tooling/oxlint/plate-baseline.json`, which lists 202 existing findings in 103 files. `plate/mock-spreads-module` fails a test that mocks a `platejs` or `@platejs/*` module without spreading the real module. An exception names its reason, an expiry at most 90 days out and an approver.
- The Plate schema adoption audit passes with its 46 findings from before 2026-10-05 listed in `tooling/scripts/plate-schema-adoption-baseline.json`, which contains that debt and fixes none of it.
- 61 of the 91 `as never` casts in plitejs and platejs source are gone, all type-only. The 10 annotated editor callbacks are gone; the untyped history helpers type their editor as `Editor<Value, readonly [HistoryPlugin]>`, and the hyperscript fixture reader narrows with `isEditor`.
- The two DOCX benchmarks keep their correctness and work-count assertions in the blocking lane. Their wall-clock and memory budgets, and the rewrite of their tracked results, run only under `pnpm bench:docx`.
- The slice fitter keeps an identical replacement whole instead of trimming it to an empty change, which the range guard refused when a paste filled a non-rectangular table fragment.
- `tooling/config/bunTestSetup.ts` sets `_FUMADOCS_MDX=1`, so no Bun test process runs fumadocs codegen into `apps/www/.source` while other test files read it.
- Type-aware lint is clean, with unawaited `editor.api.history.undo()` and `redo()` promises marked `void`.
- Regenerated stale output: `packages/platejs/turbo.json`, `packages/test/turbo.json`, and `plugins.generated.ts` and `plugins.schema.json` under `apps/www/src/registry/components/editor/`.
- `tooling/scripts/review-ledger.mjs next` skips every open scope that a plan names in `review_scopes` while that plan's `Status:` is active, held or planning and its file changed in the working tree or in the last 14 days, and lists each under `inFlight`. It also lists the offered scope's uncommitted member files under `uncommitted`. `.agents/playbooks/api-review.md` never recommends an `inFlight` scope and treats those files, when no plan stands behind them, as another session's work.
- `.agents/pstack/decisions-check.mjs` refuses a new row whose evidence cites a missing run-directory path, and `append --from` writes a batch only when every row passes. `.agents/pstack/plan-open.mjs` refuses a newly closed box that cites a missing run-directory path or a `.log` with no `exit=<code>` line. Both judge lines since `HEAD`, or since `PSTACK_BASE`.
- Shared helpers `proof.mjs`, `mutate.mjs`, `reply.mjs` and `reread.mjs` write proof logs, revert a fix in a fresh worktree to show its test fails, copy a finished subagent reply, and print each changed instruction sentence. A SessionStart hook in `.claude/settings.json` runs `reread.mjs`.
- `tooling/scripts/proof-worktree.mjs` makes a clean detached worktree with linked `node_modules`, or an offline install with `--install`, and copied `.env` files. `--with` copies a candidate file in and labels the run a candidate, and after `--` it runs a command through `proof.mjs` and removes the worktree. `--expect-fail <text>` refuses a run in which that command passes or its output lacks a text, such as a case's failure line. A new case that passes at the base is refused even when other cases in its file fail, unless a longer case title that starts with the same text fails. Each text matches anywhere in the output, so the log, not the match, ties a failure to its defect. Every write it makes into the worktree refuses a directory that resolves elsewhere and replaces a symlink at its own path. `AGENTS.md` pins a run's own baseline to its intake base, and the Plan playbook reads another plan's check at `HEAD`, not its Status.
- The pstack block gives each mechanism one replacement in a plan iteration's diff rounds. A later critical finding against it reverts it to its code from before the iteration changed it, narrows the claim and sends the revert to the next diff round, and a new plan iteration rebuilds it when the goal still needs it. The Build playbook revises the plan in the same file for that one replacement, with `best-api-review` first for a Plate or Plite API or architecture and neither `architect` nor a plan panel.
- Each panel round's fixes get their writing passes, and `decisions-check.mjs append` refuses a later round's `seats` row with no `writing` row after the previous one. comment-sicko only reports. `mutate.mjs` links each `node_modules` entry except `.cache`, `.vite` and `.vite-temp`.
- verify reads its command recipes before any probe or base run. benchmark reads each cohort's mode and workload back from the page, counts layout work with CDP `Performance.getMetrics`, runs base arms through `proof-worktree.mjs` and runs `pstack:benchmark-checklist` before any result is logged `verified`.
- Each www docs mode generates into its own directory, `.source`, `.source-dev` or `.source-async`, so a production build no longer turns a local `pnpm check` red.
- `AGENTS.md`'s `## Rules and enforcement` table pairs 32 code rules with their enforcers.
- `freeze.mjs --parent` refuses a freeze that would reset to `HEAD` a path the parent changed, that holds uncommitted changes and that no named path covers.
- `plan-open.mjs` reads a closed box's artifact, owner and stop from the box line and the uncommitted lines indented under it, and a nested box starts its own entry.
- The user-scope Bash hook refuses a removal inside a `bash -c`, `sh -c`, `zsh -c` or `eval` string in the forms its tests run.
