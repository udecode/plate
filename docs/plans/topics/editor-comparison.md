## What other editors do

| Question | Useful references |
| --- | --- |
| Independent runtime and changes | ProseMirror, Lexical, Wordgard, Slate, CKEditor 5 |
| Extension composition | Current Lexical Extensions, ProseKit, Tiptap |
| Shared blocks and schema | BlockSuite, Blok, BlockNote, Portable Text |
| Markdown input and export | Meowdown, MDXEditor, Milkdown, Vditor |
| Document layout | OpenDoc, public SuperDoc painter, canvas-editor, Pretext |
| Focus, input and agent integration | CodeMirror, RoosterJS, TinyMCE, Lexxy, Proof SDK |

Neither age nor a GitHub archive flag settles relevance: BlockNote is active, ProseMirror's canonical source moved off GitHub, and Quill's history contracts stay useful. A ProseMirror wrapper is product evidence, not another engine confirmation. Desktop engines, touch emulation, a user-agent override and CDP composition do not prove native-device behavior.

The selector and findings name exact source pins and scope limits. These references were read, not run. BlockNote remains active. SuperDoc's complete current engine is proprietary. Premirror's current-Pretext integration and native-device or speed claims remain unproved.

## Layer and owner

| Responsibility | Decision |
| --- | --- |
| Comparison set | Chosen by the question a source can change, from the candidate selector. |
| Adoption | Needs a concrete user job, a native Plate or Plite owner and a failing or discriminating proof at that owner; a scale-sensitive proposal also needs a current-owner against target measurement. A source comparison can pick the next test or design question, never settle those gates. |
| Unresolved evidence | Stays with the feature comparison it could change; that comparison's lead owns it. |

Rejected, and why:

| Alternative | Why it lost |
| --- | --- |
| A universal editor ranking | Engine, framework, product, layout and proof claims answer different questions. |
| An engine replacement inferred from the comparison | No user job, owner or proof at an owner. |
