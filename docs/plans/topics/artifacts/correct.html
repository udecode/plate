A new case that passes at the base is refused even when other cases in its file fail, unless a longer case title that starts with the same text fails. Each text matches anywhere in the output, so the log, not the match, ties a failure to its defect. Every write it makes into the worktree refuses a directory that resolves elsewhere and replaces a symlink at its own path. AGENTS.md pins a run's own baseline to its intake base, and the Plan playbook reads another plan's check at HEAD, not its Status.

  • AGENTS.md's ## Rules and enforcement table pairs 32 code rules with their enforcers.

  • plan-open.mjs reads a closed box's artifact, owner and stop from the box line and the uncommitted lines indented under it, and a nested box starts its own entry.
