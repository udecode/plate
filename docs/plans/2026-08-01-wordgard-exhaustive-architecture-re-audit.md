### Attachment reconciliation

Reaffirm:
- Semantic first-party persisted AST identities; `name` and `type` remain distinct concepts.
- Behavior-only plugins have no fake `.type`; exact portals retain literal AST types.
- `type` is explicit for AST owners; do not infer it from rendering/schema heuristics.
- Package targets use descriptors; registry strings are allowed only at the copied-code decoupling boundary.
- Persisted History and Yjs need schema-version-aware migration/invalidation beyond document initialization.
- No generic snake-case transform, runtime aliases, dual schema, or mixed-version room.

Correct:
- `KEYS` must not spread `NODES`; plugin vocabulary and persisted vocabulary are independent even when first-party strings match.
- Migration is a pure, JSON-safe host persistence function before editor creation, not an installed migration plugin.
- `h1` through `h6` remain distinct semantic descriptors because Plate exposes genuine per-level installation, rendering, rules, shortcuts, injection, and finite-type configuration.

### Stronger local mechanisms to keep

Keep Plite's JSON/multi-root model, canonical changes, anchors, schema fingerprints, compiled fitting, explicit extension graph, state/effect codecs, command descriptors, bounded corrections, host codecs, selection protocol, DOM scheduler, History persistence, Yjs envelope, layout/accessibility contracts, and proof graph. Keep Plate's typed feature packages, React/RSC/static rendering, HTML/Markdown codecs, copied registry, and descriptor-owned capability APIs.

### Rejections

- Nominal Leaf/Plot document substrate, global token offsets, open slices, schema-owned DOM/commands/UI, and generic `param` atoms.
- Whole Wordgard OT/collab stack when Plite/Yjs already own the product boundary.
- Implicit facets, precedence bands, appenders, blanket plugin deactivation, and whole-root reconfiguration machinery.
- Private tile renderer without a real non-React host and comparable benchmark.
- TypeScript namespaces plus output rewriting; the public forum records an actual removed-export release bug caused by this machinery.
- Declarative menu DSL; copied JSX is more transparent and registry-friendly.
- Wordgard native shadow-document reconciliation; keep Plite's narrower canonical DOM delta/import/dedupe/repair contracts.
- Editor-wide typed phrase namespaces without a concrete localization owner.
- One-heading collapse; it loses useful plugin granularity.
