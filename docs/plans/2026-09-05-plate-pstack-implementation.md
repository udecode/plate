## Agent Native Reviewer

The implemented action chain passes source, route, mirror and helper checks.
The new modes are reachable from Task and the owning skills. Performance review
does not start measurement, test audits do not silently write tests, and tiny
prose edits retain their direct text/link verification path. The new discovery
command preserves test source, inherited setup/cleanup, suite modes and
configuration; it does not convert source associations into executed coverage.

The remaining policy gap is concrete: `/Users/zbeyens/.codex/AGENTS.md` says
“run sequentially in main thread.” The managed block's generator is
`/Users/zbeyens/git/compound-engineering-plugin/src/utils/codex-agents.ts`.
The [prepared source patch](./artifacts/2026-09-05-plate-pstack-implementation/global-tool-map-proposal.diff)
replaces stale tool assumptions and permits bounded native delegation only
when active instructions allow it. Neither that source nor the global block
has been changed while the policy clarification is pending.

No independent-agent or cross-model execution was performed. Browser user
journeys, publication and end-to-end task outcome improvements were not tested
by this workflow-only validation. Static parser gaps require actual Playwright
discovery. This is a verified structural improvement, not evidence of a perfect
workflow or a measured reduction in task cost.
