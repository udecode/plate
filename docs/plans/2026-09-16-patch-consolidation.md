# Patch consolidation

Status: Complete

Objective:

Make Patch the single local bug-repair entrypoint, preserving diagnosis-only authority and corpus proof without duplicate coordinators.

Completion threshold:

One Patch repair owner; current callers and generated mirrors resolve; existing executable proof contracts pass; paired synthetic tasks retain acceptance and authority without materially worse outcomes.

Verification surface:

Source and generated helper tests, real source generator, generated link/anchor checks, independent action-route review and paired artifact exercises.

Constraints:

Preserve exact reporter proof, cumulative acceptance and semantic schemas. Never edit protected upstream or generated skills directly. Retain user authority, existing goal and publication boundaries.

Boundaries:

Plate workflow sources, current-project generated installations, affected helpers and callers. Shared diagnosis was inspected and remains unchanged; the Plate-specific adapter is the sole changed diagnosis owner. No product edits, publication, global installation or other-project sync.

Blocked condition:

Missing source authority, unrecoverable proof or a material behavioral regression that cannot be repaired within scope. No such blocker observed.

Decisions:

- Regression's public coordinator is retired. Existing regression template/schema names remain stable for executable receipts and historical plans; Patch owns their implementation.
- Diagnosing Bugs remains an unchanged protected shared dependency, loaded only for unresolved causal investigation. Patch owns local repair and diagnosis-only authority. No vendored copy or new shared skill.
- Generic feature TDD, test runner mechanics, actual verification, performance and architecture decisions retain their independent jobs.
- Patch's entry rule is 120 lines, versus 405 before. Detailed interaction proof belongs to Verify Plate; it loads by reported domain. The corpus template retains schema labels but no longer repeats the full domain instruction catalog.
- All 108 semantic tags from the former Regression root/methodology survive. Root-only uncached stability, selection-transition and packed dependency proof requirements were explicitly retained.
- Existing 85 semantic tests and one executable browser-attestation test survive the helper move. Removed 32 prose/parity locks; source/mirror parity uses the actual generator. Benchmark's executable owner check routes correctness to Patch; generic feature TDD remains independent.
