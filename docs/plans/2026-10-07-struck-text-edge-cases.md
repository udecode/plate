# 删除线编辑的边界情况：所有者报告与自测矩阵

Status: executed: 已提交；余项见主题文件 Open work
Topic: suggestions
Playbook: bug-fix

所有者在 2026-10-07 报告了四类问题：编辑模式下在删除线之间插入正文后按 Backspace 或划选删除，删除线位置错乱；删除线内的光标不闪烁；还有许多零散的极端情况；删除线位于表格、代码块、分栏等块级容器内时行为异常。本迭代复现所有者的两个场景，再用 Chromium 探针在段落、表格、代码块、分栏、引用、callout、标题、列表项中，按编辑与修订两种模式逐项操作，并补测回车、按词删除、双击、剪切粘贴、格式化、上下方向键等情况。探针脚本在会话临时目录 `scratchpad/struck/`，不随仓库提交。

## Brief

### What will change?

删除线不会再因删除旁边的正文而换位；光标在删除线内会闪烁；表格和分栏里能点进删除线并输入；编辑模式删除后光标停在原处；修订模式按词删除会划掉正文；回车后能撤销；双击选中整个词；表格里跨单元格拖选恢复。

### What could go wrong?

改动涉及核心层的位置解析与撤销依赖，3089 条核心测试与 1478 条 React 测试全部通过。修订模式下加格式不再作用于删除线文字。

## Defaults

| Decision | Pick | Alternative | Word |
| --- | --- | --- | --- |
| 修订模式在含删除线的选区上输入，新文字的位置 | 新文字放在被删内容之前，与现有替换规则一致 | 新文字放在被删内容之后 | 放后面 |
| 双击删除线的选词范围 | 选中可见的整个词，跨过删除线与正文，词边界与键盘按词移动相同 | 只选删除线内的字符 | 只选删除线 |
| 修订模式下格式化含删除线的选区 | 只格式化正文，删除线文字不变（所有者 2026-10-08 选定） | 删除线也记格式建议 | 删除线也加格式 |

## Main changes

- 删除线片段的位置解析沿着已删字符的插入锚点向上追溯，逐字输入后删掉第一个字符时，后续字符仍保持原来的位置；删掉删除线右边界所在的正文时，位置沿被删字符折叠的方向解析，不再退回左端点。
- 片段视图对删除线切片的开放祖先只放宽最少子节点数，其余 schema 校验照常，分栏内的删除线可编辑。
- 片段更新在外层事务中读取并构建变更时绕开外层草稿，Plate 标记插件在事务内调用的加粗、斜体可作用于包含删除线的选区。
- 撤销与审批共用同一条依赖规则：已撤销的操作不再计为依赖，回车拆段后撤销不再卡住。
- 结构编辑的区段划分只把真正包住边界的节点视为开放节点，修订模式加粗后再输入不再破坏文档结构。
- 修订模式的替换记录被替换范围的起点；替换从删除线之前开始时，新文字排在旧删除线之前，旧删除线按文档顺序排在被替换内容之间。
- 修订模式的格式命令只作用于选区中的正文；删除线内的折叠光标仍设置之后输入文字的格式。外层事务中只含正文的视图更新直接在该事务上执行。
- 修订视图中，模型持有节点选区（如拖选的表格单元格）时，正文 DOM 选区回到普通导入路径；浏览器能绘制的纯正文范围不再记为模型所有。跨单元格拖选与之后的格式快捷键恢复正常，该回退自 95eeaf92b7 引入。
- React 层：表格单元格中点击删除线交给原生选区导入；划选删除整段删除线后光标落在原位置；编辑模式删除删除线字符、以及任何跨删除线的选区删除，光标停在范围起点；修订模式按词或按行删除照常划掉正文；双击删除线时用键盘按词移动的同一规则求出词的两端；自绘光标闪烁。

## Close

### 落地

- 所有者的两个场景：编辑模式删除删除线之间的正文后，删除线保持原位；划选删除后光标停在删除点。
- 光标闪烁、表格单元格点击、分栏内输入、编辑模式 Backspace 光标、跨删除线选区删除的光标、修订模式按词删除、回车撤销、双击选词、包含删除线的选区加粗（编辑模式与修订模式不再报错）、修订模式在含删除线的选区上输入的顺序、表格内跨单元格拖选。
