# Move to pstack 0.9.64

Status: executed
Topic: pstack

pstack moved from v0.9.54 to v0.9.64, and its 0.9.57 release took over project playbooks, the mechanism plate-2 and Ellie built. The block now points at poteto-mode for how a project playbook applies, keeps each project's playbook list, and lets pstack's Opening a PR own the PR body's sections. The move ships in one batch with the topic-index commits, once a Claude Code smoke can run.

## Main changes

- **Project playbooks come from poteto-mode.** pstack 0.9.57 added a Project playbooks paragraph to poteto-mode with the same `extends`, `when` and quoted-anchor changes, and `check-playbooks.mjs` checks the anchors when a playbook applies. The block drops its own how-to sentence and keeps the rendered list. sync-pstack's anchor check stays, because it refuses a tag before the pin moves.
- **The PR body follows pstack.** Opening a PR in 0.9.64 adds `## What changed` for real symbols and paths and makes `## Scope` name what the PR covers and leaves out. The block keeps only that the body links its plan first.
- **Nothing else needs an override.** Fresh subagents by default, the hourly audit tick, Pi support and the manifest fixes change nothing the block or a project playbook quotes; `sync --tag v0.9.64 --dry-run` refuses no anchor in either project.
