# Inline one-use plugin chains

Objective:
Inline every repo-scoped one-use plugin descriptor whose only job is to feed an
exported builder chain, preserve exact inferred public types, repair the
smallest Core inference/runtime owners exposed by the sweep, and encode the
result as immutable Plate Next doctrine.

Flow mode:
one-shot execution

Completion threshold:

- Zero unjustified private production descriptors feed exported plugin chains.
- Every exported plugin descriptor remains an unannotated alias or a complete
  inferred chain; no public compiler/context ferry type is introduced.
- Public AST aliases derive from final descriptors and exact operation inputs
  do not widen to generic `Element` or `Node` contracts.
- A TS7056 exception requires captured direct declaration failure, the minimum
  exact private source/final stage pair, marked stages, a private-only final
  annotation, green declaration emit, an explicit audit count, and a deletion
  gate.
- Core and all 15 affected packages pass source typecheck, declaration build,
  behavior tests, lint, source audits, doctrine validation, generated skill
  parity, and final review.
- The goal checker passes.

Verification surface:

- Core typecheck, declaration build, type contracts, focused runtime tests, and
  full package tests.
- Source-first typecheck, declaration build, and package tests for Basic Nodes,
  Callout, Code Block, Code Drawing, Comment, Date, Footnote, Link, List, List
  Classic, Math, Media, Suggestion, Table, and Utils.
- Production descriptor topology, exported annotation/cast, package rule-editor
  scaffolding, private Table type export, and flat schema-portal audits.
- Plate Next registry validation, doctrine fingerprint, generated skill sync,
  agent-native route review, structured autoreview, scoped Biome, and diff
  whitespace checks.
- Browser proof is N/A because the packet has no rendered route or component
  behavior.

Constraints:

- Keep public plugin names and behavior.
- No compatibility aliases, public shadow definitions, casts, `any`, widened
  operation generics, package-level editor reconstructions, or generated
  application types as local inference workarounds.
- Colocate one-owner implementation behavior; retain separate source only for
  durable reuse, runtime identity, an external boundary, or the proven TS7056
  declaration exception.
- Edit rule sources, never generated skill mirrors; regenerate with
  `pnpm install`.
- Do not broaden this pattern sweep into a full Core or per-package review.
- Do not touch templates, stage files, commit, push, or create a PR.

Boundaries:

- Production `packages/*/src/**/*.{ts,tsx}` for the exact descriptor topology
  class.
- The smallest Core owners required for schema identity, factory portability,
  and input-rule runtime correctness.
- Focused package tests/type contracts, this plan and its review artifacts,
  `.agents/rules/plate-next*`, Plate Plugin Creator, Best API, and Plate Vision.
- Package review/sync attestations are N/A; this is a cross-package pattern
  packet, not a full package file-by-file review.
- Broad Core drift ledger, package file manifest, all-package sync, registry
  changelog, and browser route verification are N/A.

Blocked condition:
Stop only if the exact public type or runtime behavior cannot be preserved by
the smallest owner repair. No blocker remains. TypeScript 7 still cannot emit
the two complete Code Block-package direct chains, so the proven private TS7056
exception is the final accepted boundary.

Best Plate v2 decision:

- Default: one public plugin owns one direct inferred chain.
- Public node types derive from the final descriptor.
- Context-bound factories keep the exact editor only in author callbacks and
  expose portable factory/results.
- Recursive algorithms may use a private structural domain contract, never a
  public shadow AST.
- TS7056 is not solved by widening, casts, exported annotations, or public Core
  compiler carriers. Keep the smallest private exact declaration pair and
  delete it when direct declaration emit succeeds.
