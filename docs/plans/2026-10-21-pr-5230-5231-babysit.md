## Brief

### What will change?

Both fixes merge into the beta branch. Copied diagram blocks install the engine versions Plate tested, and closing the More formatting menu keeps the floating toolbar and the selection.

### What could go wrong?

A pinned version can fall behind the lockfile later. After the first PR merges, the second conflicts again in the same generated files, so it gets the latest code merged in again and its checks rerun.

## Teach

Plate's docs site ships copied UI through a registry. Each registry item lists the npm packages a copied file needs, and the site's build writes those lists into generated files that every PR touching the registry rewrites.

PR 5231 pins four diagram engines to the versions in the lockfile, so a copied diagram block installs the version Plate tested. PR 5230 gives the More formatting menu a fallback that focuses the editor when the menu closes without picking an item, such as a second click on its button. Before, focus stayed on the button, so the editor lost its selection and the floating toolbar went away.

Both PRs were cut before other registry changes landed on the beta branch, so their generated files no longer merged. Rebuilding those files on top of the latest code resolves the conflict without touching either author's code.
