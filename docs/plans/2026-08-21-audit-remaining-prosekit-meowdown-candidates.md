- outcome: the worthwhile Plite behavior candidate was real. Cross-editor
  native text drag inserted into the target but failed to delete the selected

  code to copy.

  document-scoped drag session that captures the source editor,

  from the source only after a successful move into the target and only while
  the source document is unchanged.
- strongest rejected alternative: copy Meowdown's ProseMirror plugins, hidden
  Markdown runs, virtual caret, or synthetic-touch event policy into Plite.
- consequence: Plite owns only the private selected-text drag session. The two
  other useful leftovers landed in Plate Markdown and Plate DnD.

- Keep the Plite target private. A public drag-session API would make ordinary
  editing consumers coordinate runtime authority they should never see.

  explicit authority, but only browser behavior can prove a user-visible bug.
- Take Meowdown's raw-iOS case as a proof prompt, not implementation authority.
- Route the remaining DnD and Markdown strength to Plate. Pulling them into
  Plite would be an ownership error.
- Reject hidden-source and virtual-caret machinery until Plate accepts a real
  Markdown-source product.
