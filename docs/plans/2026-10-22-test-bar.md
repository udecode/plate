# Decide Plate's closed list of what a test may guard

Status: executed: the library bar landed in the coding standards

## Brief

### What will change?

Plate keeps a test only when it guards a public API call, an editor rule, an outside format, stored data, a named regression or a browser interaction. Any other test needs its own named bug, and an unsure one goes.

### What could go wrong?

An unsure internal test that guarded a real bug gets cut. Tests on the list are never cut on doubt, so public API, format, editor-rule and browser tests stay.
