# Hard-cut handwritten AST mirrors

Objective:
Hard-cut every unjustified handwritten production Plate/Plite AST mirror. The
bounded production manifest must have zero unclassified or unjustified rows,
and every affected package must pass source-first type and behavior proof.

Completion threshold:
- Every candidate under `packages/**/src` has a ledger row.
- Feature node identities use `ElementOf` or `TextOf` over their final
  descriptor.
- Cross-plugin property capabilities use `ElementWith` or `TextWith` over
  descriptors or reusable authored property maps.
- Recursive and malformed-input algorithms use broad Plite nodes plus runtime
  narrowing instead of private structural mirrors.
- Persisted identities and document behavior do not change.
- Affected package typechecks, focused tests, lint, barrels, doctrine
  validation, release notes, and the final source audit are recorded.

Constraints:
- Plite owns schema/property inference; Plate Core exposes the descriptor-aware
  authoring utility; feature packages consume it.
- No compatibility aliases, fake cross-plugin fields, `any`, compensating
  casts, or duplicated feature property maps.
- Property-only plugins do not become element identities.
- Prefix families stay optional and cannot be claimed as one required key.
- Keep independent compiler, browser, external-format, generated, render,
  domain-payload, and mutable-algorithm records when they do not restate a
  persisted feature schema.
- Do not repair unrelated docs/API work merely because a broad shared checkout
  gate discovers it.

Boundaries:
- In scope: Plite property descriptors/builders, Core schema model and public
  node-type utilities, affected feature aliases/algorithms/tests, doctrine,
  barrels, changesets, this plan, and its ledger.
- Out of scope: persisted-name migration, command redesign, registry-generated
  editor types, unrelated contextual plugin-configuration docs, and UI work.
- Release impact: public Core/Plite inference and the Media image schema are
  published package changes; existing package changesets own those deltas.

Best Plate v2 recommendation:

capabilities explicitly from their schema owners, and use broad nodes with
runtime guards at malformed/open-world boundaries. Reject handwritten property
bags, pretending cross-plugin fields belong to a feature identity, and generic
helper types that copy the schema by hand.

Findings:
- The handwritten types hid three real owner bugs: Plite widened validated JSON,
  Image codecs persisted undeclared `title`, and ID-heavy Table fixtures treated
  NodeId as a Table-owned field.
- Fixing those owners made the feature aliases shorter and more accurate; no
  compatibility layer was necessary.

Decisions and tradeoffs:
- Required local IDs are allowed only for exact property keys. Prefix families
  remain optional because one local family ID does not prove a concrete key.
- Table's public element aliases exclude NodeId. Tests that guarantee installed
  NodeId compose `IdElement`; production open-input algorithms use runtime
  accessors.
- `PropertyValueDescriptor['~schema.value']` is type-only and optional, matching
  the existing schema-node carrier pattern without changing runtime output.
