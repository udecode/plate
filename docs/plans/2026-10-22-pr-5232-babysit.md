## Teach

A Word file stores a table as rows of cells, and a cell holds paragraphs or another table. The exporter turns the editor's HTML into that format. Each table gets a width limit, and each row splits it evenly among its cells, so pictures and inner tables stay inside.

Before the PR, a table inside a cell went to the paragraph builder, which wrote an empty paragraph. The table and its text vanished. The PR sends it to the table builder, which already calls the cell builder, so nesting works at any depth.

The width limit still had a hole. Each row split the page width, not its own table's limit, so a table two levels down was as wide as the outer column. My commit makes each row split its own table's limit. Top-level tables still get the page width, so they look the same.

Plate v2 already did all this, since it draws what is inside a cell with the same code it uses for the page. Word merges two tables that touch, so that code adds an empty paragraph after each table. No v2 test checked for that paragraph inside a cell. The new test does.
