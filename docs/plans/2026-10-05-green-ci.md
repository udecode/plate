- `tooling/scripts/finding-baseline.mjs` owns shrink-only finding baselines. It lists each finding by rule, file and the trimmed text of the line it flags. A finding it does not list fails, `--check` also fails on a listed finding the tree no longer holds, and the copy at the base commit bounds each rule it lists. The `plate/*` lint baseline and the Plate schema adoption audit both run through it.
- The Plate schema adoption audit (`tooling/scripts/check-plate-schema-adoption.mjs`) passes with the 46 findings it had before this run listed in `tooling/scripts/plate-schema-adoption-baseline.json`. The baseline contains that debt; it fixes none of it. Three raw-query allowlist counts the code no longer reaches were dropped from the audit.
- `plate/mock-spreads-module` fails a test that mocks a `platejs` or `@platejs/*` module without spreading the real module. The 35 partial mocks in 22 files that exist today are baselined.
- The two DOCX benchmarks keep their correctness and work-count assertions in the blocking lane. Their wall-clock and memory budgets, and the rewrite of their tracked results, run only under `pnpm bench:docx`.
- The slice fitter keeps an identical replacement whole instead of trimming it to an empty change, which the range guard refused. That refusal had broken filling a non-rectangular table fragment on paste since `4e16eada7d`.
- `tooling/config/bunTestSetup.ts` sets `_FUMADOCS_MDX=1`, so no Bun test process runs fumadocs codegen into `apps/www/.source` while other test files read it.
- Type-aware lint is clean. Most of its 459 errors were unawaited `editor.api.history.undo()` and `redo()` promises, now marked `void`.
