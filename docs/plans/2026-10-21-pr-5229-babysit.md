## Teach

A Plate plugin starts as a Base plugin with no React parts. The toReactPlugin helper adds the React parts, such as the component that draws a mark. An app then calls configure or extend on the plugin to change its options.

Each configure or extend call builds the next plugin from the Base plugin it started from, so it forgets what the React layer added. The React layer already added its dependencies back after each call, but not its component. The Basic Marks kit configures the script plugin, so the component fell off and subscript and superscript text drew as plain text.

The PR added the component back inside the helper that every call goes through, by reading it off the old plugin. My commit puts the component and the dependencies in one record that the React layer adds back after every call. The behavior is the same, with one path and less code.
