## Teach

The suggestion demo shows a document three ways. Markup shows every pending change, Accepted drops them, and Proposed applies them. The previews move text, so a preview spot is not the saved spot.

Before this PR, a click stored the preview's spot as a saved one and threw when it fell past the saved text's end. The PR translates both ways, so a click selects the saved text it shows, and collaborators see the saved spot. A range or path across lines a pending join reorders selects the saved text between its ends, which can be other text. A fix needs a selection of several pieces.

My repair keeps one translator per preview. Reads return preview spots, and editor commands keep saved spots. Where one saved spot shows twice, as on a line a pending join empties, a click keeps the side that reads back where it landed. A range starting there can read its start at the other place.
