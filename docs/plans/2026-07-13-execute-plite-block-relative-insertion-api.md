Source-backed architecture north star:
- `tx.nodes.insert` remains literal.
- `tx.blocks.insertAfter(blocks, { at, select })` owns block-relative placement,
  validates all payloads before target resolution, and carries explicit root law
  through reference lookup and final insertion.
- Plate commands own product fallback policy and call the installed transaction
  API; they do not reproduce selection/block/path boilerplate.

| Surface | Shape | Verdict |
