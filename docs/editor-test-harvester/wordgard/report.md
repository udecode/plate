# Wordgard Editor Test Harvest

## Verdict

Wordgard was worth harvesting, but not by transplanting its suite. Current
Plite and Plate are materially stronger in IME, DOM mapping, Yjs, tables,
multi-root editing, and browser breadth. The verified 27-file source adds a
useful dirty-DOM mutation ledger and strengthens collaboration, decoration,
composition, and slice parsing pressure. Those behaviors are mapped below;
no portable Wordgard test concept remains unmapped.

This is a current-source harvest. The prior full inventory was refreshed
incrementally only after the current test-tree diff proved empty and the exact
file, line, and declared-case counts were rechecked. The closure rows name the
live laws and the deliberate representation or product-policy decisions.
