Current Markdown regression proof also includes [gfmSurface.spec.ts](../../packages/platejs/src/markdown/lib/gfmSurface.spec.ts) for heading autolinks, [paragraphBreaks.spec.ts](../../packages/platejs/src/markdown/lib/deserializer/paragraphBreaks.spec.ts) for repeated trailing breaks, [standardList.spec.ts](../../packages/platejs/src/markdown/lib/serializer/standardList.spec.ts) for list trailing breaks, and [table.spec.ts](../../packages/platejs/src/markdown/lib/table.spec.ts) for sized table images. The linked fix plan records local browser evidence; it does not establish browser-matrix coverage.

The retired protocol and parity matrices recorded a status for each spec ID below. `tested` mostly rested on test files that `git ls-files` no longer returns; where a cited file is live but holds no matching case or asserts other behavior, the row says so. `specified` and `deferred` rows recorded no passing test, and `partial` rows recorded tests for some parts only. Current proof names a live test that covers the rule, and `gap` means none is mapped. A gap stays an evidence gap until a current test is mapped here or a replay runs through `verify`; no row counts as tested on its matrix record.
