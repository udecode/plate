- **`export-toolbar-button`**: Fix HTML and Word export throwing on tables, task lists, callouts, columns, code blocks and images by drawing the file with `BaseEditorKit` as `presentation`.

<!-- entry: {"id":"2026-10-09-block-list-static-single-indent","kind":"fix","migrationNotes":[]} -->

- **`block-list-static`**: Drop the per-level `margin-left` on numbered and task lists, so static HTML indents a nested list once and Word takes its level from the block's indent.

<!-- entry: {"id":"2026-10-10-export-toolbar-failure-toast","kind":"fix","migrationNotes":[]} -->

- **`export-toolbar-button`**: Show an error toast when HTML or Word export throws, instead of failing with no message.

<!-- entry: {"id":"2026-10-10-docx-export-stylesheet-owns-word-look","kind":"fix","migrationNotes":[]} -->

- **`docx-export`**: Move the Word look of callouts, code blocks, and empty equation and table of contents placeholders into `DOCX_EXPORT_STYLES`, because the package's DOCX drawings leave colors, fonts and sizes to the stylesheet.

<!-- entry: {"id":"2026-10-10-block-list-static-task-marker","kind":"fix","migrationNotes":[]} -->

- **`block-list-static`**: Draw the task checkbox inside its `li` and mark the `li` with `data-checked`, so Word export gives each task one paragraph with a ☑ or ☐ list marker.

<!-- entry: {"id":"2026-10-10-indent-static-image-target","kind":"fix","migrationNotes":[]} -->

- **`indent-static`**: Target images like `IndentKit` does, so a static editor loads and indents an image the live editor indented instead of throwing a schema error.

<!-- entry: {"id":"2026-10-10-list-static-image-target","kind":"fix","migrationNotes":[]} -->

- **`list-static`**: Target images like `ListKit` does, so a static editor loads an image in a list and draws it as a list item.
