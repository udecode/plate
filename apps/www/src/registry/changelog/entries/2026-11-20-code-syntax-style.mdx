<!-- entry: {"id":"2026-11-20-code-block-color-blocks-through-one-5dea8edc","kind":"behavior","migrationNotes":["Copying the new code-block or code-block-static by hand also needs the code-syntax-style variables in your stylesheet; the shadcn CLI adds them."]} -->

- **`code-block`**, **`code-block-static`**, **`code-syntax-style`**: Color highlighted code through `--syntax-*` CSS variables with light and dark values, such as `--syntax-keyword` and `--syntax-string`, which the new `code-syntax-style` item adds to your stylesheet. Change a variable once to restyle the editor, the CodeMirror view and static output. Built-in names such as Python's `str` now take the built-in color, and language names such as `console` and `this`, template tags and template variables take the keyword color.

<!-- entry: {"id":"2026-11-20-docx-export-code-colors-match-2b41c7e0","kind":"fix","migrationNotes":[]} -->

- **`docx-export`**: Fix Word export code colors that differed from the editor. Code in a Word file uses the light values of the syntax variables, including the diff background colors and the comment color for inline code in Markdown.
