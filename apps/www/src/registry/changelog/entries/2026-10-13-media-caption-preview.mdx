<!-- entry: {"id":"2026-10-13-caption-hidden-until-caret-8ab1a415","kind":"behavior","migrationNotes":["Remove the active prop from Caption; it shows an empty caption only while the caret is inside it."]} -->

- **`caption`**, **`media-image`**, **`media-audio`**, **`media-embed`**, **`media-file`**, **`media-video`**: Keep an empty caption hidden while its media is selected, so selecting media no longer shifts the page. The caption shows once the caret enters it, such as through the media toolbar's Caption button, and `Caption` no longer takes an `active` prop.

<!-- entry: {"id":"2026-10-13-image-preview-by-key-4f1c2d7e","kind":"fix","migrationNotes":["Call imagePlugin api.preview.open with the image's path and URL instead of the element."]} -->

- **`media-image`**, **`media-preview-dialog`**: Open the image preview on double-click again; `api.preview.open` takes the image's path and URL. The preview renders above the page, centers the image, and closes on a backdrop click or Escape.

<!-- entry: {"id":"2026-10-14-file-click-media-toolbar-5c9e21b3","kind":"behavior","migrationNotes":[]} -->

- **`media-file`**, **`media-audio`**, **`media-video`**, **`media-image`**, **`media-toolbar`**: Select a file on click in an editable editor and open it on double-click. Show the media toolbar with Preview, Caption and delete while a file, audio or video node is selected. The image toolbar also gets Preview, which opens the image preview. The file and audio toolbars sit above their block, so neither covers the next block, and the audio selection ring fits the player. File and audio blocks get vertical padding so a selection ring does not overlap the block next to it, and a click in that padding selects the block instead of opening its caption. A click on an audio or video player selects that node and returns the keyboard to the editor, and Preview no longer keeps focus, so arrow keys keep moving the selection.
