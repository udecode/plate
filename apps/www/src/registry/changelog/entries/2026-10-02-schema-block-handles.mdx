- **`dnd`**: Every selectable block gets a handle at any depth, such as blocks inside blockquotes, details, columns and table cells, and only the innermost hovered block shows its handle. The handle reads its blocks from `editor.read.transfer.nodes`, and a selected table no longer hides the editor's handles.
<!-- entry: {"id":"2026-10-02-block-menu-cut-transfer-nodes","kind":"behavior","migrationNotes":[]} -->
- **`block-menu`**: Cut takes the blocks `editor.read.transfer.nodes()` returns, such as a list item with its nested items.
