- **`board`**: Add an image button after the board toolbar's tools. It opens a file picker for pictures and uploads each picked file as an image shape, in a row centered on the view. The button is disabled on a board that takes no picture files, such as a read-only board or an editor without upload or without `BoardImageKit`. The board now depends on `use-file-picker`.
