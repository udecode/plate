- **`upload`**: Open an upload placeholder's file picker for one file where a second placeholder does not fit after it, such as in a board's image shape. The picker asks the upload plugin's `fitsAfter(key)` whether a second placeholder fits. Picking several files there used to upload none and report that they cannot be added. A placeholder in the document still takes several files.
