- **`mode-toolbar-button`**: The button now writes Viewing through `setEditorViewing` alone, for every editor `useEditor()` returns. Choosing Editing no longer lifts a lock the app set on an editor view, such as one an `EditorProvider` hands the button, and the button shows Viewing while that lock holds.
