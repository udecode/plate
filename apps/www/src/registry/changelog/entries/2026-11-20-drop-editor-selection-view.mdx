- **`fixed-toolbar`**, **`floating-toolbar`**, **`ai-menu`**, **`comment-toolbar-button`**: Drop the `EditorSelectionView` wrapper, which `platejs/react` no longer exports. The fixed toolbar already acts on the root that holds the caret, and the floating toolbar and the AI menu render in the `caret` slot, so they act on a board note's text without it. Over note text, the floating toolbar shows the same buttons as over page text.
