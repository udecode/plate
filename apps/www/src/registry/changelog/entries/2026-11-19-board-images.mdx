- **`board`**: Add `BoardImageKit`, an image shape that draws its picture and alt text across its box without stretching it. Add it beside `BoardKit` in an editor that installs the image plugin. Paste an image link, or a picture copied from a web page, on the board, and it lands at the pointer at its own proportions, which every resize keeps. Enter and a double-click keep an image shape selected and put no caret in it.

- **`board-demo`**, **`board-page-demo`**: Add `BoardImageKit`, and install `ImagePlugin` in the board page demo, so a pasted image link lands on both boards.
