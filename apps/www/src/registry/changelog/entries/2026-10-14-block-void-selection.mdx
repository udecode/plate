- **`code-drawing`**, **`excalidraw`**, **`upload`**: Mark a block entered with the caret with a ring on code drawings and Excalidraw canvases and a tinted background on upload placeholders.

- **`toc`**, **`math`**, **`horizontal-rule`**, **`code-drawing`**, **`excalidraw`**, **`upload`**: Leave a block selection to the blue block highlight instead of adding the caret-entry style.

- **`media-image`**, **`media-file`**, **`media-audio`**, **`media-video`**, **`media-embed`**: Show the media ring and toolbar only when the media node is clicked or arrowed into; a block selection shows the blue block highlight instead, even when it holds only that media node.

- **`mention`**, **`tag`**, **`footnote`**: Keep the inline focus style off mentions, tags and footnote references inside a block selection.

- **`dnd`**, **`block-menu`**: Turn a selected media node into a block selection when its drag handle is clicked or its block menu opens.
