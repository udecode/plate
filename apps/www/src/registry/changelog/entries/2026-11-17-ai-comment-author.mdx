- **`use-chat`**, **`comment`**, **`ai-api`**, **`editor-ai`**, **`ai-demo`**, **`discussion-demo`**, **`playground-demo`**: Write AI comments and suggestions under the AI's own name. `use-chat` exports `aiUser`, sets `authorId: aiUser.id` on `AIChatTransportPlugin`, creates each generated comment as `aiUser` with `data.requestedBy` naming the editor's user and `data.model` naming the model the route streamed with it, and the editor and demos list `aiUser` among the comment users. `comment` lets the user in `requestedBy` resolve, reopen, edit and delete the AI's messages, and resolve and reopen stay with the thread's creator or that requester when its first message is removed.
