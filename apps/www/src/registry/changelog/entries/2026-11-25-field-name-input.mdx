<!-- entry: {"id":"2026-11-25-field-name-input","kind":"new","migrationNotes":["Update `platejs` with the copied `field` component, because its Name input writes the field's `name`, which older versions refuse."]} -->

- **`field`**: Add a Name input to the field settings. It keeps what you type and writes the name on blur, on Enter or when the settings close, and removes the name when emptied. A name the rule refuses, such as one with a space at either end or a tab, stays in the input with an error, and the settings stay open until it changes. The Show when list shows each named field's name beside its label, and an answer the editor refuses shows Not saved.

- **`field-demo`**: Name every field of the lease, and ask for the tenant's name again beside the tenant's signature, so typing it in one place fills the other.
