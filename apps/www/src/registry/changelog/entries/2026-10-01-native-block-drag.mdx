- **`dnd`**: Drag handles start a native drag with `editor.api.dom.drag.start`, and `DropIndicator` paints `useDropIndicator()` in each view. `DndKit` needs no `DndProvider`, and the `react-dnd` dependencies are gone.
- **`column`**: The column handle drags its column natively; the vertical drop line comes from `DndKit`.
- **`table`**: The row handle drags its row natively; the drop line comes from `DndKit`.
- **`media-image`**, **`media-video`**: Dragging media starts the same native block drag.
- **`upload`**: The kit enables `nativeDrop`, so dropped files land at the edge under the pointer.
