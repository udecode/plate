- **`turn-into-toolbar-button`**, **`insert-toolbar-button`**: Disable each item the caret's parent cannot hold, read through `editor.read.schema.canPlace` and, for the heading levels, `BaseHeadingPlugin`'s `read.canSetLevel`. With the caret in a board note, Turn into disables Quote, Details, Code and 3 columns, and Insert disables Table, Code, Quote, Divider and the other blocks a note cannot hold, while Text, Paragraph, the headings and the lists stay enabled. Over page text every item stays enabled.
