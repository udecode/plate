- **`more-toolbar-button`**: Keep the floating toolbar and the selected text when a second click on More formatting, or Escape, closes it.
- **`editor-dropdown-menu`**: When a click outside a non-modal menu, a right-click outside any menu, Tab, or a focus move to another control closes a dropdown, focus stays where the user put it. It no longer moves back into the editor or, on Base UI, to the menu's trigger. This applies to every editor dropdown: More formatting, Turn into, font color, insert, mode, align, line height, list, export, import, media, comment, the table menus and the block drag handle menu. When an item moves focus itself, the menu leaves focus there. A press on another button in the menu's own toolbar still puts focus back in the editor. Base UI menus close without an exit animation, as Radix menus already do, so a click right after a close keeps its focus.
