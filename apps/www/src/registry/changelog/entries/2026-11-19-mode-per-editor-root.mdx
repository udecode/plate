- **`mode-toolbar-button`**: Viewing now turns every part of the editor root read-only, board notes included, through `setEditorViewing`. A read-only note no longer shows the button as Viewing while the page around it stays writable. When the toolbar controls no editing area, such as under `EditorProvider` or while no `EditorContent` is mounted, Viewing still locks the editor.
