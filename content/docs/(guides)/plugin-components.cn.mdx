默认情况下，Plate插件是无头(headless)的，意味着所有节点都将以纯文本形式渲染。本指南将展示如何为编辑器创建和样式化自定义组件。

## Plate UI

除非您希望从零开始构建所有内容，否则我们建议使用[Plate UI](/docs/components)作为起点。Plate UI是一组可直接复制到您的应用中并根据需求修改的组件集合。

无论您使用Plate UI还是从零开始构建自己的组件，创建和注册组件的过程都是相似的。

## 定义组件

使用`PlateElement`处理元素节点（如段落、标题），使用`PlateLeaf`处理文本叶子节点（如粗体、斜体）。这些组件负责将必要的Plate属性应用到您的自定义HTML元素上。

确保无条件渲染`children`属性，即使对于void节点，这也是编辑器正常工作的必要条件。

### 元素组件

```tsx
import type { BlockquotePlugin } from 'platejs/react';
import { type PlateElementProps, PlateElement } from 'platejs/react';

export function BlockquoteElement(
  props: PlateElementProps<typeof BlockquotePlugin>
) {
  // props包含attributes, children, element, editor等属性
  // 以及您的插件可能传递的任何自定义属性
  return (
    <PlateElement
      as="blockquote"
      className="my-1 border-l-2 pl-6 italic" // 直接应用自定义样式
      {...props} // 传递所有原始属性(attributes, children, element等)
    />
  );
}
```

此示例定义了一个`BlockquoteElement`。`PlateElement`上的`as`属性指定它应渲染为HTML `<blockquote>`。`PlateElement`负责处理通过`{...props}`传递的`children`渲染。

### 叶子组件

```tsx
import type { CodePlugin } from 'platejs/react';
import { type PlateLeafProps, PlateLeaf } from 'platejs/react';

export function CodeLeaf(props: PlateLeafProps<typeof CodePlugin>) {
  // props包含attributes, children, leaf, text, editor等属性
  // 以及您的插件可能传递的任何自定义属性
  return (
    <PlateLeaf
      as="code"
      className="rounded-md bg-muted px-[0.3em] py-[0.2em] font-mono text-sm" // 应用自定义样式
      {...props} // 传递所有原始属性(attributes, children, leaf, text等)
    />
  );
}
```

### 样式设计

我们推荐使用Tailwind CSS来样式化组件，如Plate UI中所示。

或者，Plate会生成类似`plite-<节点类型>`的类名（例如段落为`plite-p`，H1标题为`plite-h1`），您可以通过全局CSS定位这些类名：

```css
.plite-p {
  margin-bottom: 1rem;
}
.plite-bold {
  font-weight: bold;
}
```

## 注册组件

要使用您的自定义组件，需要将它们注册到相应的插件或直接注册到编辑器配置中。

### 已有插件的 `component`

`component` 是绑定插件普通节点组件的方法。

```tsx
const plugins = [
  ParagraphPlugin.configure({ component: MyParagraphElement }),
  CodeBlockPlugin.configure({ component: MyCodeBlockElement }),
  CodeHighlightPlugin.configure({ component: MyCodeSyntaxLeaf }),
]
```

### 组件与用户覆盖

同一个插件还需要规则、快捷键、options 或 parser 行为时，把所有覆盖放进同一次
终结的 `.configure()`。

```tsx
const plugins = [
  CodePlugin.configure({
    component: MyCodeLeaf,
    inputRules: [CodeRules.markdown()],
    shortcuts: { toggle: { keys: 'mod+e' } },
  }),
];
```

## 原生 HTML 组件

只需要更改 HTML 标签时，直接把标签绑定到插件的 `component`。

```ts title="quote-plugin.ts" showLineNumbers
import { schema } from 'platejs';
import { definePlatePlugin } from 'platejs/react';

export const QuotePlugin = definePlatePlugin('quote', {
  component: 'blockquote',
  schema: {
    element: { content: schema.content.text({ default: 'text', min: 1 }) },
  },
});
```

需要 class、嵌套控件、popover、toolbar、resize handle 或插件 state 时，使用自定义组件。

## API 参考

| API | 用途 | 说明 |
| --- | --- | --- |
| `PlateElement` | Element 节点。 | 默认渲染 `div`；接受 `as`、`className`、`style` 和 Plate render props。 |
| `PlateLeaf` | Mark 和 decoration 文本。 | 默认渲染 `span`；用于声明 `schema.mark` 的插件。 |
| `plugin.configure({ component: Component })` | 绑定普通节点组件。 | 在同一次终结配置中加入组件和所有用户覆盖。 |
| `plugin.configure({ component: 'tag' })` | 使用原生 HTML 标签。 | 接受 `'blockquote'`、`'strong'` 或 `'code'` 等标签。 |
