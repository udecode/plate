默认情况下，Plate插件是无头(headless)的，意味着所有节点都将以纯文本形式渲染。本指南将展示如何为编辑器创建和样式化自定义组件。

## Plate UI

除非您希望从零开始构建所有内容，否则我们建议使用[Plate UI](/docs/components)作为起点。Plate UI是一组可直接复制到您的应用中并根据需求修改的组件集合。

无论您使用Plate UI还是从零开始构建自己的组件，创建和注册组件的过程都是相似的。

## 定义组件

使用`EditorElement`处理元素节点（如段落、标题），使用`EditorLeaf`处理文本叶子节点（如粗体、斜体）。这些组件负责将必要的Plate属性应用到您的自定义HTML元素上。

确保无条件渲染`children`属性，即使对于void节点，这也是编辑器正常工作的必要条件。

### 元素组件

```tsx
import type { BlockquotePlugin } from 'platejs/react';
import { type EditorElementProps, EditorElement } from 'platejs/react';

export function BlockquoteElement(
  props: EditorElementProps<typeof BlockquotePlugin>
) {
  // props包含attributes, children, element, editor等属性
  // 以及您的插件可能传递的任何自定义属性
  return (
    <EditorElement
      as="blockquote"
      className="my-1 border-l-2 pl-6 italic" // 直接应用自定义样式
      {...props} // 传递所有原始属性(attributes, children, element等)
    />
  );
}
```

此示例定义了一个`BlockquoteElement`。`EditorElement`上的`as`属性指定它应渲染为HTML `<blockquote>`。`EditorElement`负责处理通过`{...props}`传递的`children`渲染。

### 叶子组件

```tsx
import type { CodePlugin } from 'platejs/react';
import { type EditorLeafProps, EditorLeaf } from 'platejs/react';

export function CodeLeaf(props: EditorLeafProps<typeof CodePlugin>) {
  // props包含attributes, children, leaf, text, editor等属性
  // 以及您的插件可能传递的任何自定义属性
  return (
    <EditorLeaf
      as="code"
      className="rounded-md bg-muted px-[0.3em] py-[0.2em] font-mono text-sm" // 应用自定义样式
      {...props} // 传递所有原始属性(attributes, children, leaf, text等)
    />
  );
}
```

### 样式设计

我们推荐使用Tailwind CSS来样式化组件，如Plate UI中所示。

或者，Plate会生成类似`editor-<节点类型>`的类名（例如段落为`editor-p`，H1标题为`editor-h1`），您可以通过全局CSS定位这些类名：

```css
.editor-p {
  margin-bottom: 1rem;
}
.editor-bold {
  font-weight: bold;
}
```

## 注册组件

要使用您的自定义组件，需要将它们注册到相应的插件或直接注册到编辑器配置中。

### 已有插件的 `component`

`component` 是绑定插件普通节点组件的方法。

```tsx
const plugins = [
  ParagraphPlugin.configure({ component: MyParagraphElement }),
  CodeBlockPlugin.configure({ component: MyCodeBlockElement }),
  CodeHighlightPlugin.configure({ component: MyCodeSyntaxLeaf }),
]
```

### 组件与用户覆盖

同一个插件还需要规则、快捷键、options 或 parser 行为时，把所有覆盖放进同一次
终结的 `.configure()`。

```tsx
const plugins = [
  CodePlugin.configure({
    component: MyCodeLeaf,
    inputRules: [CodeRules.markdown()],
    shortcuts: { toggle: { keys: 'mod+e' } },
  }),
];
```

## 原生 HTML 组件

只需要更改 HTML 标签时，直接把标签绑定到插件的 `component`。

```ts title="quote-plugin.ts" showLineNumbers
import { schema } from 'platejs';
import { definePlugin } from 'platejs/react';

export const QuotePlugin = definePlugin('quote', {
  component: 'blockquote',
  schema: {
    element: { content: schema.content.text({ default: 'text', min: 1 }) },
  },
});
```

需要 class、嵌套控件、popover、toolbar、resize handle 或插件 state 时，使用自定义组件。

## 嵌入式组件

void element 可以承载自行处理指针、键盘、剪贴板和焦点的组件，例如绘图画布。用带有
`contentEditable={false}` 和 `data-editor-root-chrome-ignore="true"` 的元素包裹该组件。

```tsx showLineNumbers
'use client';

import type { ExcalidrawPlugin } from 'platejs/excalidraw/react';
import { type EditorElementProps, EditorElement } from 'platejs/react';

export function ExcalidrawElement({
  children,
  ...props
}: EditorElementProps<typeof ExcalidrawPlugin>) {
  return (
    <EditorElement {...props}>
      <div contentEditable={false} data-editor-root-chrome-ignore="true">
        {/* 在这里渲染画布。 */}
      </div>
      {children}
    </EditorElement>
  );
}
```

在带标记的包裹元素内，编辑器把指针、键盘、剪贴板和焦点事件以及 DOM 变更交给该组件。
编辑器对 `input`、`textarea`、`button` 等原生控件也是这样处理。在包裹元素之外点击仍会选中该节点。
[Excalidraw](/docs/excalidraw) element 是一个完整示例。

<Callout type="info" title="编辑器仍会接管的按键">
  在 IME 组合输入之外，编辑器会在组件自身的按键处理器运行之前接管撤销和重做快捷键，
  无论按键发生在带标记的组件、原生控件还是嵌套编辑器中。可编辑的编辑器会为它们运行自身的历史记录，
  即使没有可撤销的内容。只读编辑器只会拦截它们，因此原生文本框仍会执行浏览器自身的撤销。
  编辑器还会接管嵌套编辑器中的 Shift+方向键；当自身选区位于另一个根时，也会接管任意组件中的 Shift+方向键。
  当编辑器持有由它自己绘制的选区时，例如跨根的选区，它还会接管任意组件中的 Backspace、Delete 和 Enter，
  按住 Alt、Ctrl 或 Meta 时除外。
</Callout>

## API 参考

| API | 用途 | 说明 |
| --- | --- | --- |
| `EditorElement` | Element 节点。 | 默认渲染 `div`；接受 `as`、`className`、`style` 和 Plate render props。 |
| `EditorLeaf` | Mark 和 decoration 文本。 | 默认渲染 `span`；用于声明 `schema.mark` 的插件。 |
| `plugin.configure({ component: Component })` | 绑定普通节点组件。 | 在同一次终结配置中加入组件和所有用户覆盖。 |
| `plugin.configure({ component: 'tag' })` | 使用原生 HTML 标签。 | 接受 `'blockquote'`、`'strong'` 或 `'code'` 等标签。 |
| `data-editor-root-chrome-ignore="true"` | 包裹自行处理输入的组件。 | 与 `contentEditable={false}` 一起使用；撤销和重做快捷键仍由编辑器接管。 |
