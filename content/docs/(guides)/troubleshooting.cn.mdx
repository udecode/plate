## 依赖冲突

使用 Plate 的项目中，依赖版本不匹配或冲突是常见问题来源。本节介绍如何识别和解决这类问题。

### 使用 Plate CLI 更新 Plate

编辑器功能统一由 `platejs` 提供。使用 Plate CLI 即可更新完整编辑器，无需对齐多个功能包。

**使用方法：**

要将 `platejs` 更新到特定版本，请在项目根目录运行：
```bash
npx @platejs/cli@latest deps platejs 54.0.0 --install --yes
```

要更新到指定主版本的最新版本：
```bash
npx @platejs/cli@latest deps platejs 54 --install --yes
```

### 示例：多个 Plate 实例

**问题：** 出现意外行为或"hooks can only be called inside a component"错误。

**根本原因：** 项目中安装了多个 `platejs` 版本或多个 React 运行时。

**诊断方法：** 检查多个 Plate 包版本：

```bash
# npm
npm ls platejs

# pnpm
pnpm why platejs
```

**解决方案：**
使用上述 Plate CLI 命令更新 `platejs`，然后检查锁文件是否仍解析出多个版本。

### 示例：多个 Plate 实例

**问题：** 编辑器功能可能无法正常工作。

**根本原因：** 包管理器有时会安装不匹配的 Plate 依赖版本。例如，`pnpm` 可能安装多个 `platejs` 版本。

**诊断方法：** 检查多个 Plate 版本：

```bash
# npm
npm ls platejs react react-dom

# pnpm
pnpm why platejs
pnpm why react react-dom
```

**解决方案：** 按顺序尝试以下解决方案：

1. 从 `package.json` 中移除 `slate*` 依赖（如果有）。Plate 会管理这些依赖。

2. 使用上述 Plate CLI 命令更新 `platejs`。

2. 强制使用一致的 Plite 依赖版本：

```jsonc
// package.json
{
  "resolutions": {
    "platejs": "54.0.0-beta.0",
    "platejs/dom": "54.0.0-beta.0",
    "platejs/react": "54.0.0-beta.0"
  }
}
```
