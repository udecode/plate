本指南涵盖了Plate编辑器实例上可用的各种方法。

## 访问编辑器

访问编辑器实例的方式取决于您需要的上下文。

### Plate组件内部

使用以下钩子之一：

- `useEditor`: 获取必需的活动编辑器，不触发重新渲染。
- `useEditorSelector`: 仅当特定编辑器属性变化时重新渲染。
- `useEditorState`: 从不可变 state view 订阅派生值。

```ts
import { useEditor, useEditorSelector, useEditorState } from 'platejs/react';

const MyComponent = () => {
  const editor = useEditor();
  const hasSelection = useEditorSelector((editor) => !!editor.selection);
  const selection = useEditorState((state) => state.selection());
  
  // ...
};
```

#### useEditor

- 返回稳定的活动编辑器引用，适用于回调、effect 和命令。
- 没有匹配的活动编辑器时抛出错误。

#### useEditorSelector

- 订阅基于编辑器的特定选择器。这是订阅状态变化最高效的方式。
- 示例用法：`const hasSelection = useEditorSelector((editor) => !!editor.selection);`
- 当您希望组件响应特定变化重新渲染时，可以使用`useEditorSelector`访问相关属性。
- 选择器函数在每次编辑器变化时被调用（如每次按键或选择变化），但组件仅在返回值变化时重新渲染。
- 为确保正常工作，返回值应能使用`===`进行比较。通常这意味着返回原始值（数字、字符串或布尔值）。
- 可以为`useEditorSelector`提供自定义的`equalityFn`选项来处理`===`不适用的情况。
- 选择器始终读取最新 render 的闭包值，不接收依赖项列表。

#### useEditorState

- 从不可变 editor state 派生值，仅在结果变化时重新渲染。

### Plate组件外部

要在`Plate`组件外部访问编辑器或处理多个编辑器，使用`PlateController`组件：

```ts
import { PlateController, useActiveEditor } from 'platejs/react';

const App = () => (
  <PlateController>
    <Toolbar />
    <MyEditor />
  </PlateController>
);

const Toolbar = () => {
  const editor = useActiveEditor();

  if (!editor) return null;
  // 在此使用编辑器方法
};
```

`PlateController`管理活动编辑器：
- 默认第一个挂载的编辑器为活动状态（可通过`Plate`上的`primary={false}`覆盖）。
- 焦点改变会切换活动编辑器。
- 编辑器保持活动状态直到另一个编辑器获得焦点或自身卸载。

`useActiveEditor()` 在没有活动编辑器时返回 `null`。需要编辑器才能渲染的组件使用 `useEditor()`，并在缺少编辑器时立即抛出错误。

```ts
const Toolbar = () => {
  const editor = useActiveEditor();
  
  if (!editor) {
    return <div>编辑器未就绪</div>;
  }
  
  return <div>{/* 工具栏内容 */}</div>;
};
```


## 编辑器 API 和命令

`editor.api` 用于读取、DOM service 和 host helper。`editor.update` 用于会改变文档、选择、历史或插件状态的命令。

```ts title="editor-methods.ts" showLineNumbers
const selectedText = editor.selection
  ? editor.api.string(editor.selection)
  : '';

const currentBlock = editor.api.block();

if (selectedText && !editor.api.hasMark('bold')) {
  editor.update((tx) => tx.marks.toggle('bold'));
}

editor.update((tx) => {
  tx.nodes.insert({
    children: [{ text: 'New paragraph' }],
    type: 'p',
  });
});
```

| 表面 | 示例 | 用途 |
| --- | --- | --- |
| `editor.api` | `string`, `block`, `hasMark`, `isExpanded`, `dom.focus` | 读取编辑器状态、检查 selection、DOM/runtime services。 |
| `editor.update` | `tx.nodes.insert`, `tx.nodes.set`, `tx.marks.toggle`, `tx.selection.set` | 修改文档或编辑器状态。 |

## 插件方法

插件 helper 让 TypeScript 从传入的插件推断 API。插件命令通过 `editor.update` 执行。

```ts title="table-methods.ts" showLineNumbers
import { TablePlugin } from '@platejs/table/react';

const cell = editor.api.create.tableCell();

editor.update((tx) => tx.insert.tableRow());
```

| 方法 | 用途 |
| --- | --- |
| `editor.getPlugin(plugin)` | 读取已解析插件实例。 |
| `editor.getType(pluginKey)` | 读取插件 key 注册的节点 type。 |
| `editor.getInjectProps(plugin)` | 读取已解析 injected node props。 |

### getPlugin

通过键或基础插件获取编辑器插件实例：

```ts
const codeBlockPlugin = editor.getPlugin(CodeBlockPlugin);
const headingPlugin = editor.getPlugin({ key: KEYS.heading });
```

### getType

获取与插件关联的节点类型：

```ts
const paragraphType = editor.getType(KEYS.p);
```

## 选项方法

### getOption

获取插件的特定选项值：

```ts
const search = editor.plugin(FindReplacePlugin).getOption('search');
```

要订阅选项变化，可使用`usePluginOption`或`usePluginOptions`钩子。

### getOptions

获取插件的所有选项：

```ts
const linkOptions = editor.plugin(LinkPlugin).getOptions();
```

### setOption

设置插件的特定选项值：

```ts
editor.plugin(FindReplacePlugin).setOption('search', 'hello');
```

### setOptions

设置插件的多个选项：

```ts
editor.plugin(FindReplacePlugin).setOptions({
  search: 'hello',
  caseSensitive: true,
});
```

也可使用Immer函数更新选项：

```ts
editor.plugin(FindReplacePlugin).setOptions((draft) => {
  draft.search = 'hello';
  draft.caseSensitive = true;
});
```

### getOptionsStore

获取插件的[zustand-x](https://github.com/udecode/zustand-x)选项存储：

```ts
const store = editor.getOptionsStore(FindReplacePlugin);
```
