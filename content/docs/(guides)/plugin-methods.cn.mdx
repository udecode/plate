---
title: 插件方法
description: 编写和配置 Plate 插件。
---

插件作者把互相独立的字段放进插件 constructor。应用和 registry 通过一次终结的
`.configure()` 完成用户覆盖，其中可以包含普通节点的 `component`。

## 方法概览

| 方法 | 用途 | 类型行为 |
| --- | --- | --- |
| `.extend()` | 适配 import/prebuilt descriptor、使用 constructor 无法访问的 shared factory，或消费前一阶段类型。 | 扩展插件类型。 |
| `.configure()` | 为一个用户覆盖现有字段。 | 终结调用，不扩展类型。 |
| `.clone()` | 复制插件定义。 | 返回新的插件对象。 |

`createBasePlugin()` 和 `createPlatePlugin()` 拥有所有互相独立的作者贡献：

| 字段 | 所有权 |
| --- | --- |
| `api` | 插件作用域内的不可变服务和查询。 |
| `read` | 快照或事务内的读取。 |
| `selectors` | 派生 option 值，包括 React 订阅。 |
| `update` | 绑定事务的插件变更。 |
| `extension` | Plite 运行时能力，包括编辑器级分组。 |
| `codecs` | 插件拥有的格式解码和编码。 |

回调接收推断后的[插件上下文](/docs/plugin-context)，包括 `editor`、`plugin`、
`api`、`read`、`defineCodecs`、`defineEditorExtension`、`getOption`、
`getOptions`，以及 update 贡献中的活动 `tx`。

## 使用 Constructor Context

互相独立的字段及其 context callback 放进 constructor。只有 import/prebuilt
declaration 或前一阶段新增的类型才使用 `.extend()`。

```tsx title="counter-plugin.tsx" showLineNumbers
import { createPlatePlugin, usePluginOption } from 'platejs/react';

type CounterOptions = {
  value: number;
};

type CounterApi = {
  isEmpty: () => boolean;
};

type CounterUpdate = {
  insertLabel: () => void;
};

type CounterSelectors = {
  doubled: (factor: number) => number;
  isEven: () => boolean;
};

export const CounterPlugin = createPlatePlugin({
  api: ({ getOption }): CounterApi => ({
    isEmpty: () => getOption('value') === 0,
  }),
  key: 'counter',
  options: {
    value: 0,
  },
  selectors: ({ getOptions }): CounterSelectors => ({
    doubled: (factor) => getOptions().value * factor,
    isEven: () => getOptions().value % 2 === 0,
  }),
  update: ({ getOption, tx }): CounterUpdate => ({
    insertLabel: () => {
      tx.text.insert(`Count: ${getOption('value')}`);
    },
  }),
});

export function CounterValue() {
  const doubled = usePluginOption(CounterPlugin, 'doubled', 2);
  const isEven = usePluginOption(CounterPlugin, 'isEven');

  return (
    <span>
      {doubled} / {isEven ? 'even' : 'odd'}
    </span>
  );
}
```

可选返回类型描述所添加的字段。对 `update` 来说，它描述 callback
返回的命令对象，而不是 callback 本身。完整合约可推断时不要写。

解析后，具体编辑器通过可读 key 暴露插件 API。通用包代码使用类型化 portal。

```ts
editor.api.counter.isEmpty();
editor.plugin(CounterPlugin).api.isEmpty();
editor.plugin(CounterPlugin).update.insertLabel();
```

后续 update 贡献通过活动事务组复用前一个 update：

```ts
.extend(({ plugin }) => ({
  update: ({ tx }) => ({
    insertPair: () => {
      tx[plugin.key].insertLabel();
      tx[plugin.key].insertLabel();
    },
  }),
}))
```

在这里调用 portal 的一次性 update 会打开嵌套事务。

## 安装 Plite 能力

通用编辑器底层行为放在 `extension` 字段：schema 事实、state、command、
correction、query middleware 和运行时服务。没有 `name` 的原始 extension options
继承插件 key。

```ts title="single-line-plugin.ts" showLineNumbers
import { createBasePlugin, editorCommands } from 'platejs';

export const SingleLinePlugin = createBasePlugin({
  extension: {
    commands: ({ handle }) => [
      handle(editorCommands.insertBreak, ({ state }) =>
        state.transaction(() => {})
      ),
    ],
  },
  key: 'singleLine',
});
```

Inline extension object 不需要 helper。若 extension declaration 是抽取后可复用的
factory，contextual typing 无法从 `extension` 字段反向流入 factory。传入 plugin
context，并返回其中的 `defineEditorExtension` identity helper：

```ts title="trigger-plugin.ts" showLineNumbers
import {
  type BasePluginContext,
  createBasePlugin,
  editorCommands,
  type PluginConfig,
} from 'platejs';

type TriggerConfig = PluginConfig<
  'trigger',
  { enabled: boolean }
>;

const withTriggerExtension = (context: BasePluginContext<TriggerConfig>) =>
  context.defineEditorExtension({
    commands: ({ handle }) => [
      handle(editorCommands.insertBreak, ({ state }) => {
        if (!context.getOption('enabled')) return false;

        return state.transaction(() => {});
      }),
    ],
  });

export const TriggerPlugin = createBasePlugin<TriggerConfig>({
  extension: (context) => withTriggerExtension(context),
  key: 'trigger',
  options: { enabled: true },
});
```

constructor 的 context helper 保留嵌套 command、input、state、transaction 和
dependency inference。从
`@platejs/plite` import 的 `defineEditorExtension` 用于 standalone Plite
extension，不能替代这里的 Plate plugin context。

真正无 key 的编辑器级能力也属于 `extension`。插件专用 API 保持在 `api`，
不要发布两份实现。

## 声明产品 Codec

使用 callback 中的 `defineCodecs` 构建 MIME-keyed map。它是 codec callback
唯一的 inline inference anchor。

```ts title="records-plugin.ts" showLineNumbers
import { ContentSlice } from '@platejs/plite';
import { createBasePlugin } from 'platejs';

export const RecordsPlugin = createBasePlugin({
  codecs: ({ defineCodecs }) =>
    defineCodecs({
      'application/json': {
        scope: 'document',
        decode: ({ data }) => ContentSlice.fromJSON(JSON.parse(data)),
        encode: ({ slice }) => JSON.stringify(slice),
      },
    }),
  key: 'records',
});
```

只有格式表示完整文档时才使用 document scope。
Self/product codec 使用 `defineCodecs(map)`。Foreign codec 使用
`defineCodecs(TargetPlugin, map)`；helper 会把 target 注入每个 HTML rule。
Map 中的 `'text/html'` 接受单个 schema-aware rule 或非空有序 rule tuple。
一个插件拥有多个 HTML 表示时，该 tuple 保持在同一个 map 中。不要直接声明
codec map，也不要手动添加 `target`。

## 绑定组件

普通节点组件与其他用户覆盖放进同一次终结的 `.configure()`。

```tsx title="plugins.tsx" showLineNumbers
import { ParagraphPlugin } from 'platejs/react';

import { ParagraphElement } from '@/components/ui/paragraph-node';

export const AppParagraphPlugin = ParagraphPlugin.configure({
  component: ParagraphElement,
  shortcuts: {
    toggle: { keys: 'mod+alt+0' },
  },
});
```

组件绑定不会扩展插件类型。不要通过 renderer registry 字段分配节点组件。

## 配置现有字段

应用或 registry 安装插件时，用一次 `.configure()` 修改作者已经声明的字段。

```tsx title="plugins.tsx" showLineNumbers
import { H1Plugin } from '@platejs/basic-nodes/react';

export const AppH1Plugin = H1Plugin.configure({
  options: {
    levels: [1, 2],
  },
  shortcuts: {
    toggle: { keys: 'mod+alt+1' },
  },
});
```

对象配置遵循 Plate 合并规则：对象深度合并，数组替换，`options` 浅合并。
`.configure()` 不能发布新能力，并且必须是最后一次调用。

## 配置关联插件

直接配置必需依赖的描述符，并把完整描述符放在同一个应用或 registry 插件数组中。

```ts
const CellPlugin = createPlatePlugin({
  key: 'cell',
  options: { padding: 12 },
});

const GridPlugin = createPlatePlugin({
  key: 'grid',
  dependencies: [CellPlugin],
});

export const AppGridPlugins = [
  GridPlugin,
  CellPlugin.configure({ options: { padding: 8 } }),
];
```

可选能力是普通数组项。两个相同 key 的显式描述符会报错；数组顺序不是覆盖机制。

## 将 Plite 插件转换为 Plate 插件

语义基础已经存在、剩余工作仅属于 React 时，使用 `toPlatePlugin()`。

```tsx title="mention-plugin.tsx" showLineNumbers
import { createBasePlugin, schema } from 'platejs';
import { toPlatePlugin } from 'platejs/react';

import { MentionElement } from '@/components/ui/mention-node';

const BaseMentionPlugin = createBasePlugin({
  key: 'mention',
  schema: {
    element: {
      content: schema.content.text({ default: 'text', min: 1 }),
      inline: true,
    },
  },
});

export const MentionPlugin =
  toPlatePlugin(BaseMentionPlugin).configure({ component: MentionElement });
```

转换后的插件保持同一个创作模型：互相独立的字段放进 constructor，只有适配
import/prebuilt declaration、使用 constructor 无法访问的 shared factory，或需要
前一阶段类型时才使用 `.extend()`，最后调用一次 `.configure({ component })`。
