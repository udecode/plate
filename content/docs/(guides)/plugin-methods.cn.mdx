title: 插件方法
description: 编写和配置 Plate 插件。
---

插件作者把互相独立的字段放进插件 constructor。应用和 registry 通过一次终结的
`.configure()` 完成用户覆盖，其中可以包含普通节点的 `component`。

## 方法概览

| 方法 | 用途 | 类型行为 |
| --- | --- | --- |
| `.extend()` | 适配 import/prebuilt descriptor、使用 constructor 无法访问的 shared factory，或消费前一阶段类型。 | 扩展插件类型。 |
| `.configure()` | 为一个用户覆盖现有字段。 | 终结调用，不扩展类型。 |

`defineBasePlugin()` 和 `definePlatePlugin()` 拥有所有互相独立的作者贡献：

| 字段 | 所有权 |
| --- | --- |
| `initialState` | 此插件 editor-local store 的初始值。 |
| `api` | 创建插件作用域内不可变服务和查询的 factory。 |
| `read` | 快照或事务内的读取。 |
| `selectors` | 纯 state-first 派生值，包括 React 订阅。 |
| `update` | 绑定事务的插件变更。 |
| 原生 Plite 字段 | Read middleware、command、correction、state/effect/facet/selection descriptor、contribution、lifecycle、activation 和 validation。 |
| `codecs` | 插件拥有的格式解码和编码。 |

回调接收推断后的[插件上下文](/docs/plugin-context)，包括 `editor`、`plugin`、
`api`、`read`、`defineCodecs`、`store`，以及 update 贡献中的活动 `tx`。

## 使用 Constructor Context

互相独立的字段及其 context callback 放进 constructor。只有 import/prebuilt
declaration 或前一阶段新增的类型才使用 `.extend()`。

```tsx title="counter-plugin.tsx" showLineNumbers
import { definePlatePlugin, usePluginStore } from 'platejs/react';

export type CounterPluginState = {
  value: number;
};

export const CounterPlugin = definePlatePlugin('counter', {
  api: ({ store }) => ({
    isEmpty: () => store.get('value') === 0,
  }),
  initialState: {
    value: 0,
  } satisfies CounterPluginState,  selectors: {
    doubled: (state, factor: number) => state.value * factor,
    isEven: (state) => state.value % 2 === 0,
  },
  update: ({ store, tx }) => ({
    insertLabel: () => {
      tx.text.insert(`Count: ${store.get('value')}`);
    },
  }),
});

export function CounterValue() {
  const doubled = usePluginStore(CounterPlugin, 'doubled', 2);
  const isEven = usePluginStore(CounterPlugin, 'isEven');

  return (
    <span>
      {doubled} / {isEven ? 'even' : 'odd'}
    </span>
  );
}
```

让 constructor 推断新增的 API、read、selector 和 update group。只有包使用者
需要该合约时，才保留导出的 state type。

解析后，具体编辑器通过可读名称暴露插件 API。通用包代码使用类型化 portal。

```ts
editor.api.counter.isEmpty();
editor.plugin(CounterPlugin).api.isEmpty();
editor.plugin(CounterPlugin).update.insertLabel();
```

后续 update 贡献通过活动事务组复用前一个 update：

```ts
.extend(() => ({
  update: ({ tx }) => ({
    insertPair: () => {
      tx.plugin(CounterPlugin).insertLabel();
      tx.plugin(CounterPlugin).insertLabel();
    },
  }),
}))
```

在这里调用 portal 的一次性 update 会打开嵌套事务。

## 安装 Plite 能力

通用编辑器底层行为直接声明在插件上：schema、command、correction、read
middleware、state/effect/facet/selection descriptor、contribution、
lifecycle、activation 和 validation。

```ts title="single-line-plugin.ts" showLineNumbers
import { defineBasePlugin, editorCommands } from 'platejs';

export const SingleLinePlugin = defineBasePlugin('singleLine', {
  commands: ({ handle }) => [
    handle(editorCommands.insertBreak, ({ state }) =>
      state.transaction(() => {})
    ),
  ],});
```

原生 callback 只接收对应的 Plite capability context。需要前一阶段的
plugin store、read、API 或 update group 时，增加一次 `.extend()` 并在闭包中
使用该能力。不要为了转发 owner context 新增 helper 参数：

```ts title="trigger-plugin.ts" showLineNumbers
import { defineBasePlugin, editorCommands } from 'platejs';

export const TriggerPlugin = defineBasePlugin('trigger', {
  initialState: { enabled: true },}).extend(({ store }) => ({
  commands: ({ handle }) => [
    handle(editorCommands.insertBreak, ({ state }) => {
      if (!store.get('enabled')) return false;

      return state.transaction(() => {});
    }),
  ],
}));
```

独立复用的 Plite descriptor 使用从 `@platejs/plite` import 的
`defineExtension`，然后把 descriptor 放进 `dependencies`。

插件专用和 editor-wide host service 共用根级 `api` channel；Plite 会按插件
name 投影它。不要发布两份实现。

## 声明产品 Codec

使用 callback 中的 `defineCodecs` 构建 MIME-keyed map。它是 codec callback
唯一的 inline inference anchor。

```ts title="records-plugin.ts" showLineNumbers
import { ContentSlice } from '@platejs/plite';
import { defineBasePlugin } from 'platejs';

export const RecordsPlugin = defineBasePlugin('records', {
  codecs: ({ defineCodecs }) =>
    defineCodecs({
      'application/json': {
        scope: 'document',
        decode: ({ data }) => ContentSlice.fromJSON(JSON.parse(data)),
        encode: ({ slice }) => JSON.stringify(slice),
      },
    }),});
```

只有格式表示完整文档时才使用 document scope。
Self/product codec 使用 `defineCodecs(map)`。Foreign codec 使用
`defineCodecs(TargetPlugin, map)`；helper 会把 target 注入每个 HTML rule。
Map 中的 `'text/html'` 接受单个 schema-aware rule 或非空有序 rule tuple。
一个插件拥有多个 HTML 表示时，该 tuple 保持在同一个 map 中。不要直接声明
codec map，也不要手动添加 `target`。

## 绑定组件

普通节点组件与其他用户覆盖放进同一次终结的 `.configure()`。

```tsx title="plugins.tsx" showLineNumbers
import { ParagraphPlugin } from 'platejs/react';

import { ParagraphElement } from '@/components/editor/paragraph';

export const AppParagraphPlugin = ParagraphPlugin.configure({
  component: ParagraphElement,
  shortcuts: {
    toggle: { keys: 'mod+alt+0' },
  },
});
```

组件绑定不会扩展插件类型。不要通过 renderer registry 字段分配节点组件。

## 配置现有字段

应用或 registry 安装插件时，用一次 `.configure()` 修改作者已经声明的字段。

```tsx title="plugins.tsx" showLineNumbers
import { HeadingPlugin } from '@platejs/basic-nodes/react';

export const AppHeadingPlugin = HeadingPlugin.configure({
  initialState: {
    levels: [1, 2],
  },
});
```

对象配置遵循 Plate 合并规则：对象深度合并，数组替换，`initialState` 浅合并。
`.configure()` 不能发布新能力，并且必须是最后一次调用。

## 配置关联插件

直接配置必需依赖的描述符，并把完整描述符放在同一个应用或 registry 插件数组中。

```ts
type CellPluginState = {
  padding: number;
};

const initialState: CellPluginState = {
  padding: 12,
};

const CellPlugin = definePlatePlugin('cell', {
  initialState,});

const GridPlugin = definePlatePlugin('grid', {
  dependencies: [CellPlugin],
});

export const AppGridPlugins = [
  GridPlugin,
  CellPlugin.configure({ initialState: { padding: 8 } }),
];
```

可选能力是普通数组项。从同一个已创作插件派生的终端配置会按数组顺序组合：较早的字段
会保留，除非后面的配置定义了同一字段。无关的插件和分叉的创作分支不能共享同一个名称。

## 将 Plite 插件转换为 Plate 插件

在所属 React entrypoint 中使用 `toPlatePlugin()` 发布可复用 Plate descriptor
或添加 Plate-only behavior。应用用户不为设置 component 而插入转换。

```tsx title="script-plugin.tsx" showLineNumbers
import { BaseScriptPlugin } from '@platejs/basic-nodes';
import { PlateLeaf, toPlatePlugin } from 'platejs/react';

export const ScriptPlugin = toPlatePlugin(BaseScriptPlugin, {
  component: (props) => (
    <PlateLeaf
      {...props}
      as={props.leaf['script'] === 'sub' ? 'sub' : 'sup'}
    >
      {props.children}
    </PlateLeaf>
  ),
});
```

package 的 React owner 发布 `ScriptPlugin`；static/RSC 代码可直接在
`BaseScriptPlugin` 上绑定 server-safe component，无需导入 `platejs/react`。
