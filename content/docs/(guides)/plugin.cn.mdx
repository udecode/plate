Plate插件具有高度可配置性，允许您根据需要定制其行为。本指南将介绍最常见的配置选项及使用方法。

- [入门指南：组件](/docs/installation#components) - 添加插件到编辑器的说明
- [PlatePlugin API](/docs/api/core/plate-plugin) - 创建插件的完整API参考

## 基础插件配置

### 新建插件

最基本的插件配置只需一个`key`：

```ts
const MyPlugin = createPlatePlugin({
  key: 'minimal',
});
```

虽然这个插件目前没有任何功能，但它是更复杂配置的起点。

### 现有插件

使用`.configure`方法可以配置现有插件：

```ts
const ConfiguredPlugin = MyPlugin.configure({
  options: {
    myOption: 'new value',
  },
});
```

## Schema 插件

Schema 插件在顶层声明文档类型，并在 `schema` 下声明模型行为。React
渲染配置位于 `render` 下。

### 元素

使用 `schema.element` 声明新元素类型：

```ts
import { schema } from 'platejs';

const ParagraphPlugin = createPlatePlugin({
  key: 'p',
  type: 'p',
  schema: {
    element: { content: schema.content.text({ default: 'text', min: 1 }) },
  },
});
```

您可以为元素关联组件。详见[插件组件](/docs/plugin-components)。

```ts
import { schema } from 'platejs';

const ParagraphPlugin = createPlatePlugin({
  key: 'p',
  type: 'p',
  schema: {
    element: { content: schema.content.text({ default: 'text', min: 1 }) },
  },
  render: { node: ParagraphElement },
});
```

### 行内元素、Void 元素和文本属性

元素行为位于 `schema.element` 中。使用 `schema.mark` 下的属性描述符声明布尔文本属性：

```ts
import { property, schema } from 'platejs';

const LinkPlugin = createPlatePlugin({
  key: 'link',
  type: 'a',
  schema: {
    element: {
      content: schema.content.text({ default: 'text', min: 1 }),
      inline: true,
    },
  },
});

const ImagePlugin = createPlatePlugin({
  key: 'image',
  type: 'img',
  schema: { element: { void: 'block' } },
});

const BoldPlugin = createPlatePlugin({
  key: 'bold',
  schema: {
    mark: property.boolean({ default: false, omitDefault: true }),
  },
});
```

## 行为插件

除了声明元素或文本属性外，您可能还想自定义编辑器的行为。Plate提供了多种插件选项来修改编辑器行为。

### 插件规则

`rules`属性允许您配置常见的编辑行为，如拆分、删除和合并节点，而无需重写编辑器方法。这是为自定义元素定义直观交互的强大方式。

例如，您可以定义当用户在空标题中按`Enter`或在块引用开头按`Backspace`时发生的情况。

```ts
import { H1Plugin } from '@platejs/heading/react';

H1Plugin.configure({
  rules: {
    break: { empty: 'reset' },
  },
});
```

完整规则列表和可用操作请见[插件规则指南](/docs/plugin-rules)。

### 事件处理器

推荐通过`handlers`插件选项响应插件内部用户生成的事件。处理器应是一个接收`PlatePluginContext & { event }`对象的函数。

`onChange`处理器（当编辑器值变化时调用）是个例外，其上下文对象包含变化的`value`而非`event`。

```ts showLineNumbers
const ExamplePlugin = createPlatePlugin({
  key: 'example',
  handlers: {
    onChange: ({ editor, value })  => {
      console.info(editor, value);
    },
    onKeyDown: ({ editor, event }) => {
      console.info(`You pressed ${event.key}`);
    },
  },
});
```

### 注入属性

您可能希望向具有特定属性的任何节点注入类名或CSS属性。例如，以下插件为具有`align`属性的段落设置`textAlign` CSS属性。

```ts showLineNumbers
import { KEYS, property, target } from 'platejs';

const TextAlignPlugin = createPlatePlugin({
  key: 'align',
  schema: ({ own, plugins, targetPluginKeys }) => ({
    properties: [
      own.elementProperty(property.string(), {
        target: target.types(plugins.elementTypesByKey(targetPluginKeys)),
        typeChange: 'preserve-if-allowed',
      }),
    ],
  }),
  inject: {
    isBlock: true,
    nodeProps: {
      defaultNodeValue: 'start',
      styleKey: 'textAlign',
      validNodeValues: ['start', 'left', 'center', 'right', 'end', 'justify'],
    },
  },
  targetPluginKeys: [KEYS.p],
}).extendHtmlCodec(() => ({
  decode: ({ element }) => element.style.textAlign || undefined,
  encode: ({ value }) => ({ style: { textAlign: value } }),
  match: [
    {
      style: {
        textAlign: ['start', 'left', 'center', 'right', 'end', 'justify'],
      },
    },
  ],
}));
```

`inject.nodeProps` 负责渲染，`.extendHtmlCodec()` 负责双向 HTML 声明。
两者都使用插件解析后的 `type`，因此最终的 `.configure({ type })` 可以修改存储
属性，而不需要在 codec 中重复 key。

受该插件影响的段落节点如下：

```ts showLineNumbers {3}
{
  type: 'p',
  align: 'right',
  children: [{ text: '本段落右对齐！' }],
}
```

### 扩展 API 和事务命令

使用 `.extendEditorApi()` 添加编辑器级读取或服务，使用 `.extendTx()` 添加插件自己的文档变更。两者保持分离，调用方可以直接看出某个方法是否会修改编辑器。

```ts
type CustomConfig = PluginConfig<'custom', { allowDelete: boolean }>;

const CustomPlugin = createPlatePlugin<CustomConfig>({
  key: 'custom',
  options: { allowDelete: true },
})
  .extendEditorApi(({ getOptions }) => ({
    canDelete: () => getOptions().allowDelete,
  }))
  .extendTx(({ getOptions }) => (tx) => ({
    deleteBackward() {
      if (!getOptions().allowDelete) return;

      tx.text.delete({ reverse: true, unit: 'character' });
    },
  }));

editor.api.canDelete();
editor.update((tx) => tx.custom.deleteBackward());
```

### 安装 Plite 扩展（高级）

当 Plate 插件需要安装 Plite 底层能力时使用 `.extendExtension()`：schema、state、tx、command、correction 或运行时服务。

```ts showLineNumbers
import { defineEditorExtension } from 'platejs';
import { createPlatePlugin } from 'platejs/react';

const customState = defineEditorExtension({
  name: 'custom-state',
  state: {
    customState() {
      return {
        enabled: () => true,
      };
    },
  },
});

const CustomStatePlugin = createPlatePlugin({
  key: 'customState',
}).extendExtension(customState);
```

<Callout type="info" title="扩展、API 与事务">
- 使用 `.extendExtension()` 安装 Plite 底层能力。
- 使用 `.extendApi()` 或 `.extendEditorApi()` 添加读取与服务。
- 使用 `editor.update.*` 或活动事务中的 `tx` 组执行变更。
</Callout>

## 高级插件配置

### 插件存储

每个插件都有自己的存储，可用于管理插件特定状态。

```ts
const MyPlugin = createPlatePlugin({
  key: 'myPlugin',
  options: {
    count: 0,
  },
}).extend(({ editor, plugin, setOption }) => ({
  handlers: {
    onClick: () => {
      setOption('count', 1);
    },
  },
}));
```

您可以使用以下方法访问和更新存储：

```ts
// 获取当前值
const count = editor.plugin(MyPlugin).getOption('count');

// 设置新值
editor.plugin(MyPlugin).setOption('count', 5);

// 基于先前状态更新值
editor.plugin(MyPlugin).setOption('count', (prev) => prev + 1);
```

在React组件中，可以使用`usePluginOption`或`usePluginOptions`钩子订阅存储变更：

```tsx
const MyComponent = () => {
  const count = usePluginOption(MyPlugin, 'count');
  return <div>计数: {count}</div>;
};
```

更多内容请见[插件上下文](/docs/plugin-context)和[编辑器方法](/docs/editor-methods)指南。

### 依赖项

使用插件对象声明所需依赖项。Plate 会递归安装依赖图，按插件 key 去重，并在依赖插件之后加载当前插件。

```ts
const MyPlugin = createPlatePlugin({
  key: 'myPlugin',
  dependencies: [ParagraphPlugin, ListPlugin],
});
```

### 启用标志

`enabled`属性允许您有条件地启用或禁用插件：

```ts
const MyPlugin = createPlatePlugin({
  key: 'myPlugin',
  enabled: true, // 或false禁用
});
```

### 可选能力

可选能力应作为普通插件直接放在使用者的插件数组中。当增强能力需要宿主时，由增强
能力依赖宿主：

```ts
const CodeHighlightPlugin = createPlatePlugin({
  key: 'codeHighlight',
  dependencies: [CodeBlockPlugin],
});

const plugins = [CodeBlockPlugin, CodeHighlightPlugin];
```

需要纯文本代码块时省略 `CodeHighlightPlugin`。宿主不会安装可选增强能力。

### 插件优先级

`priority`属性决定插件注册和执行的顺序。优先级值较高的插件优先处理：

```ts
const HighPriorityPlugin = createPlatePlugin({
  key: 'highPriority',
  priority: 100,
});

const LowPriorityPlugin = createPlatePlugin({
  key: 'lowPriority',
  priority: 50,
});
```

这在需要确保某些插件先于其他插件初始化或运行时特别有用。

### HTML 输入钩子

使用 `parsers.html` 下的扁平钩子决定插件是否参与 HTML 输入、转换源字符串，
或转换已解码的 fragment。

```ts
const HtmlCleanupPlugin = createPlatePlugin({
  key: 'htmlCleanup',
  parsers: {
    html: {
      query: ({ data, format }) =>
        format === 'text/html' && data.includes('<!--StartFragment-->'),
      transformData: ({ data }) =>
        data.replaceAll(/<!--(?:Start|End)Fragment-->/g, ''),
    },
  },
});
```

`query`、`transformData` 和 `transformFragment` 都直接位于
`parsers.html` 下。节点级 HTML 转换与这些完整输入钩子分开。

## 类型化插件

使用上述方法时，插件类型会根据给定配置自动推断。

如果需要显式传递泛型类型，可以使用`createPlatePlugin`。

### 使用createPlatePlugin

`createPlatePlugin`函数允许创建类型化插件：

```ts
type CodeBlockConfig = PluginConfig<
  // key
  'codeBlock',
  // options
  { syntax: boolean; syntaxPopularFirst: boolean },
  // api
  {
    plugin: {
      getSyntaxState: () => boolean;
    };
    toggleSyntax: () => void;
  },
  // tx
  {
    insert: {
      codeBlock: () => void;
    };
  },
  // selectors
  {}
>;

const CodeBlockPlugin = createPlatePlugin<CodeBlockConfig>({
  key: 'codeBlock',
  type: 'code_block',
  options: { syntax: true, syntaxPopularFirst: false },
}).extendEditorApi<CodeBlockConfig['api']>(() => ({
  plugin: {
    getSyntaxState: () => true,
  },
  toggleSyntax: () => {},
})).extendTxGroup('insert', ({ getOptions }) => (tx) => ({
  codeBlock: () => {
    tx.nodes.insert({
      type: 'code_block',
      language: getOptions().language,
      children: [{ text: '' }],
    });
  },
}));
```

### 使用类型化插件

使用类型化插件时，您将获得完整的类型检查和自动补全功能 ✨

```ts
const editor = createPlateEditor({
  plugins: [ExtendedCodeBlockPlugin],
});

// 类型安全的选项访问
const options = editor.plugin(ExtendedCodeBlockPlugin).getOptions();
options.syntax;
options.syntaxPopularFirst;
options.hotkey;

// 类型安全的API
editor.api.toggleSyntax();
editor.api.plugin.getSyntaxState();
editor.api.plugin2.setLanguage('python');
editor.api.plugin.getLanguage();

// 类型安全的事务
editor.update((tx) => tx.insert.codeBlock());
```
