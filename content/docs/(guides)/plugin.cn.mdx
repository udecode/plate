Plate 插件具有高度可配置性，允许您根据需要定制其行为。本指南将介绍最常见的配置选项及使用方法。

- [入门指南：组件](/docs/installation#components) - 添加插件到编辑器的说明
- [PlatePlugin API](/docs/api/core/plate-plugin) - 创建插件的完整 API 参考

## 基础插件配置

### 新建插件

最基本的插件配置只需一个`name`：

```ts
const MyPlugin = createPlatePlugin({
  name: "minimal",
});
```

虽然这个插件目前没有任何功能，但它是更复杂配置的起点。

### 现有插件

使用`.configure`方法可以配置现有插件：

```ts
const ConfiguredPlugin = MyPlugin.configure({
  initialState: {
    myOption: "new value",
  },
});
```

## Schema 插件

Schema 插件在顶层声明文档类型，并在 `schema` 下声明模型行为。React
渲染配置位于 `render` 下。

### 元素

使用 `schema.element` 声明新元素类型：

```ts
import { schema } from "platejs";

const ParagraphPlugin = createPlatePlugin({
  name: "p",
  type: "p",
  schema: {
    element: { content: schema.content.text({ default: "text", min: 1 }) },
  },
});
```

您可以为元素关联组件。详见[插件组件](/docs/plugin-components)。

```ts
import { schema } from "platejs";

const ParagraphPlugin = createPlatePlugin({
  name: "p",
  type: "p",
  schema: {
    element: { content: schema.content.text({ default: "text", min: 1 }) },
  },
}).configure({ component: ParagraphElement });
```

### 行内元素、Void 元素和文本属性

元素行为位于 `schema.element` 中。使用 `schema.mark` 下的属性描述符声明布尔文本属性：

```ts
import { property, schema } from "platejs";

const LinkPlugin = createPlatePlugin({
  name: "link",
  type: "a",
  schema: {
    element: {
      content: schema.content.text({ default: "text", min: 1 }),
      inline: true,
    },
  },
});

const ImagePlugin = createPlatePlugin({
  name: "image",
  type: "img",
  schema: { element: { void: "block" } },
});

const BoldPlugin = createPlatePlugin({
  name: "bold",
  schema: {
    mark: property.boolean({ default: false, omitDefault: true }),
  },
});
```

## 行为插件

除了声明元素或文本属性外，您可能还想自定义编辑器的行为。Plate 提供了多种插件选项来修改编辑器行为。

### 插件规则

`rules`属性允许您配置常见的编辑行为，如拆分、删除和合并节点，而无需重写编辑器方法。这是为自定义元素定义直观交互的强大方式。

例如，您可以定义当用户在空标题中按`Enter`或在块引用开头按`Backspace`时发生的情况。

```ts
import { H1Plugin } from "@platejs/heading/react";

H1Plugin.configure({
  rules: {
    break: { empty: "reset" },
  },
});
```

完整规则列表和可用操作请见[插件规则指南](/docs/plugin-rules)。

### 事件处理器

插件的 `on` 字段同时管理 editor lifecycle 和 React DOM 事件。DOM handler
接收 `PlatePluginContext & { event }` 对象。

子项名称不重复 `on` 前缀。Lifecycle handler 使用 `commit`、`nodeChange`
和 `textChange`；DOM handler 使用 `keyDown`、`paste` 和 `click`。

```ts showLineNumbers
const ExamplePlugin = createPlatePlugin({
  on: {
    commit: ({ editor, snapshot }) => {
      console.info(editor, snapshot.children);
    },
    keyDown: ({ editor, event }) => {
      console.info(`You pressed ${event.key}`);
    },
  },
  name: "example",
});
```

### 注入属性

您可能希望向具有特定属性的任何节点注入类名或 CSS 属性。例如，以下插件为具有`align`属性的段落设置`textAlign` CSS 属性。

```ts showLineNumbers
import { KEYS, property, target } from "platejs";

const TextAlignPlugin = createPlatePlugin({
  codecs: ({ defineCodecs }) =>
    defineCodecs({
      "text/html": {
        decode: ({ element }) => element.style.textAlign || undefined,
        encode: ({ value }) => ({ style: { textAlign: value } }),
        match: [
          {
            style: {
              textAlign: ["start", "left", "center", "right", "end", "justify"],
            },
          },
        ],
      },
    }),
  inject: {
    isBlock: true,
    nodeProps: {
      defaultNodeValue: "start",
      styleKey: "textAlign",
      validNodeValues: ["start", "left", "center", "right", "end", "justify"],
    },
  },
  name: "align",
  schema: ({ own, plugins, targetPluginNames }) => ({
    properties: [
      own.elementProperty(property.string(), {
        target: target.types(plugins.elementTypesByName(targetPluginNames)),
        typeChange: "preserve-if-allowed",
      }),
    ],
  }),
  targetPluginNames: [KEYS.p],
});
```

`inject.nodeProps` 负责渲染，constructor 的 `codecs` callback 把双向 HTML
声明绑定到插件 schema。`defineCodecs` 根据 property 声明推断 `value`。两条
路径都使用插件解析后的 `type`，因此最终的 `.configure({ type })` 可以修改
存储属性，而不需要在 codec 中重复插件名称。

受该插件影响的段落节点如下：

```ts showLineNumbers {3}
{
  type: 'p',
  align: 'right',
  children: [{ text: '本段落右对齐！' }],
}
```

### 扩展 API 和事务命令

插件读取和服务放在 `api`，文档变更放在 `update`。Constructor callback
直接接收 plugin context。

```ts
export type CustomPluginState = {
  prefix: string;
};

const CustomPlugin = createPlatePlugin({
  api: ({ store }) => ({
    getPrefix: () => store.get("prefix"),
  }),
  initialState: {
    prefix: "Note: ",
  } satisfies CustomPluginState,
  name: "custom",
  update: ({ store, tx }) => ({
    insertPrefix: () => {
      tx.text.insert(store.get("prefix"));
    },
  }),
});
```

插件解析后，具体 editor 会在 root API 推断其 read；一次性 write 使用
name-scoped update helper：

```ts
editor.api.custom.getPrefix();
editor.update.custom.insertPrefix();
```

通用包代码可以通过 `editor.plugin(CustomPlugin).api.getPrefix()` 访问同一个
immutable API object。

### 原生 Plite 能力

Plate 插件直接在插件根级声明 Plite 能力。使用 `readMiddleware`、`commands`、
`corrections`、`stateFields`、`effectTypes`、`facetProviders`、
`selectionKinds`、`contributions`、`on`、`activate` 和 `validate`，
不再添加第二层 wrapper。

```ts showLineNumbers
import { createPlatePlugin, defineStateField } from "platejs";

const enabledField = defineStateField({
  initial: false,
  key: "customState.enabled",
});

const CustomStatePlugin = createPlatePlugin({
  name: "customState",
  stateFields: [enabledField],
  read: ({ state }) => ({
    enabled: () => state.getField(enabledField),
  }),
  on: {
    commit: ({ commit }) => {
      console.info(commit.changed);
    },
  },
});
```

<Callout type="info" title="扩展、API 与事务">
  - 每个独立能力直接放进 constructor。只有 import/prebuilt descriptor、
  constructor 无法访问的 shared factory 或前一阶段类型才使用 `.extend()`。
</Callout>

独立复用的 standalone Plite descriptor 使用从 `@platejs/plite` import 的
`defineEditorExtension`。详见
[插件方法](/docs/plugin-methods#install-plite-capabilities)。

## 高级插件配置

### 插件存储

每个插件都有自己的存储，可用于管理插件特定状态。

```ts
type MyPluginState = {
  count: number;
};

const initialState: MyPluginState = {
  count: 0,
};

const MyPlugin = createPlatePlugin({
  initialState,
  name: "myPlugin",
  on: {
    click: ({ store }) => {
      store.set({ count: 1 });
    },
  },
});
```

您可以使用以下方法访问和更新存储：

```ts
// 获取当前值
const count = editor.plugin(MyPlugin).store.get("count");

// 设置新值
editor.plugin(MyPlugin).store.set({ count: 5 });

// 基于先前状态更新值
editor.plugin(MyPlugin).store.set((state) => {
  state.count += 1;
});
```

在 React 组件中使用 `usePluginStore` 订阅存储变更：

```tsx
const MyComponent = () => {
  const count = usePluginStore(MyPlugin, "count");
  return <div>计数: {count}</div>;
};
```

更多内容请见[插件上下文](/docs/plugin-context)和[编辑器方法](/docs/editor-methods)指南。

### 依赖项

使用插件对象声明所需依赖项。Plate 会递归安装依赖图，按插件名称去重，并在依赖插件之后加载当前插件。

```ts
const MyPlugin = createPlatePlugin({
  name: "myPlugin",
  dependencies: [ParagraphPlugin, ListPlugin],
});
```

### 启用标志

`enabled`属性允许您有条件地启用或禁用插件：

```ts
const MyPlugin = createPlatePlugin({
  name: "myPlugin",
  enabled: true, // 或false禁用
});
```

### 可选能力

可选能力应作为普通插件直接放在使用者的插件数组中。当增强能力需要宿主时，由增强
能力依赖宿主：

```ts
const CodeHighlightPlugin = createPlatePlugin({
  name: "codeHighlight",
  dependencies: [CodeBlockPlugin],
});

const plugins = [CodeBlockPlugin, CodeHighlightPlugin];
```

需要纯文本代码块时省略 `CodeHighlightPlugin`。宿主不会安装可选增强能力。

### 插件顺序

依赖项会在其使用者之前加载。互不依赖的插件保持应用提供的顺序：

```ts
const plugins = [LinkPlugin, MentionPlugin, CommentPlugin];
```

真正的安装要求应使用 `dependencies`。有冲突的快捷键、输入规则和编解码器各自
使用局部 `priority`；插件注册没有全局优先级。

### HTML 输入钩子

使用 `parsers.html` 下的扁平钩子决定插件是否参与 HTML 输入、转换源字符串，
或转换已解码的 fragment。

```ts
const HtmlCleanupPlugin = createPlatePlugin({
  name: "htmlCleanup",
  parsers: {
    html: {
      query: ({ data, format }) =>
        format === "text/html" && data.includes("<!--StartFragment-->"),
      transformData: ({ data }) =>
        data.replaceAll(/<!--(?:Start|End)Fragment-->/g, ""),
    },
  },
});
```

`query`、`transformData` 和 `transformFragment` 都直接位于
`parsers.html` 下。节点级 HTML 转换与这些完整输入钩子分开。

## 类型化插件

`createPlatePlugin` 会从 author object 推断一个精确 definition。通过带类型的
`initialState` 值或 `satisfies` 固定 state contract；不要向 factory 传入调用方
泛型。

### 使用 createPlatePlugin

推断后的 definition 会携带插件 name、state、API、read 和 update：

```ts
export type CodeBlockPluginState = {
  language: string;
  syntax: boolean;
  syntaxPopularFirst: boolean;
};

const initialState: CodeBlockPluginState = {
  language: "typescript",
  syntax: true,
  syntaxPopularFirst: false,
};

export const CodeBlockPlugin = createPlatePlugin({
  api: ({ store }) => ({
    getLanguage: () => store.get("language"),
    getSyntaxState: () => store.get("syntax"),
  }),
  initialState,
  name: "codeBlock",
  type: "code_block",
  update: ({ store, tx }) => ({
    insertCodeBlock: () => {
      tx.nodes.insert({
        type: "code_block",
        language: store.get("language"),
        children: [{ text: "" }],
      });
    },
  }),
});
```

### 使用类型化插件

使用类型化插件时，您将获得完整的类型检查和自动补全功能 ✨

```ts
const editor = createPlateEditor({
  plugins: [CodeBlockPlugin],
});

// 类型安全的 state 访问
const state = editor.plugin(CodeBlockPlugin).store.get();
state.language;
state.syntax;
state.syntaxPopularFirst;

// 类型安全的API
editor.api.codeBlock.getSyntaxState();
editor.api.codeBlock.getLanguage();

// 类型安全的更新
editor.update.codeBlock.insertCodeBlock();
```
