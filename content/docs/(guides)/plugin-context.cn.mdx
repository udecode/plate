---
title: 插件上下文
description: 理解并利用 Plate 插件中的插件上下文。
---

插件上下文是一个在所有插件方法中都可用的对象，提供了对编辑器实例、插件配置和实用函数的访问。

## 访问插件上下文

### 插件方法

插件上下文作为第一个参数在所有插件方法中可用：

```ts
const MyPlugin = definePlatePlugin('myPlugin', {
  on: {
    keyDown: (ctx) => {
      // ctx 就是插件上下文
      console.info(ctx.editor, ctx.plugin);
    },
  },
});
```

### `editor.plugin`

需要访问其他插件时，使用该插件 descriptor 打开类型化 consumer portal。

```ts
const MyPlugin = definePlatePlugin('myPlugin', {
  on: {
    keyDown: ({ editor }) => {
      const linkCtx = editor.plugin(LinkPlugin);
    },
  },
});
```

### `useEditorPlugin`

在 React 组件中，使用 `useEditorPlugin` 访问 consumer portal：

```ts
const MyComponent = () => {
  const { name } = useEditorPlugin(MyPlugin);
  
  return <div>{name}</div>;
};
```

## 插件上下文属性

### `editor`

当前的 `PlateEditor` 实例：

```ts
const MyPlugin = definePlatePlugin('myPlugin', {
  on: {
    commit: ({ editor }) => {
      console.info('编辑器内容:', editor.children);
    },
  },
});
```

### `plugin`

当前插件的配置：

```ts
const MyPlugin = definePlatePlugin('myPlugin', {
  on: {
    keyDown: ({ plugin }) => {
      console.info('插件名称:', plugin.name);
    },
  },
});
```

### `store`

`store` 读取、更新和订阅当前插件的 editor-local state：

```ts
type MyPluginState = {
  myValue: string;
};

const initialState: MyPluginState = {
  myValue: 'default',
};

const MyPlugin = definePlatePlugin('myPlugin', {
  initialState,  on: {
    click: ({ store }) => {
      const myValue = store.get('myValue');
      console.info('state 值:', myValue);
    },
  },
});
```

调用 `store.get()` 读取完整 state：

```ts
type MyPluginState = {
  value1: string;
  value2: string;
};

const initialState: MyPluginState = {
  value1: 'a',
  value2: 'b',
};

const MyPlugin = definePlatePlugin('myPlugin', {
  initialState,  on: {
    click: ({ store }) => {
      console.info('完整 state:', store.get());
    },
  },
});
```

调用 `store.set(partial)` 合并字段：

```ts
type MyPluginState = {
  count: number;
};

const initialState: MyPluginState = {
  count: 0,
};

const MyPlugin = definePlatePlugin('myPlugin', {
  initialState,  on: {
    click: ({ store }) => {
      store.set({ count: 1 });
    },
  },
});
```

调用 `store.set(recipe)` 通过 draft 更新：

```ts
type MyPluginState = {
  count: number;
};

const initialState: MyPluginState = {
  count: 0,
};

const MyPlugin = definePlatePlugin('myPlugin', {
  initialState,  on: {
    click: ({ store }) => {
      store.set((state) => {
        state.count += 1;
      });
    },
  },
});
```

### `name`

插件的不可变能力标识。Element 的持久化标识来自 `schema.type`，primary mark
的持久化标识来自 `schema.key`：

```ts
const MyPlugin = definePlatePlugin('myPlugin', {
  on: {
    keyDown: ({ name }) => {
      console.info('插件标识:', name);
    },
  },
});
```

### Property mutation

在 `update` 中，写入一个唯一 property 时使用 literal-key overload。Plate 从当前
插件及其 required dependencies 推断 key 和 value：

```ts
const LineHeightPlugin = defineBasePlugin('lineHeight', {
  schema: {
    properties: {
      lineHeight: schema.elementProperty(property.number()),
    },
  },
  update: ({ tx }) => ({
    set: (value: number) => tx.nodes.set('lineHeight', value),
    unset: () => tx.nodes.unset('lineHeight'),
  }),
});
```

Aliased property 使用 `schema.properties.<localId>`。结构性变更和原子 multi-property
写入保留 object form。Prefix family 和 cross-node behavior 放在语义 plugin update
method 中。

### `defineCodecs`

在 constructor 的 `codecs` callback 中使用 `defineCodecs`。它是 codec map
唯一的 inference anchor：

```ts
import { defineBasePlugin, property } from 'platejs';

const StrongPlugin = defineBasePlugin('strong', {
  codecs: ({ defineCodecs }) =>
    defineCodecs({
      'text/html': {
        decode: () => true,
        decodeOnly: true,
        match: [{ tag: 'strong' }],
      },
    }),  schema: { mark: property.boolean() },
});
```

Self/product map 使用 `defineCodecs(map)`。Foreign contribution 使用
`defineCodecs(TargetPlugin, map)`，Plate 会把 target 注入每个 HTML rule。
Map 保持 MIME-keyed；`'text/html'` 使用单个 rule 或非空有序 rule tuple。
不要直接声明 codec map，也不要标注 callback 参数。

### 原生能力推断

原生 Plite 字段直接放在 constructor 或分阶段 `.extend()` callback 中。
能力专属 helper 和 Plate plugin context 会一起推断。抽取 domain input，
不要抽取整个 Plate plugin context。

从 `@platejs/plite` import 的 `defineExtension` 只用于独立复用的
standalone Plite descriptor。完整示例见
[插件方法](/docs/plugin-methods#install-plite-capabilities)。
