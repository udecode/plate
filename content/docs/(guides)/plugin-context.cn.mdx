---
title: 插件上下文
description: 理解并利用 Plate 插件中的插件上下文。
---

插件上下文是一个在所有插件方法中都可用的对象，提供了对编辑器实例、插件配置和实用函数的访问。

## 访问插件上下文

### 插件方法

插件上下文作为第一个参数在所有插件方法中可用：

```ts
const MyPlugin = definePlugin('myPlugin', {
  on: {
    keyDown: (ctx) => {
      // ctx 就是插件上下文
      console.info(ctx.editor, ctx.plugin);
    },
  },
});
```

### `editor.plugin`

需要访问其他插件时，使用该插件 descriptor 打开类型化 consumer portal。

```ts
const MyPlugin = definePlugin('myPlugin', {
  on: {
    keyDown: ({ editor }) => {
      const linkCtx = editor.plugin(LinkPlugin);
    },
  },
});
```

### `useEditor().plugin`

在 React 组件中，使用 `useEditor()` 获取编辑器，再调用 `plugin` 访问 consumer portal：

```ts
const MyComponent = () => {
  const { name } = useEditor().plugin(MyPlugin);
  
  return <div>{name}</div>;
};
```

## 插件上下文属性

### `editor`

当前的 `Editor` 实例：

```ts
const MyPlugin = definePlugin('myPlugin', {
  on: {
    commit: ({ editor }) => {
      console.info('编辑器内容:', editor.read.children());
    },
  },
});
```

### `plugin`

当前插件的配置：

```ts
const MyPlugin = definePlugin('myPlugin', {
  on: {
    keyDown: ({ plugin }) => {
      console.info('插件名称:', plugin.name);
    },
  },
});
```

### `store`

`store` 读取、更新和订阅当前插件的 editor-local state：

```ts
type MyPluginState = {
  myValue: string;
};

const initialState: MyPluginState = {
  myValue: 'default',
};

const MyPlugin = definePlugin('myPlugin', {
  initialState,  on: {
    click: ({ store }) => {
      const myValue = store.get('myValue');
      console.info('state 值:', myValue);
    },
  },
});
```

调用 `store.get()` 读取完整 state：

```ts
type MyPluginState = {
  value1: string;
  value2: string;
};

const initialState: MyPluginState = {
  value1: 'a',
  value2: 'b',
};

const MyPlugin = definePlugin('myPlugin', {
  initialState,  on: {
    click: ({ store }) => {
      console.info('完整 state:', store.get());
    },
  },
});
```

调用 `store.set(partial)` 合并字段：

```ts
type MyPluginState = {
  count: number;
};

const initialState: MyPluginState = {
  count: 0,
};

const MyPlugin = definePlugin('myPlugin', {
  initialState,  on: {
    click: ({ store }) => {
      store.set({ count: 1 });
    },
  },
});
```

调用 `store.set(recipe)` 通过 draft 更新：

```ts
type MyPluginState = {
  count: number;
};

const initialState: MyPluginState = {
  count: 0,
};

const MyPlugin = definePlugin('myPlugin', {
  initialState,  on: {
    click: ({ store }) => {
      store.set((state) => {
        state.count += 1;
      });
    },
  },
});
```

### `name`

插件的不可变能力标识。Element 的持久化标识来自 `schema.type`，primary mark
的持久化标识来自 `schema.key`：

```ts
const MyPlugin = definePlugin('myPlugin', {
  on: {
    keyDown: ({ name }) => {
      console.info('插件标识:', name);
    },
  },
});
```

### Property mutation

在 `update` 中传入 property patch object。Plate 从当前插件及其 required
dependencies 推断每个 key 和 value：

```ts
const LineHeightPlugin = definePlugin('lineHeight', {
  schema: {
    properties: {
      lineHeight: schema.elementProperty(property.number()),
    },
  },
  update: ({ tx }) => ({
    set: txLocate(false, (value: number) =>
      tx.nodes.set({ lineHeight: value })
    ),
    unset: () => tx.nodes.unset('lineHeight'),
  }),
});
```

Aliased property 使用 property handle 的精确 key 作为 computed object key。Prefix
family 和 cross-node behavior 放在语义 plugin update method 中。

### `defineFormats`

在 constructor 的 `formats` callback 中使用 `defineFormats`。该 callback 只有
`defineFormats` 与静态 `schema` binding，不能读取 live editor 或 store。运行时
mapping callback 接收冻结的 `pluginState`、mapping `registry`、schema view 和本次
conversion 的 context。

```ts
import { definePlugin, property } from 'platejs';

const StrongPlugin = definePlugin('strong', {
  formats: ({ defineFormats }) =>
    defineFormats({
      html: {
        decode: () => true,
        decodeOnly: true,
        match: [{ tag: 'strong' }],
      },
    }),  schema: { mark: property.boolean() },
});
```

Self mapping 使用 `defineFormats(map)`。Foreign contribution 使用
`defineFormats(TargetPlugin, map)`，Plate 会把 target 注入每个 HTML rule。
语义 key 是 `html`、`markdown` 和 `plainText`；HTML 使用单个 rule 或非空有序
rule tuple。Whole-payload browser MIME 处理通过 `dataTransferFormats` 注册。
不要标注 mapping callback 参数。

### 原生能力推断

编辑器字段直接放在 constructor 或分阶段 `.extend()` callback 中。
能力专属 helper 和 Plate plugin context 会一起推断。抽取 domain input，
不要抽取整个 Plate plugin context。

从 `platejs` import 的 `definePlugin` 只用于独立复用的
standalone Plate descriptor。完整示例见
[插件方法](/docs/plugin-methods#commands)。

## 视图状态 [#view-state]

同一个编辑器的所有视图共享插件 state。当两个 `EditorRoot` 显示同一个编辑器时，
属于某个视图显示内容的状态，例如哪些区块已折叠，应放入插件的 view store。使用
`initialViewState` 声明它。Plate 为每个视图创建一份，并为基础编辑器单独创建一份。

```ts title="focus-mode-plugin.ts" showLineNumbers
import { definePlugin } from 'platejs/react';

export type FocusModeViewState = {
  enabled: boolean;
};

export const FocusModePlugin = definePlugin('focusMode', {
  initialViewState: (): FocusModeViewState => ({
    enabled: false,
  }),
  api: ({ viewStore }) => ({
    isEnabled: () => viewStore.get('enabled'),
  }),
}).extend(({ viewStoreOf }) => ({
  read: ({ state }) => ({
    isEnabled: () => viewStoreOf(state).get('enabled'),
  }),
  update: ({ tx }) => ({
    toggle: () => {
      viewStoreOf(tx).set((draft) => {
        draft.enabled = !draft.enabled;
      });
    },
  }),
}));
```

`api` factory 接收 `viewStore`，它绑定到构建该 API 的视图。插件 portal 以
`editor.plugin(FocusModePlugin).viewStore` 暴露同一个 store。

`.extend` callback 没有 `viewStore`，因为一个插件定义服务所有视图。read 或命令
通过它接收的 state 或事务访问自己的视图。`viewStoreOf(state)` 返回该 state 所属
视图的 reader，`viewStoreOf(tx)` 返回该事务所在视图的 writer。`viewStoreOf`
不接受编辑器。

view store 的写入立即生效，因此同一个 update 中之后的读取能看到它。写入只通知
该视图的订阅者，也不会添加历史记录。重新配置插件会把每个视图的状态重置为
`initialViewState`。

每个 `EditorRoot` 是一个视图。同一个 `EditorRoot` 中的 `EditorContent` 共享它的
视图，因此共享同一个光标和同一份视图状态。同一个编辑器上的两个 `EditorRoot` 是
两个视图，各自有独立的状态。视图状态在其 `EditorRoot` 保持挂载期间一直存在，
重新挂载其中的 `EditorContent` 不会丢失它。`createEditor` 或 `useCreateEditor`
返回的基础编辑器不是视图。它有自己的状态，因此通过视图设置的值不会出现在基础
编辑器上。

在组件中，`useViewStore` 订阅 `useEditor()` 返回的视图的状态。其他视图中的写入
不会在这里运行 selector。

```tsx title="focus-mode-button.tsx" showLineNumbers
import { useEditor, useViewStore } from 'platejs/react';

import { FocusModePlugin } from './focus-mode-plugin';

export function FocusModeButton() {
  const { update } = useEditor().plugin(FocusModePlugin);
  const enabled = useViewStore(FocusModePlugin, (state) => state.enabled);

  return (
    <button
      aria-pressed={enabled}
      type="button"
      onClick={() => update.toggle()}
    >
      Focus mode
    </button>
  );
}
```
