---
title: 插件上下文
description: 理解并利用 Plate 插件中的插件上下文。
---

插件上下文是一个在所有插件方法中都可用的对象，提供了对编辑器实例、插件配置和实用函数的访问。

## 访问插件上下文

### 插件方法

插件上下文作为第一个参数在所有插件方法中可用：

```ts
const MyPlugin = createPlatePlugin({
  key: 'myPlugin',
  handlers: {
    onKeyDown: (ctx) => {
      // ctx 就是插件上下文
      console.info(ctx.editor, ctx.plugin);
    },
  },
});
```

### `getBasePlugin`

当您需要访问其他插件的上下文时，这个函数特别有用。它支持跨插件通信和交互，实现更复杂和相互关联的插件行为。

```ts
const MyPlugin = createPlatePlugin({
  key: 'myPlugin',
  handlers: {
    onKeyDown: ({ editor }) => {
      const linkCtx = getBasePlugin(editor, LinkPlugin);
    },
  },
});
```

### `useEditorPlugin`

在 React 组件中，您可以使用 `useEditorPlugin` 钩子来访问插件上下文：

```ts
const MyComponent = () => {
  const { editor, plugin, type } = useEditorPlugin(MyPlugin);
  
  return <div>{type}</div>;
};
```

## 插件上下文属性

### `editor`

当前的 `PlateEditor` 实例：

```ts
const MyPlugin = createPlatePlugin({
  key: 'myPlugin',
  handlers: {
    onChange: ({ editor }) => {
      console.info('编辑器内容:', editor.children);
    },
  },
});
```

### `plugin`

当前插件的配置：

```ts
const MyPlugin = createPlatePlugin({
  key: 'myPlugin',
  handlers: {
    onKeyDown: ({ plugin }) => {
      console.info('插件键名:', plugin.key);
    },
  },
});
```

### `store`

`store` 读取、更新和订阅当前插件的 editor-local state：

```ts
type MyPluginState = {
  myValue: string;
};

const initialState: MyPluginState = {
  myValue: 'default',
};

const MyPlugin = createPlatePlugin({
  initialState,
  key: 'myPlugin',
  handlers: {
    onClick: ({ store }) => {
      const myValue = store.get('myValue');
      console.info('state 值:', myValue);
    },
  },
});
```

调用 `store.get()` 读取完整 state：

```ts
type MyPluginState = {
  value1: string;
  value2: string;
};

const initialState: MyPluginState = {
  value1: 'a',
  value2: 'b',
};

const MyPlugin = createPlatePlugin({
  initialState,
  key: 'myPlugin',
  handlers: {
    onClick: ({ store }) => {
      console.info('完整 state:', store.get());
    },
  },
});
```

调用 `store.set(partial)` 合并字段：

```ts
type MyPluginState = {
  count: number;
};

const initialState: MyPluginState = {
  count: 0,
};

const MyPlugin = createPlatePlugin({
  initialState,
  key: 'myPlugin',
  handlers: {
    onClick: ({ store }) => {
      store.set({ count: 1 });
    },
  },
});
```

调用 `store.set(recipe)` 通过 draft 更新：

```ts
type MyPluginState = {
  count: number;
};

const initialState: MyPluginState = {
  count: 0,
};

const MyPlugin = createPlatePlugin({
  initialState,
  key: 'myPlugin',
  handlers: {
    onClick: ({ store }) => {
      store.set((state) => {
        state.count += 1;
      });
    },
  },
});
```

### `type`

与插件关联的节点类型：

```ts
const MyPlugin = createPlatePlugin({
  key: 'myPlugin',
  type: 'myNodeType',
  handlers: {
    onKeyDown: ({ type }) => {
      console.info('节点类型:', type);
    },
  },
});
```

### `defineCodecs`

在 constructor 的 `codecs` callback 中使用 `defineCodecs`。它是 codec map
唯一的 inference anchor：

```ts
import { createBasePlugin, property } from 'platejs';

const StrongPlugin = createBasePlugin({
  codecs: ({ defineCodecs }) =>
    defineCodecs({
      'text/html': {
        decode: () => true,
        decodeOnly: true,
        match: [{ tag: 'strong' }],
      },
    }),
  key: 'strong',
  schema: { mark: property.boolean() },
});
```

Self/product map 使用 `defineCodecs(map)`。Foreign contribution 使用
`defineCodecs(TargetPlugin, map)`，Plate 会把 target 注入每个 HTML rule。
Map 保持 MIME-keyed；`'text/html'` 使用单个 rule 或非空有序 rule tuple。
不要直接声明 codec map，也不要标注 callback 参数。

### Extension inference

Constructor 和 `.extend()` callback 直接返回 extension object。Plate context
保持在这些 callback 内，嵌套 command、input、state、transaction、dependency
和 plugin state 就能获得 contextual typing。抽取 domain input，不要抽取
Plate plugin context。

从 `@platejs/plite` import 的 `defineEditorExtension` 只用于独立复用的
standalone Plite descriptor。完整示例见
[插件方法](/docs/plugin-methods#install-plite-capabilities)。
