---
title: 受控编辑器值
description: 控制初始值、持久化、替换和异步初始化。
---

Plate 不是普通的受控文本输入。编辑器拥有内容、选择、历史、插件状态和规范化。本指南关注安全的控制点：初始值、变更持久化、显式替换、重置和延迟初始化。

<Callout type="warning" title="不要控制每一次按键">
  不要把 `editor.children` 镜像到 React state 后在每次变更时再传回编辑器。
  这会和 Plite 的选择、历史和规范化相冲突，把普通输入变成整篇文档替换。
</Callout>

| 目标 | API |
| --- | --- |
| 设置初始内容。 | `usePlateEditor` 或 `createPlateEditor` 的 `initialValue`。 |
| 持久化编辑。 | `<Plate onValueChange>` 或 `<Plate onCommit>`。 |
| 从编辑器外部替换内容。 | `editor.update((tx) => tx.value.replace({ children: value }))`。 |
| 恢复初始内容。 | `editor.update((tx) => tx.value.replace({ children: initialValue }))`。 |
| 延迟初始化。 | `skipInitialization: true` 加一次显式 `editor.update(...)`。 |

### 延迟初始化

当协作层、多步骤加载器或异步请求拥有启动时机时，使用 `skipInitialization`。数据准备好后，用一次事务替换内容并设置选择。完整文档替换会在 schema 适配前运行每个插件的 `transformInitialValue`，因此功能插件拥有的输入迁移与同步初始化使用同一路径。

```tsx
function AsyncControlledEditor() {
  const [initialValue, setInitialValue] = React.useState();
  const [loading, setLoading] = React.useState(true);
  const editor = usePlateEditor({
    skipInitialization: true,
  });

  React.useEffect(() => {
    // 模拟异步获取
    setTimeout(() => {
      setInitialValue([
        {
          type: 'paragraph',
          children: [{ text: '已加载异步值！' }],
        },
      ]);
      setLoading(false);
    }, 1000);
  }, []);

  React.useEffect(() => {
    if (!loading && initialValue) {
      editor.update((tx) => {
        tx.value.replace({ children: initialValue });
        const end = tx.points.end([]);

        if (end) tx.selection.set(end);
      });
    }
  }, [loading, initialValue, editor]);

  if (loading) return <div>加载中…</div>;

  return (
    <Plate editor={editor}>
      <EditorContainer>
        <Editor />
      </EditorContainer>
    </Plate>
  );
}
```
