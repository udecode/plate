Plate 保存编辑器原生 JSON。Plate 定义树结构，Plate 插件添加由 Schema 校验的属性，Codec 负责与外部格式互转。

## 核心树

~~~ts
type Text = { text: string };
type Element = {
  type: string;
  children: Array<Element | Text>;
};
type EditorDocumentValue = {
  children: Element[];
  roots?: Record<string, Element[]>;
  meta?: Record<string, unknown>;
};
~~~

功能属性平铺在所属节点上。运行时 NodeKey 不写入文档。

文档顶层只包含 `children`、`roots`、`meta` 和 `records`。`records` 保存插件声明的键控记录集，例如审阅记录。所有加载路径都会拒绝其他顶层字段，应用数据请存入 `meta`。

## 应用 Schema

~~~ts
type PersistedDocumentInput = {
  document: EditorDocumentValue;
  schema: { id: string; version: number; fingerprint: string };
  selection?: Selection | 'start' | 'end';
};
~~~

应用 Schema 决定合法的元素类型、mark、属性、内容和 root。Plate 的标准非空段落语法
不需要 `root`。使用已有的描述符感知内容构造器声明自定义主 root：

~~~ts
const EditorSchema = {
  root: schema.content.element(SectionPlugin, { min: 1 }),
} as const;
~~~

最小值必须显式提供正整数。描述符必须匹配已安装的插件；
`schema.content.elements` 的第一个描述符是默认值。Root 语法参与 schema 指纹和生成的
`Value`，基数仍由运行时校验。

`defineDocumentMigrations` 将递增迁移链绑定到应用 Schema。运行时和 CLI 都在 Schema
适配前调用同一个 `migrateDocument`。命名 Schema 的 root 语法变化时，应递增版本并迁移
已存储文档。迁移步骤的文档只包含 `children`、`roots`、`meta` 和 `records`；其他已存储的顶层字段
会进入该步骤的 `legacy` 记录，由步骤提升到 `meta`，没有任何步骤提升的字段会被
`migrateDocument` 拒绝。`migrateV54` 将冻结的 v53.3.6 结构迁移到 v54，包括最终 AST
约束，并把每个旧代码块的行元素序列合并为一个带换行符的文本子节点。如果链接或媒体存储的
URL 被当前 Schema 拒绝，迁移会将其链接文本、标题、`alt` 文本或文件名保留为普通内容。已存储的
提及、表情、斜杠命令和脚注输入节点会变为普通文本形式的触发符与已输入的查询。以文本保存的行高
会转换为数字，例如 `"107%"` 变为 `1.07`，`"150%"` 或 `"1.5em"` 变为 `1.5`。迁移会丢弃已保存的
`"normal"`、`"12pt"` 等长度、零、负数和无法解析的文本，且不报告，这些块随后跟随主题行高。
待处理的 v53 建议会转换为审阅修改。当目标 Schema 会重塑被建议的节点，或文档在拒绝所有待处理
修改后无法适配目标 Schema 时，迁移会拒绝该文档，例如一条删除了目标未声明属性的建议。升级前请在
Plate v53 中接受或拒绝这些建议。

`migrateListIdentity` 为每个列表项保存 `listId`，每段相邻项一个 id，使不带列表 id 保存的文档保持原有编号。把它注册在首次包含列表插件 `listId` 和 `listLevels` 的 Schema 版本下。

### 已保存的字重

字重由加粗负责，Plate 没有字重标记。`migrateV54` 不转换任何已保存的 `fontWeight`，因为 v53
把已保存的字重叠加在加粗之上绘制。目标 Schema 没有 `fontWeight` 文本属性时，会以
`Unknown text property "fontWeight" in closed editor schema.` 拒绝每个已保存的字重，包括文本叶子、
已保存选区的标记，以及设置或删除字重的待处理建议。

有已保存字重的应用可以选择以下两种方式之一：

- 声明自己的 `fontWeight` 文本属性。所有值原样加载，应用自行负责 `bold` 之外的这份字重记录。
- 在 `migrateDocument` 之前移除字重。下面的预处理保留 v53 是否把文本绘制为加粗。`bold`、`bolder`
  和 600 到 1000 变为 `bold`，不区分大小写；`normal`、`lighter` 和 1 到 599 会同时去掉两者。它会
  拒绝无法读取的字重，例如 `inherit`、CSS 变量或 `0x2bc`。对原始 v53 值，它也会拒绝 `h1` 到 `h6`
  或 `th` 中的细字重，因为 v53 把它绘制得比该块的加粗更细。它还会拒绝带有待处理格式修改的加字重叶子，
  以及任何修改字重本身的待处理修改，
  因为两者一经转换，有人拒绝时就会抹掉原本绘制出的加粗。

~~~ts
type Json = Record<string, unknown>;

const readWeight = (weight: unknown) => {
  const value = String(weight).trim().toLowerCase();

  if (value === 'bold' || value === 'bolder') return 'heavy';
  if (value === 'normal' || value === 'lighter') return 'light';
  if (!/^\+?(\d+|\d*\.\d+)(e[+-]?\d+)?$/.test(value)) return null;

  const number = Number(value);

  if (number >= 1 && number <= 1000) return number >= 600 ? 'heavy' : 'light';

  return null;
};

const boldBlocks = new Set(['h1', 'h2', 'h3', 'h4', 'h5', 'h6', 'th']);

const touchesWeight = (change: Json) =>
  change.key === 'fontWeight' ||
  ['properties', 'newProperties'].some((key) =>
    Object.hasOwn(change[key] ?? {}, 'fontWeight')
  );

const stripLeaf = (node: Json, mayDrawBold: boolean): Json => {
  const pending = [
    ...Object.entries(node)
      .filter(([key]) => key.startsWith('suggestion_'))
      .map(([, value]) => value as Json)
      .filter((value) => value?.type === 'update'),
    ...((Array.isArray(node.authored) ? node.authored : []) as Json[]).filter(
      (mark) => mark?.kind === 'format'
    ),
  ];

  if (
    pending.length > 0 &&
    (Object.hasOwn(node, 'fontWeight') || pending.some(touchesWeight))
  ) {
    throw new Error(
      'Settle format changes on weighted text before the upgrade.'
    );
  }
  if (!Object.hasOwn(node, 'fontWeight')) return node;

  const { bold: _bold, fontWeight, ...rest } = node;
  const weight = readWeight(fontWeight);

  if (!weight || (weight === 'light' && mayDrawBold)) {
    throw new Error('Bold cannot keep how v53 drew this font weight.');
  }

  return weight === 'heavy' ? { ...rest, bold: true } : rest;
};

const stripTree = (node: Json, mayDrawBold: boolean): Json => {
  if (typeof node.text === 'string') return stripLeaf(node, mayDrawBold);

  const inside = mayDrawBold || boldBlocks.has(node.type as string);
  const next = { ...node };

  for (const key of ['children', 'caption']) {
    if (Array.isArray(node[key])) {
      next[key] = (node[key] as Json[]).map((child) =>
        stripTree(child, inside)
      );
    }
  }

  return next;
};

const stripNode = (node: Json) => stripTree(node, false);

migrateDocument(value.map(stripNode), { migrations, source: 53 });
~~~

原始 v53 值使用 `source: 53`。持久化信封需要映射 `document.children`、`document.roots` 中的每个数组
以及已保存选区的 `marks`，其余字段与 `document.meta` 按原样保留，并省略 `source`。信封形式会拒绝
所有细字重，包括已保存选区的插入字重，因为基于 v2 源码构建的应用使用自己的块类型，预处理无法判断其中
哪些会绘制为加粗：

~~~ts
const stripEnvelope = (stored: Json): Json => {
  const document = { ...(stored.document as Json) };
  const selection = stored.selection as Json | null | undefined;

  const strip = (node: Json) => stripTree(node, true);

  document.children = (document.children as Json[]).map(strip);
  if (document.roots) {
    document.roots = Object.fromEntries(
      Object.entries(document.roots as Record<string, Json[]>).map(
        ([name, children]) => [name, children.map(strip)]
      )
    );
  }

  return {
    ...stored,
    document,
    ...(selection?.marks
      ? {
          selection: {
            ...selection,
            marks: stripLeaf(selection.marks as Json, true),
          },
        }
      : {}),
  };
};

migrateDocument(stripEnvelope(stored) as PersistedDocumentInput, {
  migrations,
});
~~~

待处理插入或删除中的加字重叶子会被转换，因为无论接受还是拒绝都保留 v53 是否把它绘制为加粗。

Markdown 也可能保存字重，形式是 `<span style="font-weight: bold;">` 片段。没有插件认领字重片段。
在装有样式插件的编辑器中，只含字重的片段会使解析被拒绝，与其他样式并存的字重会被丢弃且不报告。
请在解析前改写这些片段，或保留一个声明 `fontWeight` 并带有 Markdown 映射的应用插件。

## 代表性功能结构

Plate 包定义局部节点结构，应用安装的插件元组和 Schema 决定完整语法。需要提交精确 `Value` 类型时使用 `plate generate`。

~~~ts
type HeadingElement = {
  type: 'heading';
  level: 1 | 2 | 3 | 4 | 5 | 6;
  children: Text[];
};
type CodeBlockElement = {
  type: 'codeBlock';
  language?: string;
  children: [Text];
};
type TableElement = {
  type: 'table';
  columnWidths?: Array<number | null>;
  children: TableRowElement[];
};
type TableRowElement = {
  type: 'tableRow';
  height?: number;
  children: TableCellElement[];
};
type TableCellElement = {
  type: 'tableCell';
  backgroundColor?: string;
  borders?: Partial<Record<
    'top' | 'right' | 'bottom' | 'left',
    { color?: string; style?: string; width?: number }
  >>;
  colSpan?: number;
  rowSpan?: number;
  header?: boolean;
  children: Element[];
};
type ListItemProperties = {
  listType: 'bulleted' | 'numbered' | 'task';
  listStyle?: string;
  listStart?: number;
  listRestart?: number;
  checked?: boolean;
  indent?: number;
};
type DateElement = {
  type: 'date';
  value: string;
  children: Text[];
};
type MentionElement = {
  type: 'mention';
  ref: string;
  label?: string;
  children: Text[];
};
type FootnoteReferenceElement = {
  type: 'footnoteReference';
  ref: string;
  children: Text[];
};
type EquationElement = {
  type: 'equation' | 'inlineEquation';
  latex: string;
  children: Text[];
};
type ImageElement = {
  type: 'image';
  url: string;
  naturalWidth?: number;
  naturalHeight?: number;
  children: Text[];
};
type VideoElement = {
  type: 'video';
  url: string;
  provider?: string;
  children: Text[];
};
~~~

listStart 保存条件作者意图：仅在该项是有序序列第一项时生效，被忽略时仍保留。listRestart 强制该项开启新序列。editor.read.list.ordinal(element) 计算显示编号，普通编辑不会重写后续节点。

列表起始值和重启值是有符号安全整数。元素 `id` 标识一个持久化节点实例，`ref` 表示持久化关联，运行时身份继续使用 `NodeKey`。

表格列宽只有一个所有者：TableElement.columnWidths。HTML 单元格宽度在导入时归一到该数组，`null` 表示未知宽度。图片的 naturalWidth 和 naturalHeight 保存源图片尺寸；媒体 width 保存用户选择的渲染宽度。媒体标题直接存于 children。上传草稿以 `{ type: 'upload', kind, children }` 持久化到 Plate JSON；`File`、任务、进度和错误保留在编辑器状态。上传完成后，普通媒体节点保存持久 URL。外部 HTML、Markdown 和静态输出会省略未完成草稿。

## 与标准的关系

| 模型 | Plate 的关系 |
| --- | --- |
| Slate | 使用相同的实用后代结构，并增加编译后的应用 Schema。 |
| ProseMirror | 采用相同的 Schema 优先原则，但保留扁平的编辑器原生 JSON。 |
| UNIST | 只共享树术语；Plate 不要求 position 或 data。 |
| MDAST | Markdown 外部 AST。Codec 将 heading.level 映射到 depth，将 codeBlock.language 映射到 lang。 |
| Portable Text | 可移植性参考，不是 Plate 的存储格式。 |
| Block Protocol | 块嵌入协议，不是富文本 AST 合约。 |

Codec 和适配器负责将文档契约映射为外部格式。

## 结构约束

Root 包含块。元素包含块子节点或内联/文本子节点，具体语法由编译后的 Schema 决定。内容允许文本的元素不会为空，因此清空的行会保留一个空文本作为锚点，void 也会保留其内部的空文本。只允许块的内容可以为空。属性相同的相邻文本叶子会合并，内联节点两侧的文本间隔提供有效的光标位置。

空行不保存格式。在空光标处输入的文本使用选区的待定 mark，因此光标停留在清空的粗体行时，输入仍为粗体；光标离开或文档重新加载后，该行变为普通文本。`createEditor` 以同样的规范形式加载初始值，像编辑一样合并文本、补全间隔并添加锚点。

Mark 是文本节点上由 Schema 声明的属性。Decoration 可以把文本节点拆分为渲染叶子片段，而不改变这些持久化属性。校验和适配请参阅 [Schema](/docs/schema)，Schema 合法写入之后的语义修正请参阅[编辑行为](/docs/editing-behavior#normalize-behavior)。
