Plate 提供 UI 优先、无头 React、React 服务端组件和 Node.js 四条安装路径。需要完整编辑器界面时，从 Plate UI 开始；需要自行控制渲染或只在服务端处理内容时，选择对应的底层指南。

## 环境要求

| 使用范围 | 要求 |
| --- | --- |
| Plate React API 和 Plate UI | React 和 React DOM 19.2 或更高版本。Plate 的 React 包将 `>=19.2.0` 声明为 peer dependency。 |
| 复制到项目中的 Plate UI 源码 | 在拥有这些组件的应用中启用 React Compiler。Registry 组件依赖 Compiler 负责记忆化。shadcn 命令会安装包和文件，但不会配置构建工具；请按框架参考 [React Compiler 安装指南](https://react.dev/learn/react-compiler/installation)。 |
| 已发布的 Plate 包 | 导入包代码时不需要由应用再次运行 Compiler。Plate 在发布前已针对 React 19 runtime 编译这些包。 |

这两个边界不能混为一谈：React 19.2 是包兼容性的最低版本；React Compiler 配置属于构建 Plate UI 本地源码的应用。

## 客户端集成

### 方案一：使用 Plate UI（推荐）

如果您正在使用或计划使用 [shadcn/ui](https://ui.shadcn.com/)，推荐通过 [Plate UI](/docs/plate-ui) 获取开箱即用的富文本编辑器体验。

<Steps>

#### 安装 Plate UI

首先按照 **[Plate UI 安装指南](./installation/plate-ui)** 进行操作。该指南包含核心依赖安装和 Plate UI 组件配置说明。

#### 基础使用

完成 Plate UI 安装后，根据您的 React 应用类型选择对应指南：

*   **[Next.js](./installation/next)** - 服务端渲染应用
*   **[React](./installation/react)** - 客户端应用（Vite/React Router 等）

</Steps>

### 方案二：手动配置

若项目未使用 shadcn/ui 或 Tailwind CSS，或需要框架无关方案，请参考 **[手动安装指南](./installation/manual)** 获取详细配置说明。

<Callout type="note">
  后续仍可将 Plate UI 组件集成到手动配置的项目中。
</Callout>
