This example shows the collaboration boundary: Plate renders the editor surface,
and the app owns the Yjs provider, transport, persistence, authentication, room
naming, and cursor data.

## Runtime Shape

| Piece | Owner | Notes |
| --- | --- | --- |
| `createYjsExtension` | `@platejs/yjs` | Binds a shared `Y.Doc` and provider wrapper to Plite operations. |
| Provider wrapper | App infrastructure | Wrap Hocuspocus, WebRTC, IndexedDB, or custom transport as `YjsProviderLike`. |
| Room state | App | Keep room ids, auth tokens, and persistence outside Plate packages. |
| Connection commands | `tx.yjs` | Connect, disconnect, reconnect, publish selection, clear selection, undo, and redo. |
| Connection reads | `state.yjs` | Read connected, synced, and provider status from `editor.read`. |

Use the full [Yjs guide](/docs/yjs) when wiring a real provider.

## Remote Cursors
