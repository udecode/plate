## 导出格式

| 格式 | 实现 | 输出 |
| ---- | ---- | ---- |
| HTML | `platejs/static` 的 `renderStaticHtml(model, { component: EditorStatic, projection })` | `plate.html` |
| Markdown | `model.api.markdown.serialize({ projection })` | `plate.md` |
| Word | `platejs/docx/export` 的 `exportDocx(model, { component: EditorStatic, projection, stylesheet: DOCX_EXPORT_STYLES })` | `plate.docx` |

所有格式都从 `useModelEditor()` 捕获同一份完整 document 和明确的 authored
projection。导出读取 model，而不是 DOM，因此 selection、placeholder 和 review
decoration 不会进入文件。当前 editor 提供已编译的 schema、format mapping 和 static
component 绑定；导出不会创建第二个 conversion editor。

HTML 文件内联应用自身的 stylesheet，并复制页面的 `body` class。跨域
stylesheet 保留为 link。

## Suggestions

当 document 包含未解决的 [suggestion](/docs/suggestion) 时，菜单显示
**Unresolved suggestions** 选项：

| 选项 | Projection | 结果 |
| ---- | ---------- | ---- |
| Include suggested changes | `proposed` | 应用 pending suggestion 的 document |
| Exclude suggested changes | `accepted` | 不含 pending suggestion 的 document |

初始选项跟随已挂载的 view。HTML、Markdown 和 Word 使用同一个选择。
**Export as Word with tracked changes** 使用 `review`，把 pending suggestion
写成 Word revision。Conflict 无法忠实表示为 Word revision，因此 review
导出会返回错误，直到 conflict 被解决。

没有未解决 suggestion 时，Word 导出使用 `review`。保留且未修改的已导入
DOCX 可以逐字节返回。每个 exporter 都返回 diagnostic，菜单会显示对应的
warning 或 error toast。
