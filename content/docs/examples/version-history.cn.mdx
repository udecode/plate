此示例把 editor 文档的快照保存为版本。编辑文本，保存一个版本以与上一个版本比较，或恢复任意已保存的版本。

带评论的应用版本预览与恢复请参阅[评论的历史版本](/cn/docs/comment#历史版本)。

## 用法

- `editor.read.value()` 把完整文档捕获为一个版本。
- `tx.value.replace(revision)` 以一次可撤销的更新恢复已保存的版本。
- `platejs/diff` 的 `compare(...)` 比较两个不可变的已保存版本，不修改 editor。
- 复制的 `Diff` 组件显示比较 group、effect、筛选和导航。
- 复制的 `BasicMarksKit` 为可编辑文档提供富文本 mark。

## 比较保存的版本

演示会先捕获初始快照。编辑文档后点击 **Save revision**，即可比较最近两个快照。再次保存会开始新的比较，并取消过时的那一个。比较结果只供读取。如需将通过校验的比较结果转成待审 proposal，使用 [`proposeAuthoredComparison(...)`](/cn/docs/authored-changes#导入比较得到的版本)。

## 恢复版本

**Restore** 以一次更新把文档替换为该已保存版本：

```tsx
editor.update((tx) => tx.value.replace(revision));
```

已保存的版本保存在应用状态中，因此恢复其中一个不会影响其他版本。

## 持久化版本

把每个 `editor.read.value()` 快照作为一个文档保存。要把某个版本加载到新 editor，请将它作为 `initialValue` 传入：

```tsx
const saved = editor.read.value();

const reloaded = createEditor({
  plugins: BasicMarksKit,
  initialValue: saved,
});
```

新 editor 从空的本地 undo 和 redo stack 开始。如果文档包含评论，用 `comments.toJSON()` 将 `CommentsJSON` 与同一版本保存，通过 `initialComments` 加载；文档 undo 不会回退讨论。

要提议和审阅修改而不是替换文档，请参阅 [Authored Changes](/cn/docs/authored-changes)。
