`platejs/resizable/react` 导出两个 headless React 组件及其类型。包负责指针、
触摸、键盘、RTL、ARIA 和临时 resize 状态；registry 组件负责样式和编辑器
持久化。

## 安装

```bash
npm install platejs @tanstack/react-virtual
```

## 使用

```tsx
import type { PlateElementProps } from 'platejs/react';
import { PlateElement, useEditor, usePath } from 'platejs/react';
import { ImagePlugin } from 'platejs/media/react';
import { Resizable, ResizeHandle } from 'platejs/resizable/react';

export function ImageElement(props: PlateElementProps<typeof ImagePlugin>) {
  const editor = useEditor();
  const path = usePath();

  return (
    <PlateElement {...props}>
      <div contentEditable={false}>
        <Resizable
          align="center"
          minWidth={120}
          width={props.element.width}
          onResizeEnd={(width) =>
            editor.plugin(ImagePlugin).update.set({ width }, { at: path })
          }
        >
          <ResizeHandle direction="left" />
          <img
            alt={props.element.alt}
            src={props.element.url}
            style={{ width: '100%' }}
          />
          <ResizeHandle direction="right" />
        </Resizable>
      </div>
      {props.children}
    </PlateElement>
  );
}
```

`Resizable` 拥有 nested handle 使用的私有 family context。公共 API 不包含
provider 或原始 resize store。

## `Resizable`

<API name="Resizable">
<APIOptions type="ResizableProps">
  <APIItem name="align" type="'center' | 'left' | 'right'" optional>
    控制 resize 方向计算。默认为 `center`。
  </APIItem>
  <APIItem name="maxWidth" type="ResizeLength" optional>
    最大宽度。默认为 `100%`。
  </APIItem>
  <APIItem name="minWidth" type="ResizeLength" optional>
    最小宽度。默认为 `0`。
  </APIItem>
  <APIItem name="onResizeEnd" type="(width: ResizeLength) => void" optional>
    将最终宽度提交给功能所有者。
  </APIItem>
  <APIItem name="width" type="ResizeLength" optional>
    当前宽度。默认为 `100%`。
  </APIItem>
</APIOptions>
</API>

## `ResizeHandle`

<API name="ResizeHandle">
<APIOptions type="ResizeHandleProps">
  <APIItem name="direction" type="ResizeDirection" optional>
    Resize 边。默认为 `left`。
  </APIItem>
  <APIItem name="initialSize" type="number" optional>
    初始尺寸。省略时从父元素读取。
  </APIItem>
  <APIItem name="onResize" type="(event: ResizeEvent) => void" optional>
    覆盖最近 `Resizable` 的 callback。
  </APIItem>
</APIOptions>
</API>

Handle 渲染为 `slider`，只读模式下不渲染，拖动期间监听元素所属的窗口，并支持
方向键。按住 Shift 可使用更大的键盘步长。指针取消、窗口失焦、组件卸载、只读状态
变化或外部宽度变化都会丢弃预览。ARIA 数值和边界使用像素，值文本保留配置的单位。

## 类型

| API | 定义 |
| --- | --- |
| `ResizeDirection` | `'bottom'`、`'left'`、`'right'` 或 `'top'`。 |
| `ResizeLength` | `number` 或 `string`；像素值如 `120`、`"120px"`，或 `"50%"` 等百分比字符串。 |
| `ResizeEvent` | `{ delta; direction; finished; initialSize }` |
