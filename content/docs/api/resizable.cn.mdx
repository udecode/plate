`@platejs/resizable` 导出两个 headless React 组件和长度工具。包负责指针、
触摸、键盘、RTL、ARIA 和临时 resize 状态；registry 组件负责样式和编辑器
持久化。

## 安装

```bash
npm install @platejs/resizable
```

## 使用

```tsx
import type { PlateElementProps } from 'platejs/react';
import { PlateElement, useEditor } from 'platejs/react';
import { Image, ImagePlugin } from '@platejs/media/react';
import { Resizable, ResizeHandle } from '@platejs/resizable';

export function ImageElement(props: PlateElementProps<typeof ImagePlugin>) {
  const editor = useEditor();

  return (
    <PlateElement {...props}>
      <Resizable
        align="center"
        width={props.element.width}
        onResizeEnd={(width) =>
          editor.plugin(ImagePlugin).update.set(
            { width },
            { at: props.element }
          )
        }
      >
        <ResizeHandle direction="left" />
        <Image alt={props.element.alt} />
        <ResizeHandle direction="right" />
      </Resizable>
      {props.children}
    </PlateElement>
  );
}
```

`Resizable` 拥有 nested handle 使用的私有 family context。公共 API 不包含
provider 或原始 resize store。

## `Resizable`

<API name="Resizable">
<APIOptions type="ResizableProps">
  <APIItem name="align" type="'center' | 'left' | 'right'" optional>
    控制 resize 方向计算。默认为 `center`。
  </APIItem>
  <APIItem name="maxWidth" type="ResizeLength" optional>
    最大宽度。默认为 `100%`。
  </APIItem>
  <APIItem name="minWidth" type="ResizeLength" optional>
    最小宽度。默认为 `92`。
  </APIItem>
  <APIItem name="onResizeEnd" type="(width: ResizeLength) => void" optional>
    将最终宽度提交给功能所有者。
  </APIItem>
  <APIItem name="width" type="ResizeLength" optional>
    当前宽度。默认为 `100%`。
  </APIItem>
</APIOptions>
</API>

## `ResizeHandle`

<API name="ResizeHandle">
<APIOptions type="ResizeHandleProps">
  <APIItem name="direction" type="ResizeDirection" optional>
    Resize 边。默认为 `left`。
  </APIItem>
  <APIItem name="initialSize" type="number" optional>
    初始尺寸。省略时从父元素读取。
  </APIItem>
  <APIItem name="onResize" type="(event: ResizeEvent) => void" optional>
    覆盖最近 `Resizable` 的 callback。
  </APIItem>
</APIOptions>
</API>

Handle 渲染为 `slider`，只读模式下不渲染，拖动期间监听 `window`，并支持
方向键。按住 Shift 可使用更大的键盘步长。

## 类型和长度工具

| API | 定义 |
| --- | --- |
| `ResizeDirection` | `'bottom' | 'left' | 'right' | 'top'` |
| `ResizeLength` | `number | \`${number}%\`` |
| `ResizeEvent` | `{ delta; direction; finished; initialSize }` |
| `resizeLengthClamp` | 在混合约束下 clamp 像素或百分比长度。 |
| `resizeLengthToRelative` | 将像素转换为百分比。 |
| `resizeLengthToStatic` | 将百分比转换为像素。 |
