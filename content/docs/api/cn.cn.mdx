`@udecode/cn` 导出一个 class name 工具，并重新导出
`@udecode/react-utils`。

## 安装

```bash
npm install @udecode/cn
```

## 使用

```tsx
import { cn } from '@udecode/cn';

export function Button({
  active,
  className,
  ...props
}: React.ComponentProps<'button'> & { active?: boolean }) {
  return (
    <button
      className={cn(
        'inline-flex rounded-md px-3 py-2',
        active && 'bg-accent',
        className
      )}
      {...props}
    />
  );
}
```

直接编写具体组件。默认属性、variant 和 React 19 `ref` 属性应保留在组件
所有者中，而不是隐藏在组件工厂里。

## API

<API name="cn">
<APIParameters>
  <APIItem name="...inputs" type="CxOptions">
    `class-variance-authority` 的 `cx` 支持的条件 class 值。
  </APIItem>
</APIParameters>
<APIReturns type="string">
  由 `cx` 合并并通过 `tailwind-merge` 规范化的 class name。
</APIReturns>
</API>
