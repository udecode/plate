`NodeApi` 包含纯节点树函数。编辑器拥有的遍历和位置解析位于
`editor.read.nodes` 下。

`NodeApi.matches(node, match, path?)` 对节点及其路径运行谓词。

## 常用方法

从 `platejs` 导入 `NodeApi`。

| 方法 | 用途 |
| --- | --- |
| `NodeApi.get(root, path)` | 读取节点；无效路径会抛出错误。 |
| `NodeApi.getIf(root, path)` | 读取节点或返回 `undefined`。 |
| `NodeApi.children(root, path)` | 遍历直接子节点及其路径。 |
| `NodeApi.descendants(root)` | 遍历后代节点及其路径。 |
| `NodeApi.texts(root)` | 遍历文本节点。 |
| `NodeApi.string(root)` | 拼接后代文本，不添加块分隔符。 |
| `NodeApi.has(root, path)` | 判断路径是否存在。 |

当前编辑器查询使用[编辑器 API](/docs/api/editor-api)，以保留根、Schema
和快照上下文。

## NodeEntry

`NodeEntry<T>` 是只读的 `[T, Path]` 元组，由节点和相对于遍历根的路径组成。
`NodeApi.children`、`NodeApi.descendants`、`NodeApi.texts` 等遍历方法返回这类条目。

```ts
import type { NodeEntry, Text } from 'platejs';

type TextEntry = NodeEntry<Text>;
```

路径描述节点在该次读取中的位置。需要跨编辑追踪位置时，使用
[锚点](/docs/api/anchor)；实时节点身份使用 `NodeKey`。
