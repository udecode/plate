---
title: 编辑器转换
description: 修改 Plate 编辑器状态的事务方法。
---

Plate 的修改方法位于 `editor.update` 下。单次修改使用直接分组方法，多次
原子修改使用回调形式。

```ts
editor.update.text.insert("Hello");

editor.update((tx) => {
  tx.nodes.set({ type: "heading" });
  tx.text.insert("Title");
});
```

## 方法分组

| 分组 | 用途 |
| --- | --- |
| `tx.text` / `tx.marks` | 文本与标记编辑。 |
| `tx.nodes` | 插入、删除、移动、拆分、合并和设置节点属性。 |
| `tx.selection` | 设置、折叠和清空模型选区。 |
| `tx.fragment` / `tx.slice` | 替换闭合内容或适配带开放边界的内容。 |
| `tx.changes` | 导入适配器或历史使用的规范文档变更。 |

回调必须同步完成。使用 `at` 显式指定其他位置，省略时使用当前选区。
读取事务内状态时使用 `tx`，以观察同一草稿中的写入。
参见[事务](/docs/transactions)与[编辑行为](/docs/editing-behavior)。

## 替换整个节点

`slice.replace` 和 `fragment.replace` 的 `at` 接受位置、活动节点或
`SelectionApi.nodes(...)` 创建的节点选区。显式节点选区会替换节点本身，
不会继承被移除节点的属性或运行时 key。

```ts
import { ContentSlice, SelectionApi } from 'platejs';

editor.update.slice.replace(
  ContentSlice.closed([{ type: 'paragraph', children: [{ text: 'Paste' }] }]),
  { at: SelectionApi.nodes([[0]]) }
);
```

选中的节点必须是同一个父节点下连续的兄弟节点。目标不存在、不连续或内容
无法通过 schema 适配时，返回 `false`，不替换其中任何成员。没有 root 的
节点选区始终指向主文档，在具名根视图中也是如此。

单次 `editor.update.slice.replace` 和 `editor.update.fragment.replace`
会运行命令处理器与[目标准备读取](/docs/api/core/plate-plugin)。
回调中的 `tx.slice.replace`、`tx.fragment.replace` 和独立的
`editor.read.slice.fit` 直接适配内容，不运行这些命令策略。
