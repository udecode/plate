`@udecode/react-utils` 提供 Plate UI 包使用的小型 React 19 工具。它也从
`platejs/react` 和 `@udecode/cn` 重新导出。

## 安装

```bash
npm install @udecode/react-utils
```

## 组件

| 组件 | 功能 |
| --- | --- |
| `PortalBody` | 将 children portal 到 `element ?? document.body`；没有 DOM 容器时直接渲染 children。 |
| `Box` | 渲染 `div`、`as` 组件，或在 `asChild` 为 true 时渲染 Radix `Slot`。 |
| `Text` | 渲染 `span`、`as` 组件，或在 `asChild` 为 true 时渲染 Radix `Slot`。 |
| `MemoizedChildren` | 对只有 `children` 属性的 fragment 进行 memo。 |

`Box` 和 `Text` 将 `ref` 作为普通 React 19 属性接收。

```tsx
import { Box, Text } from '@udecode/react-utils';

export function Status() {
  return (
    <Box className="rounded-md border p-3">
      <Text as="strong">Connected</Text>
    </Box>
  );
}
```

## Ref 与 Effect 工具

| API | 功能 |
| --- | --- |
| `composeRefs(...refs)` | 将同一个节点写入 callback ref 和 ref object，并支持 ref cleanup callback。 |
| `useComposedRef(...refs)` | 返回 memo 后的组合 ref callback。 |
| `useStableFn(fn, deps?)` | 返回调用最新 `fn` 的稳定函数。 |
| `useIsomorphicLayoutEffect` | 浏览器中使用 `useLayoutEffect`，SSR 中使用 `useEffect`。 |

## 外部点击

<API name="useOnClickOutside">
<APIParameters>
  <APIItem name="callback" type="(event: Event) => void">
    配置的事件发生在所有跟踪元素之外时调用。
  </APIItem>
  <APIItem name="options.disabled" type="boolean" optional>
    为 true 时移除事件监听。
  </APIItem>
  <APIItem name="options.eventTypes" type="string[]" optional>
    默认为 `['mousedown', 'touchstart']`。
  </APIItem>
  <APIItem name="options.refs" type="React.RefObject<HTMLElement | null>[]" optional>
    使用明确的 refs，而不是返回的 callback ref。
  </APIItem>
</APIParameters>
<APIReturns type="(element: HTMLElement | null) => void">
  注册外部点击检测元素的 callback ref。
</APIReturns>
</API>

`composeEventHandlers(original, next, options?)` 先调用 `original`。如果事件
未被阻止，或 `checkForDefaultPrevented` 为 false，再调用 `next`。
