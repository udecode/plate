Plate 组件将 `Editor` 接入 React 渲染。可编辑编辑器使用 `EditorRoot` 和 `EditorContent`，只读静态视图使用 `EditorPreview`，自定义插件组件则使用节点原语。

## 可编辑编辑器

`EditorRoot` 管理编辑器 store，`EditorContent` 在该 store 下渲染可编辑区域。

```tsx title="components/editor.tsx"
import { EditorRoot, EditorContent, useCreateEditor } from "platejs/react";

export function Editor() {
  const editor = useCreateEditor({
    initialValue: [
      {
        children: [{ text: "Start writing." }],
        type: "paragraph",
      },
    ],
  });

  return (
    <EditorRoot editor={editor}>
      <EditorContent placeholder="Write..." />
    </EditorRoot>
  );
}
```

<Callout type="warning" title="需要 Provider">
  `EditorContent` 必须渲染在 `EditorRoot` 下方。`useEditor()`
  需要活动编辑器，否则会抛出错误。只有在控制器 UI 明确处理无活动编辑器时的
  `null` 状态时，才使用 `useOptionalEditor()`。
</Callout>

### Authored 视图

为安装了 [authored changes](/docs/authored-changes) 的编辑器传入 `authored`，分别选择输入 intent 和可见 projection：

```tsx
<EditorRoot
  editor={editor}
  authored={{ intent: 'edit', projection: 'markup' }}
>
  <EditorContent />
</EditorRoot>
```

| `authored` 值 | 行为 |
| --- | --- |
| `{ intent: 'edit', projection: 'accepted' }` | 编辑 accepted 内容。 |
| `{ intent: 'edit', projection: 'markup' }` | 显示审阅标记，并将不依赖待处理内容的编辑直接发布到 accepted 内容。 |
| `{ intent: 'edit', projection: 'proposed' }` | 显示 proposed 结果，并将不依赖待处理内容的编辑直接发布到 accepted 内容。 |
| `{ intent: 'propose', projection: 'markup' }` | 将编辑记录为 proposal，并显示保留的审阅内容。 |
| `{ intent: 'propose', projection: 'proposed' }` | 将编辑记录为 proposal，并显示 proposed 结果。 |

每个 `EditorRoot` 独立配置一个 view。修改 intent 或 projection 会更新该 view，但不会重新挂载，也不会接受或拒绝 change。在 editing 的 markup 或 proposed view 中，依赖待处理内容的编辑仍会以当前作者的身份保留为可审阅 change。

## 只读视图

需要渲染内容和 Plate 复制行为，但不需要可编辑区域时，请为静态编辑器使用 `EditorPreview`。

```tsx title="components/read-only-editor.tsx"
import { EditorPreview, useStaticEditor } from "platejs/react";

const value = [
  {
    children: [{ text: "Published content." }],
    type: "paragraph",
  },
];

export function ReadOnlyEditor() {
  const editor = useStaticEditor({ initialValue: value });

  if (!editor) return null;

  return <EditorPreview editor={editor} />;
}
```

`EditorPreview` 默认通过 `onCopy` 将 Plate fragment 数据写入剪贴板；传入自定义 `onCopy` prop 后则使用你的处理器。

## 编辑器布局

`EditorFrame` 和 `EditorContainer` 都是可选的。最小编辑器只需要 `EditorRoot`
和一个可编辑区域：`platejs/react` 提供的 `EditorContent`，或
[Editor registry 组件](/docs/components/editor)提供的带样式的 `Editor`。

| 布局 | 组件结构 | 高度设置位置 |
| --- | --- | --- |
| 随内容增长、类似 textarea 的编辑器 | `Editor` | 在 `Editor` 上设置最小高度。 |
| 有独立滚动区域的编辑器 | `EditorContainer` → `Editor` | 在 `EditorContainer` 上设置高度。 |
| 固定工具栏与滚动内容共享一个面板 | `EditorFrame` → 工具栏 + `EditorContainer` → `Editor` | 在 `EditorFrame` 上设置面板总高度。 |

三种结构都放在 `EditorRoot` 内。`EditorFrame` 是复制到项目中的 UI 布局组件，
不是 `platejs/react` 的导出。它提供 flex 列布局，也可以用具有相同尺寸行为的自定义布局替代。

### 最小编辑器

使用 `variant="none"` 不应用文档布局的内边距和高度样式。以下编辑器随内容增长，
不需要这两个包裹组件：

```tsx title="components/message-editor.tsx"
import { EditorRoot, useCreateEditor } from 'platejs/react';

import { Editor } from '@/components/editor/editor';

export function MessageEditor() {
  const editor = useCreateEditor();

  return (
    <EditorRoot editor={editor}>
      <Editor
        aria-label="消息"
        className="min-h-24 rounded-md border p-3"
        placeholder="输入消息..."
        variant="none"
      />
    </EditorRoot>
  );
}
```

### 可滚动编辑器

如果需要有界的编辑区域而不需要固定工具栏，添加 `EditorContainer` 并直接在它上面
设置高度即可，无需 `EditorFrame`：

```tsx
import { Editor, EditorContainer } from '@/components/editor/editor';

<EditorRoot editor={editor}>
  <EditorContainer className="h-48 rounded-md border">
    <Editor aria-label="消息" className="min-h-full p-3" variant="none" />
  </EditorContainer>
</EditorRoot>
```

`EditorContainer` 将其 `div` 注册为编辑器的滚动元素，并将 `beforeContainer`
和 `afterContainer` 插件 slot 渲染为兄弟元素。如果安装的 kit 使用这些 slot，
即使不需要固定高度，也要保留容器；省略容器也会省略这些 UI。没有注册的容器时，
滚动元素查询会回退到编辑器根元素或可编辑元素。

### 固定工具栏与滚动内容

固定工具栏与内部滚动的编辑器可以通过 `EditorFrame` 共享有界高度。
工具栏独占一行，`EditorContainer` 在剩余空间内滚动：

```tsx
import {
  Editor,
  EditorContainer,
  EditorFrame,
} from '@/components/editor/editor';

<EditorRoot editor={editor}>
  <EditorFrame className="h-[650px]">
    <EditorContainer>
      <Editor />
    </EditorContainer>
  </EditorFrame>
</EditorRoot>
```

此结构要求编辑器包含 [FixedToolbarKit](/docs/toolbar)，由它通过 `beforeContainer`
渲染工具栏。手动渲染时，将 `FixedToolbar` 放在 frame 内、`EditorContainer` 之前。
为 frame 设置明确的高度，或为父元素设置明确的高度以供 `h-full` 填满。
frame 本身不会强制指定一个固定高度。

## 组件映射

| 组件             | 用途                                                                                |
| ---------------- | ----------------------------------------------------------------------------------- |
| `EditorRoot`          | 单个编辑器实例的 context provider。                                                   |
| `EditorContent`   | 可编辑 Plate 区域，支持插件事件、Decoration、renderer、快捷键和编辑器 effect。      |
| `EditorPreview`      | 支持 Plate fragment 复制的静态只读渲染。                                            |
| `EditorContainer` | 编辑器容器 `div`，并提供 `beforeContainer` 和 `afterContainer` 插件 slot。          |
| `EditorElement`   | block 和 inline 元素的默认 renderer。                                               |
| `EditorLeaf`      | 文本片段的默认持久 mark renderer。                                                    |
| `EditorText`      | 单个文本节点全部渲染片段的默认外层 wrapper。                                         |

## 渲染管线

`EditorContent` 通过自身的编辑区域 props 和已安装插件组合行为。结构 renderer 和 Decoration source 由插件持有。通过公开的组件和插件 slot 组合界面；`EditorContent` 负责内部生命周期。

`EditorContent` 将 `slots.wrapRoot` 组合在每个可编辑视图的外层，并向每个根 slot 提供该视图的 `editableRef`。挂载前和卸载后，ref 为 `null`；集成在提交后读取它，并清理当时捕获的元素。功能 kit 使用此边界管理必需的 React 集成。

| 阶段           | 来源                                                                                                |
| -------------- | --------------------------------------------------------------------------------------------------- |
| 编辑器上下文 | `EditorRoot` 提供编辑器及插件 Decoration source，`EditorContent` 选择内容根。 |
| Editable props | `EditorContent` 串联插件 DOM 事件，以及插件持有的 element、leaf 和 text renderer。                    |
| 插件 slot      | `slots.wrapRoot`、`slots.wrapContent`、`slots.beforeEditable` 和 `slots.afterEditable` 组合可编辑区域。               |
| 生命周期 | `EditorContent` 自动管理快捷键、编辑器引用、控制器注册和清理。 |
| 只读状态 | `disabled` 强制只读；`EditorContent` 的 `readOnly` 优先于 `EditorRoot` 提供的值。 |

## 节点原语

在插件组件中使用 `EditorElement`、`EditorLeaf` 和 `EditorText`。它们会将 Plate attributes 与你的 `className`、`style` 和 `ref` 合并。

```tsx title="components/paragraph-element.tsx"
import {
  ParagraphPlugin,
  EditorElement,
  type EditorElementProps,
} from "platejs/react";

export function ParagraphElement(
  props: EditorElementProps<typeof ParagraphPlugin>
) {
  return <EditorElement as="p" className="leading-7" {...props} />;
}
```

组件属于单个插件时，传入插件 descriptor。props 会推断该插件配置的元素类型。

```tsx title="components/quote-element.tsx"
import { QuotePlugin } from "@/components/editor/quote-plugin";
import { EditorElement, type EditorElementProps } from "platejs/react";

export function QuoteElement(props: EditorElementProps<typeof QuotePlugin>) {
  return <EditorElement as="blockquote" {...props} />;
}
```

没有插件所有者的底层 renderer 基础设施使用原始 render contract：

```tsx
import type { Element, RenderElementProps } from "platejs";

export function TypedElement<TElement extends Element>(
  props: RenderElementProps<TElement>
) {
  return <div {...props.attributes}>{props.children}</div>;
}
```

当 schema 元素拥有命名内容根时，通过类型化的 `slots.contentRoot(slot)` 函数渲染。相同组件可用于交互式和静态渲染；Plate 会选择可编辑根视图或静态根子节点。

```tsx title="components/figure-element.tsx"
import { FigurePlugin } from "@/components/editor/figure-plugin";
import type { EditorElementProps } from "platejs/react";

export function FigureElement({
  attributes,
  children,
  slots,
}: EditorElementProps<typeof FigurePlugin>) {
  return (
    <figure {...attributes}>
      {children}
      <figcaption>{slots.contentRoot("caption")}</figcaption>
    </figure>
  );
}
```

| 原语                | 行为                                                                                                                                                                                          |
| ------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `EditorElement`      | 添加 `data-editor-node="element"`，保留 Plate 的 `data-editor-node-key`，提供类型化的元素自有 content-root slot，并在需要时添加 directional-affinity spacer。 |
| `EditorLeaf`         | 在文本片段外渲染持久 mark，并在需要时添加 hard-affinity spacer。                                                                                                                              |
| `EditorText`         | 在所有 mark 和 Decoration 片段外渲染单个文本节点 wrapper。                                                                                                                                   |

## API 参考

### `EditorRoot`

单个编辑器实例的根 provider。

<API name="Plate">
  <APIProps>
    <APIItem name="editor" type="Editor | null">
      编辑器实例。为 `null` 时，`EditorRoot` 不渲染任何内容。
    </APIItem>
    <APIItem name="children" type="React.ReactNode">
      可读取 Plate store 的 React 子节点。
    </APIItem>
    <APIItem name="authored" type="EditorViewOptions['authored']" optional>
      设置当前已挂载 authored view 的输入 intent，以及 accepted、proposed 或 markup
      projection。编辑模式可以继续显示待处理 change；切换 projection 不会接受或拒绝它们。
    </APIItem>
    <APIItem name="readOnly" type="boolean" optional>
      提供给内容区域的只读状态。默认为 `editor.read.view.isReadOnly()`。
    </APIItem>
    <APIItem name="primary" type="boolean" optional>
      将编辑器注册为 `EditorController` 的主编辑器。
    </APIItem>
    <APIItem
      name="onCommit"
      type="({ commit, editor, snapshot }) => void"
      optional
    >
      在 `EditorRoot` provider 的生命周期内观察每个已发布的编辑器 commit。
    </APIItem>
    <APIItem
      name="onValueChange"
      type="({ commit, editor, snapshot, value: EditorDocumentValue }) => void"
      optional
    >
      观察改变可序列化文档的 commit。`value` 包含主 `children`、命名 `roots`
      和持久化 `meta`。
    </APIItem>
    <APIItem
      name="onSelectionChange"
      type="({ commit, editor, selection, snapshot }) => void"
      optional
    >
      观察改变主根选区的 commit。
    </APIItem>
    <APIItem
      name="onNodeChange"
      type="({ editor, kind, node, path, previousNode, previousPath, commit }) => void"
      optional
    >
      在 `EditorRoot` provider 的生命周期内观察规范化节点变更。
    </APIItem>
    <APIItem
      name="onTextChange"
      type="({ editor, node, path, previousPath, previousText, text, commit }) => void"
      optional
    >
      在 `EditorRoot` provider 的生命周期内观察规范化文本变更。
    </APIItem>
    <APIItem name="suppressInstanceWarning" type="boolean" optional>
      禁止对同一编辑器实例的多次挂载发出警告。
    </APIItem>
  </APIProps>
</API>

### `EditorContent`

`EditorRoot` 编辑器的可编辑区域。

<API name="EditorContent">
  <APIProps>
    <APIItem name="autoFocusOnEditable" type="boolean" optional>
      `readOnly` 从 `true` 变为 `false` 时，将焦点移到编辑器末尾。
    </APIItem>
    <APIItem name="disabled" type="boolean" optional>
      强制只读状态并设置 `aria-disabled`。
    </APIItem>
    <APIItem name="readOnly" type="boolean" optional>
      覆盖 `EditorRoot` 提供的只读值。`disabled` 为 `true` 时始终只读。
    </APIItem>
    <APIItem name="placeholder" type="React.ReactNode" optional>
      可编辑区域的占位内容。
    </APIItem>
    <APIItem
      name="scrollSelectionIntoView"
      type="(editor, domRange) => void"
      optional
    >
      Plate 的选区滚动 hook。
    </APIItem>
    <APIItem
      name="onDOMBeforeInput"
      type="(event: InputEvent) => void"
      optional
    >
      通过插件 handler 管线传递的 DOM before-input handler。
    </APIItem>
    <APIItem
      name="onKeyDown"
      type="(event: React.KeyboardEvent) => void"
      optional
    >
      通过插件 handler 管线传递的键盘 handler。
    </APIItem>
    <APIItem name="disableDefaultStyles" type="boolean" optional>
      传给 Plate `Editable`。
    </APIItem>
    <APIItem name="role" type="string" optional>
      传给 Plate `Editable` 的 ARIA role。
    </APIItem>
    <APIItem name="style" type="React.CSSProperties" optional>
      传给 Plate `Editable` 的 style 对象。
    </APIItem>
  </APIProps>
</API>

`EditorContent` 还接受 `DOMHandlers` 中列出的 DOM handler props，包括剪贴板、composition、焦点、键盘、pointer、鼠标、drag、touch、media 和表单 handler。

### `EditorPreview`

支持 Plate 复制的只读静态 renderer。

<API name="EditorPreview">
  <APIProps>
    <APIItem name="editor" type="Editor">
      静态编辑器实例。
    </APIItem>
    <APIItem
      name="onCopy"
      type="React.ClipboardEventHandler<HTMLDivElement>"
      optional
    >
      覆盖默认的 Plate fragment 复制 handler。
    </APIItem>
    <APIItem name="className" type="string" optional>
      由 `EditorStatic` 与 `editor-editor` class 合并。
    </APIItem>
    <APIItem name="style" type="React.CSSProperties" optional>
      传给静态根 `div` 的 style 对象。
    </APIItem>
  </APIProps>
</API>

### `EditorContainer`

可选的容器 `div`，用于注册编辑器的滚动元素并渲染插件容器 slot。
`EditorContent` 可以独立使用。包内组件不带滚动样式；请自行添加，或使用带样式的
[Editor registry 组件](/docs/components/editor)。最小编辑器、可滚动编辑器和固定工具栏
的组合方式见[编辑器布局](#编辑器布局)。

<API name="EditorContainer">
  <APIProps>
    <APIItem name="children" type="React.ReactNode" optional>
      渲染在容器内的内容。
    </APIItem>
    <APIItem
      name="...props"
      type="React.HTMLAttributes<HTMLDivElement>"
      optional
    >
      传给容器 `div` 的 HTML props。兄弟 slot 接收 `containerRef`，不接收这些 props。
    </APIItem>
  </APIProps>
</API>

### 渲染原语

| API            | 默认元素           | 说明                                                                                                         |
| -------------- | ------------------ | ------------------------------------------------------------------------------------------------------------ |
| `EditorElement` | `div`              | 接受 `as`、`attributes`、`className`、`style`、`ref`、`element`、`path`、`editor`、`plugin` 和 `insetProp`。 |
| `EditorLeaf`    | `span`             | 接受 `as`、`attributes`、`className`、`style`、`ref`、`leaf`、`text`、`editor`、`plugin` 和 `inset`。        |
| `EditorText`    | `span`             | 接受 `as`、`attributes`、`className`、`style`、`ref`、`text`、`editor` 和 `plugin`。                         |
