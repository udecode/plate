title: 编辑器上下文
description: 通过 Plate React hook 读取编辑器、插件和焦点状态。
---

从 `platejs/react` 导入 Plate 状态 hook。文档状态使用编辑器 hook，插件状态使用
`usePluginStore`，焦点记录使用事件 hook。

## 编辑器状态

编辑器 hook 需要位于 `Plate` 下，或位于连接共享 UI 和编辑器的
[PlateController](/docs/api/core/plate-controller) 下。

| Hook | 返回值 |
| --- | --- |
| `useEditor()` | 匹配的编辑器；没有活动编辑器时抛出错误。 |
| `useOptionalEditor()` | 匹配的编辑器；控制器中没有匹配编辑器时返回 `null`。 |
| `useEditorId()` | 解析到的编辑器 ID。 |
| `useEditorMounted()` | 编辑器的可编辑区域是否已挂载。 |
| `useEditorSelection()` | 当前所选根的范围选区，或 `null`。 |
| `useEditorHasSelection()` | 所选根是否有文本选区，包括折叠的光标。仅在选区存在状态变化时重新渲染。 |
| `useEditorValue()` | 当前所选根的子节点。 |
| `useEditorState(selector, options?)` | 从不可变编辑器状态派生并订阅的值。 |

hook 使用最近的 `PlateContent`、`Plate`、`PlateController` 或 `EditorProvider` 所选的编辑器。`useOptionalEditor()` 在没有 provider 或没有所选编辑器时返回 `null`。应用 ID 不参与挂载视图的查找。

```tsx
import { useEditorMounted, useEditorValue } from 'platejs/react';

export function EditorStatus() {
  const mounted = useEditorMounted();
  const value = useEditorValue();

  return <p>{mounted ? `${value.length} 个顶层节点` : '正在加载编辑器…'}</p>;
}
```

## 容器和生命周期

`useEditorContainerRef()` 返回匹配的 `PlateContainer` 引用。挂载前和卸载后，
其 `current` 值为 `null`。使用它将编辑器 UI 锚定到容器；它不代表可编辑 DOM 元素。

`Plate` 和 `PlateContent` 管理编辑器注册及挂载状态。通过 `Plate` 的 `primary`
prop 设置主编辑器资格，通过它们的 `readOnly` prop 传入只读状态。

## 插件状态

插件状态属于已安装的描述符及其编辑器。让描述符推断状态键和 selector 返回值。

```tsx
import { definePlatePlugin, usePluginStore } from 'platejs/react';

export const PanelPlugin = definePlatePlugin('panel', {
  initialState: { open: false },
});

export function PanelStatus() {
  const open = usePluginStore(PanelPlugin, 'open');

  return <p>{open ? '面板已打开' : '面板已关闭'}</p>;
}
```

在编辑器的 `plugins` 数组中加入 `PanelPlugin`。需要 selector 回调时，使用
`usePluginStore(PanelPlugin, (state) => state.open)`。
`useEditorPlugin(PanelPlugin)` 返回从描述符推断的 portal，供调用 API；它不会
订阅插件状态。在 React 渲染之外，通过
`editor.plugin(PanelPlugin).store.get('open')` 读取当前值。

## 焦点记录

`useEditorFocused()` 读取当前可编辑区域是否拥有焦点。
`useFocusedLast()` 判断 provider 中的编辑器是否是所属文档中最近获得焦点的编辑器。
工具栏输入框获得焦点时，结果保持 `true`；同一文档中的另一个编辑器获得焦点，
或该视图卸载时，结果变为 `false`。不同文档各自维护焦点记录，编辑器 ID 相同
也不会混淆实例。

```tsx
import { useFocusedLast } from 'platejs/react';

export function EditorTools() {
  const focusedLast = useFocusedLast();

  return <div hidden={!focusedLast}>Editor tools</div>;
}
```

在 `Plate` 下使用此 hook，或在拥有活动编辑器的 `PlateController` 下使用。
控制器为空时，先用 `useOptionalEditor()` 判断是否挂载包含严格编辑器 hook 的子组件。
状态、值和选区 hook 都需要活动编辑器。

## 显式编辑器

用 `<EditorProvider editor={editor}>` 将 UI 绑定到已有编辑器；`editor={null}` 表示没有目标。此 provider 不创建文档、历史或可编辑视图。需要保留具体编辑器类型时，使用 `useEditorRuntimeState(editor, selector)`、`useEditorViewState(editor, selector)` 或 `useEditorPluginStore(editor, Plugin, selector)`。

`useEditorReadOnly()` 读取所选视图当前的只读状态；捕获的视图卸载后会拒绝写入。一个模型的多个视图共享文档、插件 store 和撤销历史。
