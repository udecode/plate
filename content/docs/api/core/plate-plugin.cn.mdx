Plate 插件是传给 `Plate` 组件 [plugins](/docs/api/core/plate-components#plugins) 属性的描述符。将同一个描述符传给 `editor.plugin(MyPlugin)`，即可类型安全地访问插件 API、update 命令和实时 options；React 组件通过 `usePluginOption` 或 `usePluginOptions` 订阅变化。

## 插件属性

<API name="Properties">
<APIAttributes>
<APIItem name="key" type="C['key']" required>
Plate 用于通过 `editor.plugin(MyPlugin)` 解析描述符的唯一标识符。
</APIItem>

<APIItem name="targetPluginKeys" type="readonly string[]">
插件的 schema 和 host 行为所针对的插件 key。

- **默认值:** `[]`
</APIItem>

<APIItem name="api" type="Record<string, Function>">
插件拥有的 API 函数，通过 `editor.plugin(MyPlugin).api` 访问。只有属于根
`editor.api` 表面的 API 才使用 `.extendEditorApi()`。
</APIItem>

<APIItem name="tx" type="Record<string, Function>">
插件提供的事务命令。通过 `editor.plugin(MyPlugin).update.method()` 执行单个命令，
或在 `editor.update((tx) => tx[key].method())` 中组合命令。
</APIItem>

<APIItem name="options" type="Record<string, any>">
插件拥有的值，用于 schema 工厂、parser、host codec 与运行时行为。包作者通过
`create*Plugin()` 或 `.extend()` 声明默认值；应用用户通过一次最终
`.configure({ options: { ... } })` 设置描述符值；通过
`editor.plugin(MyPlugin).getOptions()`、`.setOption()` 或 `.setOptions()`
读取或更新实时值。更新 options 不会重新编译 schema。
</APIItem>

<APIItem name="handlers" type="{ onChange?: (editor: PlateEditor) => void } & Record<string, Function>">
各种编辑器事件的事件处理器。

<APISubList>
<APISubListItem parent="handlers" name="onChange" type="(editor: PlateEditor) => void" optional>
每当编辑器内容更改时调用。
</APISubListItem>
<APISubListItem parent="handlers" name="onNodeChange" type="OnNodeChange" optional>
每当发生节点操作时调用（插入、删除、设置、合并、拆分、移动）。

```ts
type OnNodeChange = (
  ctx: PlatePluginContext & {
  node: Descendant;
  operation: NodeOperation;
  prevNode: Descendant;
  }
) => HandlerReturnType;
```

**参数：**

- `node`：操作后的节点
- `operation`：发生的节点操作
- `prevNode`：操作前的节点

**注意：** 对于 `insert_node` 和 `remove_node` 操作，`node` 和 `prevNode` 包含相同的值以避免空值情况。

</APISubListItem>
<APISubListItem parent="handlers" name="onTextChange" type="OnTextChange" optional>
每当发生文本操作时调用（插入或删除文本）。

```ts
type OnTextChange = (
  ctx: PlatePluginContext & {
  node: Descendant;
  operation: TextOperation;
  prevText: string;
  text: string;
  }
) => HandlerReturnType;
```

**参数：**

- `node`：包含已更改文本的父节点
- `operation`：发生的文本操作（`insert_text` 或 `remove_text`）
- `prevText`：操作前的文本内容
- `text`：操作后的文本内容
</APISubListItem>
</APISubList>
</APIItem>

<APIItem name="type" type="string">

<APIItem name="schema" type="PluginSchema<C> | null">
声明插件的 Plite 模型。元素语法使用 `schema.element`，类型化文本属性描述符使用
`schema.mark`，跨节点属性使用 `schema.properties`。Schema 工厂接收编译时使用的插件
`options` 快照。
布尔文本属性使用 `property.boolean({ default: false, omitDefault: true })`。
</APIItem>

<APIItem name="rules" type="object">
定义插件编译后的 schema 类型的编辑行为。

<APISubList>
<APISubListItem parent="rules" name="selection.affinity" type="'default' | 'directional' | 'outward' | 'hard'" optional>
定义节点边界的选区行为。参见 [插件规则](/docs/plugin-rules#rulesselection)。

- `'default'`: 使用 Plite 的默认行为
- `'directional'`: 选区亲和性由光标移动方向决定。根据接近方向保持向内或向外亲和性
- `'outward'`: 强制向外亲和性。在标记边缘输入不会将标记应用到新文本
- `'hard'`: 创建需要两次按键才能跨越的"硬"边缘。使用基于偏移的导航

- **默认值:** `undefined` (Plite 的默认行为)
</APISubListItem>
<APISubListItem parent="rules" name="break.empty" type="'default' | 'deleteExit' | 'exit' | 'lift' | 'reset'" optional>
在空块中按下 Enter 时的动作。参见 [插件规则](/docs/plugin-rules)。

- `'default'`: 默认行为
- `'reset'`: 重置块为默认段落类型
- `'exit'`: 退出当前块
- `'lift'`: 将当前块从最近匹配的祖先中提升出来
- `'deleteExit'`: 向后删除然后退出
</APISubListItem>
<APISubListItem parent="rules" name="break.emptyLineEnd" type="'default' | 'deleteExit' | 'exit'" optional>
在空行末尾按下 Enter 时的动作。通常与 `rules.break.default: 'lineBreak'` 一起使用。参见 [插件规则](/docs/plugin-rules)。

- `'default'`: 默认行为
- `'exit'`: 退出当前块
- `'deleteExit'`: 向后删除然后退出
</APISubListItem>
<APISubListItem parent="rules" name="break.default" type="'default' | 'deleteExit' | 'exit' | 'lineBreak'" optional>
按下 Enter 时的默认动作。默认为分割块。参见 [插件规则](/docs/plugin-rules)。

- `'default'`: 默认行为
- `'exit'`: 退出当前块
- `'lineBreak'`: 插入换行符
- `'deleteExit'`: 向后删除然后退出
</APISubListItem>
<APISubListItem parent="rules" name="break.splitReset" type="boolean" optional>
如果为 true，分割后的新块将被重置为默认类型。参见 [插件规则](/docs/plugin-rules)。
</APISubListItem>
<APISubListItem parent="rules" name="delete.start" type="'default' | 'lift' | 'reset'" optional>
在块开头按下 Backspace 时的动作。无论块是否为空都适用。参见 [插件规则](/docs/plugin-rules)。

- `'default'`: 默认行为
- `'lift'`: 将当前块从最近匹配的祖先中提升出来
- `'reset'`: 重置块为默认段落类型
</APISubListItem>
<APISubListItem parent="rules" name="delete.empty" type="'default' | 'reset'" optional>
块为空时按下 Backspace 时的动作。参见 [插件规则](/docs/plugin-rules)。

- `'default'`: 默认行为
- `'reset'`: 重置块为默认段落类型
</APISubListItem>
<APISubListItem parent="rules" name="match" type="MatchRules" optional>

**示例:** `matchRules: ({ node }) => Boolean(node.listStyleType)`

示例：列表插件设置 `match: ({ node }) => !!node.listStyleType` 以在段落是列表项时覆盖段落行为。

</APISubListItem>
<APISubListItem parent="rules" name="merge.removeEmpty" type="boolean" optional>

<APIItem name="editOnly" type="boolean | EditOnlyConfig" optional>
配置哪些插件功能仅在编辑器非只读时激活。

可以是布尔值或对象配置：

```ts
type EditOnlyConfig = {
  render?: boolean;      // 默认: true
  handlers?: boolean;    // 默认: true
  inject?: boolean;      // 默认: true
  transformInitialValue?: boolean;  // 默认: false
};
```

当设置为 `true`（布尔值）时：

- `render`、`handlers` 和 `inject.nodeProps` 仅在编辑器非只读时激活
- `transformInitialValue` 无论只读状态如何都保持激活

当设置为对象时：

- 每个属性可以单独配置
- 属性默认是仅编辑的（`true`），除了 `transformInitialValue` 默认始终激活（`false`）
- 将属性设置为 `false` 使其始终激活，无论只读状态如何
- 对于 `transformInitialValue`，设置为 `true` 使其仅在编辑时激活

示例：

```ts
// 所有功能（除 transformInitialValue 外）都是仅编辑的
editOnly: true;

// transformInitialValue 是仅编辑的，其他保持默认行为
editOnly: {
  transformInitialValue: true;
}

// render 始终激活，其他遵循默认行为
editOnly: {
  render: false;
}
```

</APIItem>
</APIAttributes>
</API>

## 插件方法

<APIItem name="configure" type="(config: PlatePluginConfig | ((ctx: PlatePluginContext) => Partial<Pick<PlatePluginConfig, 'options' | 'handlers' | 'render' | 'shortcuts'>>)) => ConfiguredPlatePlugin">
应用一次最终用户配置，并返回不能再次配置或扩展的描述符。对象形式用于定义字段；
回调形式可根据已解析编辑器上下文生成已有的 `options`、`handlers`、`render` 或
`shortcuts`。此前声明的运行时扩展可以读取配置值，重叠字段最终仍以用户配置为准。

```ts
HeadingPlugin.configure({
  options: { levels: [1, 2, 3] },
});
```

</APIItem>

<APIItem name="configurePlugin" type="(plugin: PluginReference | { key: string }, config: PluginMethodConfig) => PlatePlugin">
配置已有的嵌套插件。找不到目标时，返回原父插件。
</APIItem>

<APIItem name="extend" type="(config: Partial<PlatePlugin> | ((ctx: PlatePluginContext) => Partial<PlatePlugin>)) => PlatePlugin">
创建一个包含包内或可复用行为的新插件实例。所有 `.extend*()` 调用必须在用户
`.configure()` 之前完成。

```ts
(
  extendConfig:
    | Partial<PlatePlugin>
    | ((ctx: PlatePluginContext<AnyPluginConfig>) => Partial<PlatePlugin>)
) => PlatePlugin;
```

</APIItem>

<APIItem name="extendPlugin" type="(plugin: PluginReference | { key: string }, config: PluginMethodConfig) => PlatePlugin">
扩展现有嵌套插件或在未找到时添加新插件。支持深层嵌套。

```ts
(
  plugin: PluginReference | { key: string },
  extendConfig: PluginMethodConfig
) => PlatePlugin;
```

</APIItem>

<APIItem name="withComponent" type="function">
设置或替换与插件关联的组件。当唯一的变更是绑定组件时，这是首选方式，并应在最终
用户配置之前调用。

```ts
(component: NodeComponent) => PlatePlugin<C>;
```

</APIItem>

<APIItem name="extendExtension" type="function">
安装一个 Plite 编辑器扩展。用于 schema、state、tx、command、correction、query middleware 或运行时服务。

```ts
(
  extension: ExtendPlateEditorExtension<C> | PlateEditorExtensionInput
) => PlatePlugin<C>;
```

</APIItem>

<APIItem name="extendApi" type="(api: (ctx: PlatePluginContext) => Record<string, Function>) => PlatePlugin">
扩展插件的 API。

(api: (ctx: PlatePluginContext) => Record<string, Function>) => PlatePlugin;
```

</APIItem>

<APIItem name="extendEditorApi" type="(api: (ctx: PlatePluginContext) => Record<string, Function>) => PlatePlugin">
使用插件特定方法扩展编辑器的 API。

(api: (ctx: PlatePluginContext) => Record<string, Function>) => PlatePlugin;
```

</APIItem>

(tx: (ctx: PlatePluginContext) => (transaction) => Record<string, Function>) =>

(
  key: string,

</APIItem>

<APIItem name="extendSelectors" type="(options: (ctx: PlatePluginContext) => Record<string, any>) => PlatePlugin">

(options: (ctx: PlatePluginContext) => Record<string, any>) => PlatePlugin;
