`PlateController` 让单个 `<Plate>` subtree 之外的 UI 读取活动 editor store。它适用于共享 toolbar、sidebar、inspector 和多编辑器 shell。

## 基本用法

把共享 UI 和编辑器放在 `PlateController` 中。`PlateContent` 通过 `PlateControllerEffect` 注册每个已挂载的 editor store。

```tsx
import {
  Plate,
  PlateContent,
  PlateController,
  useActiveEditor,
  usePlateEditor,
} from 'platejs/react';

function ActiveEditorLabel() {
  const editor = useActiveEditor();

  if (!editor) return <p>没有活动编辑器。</p>;

  return <p>活动编辑器：{editor.id}</p>;
}

export function EditorShell() {
  const editor = usePlateEditor({ id: 'main' });

  return (
    <PlateController>
      <ActiveEditorLabel />
      <Plate editor={editor}>
        <PlateContent />
      </Plate>
    </PlateController>
  );
}
```

`primary` 是 `Plate` prop，不属于 `createPlateEditor` 或 `usePlateEditor` options。

## 活动编辑器查找

| Hook | 行为 |
| --- | --- |
| `useEditor({ id: 'main' })` | 获取 `main` 的活动 store；不存在时抛出错误。 |
| `useEditor()` | 获取活动 editor，或第一个已挂载的 primary editor；不存在时抛出错误。 |
| `useActiveEditor()` | 使用同样的查找规则，没有活动 editor 时返回 `null`。 |

没有显式 ID 时，controller 依次查找 `activeId`、`primaryEditorIds`，然后得到“没有活动编辑器”。Plate 内部保留 inert editor 以维持 Hooks 调用结构，但 public code 永远不会得到它。

可以在没有 editor 时渲染的 UI 使用 `useActiveEditor()`。必须拥有 editor 的 command 和组件使用 `useEditor()`，让缺失 provider 立即报错。

## 注册

`PlateControllerEffect` 在 `PlateContent` 内运行。它按 editor ID 注册当前 `Plate` store，在 mount/unmount 时维护 `primaryEditorIds`，并在 Plite focus 进入 editor 时设置 `activeId`。

| State | 类型 | 默认值 |
| --- | --- | --- |
| `activeId` | `string \| null` | `null` |
| `editorStores` | `Record<string, JotaiStore \| null>` | `{}` |
| `primaryEditorIds` | `string[]` | `[]` |

### `usePlateControllerStore`

按 controller state 解析 Plate Jotai store。传 `idProp` 直接查找指定 editor；省略时按活动 editor 和 primary editor 顺序查找。
