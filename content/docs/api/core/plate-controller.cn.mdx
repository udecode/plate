---
title: Plate 控制器
description: 将共享 React UI 连接到活动的 Plate 编辑器。
---

`PlateController` 让共享工具栏、面板和检查器在单个 `Plate` 子树之外获取编辑器。

## 用法

用 `PlateController` 包裹共享 UI 和参与的编辑器。`PlateContent` 会自动注册每个
已挂载的编辑器，并在卸载时清理。

```tsx title="components/editor-shell.tsx"
import {
  Plate,
  PlateContent,
  PlateController,
  useCreateEditor,
  useOptionalEditor,
} from 'platejs/react';

export function EditorShell() {
  const main = useCreateEditor({ id: 'main' });
  const secondary = useCreateEditor({ id: 'secondary' });

  return (
    <PlateController>
      <ActiveEditorLabel />
      <Plate editor={main}>
        <PlateContent />
      </Plate>
      <Plate editor={secondary} primary={false}>
        <PlateContent />
      </Plate>
    </PlateController>
  );
}

function ActiveEditorLabel() {
  const editor = useOptionalEditor();

  return <p>{editor ? `活动编辑器：${editor.id}` : '尚未选择编辑器。'}</p>;
}
```

`primary` 在 `Plate` 上设置，默认为 `true`。`primary={false}` 的视图仍可在聚焦后成为活动视图。ID 是应用标签；同一模型和 ID 可以拥有多个挂载视图。

## 编辑器查找

`useEditor()` 返回最近 provider 所选的编辑器，没有目标时抛出错误。`useOptionalEditor()` 使用相同规则，没有 provider 或没有目标时返回 `null`。

- `PlateContent` 内的 hook 使用该可编辑视图，包括其根、DOM 和当前只读状态。
- `Plate` 内、content 外的 UI 跟随该 Plate 中最近聚焦的视图，首次聚焦前使用第一个已挂载视图。没有 content 时使用模型。
- 控制器下的共享 UI 使用最近聚焦且仍挂载的视图；首次聚焦前或目标卸载后，使用第一个已挂载的主视图。
- 嵌套的 `Plate` 和 `PlateController` 为后代提供自己的作用域。

失焦保留活动视图，供工具栏使用。`PlateContent` 管理注册和清理；只有带可编辑 DOM 的视图才参与控制器选择。

## 固定交互目标

用 `EditorProvider` 将一组控件绑定到已有编辑器。例如，弹出菜单可以捕获打开时的 `useEditor()` 返回值，并在菜单关闭前通过此 provider 保持目标。

```tsx
import { EditorProvider } from 'platejs/react';

<EditorProvider editor={capturedEditor}>
  <Toolbar />
</EditorProvider>
```

`EditorProvider` 接收 `editor: Editor | null` 和 `children: React.ReactNode`，不创建可编辑视图。React portal 保留此上下文。目标变为只读或卸载后，命令读取当前权限并拒绝写入；不会切换到其他视图。

## API 参考

`PlateController` 只接收 `children: React.ReactNode`。`Plate` 的 `primary` prop 决定首次选择和回退资格。

状态与焦点订阅参见[编辑器上下文](/cn/docs/api/core/plate-store)。
