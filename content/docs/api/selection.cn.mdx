description: 活动范围、精确节点成员和语义选区写入。
---

`editor.read.selection()` 返回包含 `anchor` 和 `focus` 的范围，或 `null`。
完整的可序列化选区是 `TextSelection` 或 `NodeSelection`。
`SelectionApi` 已冻结，自定义辅助方法应组合它，而不是修改它。

## 读取选区

#### `editor.read.selection()`

读取活动范围。读取和更新回调中分别使用 `state.selection()` 和
`tx.selection()`。返回值不含选区种类或插件数据。

节点选区的单一范围连接其 anchor 和 focus 节点。用
`selection.nodes()` 读取精确成员，避免把这个代表范围当作连续选择。

#### `editor.read.selection.ranges()`

文本选区返回一个范围，节点选区为每个成员返回一个范围。没有选区时返回
空数组。回调中同样可以使用 `state.selection.ranges()` 和
`tx.selection.ranges()`。

## 写入选区

#### `editor.update.selection.setNodes(targets, options?)`

按 `Path`、`NodeKey` 或活动节点选择同一根中的节点。编辑器会排序、去重，
并移除已选祖先的后代。空集合清空选区；不存在或属于其他编辑器的目标会
拒绝整个更新。

`options` 中的 `anchor` 和 `focus` 用于保留方向，两者都必须属于选中成员。
省略时按文档顺序确定端点。若同一事务前面的写入创建或移动了目标，使用
`tx.selection.setNodes(targets)`。

## 静态方法

#### `SelectionApi.equals(left, right)`

比较完整的文本或节点选区。

#### `SelectionApi.isSelection(value)`

检查是否为内置的可序列化选区形状，不检查路径或位置是否存在于文档中。

#### `SelectionApi.isText(value)`

检查文本选区形状。插入标记只允许出现在折叠的文本选区中。

#### `SelectionApi.isNode(value)`

检查节点选区形状和规范化后的成员路径。

#### `SelectionApi.root(selection)`

读取具名根标识。主文档选区返回 `undefined`。

#### `SelectionApi.text(range, options?)`

根据范围以及可选的 affinity、插入标记创建文本选区。

#### `SelectionApi.nodes(paths, options?)`

创建独立的节点选区。路径列表不能为空。路径会排序、去重，并移除已选祖先
的后代。`anchorPath` 和 `focusPath` 必须是精确成员，用于保留方向。
修改活动选区时使用 `selection.setNodes(...)`。

## 验证选区

#### `state.selection.isValid(value)`

按当前文档验证选区。直接读取形式是 `editor.read.selection.isValid(value)`。
它接受 `null`，拒绝未知选区种类，并验证对应根中的位置或精确节点路径。

```ts
if (editor.read.selection.isValid(input)) {
  editor.update.selection.set(input);
}
```

Plate React 的节点选区只存在于模型中。编辑器保持焦点，浏览器原生选区
没有范围。可使用[节点选择组件](/docs/api/core/plate-components#node-selection)
渲染高亮和空白区域拖选。
