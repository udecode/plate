---
title: 编辑器转换
description: 修改 Plite 编辑器状态的事务方法。
---

Plite 的修改方法位于 `editor.update` 下。单次修改使用直接分组方法，多次
原子修改使用回调形式。

```ts
editor.update.text.insert("Hello");

editor.update((tx) => {
  tx.nodes.set({ type: "heading" });
  tx.text.insert("Title");
});
```

完整参考见 [Plite transform reference](/docs/plite/api/transforms)。
