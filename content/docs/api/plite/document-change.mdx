`commit.changes` and import canonical changes through `tx.changes.apply`.

Read [Document Changes](/docs/plite/concepts/05-document-changes) for the
algebra and [Canonical Change Substrate](/docs/plite/walkthroughs/07-canonical-change-substrate)
