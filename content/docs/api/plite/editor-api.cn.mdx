---
title: 编辑器 API
description: 通过分组且快照安全的 API 读取 Plite 编辑器状态。
---

Plite 将编辑器查询放在 `editor.read` 下。分组 API 明确状态归属，也避免查询
方法不断堆积在编辑器根对象上。

完整参考见 [Plite Editor](/docs/plite/api/nodes/editor)。本页是 Plate 文档中
指向该 API 的索引。

## 直接读取

一次读取使用直接分组方法。

```ts
const selection = editor.read.selection();
const block = editor.read.nodes.block();
const text = editor.read.text.string([]);
const isInline = editor.read.schema.isInline(element);
```

| 分组 | 用途 |
| --- | --- |
| `editor.read.nodes` | 遍历、定位和检查文档节点。 |
| `editor.read.points` | 解析和比较点。 |
| `editor.read.ranges` | 构造、投影和检查范围。 |
| `editor.read.selection` | 检查当前选区或指定目标。 |
| `editor.read.text` | 读取指定位置的文本。 |
| `editor.read.schema` | 查询块、行内、void 和可选择策略。 |
| `editor.read.view` | 读取焦点、输入法组合和只读状态。 |
| `editor.read.runtime` | 读取运行时 ID 和快照。 |

## 快照读取

多次读取需要共享同一状态视图时，使用回调形式。

```ts
const summary = editor.read((state) => ({
  block: state.nodes.block(),
  selection: state.selection(),
  text: state.text.string([]),
}));
```

## 节点目标

带 `at` 选项的读取和更新方法接受位置、实时 descendant，或来自同一 editor 的
`NodeKey`。节点键可以定位任意文档 root 中的节点。

```ts
const nodeKey = editor.key(element);
const path = editor.read.nodes.path(element);
const entry = editor.read.nodes.get(nodeKey);
const parent = editor.read.nodes.parent(nodeKey);
```

生命周期中的节点、点和范围读取在目标不可用时返回 `undefined`。对于节点
目标，这包括已分离的节点，以及属于其他编辑器的节点。

## 运行时身份

`NodeKey` 是每个实时 descendant 的 editor 私有身份，也覆盖文本节点。它在移动
和不可变更新后保持稳定，在节点删除后失效，并且不会进入序列化值、slice、历史
记录或协作数据。

```ts
const nodeKey = editor.key(element);
const nodeKeyAtPath = editor.key([0]);
const currentPath = editor.read.nodes.path(nodeKey);

editor.update.nodes.remove({ at: nodeKey });
```

`nodes.path(nodeKey)` 只在节点属于当前 editor 或 view root 时返回路径。
base editor 的路径输入指向 main root；view 的路径输入指向该 view 的 root。

选区、拖放、overlay 和组件状态等临时行为使用运行时身份。需要持久化的应用引用
应由 schema 属性声明。

## 节点匹配

节点查询使用 `type` 进行结构选择，并使用可选的 `match` 谓词添加条件。

```ts
const callout = editor.read.nodes.find({
  type: "callout",
});

const structural = editor.read.nodes.toArray({
  type: ["table", "table_cell"],
});
```

数组选择任一列出的类型。计算策略和 TypeScript 类型缩窄使用谓词。

## 选区查询

选区检查使用明确的方法，不使用布尔查询标志。

```ts
const isCollapsed = editor.read.selection.isCollapsed();
const spansBlocks = editor.read.selection.isAcrossBlocks();
const startsHeading = editor.read.selection.isAtBlockStart({
  type: "heading",
});
const containsFirstBlock = editor.read.selection.contains([0]);
```

## 扩展 API

`editor.api` 存放已安装扩展提供的服务，不是文档查询命名空间。

```ts
editor.api.dom.focus();
editor.update({ history: "skip" }).text.insert("Imported");
```

文档修改放在 `editor.update` 下。参见
[Editor Transforms](/docs/api/plite/editor-transforms) 和
[Plite transform reference](/docs/plite/api/transforms)。
