---
title: "Debug Value Scrubbing"
description: "Debug scrubber API for redacting values in thrown Plite errors."
---

Plite formats some thrown error details with document values and nodes. Text
fields are redacted by default. Apps that need stricter diagnostics can install
a scrubber for additional fields.

## Install A Scrubber

```typescript
import { setDebugValueScrubber } from "plitejs";

setDebugValueScrubber((key, value) => {
  if (key === "text" || key === "src") return "[redacted]";
  return value;
});
```

Pass `null` or `undefined` to restore the default scrubber.

```typescript
setDebugValueScrubber(null);
```

## API

<APIReference package="plitejs" symbol="setDebugValueScrubber" />

Set the function used before Plite formats debug values.

<APIReference package="plitejs" symbol="DebugValueScrubber" />

The custom scrubber runs before Plite's default text redaction. Return the
original value to let the default scrubber handle it.
