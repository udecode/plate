title: "Node Types APIs"
description: "Node union API for editors, elements, and text nodes."
---

The `Node` union type represents all of the different types of nodes that occur in a Plite document tree.

## Types

```typescript
type Node = Editor | Element | Text;

type Descendant = Element | Text;
type Ancestor = Editor | Element;
```
