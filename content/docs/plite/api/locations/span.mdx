description: "Path-based span helper API."

A `Span` identifies its endpoints with two node paths. Unlike a `Range`, it
does not store text offsets.

## Type

```typescript
type Span = readonly [Path, Path];
```

### Check methods

#### `SpanApi.isSpan(value: unknown) => value is Span`
