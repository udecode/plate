---
title: "React"
description: "Use the React editor runtime, provider, complete EditorContent surface, hooks, and overlays."
---

`plitejs/react` owns the React editor runtime: editor creation, the `EditorRoot`
provider, the `EditorContent` surface, browser event handling, native selection
sync, void shells, hidden DOM coverage, decorations, annotations,
and external text views. Explicit large-document virtualization lives
in `plitejs/react/virtualized`.

Start with `useCreateEditor`, `EditorRoot`, and `EditorContent`.

## Minimal usage

```tsx
import { EditorRoot, EditorContent, useCreateEditor } from "plitejs/react";

const Editor = () => {
  const editor = useCreateEditor({
    initialValue: [{ type: "paragraph", children: [{ text: "" }] }],
  });

  return (
    <EditorRoot editor={editor}>
      <EditorContent placeholder="Start typing..." />
    </EditorRoot>
  );
};
```

## Stable runtime path

- [React Editor Setup](/docs/plite/libraries/plite-react/react-editor-setup): create an editor and install
  the React, DOM, and clipboard plugins; install history when needed.
- [EditorRoot](./plite): provide the editor, value changes, and
  decorations.
- [EditorContent](/docs/plite/libraries/plite-react/editable): render content, marks, voids,
  placeholders, complete document DOM, and editor event handlers.
- [Event Handling](/docs/plite/libraries/plite-react/event-handling): customize copy, paste, drop, keyboard,
  input, selection, focus, and drag behavior without replacing Plite's runtime.
- [Hooks](/docs/plite/libraries/plite-react/hooks): subscribe to editor state, runtime state, roots,
  mounted nodes, decorations, annotations, focus, read-only state, and
  selection.

## Runtime boundaries

- [React Editor](/docs/plite/libraries/plite-react/react-editor): DOM, focus, selection, clipboard, and
  React-specific editor APIs.
- `renderElement`, `renderLeaf`, and `renderText` supply DOM `attributes` to
  spread onto your own elements, and `EditorPlaceholder` renders Plite's default
  placeholder markup when a custom `renderPlaceholder` needs it.
- [DOM Coverage Boundaries](/docs/plite/libraries/plite-react/dom-coverage-boundaries): represent app-hidden
  DOM regions for selection, copy, find, and materialization.
- [External Text Views](/docs/plite/libraries/plite-react/external-text): let an adapter own one Text's DOM and
  local input while Plite retains the canonical model, selection, and history.
- [Annotations](/docs/plite/libraries/plite-react/annotations): durable anchored ranges for comments,
  diagnostics, and external review markers.
- [Hooks](/docs/plite/libraries/plite-react/hooks): runtime/root hooks for external chrome
  and selection geometry for anchored UI.

## Large documents
