---

`plitejs/diff` compares two immutable, schema-valid Plite documents without
mutating editor state.

## Install

`plitejs/diff` requires `diff-match-patch-ts` as an optional peer dependency:

```bash
npm install plitejs diff-match-patch-ts
```

## Compare documents

Pass `before`, `after`, and the editor's schema to `compare`:

```ts
import { compare } from "plitejs/diff";

const comparison = await compare({
  before: previousDocument,
  after: nextDocument,
  schema: editor.read.schema,
});
```

Each returned `Comparison` contains:

- `change`: the canonical `DocumentChange` from `before` to `after`.
- `changes`: grouped `ComparedChange` entries with spans, effects, and evidence.
- `diagnostics`: warnings or fallback notices such as `coarse-replacement` or `work-limit`.
- `before` and `after`: fingerprinted `ComparisonSnapshot` values.

Pass `projection: { before, after }` (`"accepted"` or `"proposed"`) when
comparing documents that hold authored review marks, and pass `signal` to cancel
long comparisons with an `AbortSignal`.

To turn a `Comparison` into a native pending suggestion on a live editor,
call `editor.api.authored.proposeComparison({ comparison })` from
[Authored Changes](/docs/plite/libraries/plite-authored#import-a-comparison).
