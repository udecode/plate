在 Node.js 中使用 Plate 可以验证、转换、解析或序列化完整 editor document，
无需挂载 React。

<Callout type="warning" title="使用 server-safe import">
  Editor runtime 从 `platejs` import，不要使用 `platejs/react`。Markdown 使用
  `platejs/markdown`。Node HTML parsing 使用 `platejs/html/server`。
</Callout>

<Steps>

### 安装 package

```bash
npm install platejs
```

只有进程需要解析 HTML 时才安装可选 server DOM peer：

```bash
npm install linkedom
```

`platejs/html/server` 只提供 ESM。`parse5` 是 Plate 的 direct dependency；
`linkedom` 只存在于 server graph，不会进入 browser bundle。

### 创建 headless editor

```ts title="scripts/process-content.ts"
import { BaseBoldPlugin, BaseHeadingPlugin, createEditor } from 'platejs';

const editor = createEditor({
  plugins: [BaseHeadingPlugin, BaseBoldPlugin],
  initialValue: {
    children: [
      { type: 'heading', level: 1, children: [{ text: '文档标题' }] },
      { type: 'paragraph', children: [{ text: '正文' }] },
    ],
  },
});

const document = editor.read.value();
```

`editor.read.value()` 返回完整 document，包括 named root 与持久化 metadata。
原子转换使用 `editor.update(...)`。

### 解析与序列化 Markdown

不需要 editor lifecycle 时，使用 direct function：

```ts title="scripts/markdown-io.ts"
import { BaseBoldPlugin, BaseHeadingPlugin } from 'platejs';
import { parseMarkdown, serializeMarkdown } from 'platejs/markdown';

const plugins = [BaseHeadingPlugin, BaseBoldPlugin] as const;
const parsed = parseMarkdown('# 标题\n\n**正文**', { plugins });

if (!parsed.ok) throw new Error(parsed.diagnostics[0].message);

const output = serializeMarkdown(parsed.document, {
  plugins,
  projection: 'accepted',
});

if (output.ok) console.info(output.data);
```

多次 operation 需要复用同一个 editor 的 compiled target 时，安装
`MarkdownPlugin`：

```ts
import { MarkdownPlugin } from 'platejs/markdown';

const editor = createEditor({
  plugins: [BaseHeadingPlugin, BaseBoldPlugin, MarkdownPlugin],
});

const parsed = editor.api.markdown.parse(source);
const output = editor.api.markdown.serialize({ projection: 'proposed' });
```

### 解析 HTML

```ts title="scripts/html-import.ts"
import { BaseBoldPlugin, BaseHeadingPlugin } from 'platejs';
import { parseHtml } from 'platejs/html/server';

const result = parseHtml(source, {
  plugins: [BaseHeadingPlugin, BaseBoldPlugin],
});

if (!result.ok) throw new Error(result.diagnostics[0].message);
```

Server 与 browser parser 共享同一棵 parse5 tree 和安全策略。server adapter
不会安装 ambient DOM global、执行 script 或加载 resource。

### 导入 DOCX

DOCX import 是 detached、browser/client-only operation。完整 plugin target 放进
`options`，不要传入 editor。

```ts
import { importDocx } from 'platejs/docx/import';

const result = await importDocx(file, {
  plugins: EditorKit,
  signal,
});
```

该 operation 使用 browser 或 client worker。Headless editor runtime 不表示支持
server-side DOCX conversion。

</Steps>

## Runtime boundary

| Runtime | Import | 用途 |
| --- | --- | --- |
| Node editor | `platejs` | 读取、验证与转换 document。 |
| Node Markdown | `platejs/markdown` | 解析与序列化 Markdown。 |
| Node HTML parse | `platejs/html/server` | 解析完整 HTML document 或 slice。 |
| Semantic HTML serialize | `platejs/html` | 序列化 detached Plate document。 |
| Static rendering | `platejs/static` | 渲染 server-safe static component。 |
| React editor | `platejs/react` 与 feature `/react` path | 已挂载 editing UI 与 hook。 |
