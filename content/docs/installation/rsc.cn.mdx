在 React Server Components 中使用 Plate 渲染只读编辑器内容，或在服务端生成 HTML。交互式编辑器仍应放在客户端组件中，并从 `platejs/react` 导入。本指南介绍服务端安全的静态编辑器、HTML 序列化，以及它与仅限 Node.js 处理之间的边界。

## RSC 配置

<Callout type="warning" title="使用静态导入">
  不要在 Server Component 中从 `platejs/react` 或 `@platejs/*/react`
  导入。请使用 `platejs/static`、`platejs` 和基础 `@platejs/*` 入口。
</Callout>

<Steps>

### 安装 Base Kit

如果需要 Plate UI 静态组件和默认序列化插件，请安装复制到应用中的基础编辑器 kit。

```bash
npx shadcn@latest add @plate/editor-plugins-static
```

`editor-plugins-static` 会安装 `BaseEditorKit`、静态节点组件，以及服务端渲染使用的 `editor-static` UI 组件。

### 渲染静态内容

在 Server Component 中创建静态编辑器，并使用 `<PlateStatic>` 渲染。

```tsx title="app/documents/page.tsx" showLineNumbers
import type { Value } from 'platejs';
import { createStaticEditor, PlateStatic } from 'platejs/static';

import { BaseEditorKit } from '@/components/editor/plugins-static';

const value: Value = [
  {
    children: [{ text: '服务端渲染的文档' }],
    type: 'heading', level: 1,
  },
  {
    children: [{ text: '这些内容在没有编辑器状态的情况下渲染。' }],
    type: 'paragraph',
  },
];

export default function DocumentsPage() {
  const editor = createStaticEditor({
    plugins: BaseEditorKit,
    initialValue: value,
  });

  return <PlateStatic editor={editor} />;
}
```

### 序列化 HTML

如果路由需要静态 Plate 视图的服务端 HTML，而不是 React 树，请使用 `renderStaticHtml`。

```tsx title="app/api/document-html/route.ts" showLineNumbers
import type { Value } from 'platejs';
import { createStaticEditor, renderStaticHtml } from 'platejs/static';

import { BaseEditorKit } from '@/components/editor/plugins-static';
import { EditorStatic } from '@/components/editor/editor-static';

const value: Value = [
  {
    children: [{ text: '导出的文档' }],
    type: 'heading', level: 1,
  },
  {
    children: [{ text: '这段 HTML 在服务端生成。' }],
    type: 'paragraph',
  },
];

export async function GET() {
  const editor = createStaticEditor({
    plugins: BaseEditorKit,
    initialValue: value,
  });

  const html = await renderStaticHtml(editor, {
    editorComponent: EditorStatic,
  });

  return new Response(html, {
    headers: { 'content-type': 'text/html; charset=utf-8' },
  });
}
```

### 不使用 Plate UI 的基础包

如果只需要数据转换或 Markdown 输入/输出，请使用 Node.js 路径，而不是静态 React 渲染。

```bash
npm install platejs @platejs/basic-nodes @platejs/markdown
```

该路径使用 `platejs` 的 `createBaseEditor`，不需要复制的 UI 组件。

</Steps>

## 运行时边界

| 运行时 | 导入路径 | 用途 |
| --- | --- | --- |
| Server Component | `platejs/static` | 使用 `<PlateStatic>` 生成只读 React 输出。 |
| Route Handler | `platejs/static` | 使用 `renderStaticHtml` 进行静态 React 渲染。 |
| Node.js 脚本 | `platejs`、`@platejs/*` | 验证、迁移和 Markdown 输入/输出。 |
| 客户端编辑器 | `platejs/react`、`@platejs/*/react` | 可编辑 UI、hooks 和工具栏交互。 |

<Callout type="info">
  `createStaticEditor` 会在你的插件之前加入静态 `ViewPlugin`。需要渲染输出时使用它；脚本只读取或转换值时使用 `createBaseEditor`。
</Callout>
