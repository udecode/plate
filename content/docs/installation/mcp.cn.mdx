将 shadcn MCP 服务器连接到 Plate 注册表，让编码工具访问编辑器模板、插件套件和复制的组件。

## 什么是 MCP？

Model Context Protocol（MCP）让编码工具读取服务器提供的资源并调用工具。
shadcn 服务器读取项目 `components.json` 中配置的注册表。

## 在 Plate 中使用 MCP

配置完成后，编码工具可以：

- 访问我们所有的编辑器模板、插件和 UI 组件
- 生成具有正确导入和配置的代码
- 帮助设置完整的编辑器实例或特定功能
- 保持你的 Plate 配置和组件最新

尝试询问你的 AI：

```bash
"Set up a Plate editor with basic formatting and table support"
"Add AI commands to my editor"
"Update my editor components to the latest version"
```

## 工作原理

Plate 生态系统提供结构化信息，支持 MCP 的工具可以从统一注册表中读取，包括：

- 编辑器模板和插件配置
- UI 组件及其依赖项

注册表提供各组件的源码和依赖信息，供编码工具检查配置和生成示例。

## 本地文档

注册表提供组件，不提供文档。每个 `platejs` 版本都在
`node_modules/platejs/dist/docs/` 中附带与其一致的 Markdown 文档。按照
[本地文档](/docs/installation/docs)让编码 agent 读取这些文档。

## 设置 MCP

按照以下步骤使用 Plate 设置 MCP：

### 步骤 1：安装 Plate

对于已有的 shadcn 项目，先把 Plate 注册表添加到 `components.json`：

```json
{
  "registries": {
    "@plate": "https://platejs.org/r/{style}/{name}.json"
  }
}
```

然后从 `@plate` 注册表添加基础编辑器：

```bash
npx shadcn@latest add @plate/editor-basic
```

对于新项目，创建一个包含基础 Plate 编辑器的 Base/Nova 项目：

```bash
npx shadcn@latest create @plate/editor-basic --preset b0 --base base
```

### 步骤 2：配置你的 IDE

选择适合你 IDE 的配置：

#### Cursor

复制并粘贴到 `.cursor/mcp.json`：

```json
{
  "mcpServers": {
    "plate": {
      "description": "Plate editors, plugins and components",
      "type": "stdio",
      "command": "npx",
      "args": [
        "shadcn@latest",
        "mcp"
      ]
    }
  }
}
```

#### VS Code

复制并粘贴到工作区中的 `.vscode/mcp.json`：

```json
{
  "servers": {
    "plate": {
      "type": "stdio",
      "command": "npx",
      "args": [
        "shadcn@latest",
        "mcp"
      ]
    }
  }
}
```

#### Claude

复制并粘贴到 `.mcp.json`：

```json
{
  "mcpServers": {
    "plate": {
      "description": "Plate editors, plugins and components",
      "type": "stdio",
      "command": "npx",
      "args": [
        "shadcn@latest",
        "mcp"
      ]
    }
  }
}
```

#### Codex

1. 打开或创建文件 `~/.codex/config.toml`
2. 添加以下配置：

```toml
[mcp_servers.plate]
command = "npx"
args = ["shadcn@latest", "mcp"]
```

3. 重启 Codex 以加载 MCP 服务器

## 最佳实践

1.  **本地文档：** 让编码 agent 读取 `node_modules/platejs/dist/docs/` 中与已安装版本一致的文档。参见[本地文档](/docs/installation/docs)。
2.  **AI 辅助开发：** 让 AI 处理编辑器设置、插件集成和组件添加。
3.  **手动回退：** 在需要时使用 [shadcn CLI](/docs/installation/plate-ui) 进行手动添加（例如，使用小型模型或过时的文档）。
4.  **保持更新：** 包内文档随 `platejs` 一起更新。当 AI 需要同步复制的 registry 文件时，使用 [Plate UI](/cn/docs/installation/plate-ui) 中的同步流程。
