## 功能特性

- 为段落、标题等块级元素应用自定义行高
- 向目标块级元素注入 `lineHeight` 属性

</PackageInfo>

## 套件使用

<Steps>

### 安装

最快捷的方式是使用 `LineHeightKit`，它包含预配置的 `LineHeightPlugin`，针对段落和标题元素。

<ComponentSource name="line-height-kit" />

- 配置 `Paragraph` 和 `Heading` 元素（H1-H6）支持 `lineHeight` 属性
- 提供默认行高值 `1.5` 和有效值 `[1, 1.2, 1.5, 2, 3]`

### 添加套件

将套件添加到插件中：

```tsx
import { createPlateEditor } from "platejs/react";
import { LineHeightKit } from "@/components/editor/plugins/line-height-kit";

const editor = createPlateEditor({
  plugins: [
    // ...其他插件,
    ...LineHeightKit,
  ],
});
```

</Steps>

## 手动配置

<Steps>

### 安装

```bash
npm install @platejs/basic-styles
```

### 添加插件

在创建编辑器时将 `LineHeightPlugin` 包含到 Plate 插件数组中。

```tsx
import { LineHeightPlugin } from "@platejs/basic-styles/react";
import { createPlateEditor } from "platejs/react";

const editor = createPlateEditor({
  plugins: [
    // ...其他插件,
    LineHeightPlugin,
  ],
});
```

### 配置插件

您可以配置 `LineHeightPlugin` 来指定目标元素并定义默认或有效的行高值。

```tsx
import { HeadingPlugin } from "@platejs/basic-nodes/react";
import { LineHeightPlugin } from "@platejs/basic-styles/react";
import { createPlateEditor, ParagraphPlugin } from "platejs/react";

const editor = createPlateEditor({
  plugins: [
    // ...其他插件,
    LineHeightPlugin.configure({
      config: {
        targets: [...HeadingPlugin.plugins, ParagraphPlugin],
      },
      inject: {
        nodeProps: {
          defaultNodeValue: 1.5,
          validNodeValues: [1, 1.2, 1.5, 2, 3],
        },
      },
    }),
  ],
});
```

- `inject.nodeProps.defaultNodeValue`: 设置默认行高值（如 `1.5`）
- `inject.nodeProps.validNodeValues`: 定义常用行高值列表，适用于工具栏下拉菜单
- `config.targets`: 指定哪些元素插件类型可以保存 `lineHeight` 属性

`config.targets` 是 schema 的唯一目标配置。插件会从该列表派生渲染和 HTML 解析所需的注入目标。

### 添加工具栏按钮

您可以在[工具栏](/docs/toolbar)中添加 [`LineHeightToolbarButton`](/docs/components/line-height-toolbar-button) 来控制行高。

</Steps>

## 插件

### `LineHeightPlugin`

用于设置块级元素行高的插件。它允许 `config.targets` 指定的元素保存 `lineHeight` 属性。

<API name="LineHeightPlugin">
  <APIOptions type="object">
    <APIItem name="inject.nodeProps.defaultNodeValue" type="number" optional>
      默认行高值
    </APIItem>
    <APIItem name="inject.nodeProps.validNodeValues" type="number[]" optional>
      有效行高值数组
    </APIItem>
    <APIItem name="config.targets" type="PluginReference[]" optional>
      可保存行高的元素插件描述符；注入目标由此派生 - **默认值:** `[BaseParagraphPlugin]`
    </APIItem>
  </APIOptions>
</API>

## 转换器

### `editor.update.lineHeight.set`

为编辑器中选中的节点设置行高。

<API name="editor.update.lineHeight.set">
  <APIParameters>
    <APIItem name="value" type="number">
      行高值
    </APIItem>
    <APIItem name="options" type="object" optional>
      传给 `editor.update.lineHeight.set` 的节点更新选项
    </APIItem>
  </APIParameters>
</API>
