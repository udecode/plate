## 功能特性

- 为段落、标题等块级元素应用自定义行高
- 以正数形式在目标块级元素上保存 `lineHeight` 属性
- 没有 `lineHeight` 的块跟随主题行高

</PackageInfo>

## 套件使用

<Steps>

### 安装

最快捷的方式是使用 `LineHeightKit`。它包含预配置的 `BaseLineHeightPlugin`，可安全地用于客户端和服务端渲染，并针对段落和标题元素。

<ComponentSource name="line-height" />

- 配置 `Paragraph` 和 `Heading` 元素（H1-H6）支持 `lineHeight` 属性

### 添加套件

将套件添加到插件中：

```tsx
import { createEditor } from "platejs/react";
import { LineHeightKit } from "@/components/editor/line-height";

const editor = createEditor({
  plugins: [
    // ...其他插件,
    ...LineHeightKit,
  ],
});
```

</Steps>

## 手动配置

<Steps>

### 安装

```bash
npm install platejs
```

### 添加插件

在创建编辑器时将 `BaseLineHeightPlugin` 包含到 Plate 插件数组中。

```tsx
import { BaseLineHeightPlugin } from "platejs";
import { createEditor } from "platejs/react";

const editor = createEditor({
  plugins: [
    // ...其他插件,
    BaseLineHeightPlugin,
  ],
});
```

### 配置插件

您可以配置 `BaseLineHeightPlugin` 来指定可以保存行高的元素。

```tsx
import { BaseLineHeightPlugin, PLUGINS } from "platejs";
import { createEditor } from "platejs/react";

const editor = createEditor({
  plugins: [
    // ...其他插件,
    BaseLineHeightPlugin.configure({
      targetPlugins: [
        PLUGINS.heading,
        PLUGINS.paragraph,
      ],
    }),
  ],
});
```

- `targetPlugins`: 指定哪些元素插件可以保存 `lineHeight` 属性

`targetPlugins` 是 schema 的唯一目标配置。插件会从该列表派生渲染和 HTML 解析所需的注入目标。每个已保存的值都会渲染为 CSS `line-height`。

### 添加工具栏按钮

工具栏控件需要单独安装：

```bash
npx shadcn@latest add @plate/line-height-toolbar-button
```

然后可以在[工具栏](/docs/toolbar)中添加 [`LineHeightToolbarButton`](/docs/components/line-height-toolbar-button) 来控制行高。下拉菜单在自身文件中列出预设值 `1`、`1.2`、`1.5`、`2` 和 `3`，另有一个清除行高的“默认”项。没有行高的块会勾选“默认”，选区中的值不一致时不勾选任何项。

</Steps>

## HTML

粘贴的 HTML 块带有内联 `line-height` 样式时，Plate 会把它解析为倍数，并把该数字保存到块上。

```html
<p style="line-height: 150%">Readable spacing</p>
```

| 粘贴的 CSS 行高 | 保存的值 | 诊断 |
| --- | --- | --- |
| `1.5`、`150%`、`1.5em` | `1.5` | 无 |
| 来自 Word 的 `107%` | `1.07` | 无 |
| `normal`、其他关键字、`calc()` 或 `var()` | 不保存，块跟随主题 | 丢弃属性警告 |
| `24px`、`18pt`、`1.5rem` | 不保存，块跟随主题 | 丢弃属性警告 |
| 零 | 不保存 | 丢弃属性警告 |
| 负数或其他无效的 CSS | 不保存 | 浏览器中无，服务端为丢弃属性警告 |

浏览器会在 Plate 读取样式之前丢弃负数和其他无效的 CSS 声明，因此这类粘贴不保存任何值，也没有警告。`platejs/html/server` 会保留这些声明，所以在服务端解析时同样会发出警告。

该警告会与本次粘贴的其他 [HTML 诊断](/docs/html#results-and-diagnostics)一起返回。

## 插件

### `BaseLineHeightPlugin`

用于设置块级元素行高的插件。它允许 `targetPlugins` 指定的元素保存 `lineHeight` 属性，值为正数。

<API name="BaseLineHeightPlugin">
  <APIOptions type="object">
    <APIItem name="targetPlugins" type="readonly (PluginReference | string)[]" optional>
      可保存行高的元素插件 descriptor 或动态 name；注入目标由此派生 - **默认值:**
      `[BaseParagraphPlugin]`
    </APIItem>
  </APIOptions>
</API>

## 转换器

### `editor.update.lineHeight.set`

为编辑器中选中的节点设置行高。

<API name="editor.update.lineHeight.set">
  <APIParameters>
    <APIItem name="value" type="number">
      行高值，必须为正数
    </APIItem>
    <APIItem name="options" type="object" optional>
      传给 `editor.update.lineHeight.set` 的节点更新选项
    </APIItem>
  </APIParameters>
</API>

### `editor.update.lineHeight.clear`

移除匹配块上的行高，使其跟随主题。

```tsx
editor.update.lineHeight.clear({ at: [] });
```

<API name="editor.update.lineHeight.clear">
  <APIParameters>
    <APIItem name="options" type="object" optional>
      传给 `editor.update.lineHeight.clear` 的节点更新选项
    </APIItem>
  </APIParameters>
</API>
