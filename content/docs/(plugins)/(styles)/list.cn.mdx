列表将支持的块转换为扁平列表项。列表种类、标记样式、明确编号边界、任务状态和缩进分别存储。

<ComponentPreview name="list-demo" />

<PackageInfo>

## 功能

- listType 为 bulleted、numbered 或 task。
- listStyle 可选，用于 CSS 标记样式。
- listStart 保存条件开始值，仅在该项是序列第一项时生效。
- listRestart 强制该项成为有序列表的新边界。
- checked 只属于任务项。
- 显示编号通过读取计算，不重写后续节点。

</PackageInfo>

## Kit 用法

~~~tsx
import { ListKit } from '@/components/editor/list';

const editor = createEditor({
  plugins: [...ListKit],
});
~~~

## 值

~~~ts
const value = [
  {
    type: 'paragraph',
    listType: 'numbered',
    listStart: 4,
    indent: 1,
    children: [{ text: '四' }],
  },
  {
    type: 'paragraph',
    listType: 'numbered',
    indent: 1,
    children: [{ text: '五' }],
  },
  {
    type: 'paragraph',
    listType: 'task',
    checked: false,
    indent: 1,
    children: [{ text: '发布' }],
  },
];
~~~

第二项不保存 5。Plate 通过 editor.read.list.ordinal(element) 计算。

listStart 保存潜在作者意图。存在兼容的前一项时 Plate 会忽略它，但仍保留该字段；如果后续编辑让该项成为第一项，它就会生效。当该项即使存在兼容前项也必须开启新序列时，使用 listRestart。

两个字段都是有符号安全整数，因此零和负数的有序列表起始值仍然有效。

## 命令

~~~ts
import { ListStyle, ListType } from 'platejs';
import { ListPlugin } from 'platejs/react';

const list = editor.plugin(ListPlugin);
list.update.toggle({ type: ListType.Bulleted });
list.update.toggle({
  type: ListType.Bulleted,
  listStyle: ListStyle.Square,
});
list.update.toggle({
  type: ListType.Numbered,
  listStart: 4,
});
list.update.toggle({
  type: ListType.Numbered,
  listRestart: 4,
});
list.update.toggle({ type: ListType.Task });
~~~

## HTML 和 Markdown

HTML ul 和 ol 映射到 listType。明确的 CSS list-style-type 映射到 listStyle。自然边界的 ol start 映射到 listStart；兼容序列后的 ol 边界映射到 listRestart。Plate 剪贴板 HTML 在私有列表元数据中携带这两个字段。

MDAST list.ordered 映射到 listType。两种开始策略都会序列化为当前可见的 list.start，非默认的结构化 MDAST start 会反序列化为 listRestart。Markdown 无法保留条件开始与强制重启的区别。任务复选框映射到 task 和 checked。

## API

| API | 用途 |
| --- | --- |
| ListType | bulleted、numbered 和 task 常量。 |
| ListStyle | CSS 标记常量。 |
| update.toggle(options) | 设置或移除列表语义。 |
| update.indent(options) | 增加缩进并设置列表语义。 |
| update.outdent(options) | 减少缩进。 |
| read.ordinal(element) | 计算有序项显示编号。 |
