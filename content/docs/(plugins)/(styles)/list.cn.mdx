列表将支持的块转换为扁平列表项。列表种类、标记样式、列表标识、编号起始值、任务状态和缩进分别存储。

<ComponentPreview name="list-demo" />

<PackageInfo>

## 功能

- listType 为 bulleted、numbered 或 task。
- listStyle 可选，用于 CSS 标记样式。
- listId 标识该项所属的列表。列表会跨过其他块继续编号，两个列表也可以交错。
- listLevels 按层级保存列表的起始值和重启规则，与 Word 的存储方式一致。
- listStart 在该项开启其层级时生效；listRestart 强制该项的编号。
- checked 只属于任务项。
- 显示编号通过读取计算，不重写后续节点。
- 提供“重新编号”和“继续编号”命令。

</PackageInfo>

## Kit 用法

~~~tsx
import { ListKit } from '@/components/editor/list';

const editor = createEditor({
  plugins: [...ListKit],
});
~~~

## 值

~~~ts
const value = [
  {
    type: 'paragraph',
    listType: 'numbered',
    listId: 'steps',
    listStart: 4,
    indent: 1,
    children: [{ text: '四' }],
  },
  {
    type: 'paragraph',
    children: [{ text: '步骤之间的说明。' }],
  },
  {
    type: 'paragraph',
    listType: 'numbered',
    listId: 'steps',
    indent: 1,
    children: [{ text: '五' }],
  },
  {
    type: 'paragraph',
    listType: 'task',
    listId: 'todo',
    checked: false,
    indent: 1,
    children: [{ text: '发布' }],
  },
];
~~~

第三个块不保存 5。Plate 通过 editor.read.list.ordinal(at) 计算，`at` 是该项的路径、节点或键；已知路径的静态渲染器直接传入路径。

### 编号

Plate 按文档顺序为每个列表单独编号。其他列表的块和普通块夹在它的项之间时，列表不会结束。有序项显示：

- 设置了 listRestart 时，显示该值；
- 否则在该层级仍打开时，显示列表在同层级上一项的编号加一；
- 否则依次使用 listStart、listLevels 中该层级的 start，最后是 1。

列表中的任意项都会关闭更深的层级，因此嵌套列表会在每个父项下重新编号。listLevels 中层级的 `restartAfter` 规则可以改变这一点。值为 `0` 时该层级从不重启，值为 `n` 时只在第 `n` 层或更浅层级的项之后重启。每个编号项从自己的 listLevels 读取该规则，值等于或深于其自身层级时按默认规则处理。

没有 listId 的项构成所在根的默认列表。值中包含多个列表时，为每个列表设置自己的 id。命令和输入的列表标记会为新项分配 id：它加入前面同层级的兼容项，否则加入它嵌套所在的项，否则加入后面的兼容项；64 个块之内都没有时，开启新列表。其他编辑插入的无 id 项留在所在根的默认列表中。

listStart 保存潜在作者意图。该项延续所在列表时 Plate 保留它，并在后续编辑让该项开启其层级时应用它。listRestart 即使在列表内部也会强制编号。

两个字段都是有符号安全整数，因此零和负数的有序列表起始值仍然有效。

## 命令

~~~ts
import { ListStyle, ListType } from 'platejs';
import { ListPlugin } from 'platejs/react';

const list = editor.plugin(ListPlugin);
list.update.toggle({ type: ListType.Bulleted });
list.update.toggle({
  type: ListType.Bulleted,
  listStyle: ListStyle.Square,
});
list.update.toggle({
  type: ListType.Numbered,
  listStart: 4,
});
list.update.toggle({ type: ListType.Task });

list.update.restart();
list.update.restart({ start: 4 });
list.update.continue();
~~~

`restart` 强制选中有序项的编号，默认为 1。`continue` 移除该重启；在列表第一项上，它会把整个列表并入同层级中最近的前一个有序列表，使编号接续下去。

## HTML 和 Markdown

HTML ul 和 ol 映射到 listType。明确的 CSS list-style-type 映射到 listStyle。Plate HTML 用 `data-list-id` 标识每项所属的列表，用 `data-list-levels` 保存层级规则。每次粘贴或解析都会为每个来源列表分配新的 id，因此粘贴的列表不会因为 id 相同而并入无关列表；第一个顶层粘贴列表在类型、样式和标题角色都与落入的列表匹配时并入该列表。只存在于粘贴表格中的列表保留自己的 id。在其他 HTML 中，每个 ul 或 ol 是一个列表；start 接续同层级前一个 ol 的 ol 会并入它，项下的第一个嵌套列表会并入该项的列表。Word HTML 保留 Word 的列表标识。

MDAST list.ordered 映射到 listType。每个解析出的 Markdown 列表都会得到新的 listId，不为 1 的 start 解析为 listStart。项下的第一个嵌套列表并入该项的列表，同一项下之后的嵌套列表开启自己的列表。序列化时，Plate 在列表变化、项在有序和无序之间切换或 listStyle 变化处开始新的 Markdown 列表，因此同一列表中的任务项和项目符号项仍是一个 Markdown 列表。它把每个有序列表第一项的可见编号写为 list.start；当列表编号会变为负数或超过 CommonMark 可读的九位数字时写为 1。Markdown 无法保留强制的 listRestart，也无法保留读回时会改变的列表归属，例如跨过其他块继续的列表；Plate 只检查带 listId 的项的列表归属。序列化会把每一项损失报告为 `markdown-property-omitted` 诊断。任务复选框映射到 task 和 checked。在 GFM table cell 中，列表段落写为 inline `<ul>`、`<ol start>` 与 `<li>` HTML，保留任意起始值，并读取回列表；参见 [Markdown](/docs/markdown#table-cell)。

## API

| API | 用途 |
| --- | --- |
| ListType | bulleted、numbered 和 task 常量。 |
| ListStyle | CSS 标记常量。 |
| update.toggle(options) | 设置或移除列表语义。 |
| update.restart(options?) | 强制选中有序项的编号；`start` 默认为 1。 |
| update.continue(options?) | 移除选中项的重启，或从列表第一项起把列表接到前一个列表上。 |
| update.outdent(options) | 减少缩进。 |
| update.clear(options?) | 仅清除选中列表项的列表属性与缩进，保留区块类型和文本。 |
| update.insert(input, options?) | 插入指定类型的段落列表项，并由插件负责构造与位置。 |
| read.ordinal(at) | 计算有序项显示编号；`at` 不是编辑器根中的有序项时返回 `undefined`。 |

`clear` 可通过 `at` 指定位置或节点选区，不会扩展到未选中的相邻列表项。
`insert({ type }, { replaceEmpty: true, select: true })` 在当前区块之后插入；
来源区块为空时，在同一个撤销步骤中替换它。`after` 指定来源区块，`at` 指定节点插入位置。
