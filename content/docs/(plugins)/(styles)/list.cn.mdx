列表将支持的块转换为扁平列表项。列表种类、标记样式、列表标识、编号起始值、任务状态和缩进分别存储。

<ComponentPreview name="list-demo" />

<PackageInfo>

## 功能

- listType 为 bulleted、numbered 或 task。
- listStyle 可选，用于 CSS 标记样式。
- listId 标识该项所属的列表。列表会跨过其他块继续编号，两个列表也可以交错。
- listLevels 按层级保存列表的起始值和重启规则，与 Word 的存储方式一致。
- listStart 在该项开启其层级时生效；listRestart 强制该项的编号。
- checked 只属于任务项。
- 显示编号通过读取计算，不重写后续节点。
- 提供“重新编号”和“继续编号”命令。

</PackageInfo>

## Kit 用法

~~~tsx
import { ListKit } from '@/components/editor/list';

const editor = createEditor({
  plugins: [...ListKit],
});
~~~

## 值

~~~ts
const value = [
  {
    type: 'paragraph',
    listType: 'numbered',
    listId: 'steps',
    listStart: 4,
    indent: 1,
    children: [{ text: '四' }],
  },
  {
    type: 'paragraph',
    children: [{ text: '步骤之间的说明。' }],
  },
  {
    type: 'paragraph',
    listType: 'numbered',
    listId: 'steps',
    indent: 1,
    children: [{ text: '五' }],
  },
  {
    type: 'paragraph',
    listType: 'task',
    listId: 'todo',
    checked: false,
    indent: 1,
    children: [{ text: '发布' }],
  },
];
~~~

第三个块不保存 5。Plate 通过 editor.read.list.ordinal(at) 计算，`at` 是该项的路径、节点或键；已知路径的静态渲染器直接传入路径。

### 编号

Plate 按文档顺序为每个列表单独编号。其他列表的块和普通块夹在它的项之间时，列表不会结束。有序项显示：

- 设置了 listRestart 时，显示该值；
- 否则在该层级仍打开时，显示列表在同层级上一项的编号加一；
- 否则依次使用 listStart、listLevels 中该层级的 start，最后是 1。

列表中的任意项都会关闭更深的层级，因此嵌套列表会在每个父项下重新编号。listLevels 中层级的 `restartAfter` 规则可以改变这一点。值为 `0` 时该层级从不重启，值为 `n` 时只在第 `n` 层或更浅层级的项之后重启。每个编号项从自己的 listLevels 读取该规则，值等于或深于其自身层级时按默认规则处理。

没有 listId 的项构成所在根的默认列表。值中包含多个列表时，为每个列表设置自己的 id。命令和输入的列表标记会为新项分配 id：它加入前面同层级的兼容项，否则加入它嵌套所在的项，否则加入后面的兼容项；64 个块之内都没有时，开启新列表。其他编辑插入的无 id 项留在所在根的默认列表中。

listStart 保存潜在作者意图。该项延续所在列表时 Plate 保留它，并在后续编辑让该项开启其层级时应用它。listRestart 即使在列表内部也会强制编号。

两个字段都是有符号安全整数，因此零和负数的有序列表起始值仍然有效。

## 命令

~~~ts
import { ListStyle, ListType } from 'platejs';
import { ListPlugin } from 'platejs/react';

const list = editor.plugin(ListPlugin);
list.update.toggle({ type: ListType.Bulleted });
list.update.toggle({
  type: ListType.Bulleted,
  listStyle: ListStyle.Square,
});
list.update.toggle({
  type: ListType.Numbered,
  listStart: 4,
});
list.update.toggle({ type: ListType.Task });

list.update.restart();
list.update.restart({ start: 4 });
list.update.continue();
~~~

`restart` 强制选中有序项的编号，默认为 1。`continue` 移除该重启；在列表第一项上，它会把整个列表并入同层级中最近的前一个有序列表，使编号接续下去。

## 粘贴列表

原生粘贴与单次 `editor.update.slice.replace`、
`editor.update.fragment.replace` 会应用 List 的深度、编号和空目标规则。
回调事务中的替换与独立适配不运行这些命令策略。

光标位于空段落或标题中，且目标能容纳完整列表项时，复制文本中 schema 允许的属性会保留。
目标中允许保留的 id、对齐等属性也会保留，复制项自身的属性优先。
对象和 void 项不继承这些目标属性。
空目标显式设置的起始编号与重新编号优先于复制值。替换后的节点使用自己的
运行时 key。

在 `maxLength` 限制下，粘贴只落入放得下的内容。限制截掉第一个复制项时，
剩余项落在光标所在的深度。引用中的列表在文本放不下时不粘贴任何内容。

## HTML 和 Markdown

HTML ul 和 ol 映射到 listType。明确的 CSS list-style-type 映射到 listStyle。Plate HTML 用 `data-list-id` 标识每项所属的列表，用 `data-list-levels` 保存层级规则。每次粘贴或解析都会为每个来源列表分配新的 id，因此粘贴的列表不会因为 id 相同而并入无关列表；第一个顶层粘贴列表在种类和标题角色与目标列表匹配时并入该列表，其根项采用目标的标记样式。复制的同级项落在目标项的深度；父项也被复制时，子项保留相对父项的深度。以列表项开头的多区块粘贴或闭合切片粘贴到空段落或空标题时，会在 schema 允许的情况下保留第一项的类型，在引用、表格单元格或分栏内也如此。兼容列表下方的空行会接续该列表。空目标自身的起始编号和重新编号优先于复制值。只存在于粘贴表格中的列表保留自己的 id。在其他 HTML 中，每个 ul 或 ol 是一个列表；start 接续同层级前一个 ol 的 ol 会并入它，项下的第一个嵌套列表会并入该项的列表。Word HTML 保留 Word 的列表标识。画在区块内部的列表，例如 static kit 输出的 `<h2><ol data-list-id="…"><li>…</li></ol></h2>`，会读回为带列表属性的该区块；列表项自身的 `data-list-style` 优先于所在列表的标记。

自定义对象的正文若位于独立内容根中，需要复制整个对象才能保留正文。只复制标题或说明文字时，正文可能不在复制内容中，这种部分复制不保证保留对象类型或列表编号。

MDAST list.ordered 映射到 listType。每个解析出的 Markdown 列表都会得到新的 listId，不为 1 的 start 解析为 listStart。项下的第一个嵌套列表并入该项的列表，同一项下之后的嵌套列表开启自己的列表。序列化时，Plate 在列表变化、项在有序和无序之间切换或 listStyle 变化处开始新的 Markdown 列表，因此同一列表中的任务项和项目符号项仍是一个 Markdown 列表。它把每个有序列表第一项的可见编号写为 list.start；当列表编号会变为负数或超过 CommonMark 可读的九位数字时写为 1。Markdown 无法保留强制的 listRestart，也无法保留读回时会改变的列表归属，例如跨过其他块继续的列表；Plate 只检查带 listId 的项的列表归属。序列化会把每一项损失报告为 `markdown-property-omitted` 诊断。Markdown 把列表项的后续段落解析为比该项深一级、没有 listType 的区块，这样的区块会序列化到前一项之内。任务复选框映射到 task 和 checked。在 GFM table cell 中，列表段落写为 inline `<ul>`、`<ol start>` 与 `<li>` HTML，保留任意起始值，并读取回列表；参见 [Markdown](/cn/docs/markdown#table-cell)。

列表项之后的块，例如第二段、代码块或图片，在两种格式中都解析为比该项深一级、没有 listType 的块：缩进为 1 的项之后是 `{ type: 'codeBlock', indent: 2 }`。Plate HTML 把它们写在列表之后。HTML 把它们嵌套在 `li` 中时，项的 `margin-left` 计为它的层级。`li` 或包装元素设置的样式，例如粗体，不会带到从该元素移出的内容上，解析会发出一次 `html-unsupported-content` 警告，指出第一个这样的样式。`white-space` 也是如此，因此 `pre-wrap` 保留的换行会变成空格。项的段落中的图片则保留在 HTML 运行时放置的位置，即项的文本之后、列表之外，图片之后的文本成为另一个列表项。当编辑器无法把某个列表属性放到块上时，例如 IndentPlugin 不以代码块为目标时代码块上的 `indent`，该块保留自己的类型并丢弃这个属性。HTML 将其报告为 `html-unsupported-content`，Markdown 报告为 `markdown-unsupported-node`，在任何 `lossPolicy` 下都是警告。第一个块无法放入列表的 Markdown 项，例如 ListPlugin 只以段落为目标时的标题，会读作列表段落。不是一行文本的第一个块，例如分隔线或引用，则保留自己的类型并离开列表。解析会报告这两种变化，因此 `lossPolicy: 'reject'` 会拒绝它。

## API

| API | 用途 |
| --- | --- |
| ListType | bulleted、numbered 和 task 常量。 |
| ListStyle | CSS 标记常量。 |
| update.toggle(options) | 设置或移除列表语义。 |
| update.restart(options?) | 强制选中有序项的编号；`start` 默认为 1。 |
| update.continue(options?) | 移除选中项的重启，或从列表第一项起把列表接到前一个列表上。 |
| update.outdent(options) | 减少每个选中列表项及其下方块的缩进，并在最外层清除列表属性。 |
| update.clear(options?) | 仅清除选中列表项的列表属性与缩进，保留区块类型和文本。 |
| update.insert(input, options?) | 插入指定类型的段落列表项，并由插件负责构造与位置。 |
| read.ordinal(at) | 计算有序项显示编号；`at` 不是编辑器根中的有序项时返回 `undefined`。 |

`clear` 可通过 `at` 指定位置或节点选区，不会扩展到未选中的相邻列表项。
`insert({ type }, { replaceEmpty: true, select: true })` 在当前区块之后插入；
来源区块为空时，在同一个撤销步骤中替换它。`after` 指定来源区块，`at` 指定节点插入位置。

Tab、Shift+Tab 和 `outdent` 会把列表项和它下方的块一起移动，直到下一个深度相同或更浅的块为止，
包括嵌套列表项和后续段落。拖动和剪切通过 `editor.read.transfer.nodes()` 取得同样的块。
Indent 自身的命令仍然只移动一个块。
List 会自己写入每个被移动块的深度，所以对 Indent 的 `increase` 或 `decrease` 的覆盖不会在这些移动中运行。

在 Details 标题上调用 `toggle` 时，标题变成列表项，正文放在它下面一级。如果某个正文块不能缩进，
或者结果放不进父级，它返回 `false`，文档不变，选区中的其他块也不会转换。
