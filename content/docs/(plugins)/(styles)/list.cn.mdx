## 功能

- **扁平列表模型**：任何受支持的块都可以成为列表项，无需嵌套的列表节点树。
- **项目符号、编号和待办样式**：使用 CSS 列表样式或 `KEYS.listTodo`。
- **自动缩进支持**：`ListPlugin` 会安装必需的 Indent 依赖。
- **精确目标命令**：对当前选择、路径、点或范围执行切换、缩进和减少缩进。
- **输入规则**：注册内置的 `-`、`*`、`1.` 和任务列表 Markdown 规则。

</PackageInfo>

## Kit 用法

`ListKit` 配置列表渲染、输入规则以及支持列表的块类型。

<ComponentSource name="list-kit" />

```tsx
import { createPlateEditor } from 'platejs/react';
import { ListKit } from '@/components/editor/plugins/list-kit';

const editor = createPlateEditor({
  plugins: [...ListKit],
});
```

添加[`列表工具栏按钮`](/docs/components/list-toolbar-button)以提供项目符号、编号和待办控件。

## 手动用法

### 安装

```bash
npm install @platejs/list
```

### 添加插件

`ListPlugin` 包含默认的 Indent 配置。

```tsx
import { ListPlugin } from '@platejs/list/react';
import { createPlateEditor } from 'platejs/react';

const editor = createPlateEditor({
  plugins: [ListPlugin],
});
```

### 配置列表渲染和输入规则

```tsx
import {
  BulletedListRules,
  OrderedListRules,
  TaskListRules,
} from '@platejs/list';
import { BlockquotePlugin } from '@platejs/basic-nodes/react';
import { CodeBlockPlugin } from '@platejs/code-block/react';
import { ListPlugin } from '@platejs/list/react';
import { KEYS } from 'platejs';
import { ParagraphPlugin } from 'platejs/react';
import { BlockList } from '@/components/ui/block-list';

const CustomListPlugin = ListPlugin.configure({
  targetPluginNames: [
    ...KEYS.heading,
    ParagraphPlugin.name,
    BlockquotePlugin.name,
    CodeBlockPlugin.name,
  ],
  inputRules: [
    BulletedListRules.markdown({ variant: '-' }),
    OrderedListRules.markdown({ variant: '.' }),
    TaskListRules.markdown({ checked: false }),
  ],
  render: {
    belowNodes: BlockList,
  },
});
```

需要自定义目标、偏移量或单位时，添加 `IndentPlugin.configure(...)`。显式的 Indent 配置会覆盖依赖默认值，并且运行时仍只安装一个 Indent 插件。

## API 参考

### 作用域读取

通过 List 插件入口读取列表状态：

```ts
const list = editor.plugin(ListPlugin);

list.read.isActive(ListStyleType.Disc);
list.read.isActive([ListStyleType.Disc, ListStyleType.Circle]);
list.read.isActive(KEYS.listTodo);
```

编辑器没有选择时，`isActive` 返回 `false`。

### 作用域更新

列表更新在一个 Plite 事务中运行，并生成一个撤销步骤：

```ts
const list = editor.plugin(ListPlugin);

list.update.toggle({ listStyleType: ListStyleType.Decimal });
list.update.indent({ listStyleType: ListStyleType.Disc });
list.update.outdent();
```

传入 `at` 可以在不移动选择的情况下指定位置：

```ts
list.update.toggle({ at: [2], listStyleType: ListStyleType.Disc });
list.update.toggle({
  at: {
    anchor: { path: [2, 0], offset: 0 },
    focus: { path: [4, 0], offset: 3 },
  },
  listStyleType: ListStyleType.Decimal,
});
```

- 不传 `at`：使用当前选择。
- `Path` 或 `Point`：指定一个块。
- `Range`：指定范围内所有匹配的块。
- 缺失、无效或根位置不会执行操作。

### 更新选项

```ts
type ToggleListOptions = {
  at?: Location;
  getSiblingListOptions?: GetSiblingListOptions<Element>;
  listRestart?: number;
  listRestartPolite?: number;
  listStyleType: ListStyleType | string;
};

type IndentListOptions = {
  at?: Location;
  listStyleType?: ListStyleType | string;
};

type OutdentListOptions = {
  at?: Location;
};
```

`listRestart` 在目标处重新开始编号。`listRestartPolite` 仅在目标是列表序列开头时生效。

### 领域查询

该包导出以下列表遍历和策略查询：

- `areEqListStyleType`
- `expandListItemsWithChildren`
- `getListAbove`
- `getListChildren`
- `getListSiblings` 和 `GetListSiblingsOptions`
- `getNextList`
- `getPreviousList`
- `getSiblingList` 和 `GetSiblingListOptions`
- `getSiblingListStyleType`
- `isOrderedList`

### Hooks

- `useListToolbarButtonState` 和 `useListToolbarButton`
- `useTodoListToolbarButtonState` 和 `useTodoListToolbarButton`
- `useTodoListElementState` 和 `useTodoListElement`

工具栏 hooks 通过作用域化的 `ListPlugin` API 读取和更新状态。待办元素 hook 会在复选框变化时解析元素路径，因此节点移动后仍能正确更新。
