Subscript is the `'sub'` value of Plate's `script` mark. `ScriptPlugin` owns both script positions, so switching to superscript replaces the value instead of coordinating two boolean marks.

<ComponentPreview name="basic-marks-demo" />

<PackageInfo>

## Features

- One `script` leaf property with `'sub' | 'sup'` values, owned by the `PLUGINS.script` capability.
- Directional selection affinity.
- HTML deserialization from `sub` and `vertical-align: sub`.
- `<sub>` rendering for the `'sub'` value.
- Optional `~x~` input rule through `ScriptRules`.

</PackageInfo>

## Kit Usage

<Steps>

### Add Basic Marks

`BasicMarksKit` includes `ScriptPlugin`, the subscript input rule, and a `mod+comma` shortcut.

<ComponentSource name="basic-marks" />

```tsx
import { createPlateEditor } from 'platejs/react';

import { BasicMarksKit } from '@/components/editor/basic-marks';

export const editor = createPlateEditor({
  plugins: [...BasicMarksKit],
});
```

### Add a Toolbar Control

Pass the shared plugin and the subscript value to `MarkToolbarButton`.

```tsx
import { ScriptPlugin } from '@platejs/basic-nodes/react';
import { SubscriptIcon } from 'lucide-react';

import { MarkToolbarButton } from '@/components/editor/mark-toolbar-button';

export function SubscriptToolbarButton() {
  return (
    <MarkToolbarButton
      plugin={ScriptPlugin}
      value="sub"
      tooltip="Subscript"
    >
      <SubscriptIcon />
    </MarkToolbarButton>
  );
}
```

</Steps>

## Manual Usage

Install the mark package.

```bash
npm install @platejs/basic-nodes
```

Add the shared script plugin and configure only the input rule you need.

```tsx
import { ScriptRules } from '@platejs/basic-nodes';
import { ScriptPlugin } from '@platejs/basic-nodes/react';
import { createPlateEditor } from 'platejs/react';

export const editor = createPlateEditor({
  plugins: [
    ScriptPlugin.configure({
      inputRules: [ScriptRules.markdown({ value: 'sub' })],
    }),
  ],
});
```

Toggle subscript from application code with the typed value.

```tsx
editor.update.script.toggle('sub');
```

## Ownership

| Surface | Owner | What It Does |
|---------|-------|--------------|
| `BaseScriptPlugin` | `@platejs/basic-nodes` | Declares the enum mark, HTML codec, selection rule, and typed toggle. |
| `ScriptPlugin` | `@platejs/basic-nodes/react` | Renders `'sub'` as `<sub>` and `'sup'` as `<sup>`. |
| `ScriptRules.markdown` | `@platejs/basic-nodes` | Creates a value-aware `~x~` or `^x^` input rule. |
| `BasicMarksKit` | Registry | Configures both input rules and shortcuts. |
| `MarkToolbarButton` | Registry UI | Toggles the requested script value. |

## API Reference

| API | Use |
|-----|-----|
| `editor.plugin(ScriptPlugin).schema.key` | The configured text property (default: `script`). |
| `ScriptPlugin` | Shared React plugin for subscript and superscript. |
| `ScriptRules.markdown({ value: 'sub' })` | Creates the subscript input rule. |
| `editor.update.script.toggle('sub')` | Applies subscript or removes it when already active. |
