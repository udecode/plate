下标是 `script` 标记的 `'sub'` 值。`ScriptPlugin` 同时管理下标和上标，因此切换位置只会替换一个属性值。

<ComponentPreview name="basic-marks-demo" />

<PackageInfo>

## 特性

- 使用一个 `PLUGINS.script` 属性表示 `'sub' | 'sup'`。
- 从 `sub` 标签和 `vertical-align: sub` 反序列化。
- `'sub'` 值默认渲染为 `<sub>`。
- 通过 `ScriptRules` 支持可选的 `~x~` 输入规则。

</PackageInfo>

## 套件使用

`BasicMarksKit` 包含 `ScriptPlugin`、下标输入规则和 `mod+comma` 快捷键。

<ComponentSource name="basic-marks-kit" />

```tsx
import { createPlateEditor } from 'platejs/react';

import { BasicMarksKit } from '@/components/editor/plugins/basic-marks-kit';

export const editor = createPlateEditor({
  plugins: [...BasicMarksKit],
});
```

## 手动使用

安装标记包。

```bash
npm install @platejs/basic-nodes
```

添加共享脚本插件，并配置下标输入规则。

```tsx
import { ScriptRules } from '@platejs/basic-nodes';
import { ScriptPlugin } from '@platejs/basic-nodes/react';
import { createPlateEditor } from 'platejs/react';

export const editor = createPlateEditor({
  plugins: [
    ScriptPlugin.configure({
      inputRules: [ScriptRules.markdown({ value: 'sub' })],
    }),
  ],
});
```

```tsx
editor.update.script.toggle('sub');
```

## API 参考

| API | 用途 |
|-----|------|
| `PLUGINS.script` | `script` 文本属性。 |
| `ScriptPlugin` | 下标和上标共用的 React 插件。 |
| `ScriptRules.markdown({ value: 'sub' })` | 创建下标输入规则。 |
| `editor.update.script.toggle('sub')` | 应用下标；已启用时则移除。 |
