键盘输入为选中文本应用 `kbd` 叶子标记。用它表示应渲染为 `<kbd>` 的快捷键、按键名称和命令提示。

<ComponentPreview name="basic-marks-demo" />

<PackageInfo>

## 功能特性

- 布尔类型的 `kbd` 叶子属性，由 `PLUGINS.kbd` 能力负责。
- 硬选区亲和性。
- 从 `kbd` 反序列化 HTML。
- 默认渲染为 `<kbd>`。
- Registry 提供带样式的键盘输入 `KbdLeaf`。
- 通过 `KbdLeafStatic` 支持静态渲染。

</PackageInfo>

## 套件使用

<Steps>

### 添加基础标记

`BasicMarksKit` 包含 `KbdPlugin.configure({ component: KbdLeaf })`。它不为键盘输入添加快捷键或输入规则。

<ComponentSource name="basic-marks" />

```tsx
import { createEditor } from 'platejs/react';

import { BasicMarksKit } from '@/components/editor/basic-marks';

export const editor = createEditor({
  plugins: [...BasicMarksKit],
});
```

### 添加叶子

`KbdLeaf` 为 `<kbd>` 元素提供 registry 样式。

<ComponentSource name="kbd" />

### 添加工具栏控件

Registry 的 `MoreToolbarButton` 在“更多”菜单中切换键盘输入。

```tsx
import { MoreToolbarButton } from '@/components/editor/more-toolbar-button';

export function FormattingMoreMenu() {
  return <MoreToolbarButton />;
}
```

</Steps>

## 手动使用

安装标记所在的包。

```bash
npm install platejs
```

需要默认的 `<kbd>` 渲染时，直接添加 `KbdPlugin`。

```tsx
import { KbdPlugin } from 'platejs/react';
import { createEditor } from 'platejs/react';

export const editor = createEditor({
  plugins: [KbdPlugin],
});
```

需要与套件相同的外观时，挂上 registry 叶子。

```tsx
import { KbdPlugin } from 'platejs/react';

import { KbdLeaf } from '@/components/editor/kbd';

export const kbdPlugin = KbdPlugin.configure({ component: KbdLeaf });
```

## 归属

| 接口 | 负责方 | 作用 |
|---------|-------|--------------|
| `BaseKbdPlugin` | `platejs` | 无头键盘输入标记、HTML 解析器、渲染标签、选区规则和 `toggle` 转换。 |
| `KbdPlugin` | `platejs/react` | 无头键盘输入标记的 React 包装。 |
| `KbdLeaf` | Registry UI | 使用 `EditorLeaf` 的带样式客户端 `<kbd>` 叶子。 |
| `KbdLeafStatic` | Registry UI | 使用 `EditorLeaf` 的静态渲染版本。 |
| `BasicMarksKit` | Registry | 添加 `KbdPlugin.configure({ component: KbdLeaf })`。 |
| `MoreToolbarButton` | Registry UI | 在“更多”菜单中调用 `editor.plugin(KbdPlugin).update.toggle()`。 |

包负责标记本身。Registry 负责键帽样式和工具栏位置。

## 行为

| 行为 | 来源 |
|----------|--------|
| 标记键 | `editor.plugin(KbdPlugin).schema.key`（默认：`kbd`） |
| 标记声明 | `schema.mark: property.boolean({ default: false, omitDefault: true })` |
| 切换命令 | `tx.kbd.toggle()` 切换解析后的 schema 键。 |
| 选区亲和性 | `hard` |
| HTML 标签 | `kbd` |
| 渲染输出 | `kbd` |
| 套件组件 | `KbdLeaf` |
| Registry 工具栏 | `MoreToolbarButton` 通过 `KbdPlugin` 切换。 |

## API 参考

| API | 包 | 用途 |
|-----|---------|-----|
| `BaseKbdPlugin` | `platejs` | 无头键盘输入插件。 |
| `KbdPlugin` | `platejs/react` | React 键盘输入插件。 |
| `tx.kbd.toggle()` | `platejs` | 在选区处切换键盘输入标记。 |
| `KbdLeaf` | Registry UI | 带样式的客户端键盘输入叶子。 |
| `KbdLeafStatic` | Registry UI | 带样式的静态键盘输入叶子。 |
