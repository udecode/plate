Bold applies the `bold` leaf mark to selected text. `BoldPlugin` owns the mark key, shortcut, HTML parsing, render tag, and toggle transform.

<ComponentPreview name="basic-marks-demo" />

<PackageInfo>

## Features

- Boolean `bold` leaf property owned by the `PLUGINS.bold` capability.
- Default `⌘B` / `Ctrl+B` shortcut.
- HTML deserialization from `strong`, `b`, and any `font-weight` of 600 or more.
- `<strong>` rendering by default.
- Optional Markdown-style input rules through `BoldRules`.
- Toolbar support through `MarkToolbarButton`.

</PackageInfo>

## Kit usage

<Steps>

### Add basic marks

`BasicMarksKit` includes `BoldPlugin`, bold input rules, and the standard toolbar buttons that use the plugin descriptor.

<ComponentSource name="basic-marks" />

```tsx
import { createEditor } from 'platejs/react';

import { BasicMarksKit } from '@/components/editor/basic-marks';

export const editor = createEditor({
  plugins: [...BasicMarksKit],
});
```

### Add a toolbar button

Pass `BoldPlugin` to `MarkToolbarButton` so the button uses the configured mark key.

```tsx
import { BoldIcon } from 'lucide-react';
import { BoldPlugin } from 'platejs/react';

import { MarkToolbarButton } from '@/components/editor/mark-toolbar-button';

export function BoldToolbarButton() {
  return (
    <MarkToolbarButton plugin={BoldPlugin} tooltip="Bold (⌘+B)">
      <BoldIcon />
    </MarkToolbarButton>
  );
}
```

</Steps>

## Manual usage

Install the mark package.

```bash
npm install platejs
```

Add `BoldPlugin` directly when you do not want the whole kit.

```tsx
import { BoldPlugin } from 'platejs/react';
import { createEditor } from 'platejs/react';

export const editor = createEditor({
  plugins: [BoldPlugin],
});
```

Register Markdown-style input rules when users should type bold delimiters.

```tsx
import { BoldRules } from 'platejs';
import { BoldPlugin } from 'platejs/react';

export const boldPlugin = BoldPlugin.configure({
  inputRules: [
    BoldRules.markdown({ variant: '*' }),
    BoldRules.markdown({ variant: '_' }),
  ],
});
```

## Ownership

| Surface | Owner | What It Does |
|---------|-------|--------------|
| `BaseBoldPlugin` | `platejs` | Headless bold mark, HTML parser, render tag, and `toggle` transform. |
| `BoldPlugin` | `platejs/react` | React wrapper with default `mod+b` shortcut. |
| `BoldRules.markdown` | `platejs` | Optional mark input rule factory. |
| `BasicMarksKit` | Registry | Adds `BoldPlugin` with `*` and `_` Markdown-style input rules. |
| `MarkToolbarButton` | Registry UI | Reads active mark state and calls the mark toggle hook. |

The package owns the mark. The registry owns toolbar placement and icon choice.

## Behavior

| Behavior | Source |
|----------|--------|
| Mark key | `editor.plugin(BoldPlugin).schema.key` (default: `bold`) |
| Mark declaration | `schema.mark: property.boolean({ default: false, omitDefault: true })` |
| Toggle command | `tx.bold.toggle()` toggles the resolved schema key. |
| Shortcut | `BoldPlugin` registers `mod+b`. |
| HTML tags | `strong`, `b` |
| HTML styles | Any `font-weight`. `bold` and 600 or more are bold. `bolder`, `lighter`, `inherit` and `unset` count from the parent's weight, where headings and table headers draw at 700. |
| HTML guard | A weight below 600 turns bold off only inside text drawn bold. `strong` and `b` stay bold unless they state a weight Plate can read. |
| Render output | `strong` |

Bold is Plate's only owner of font weight; no plugin stores a separate weight.
Paste reads each element's own weight, as the source drew it.
On the server, `platejs/html/server` ignores a weight written in a `font` shorthand, under `FONT-WEIGHT` or beside a comment.
It also reads the last of several `font-weight` declarations, even when an earlier one is `!important`.

| Pasted HTML | Stored |
|-------------|--------|
| `<span style="font-weight: 800">a</span>` | `a` bold |
| `<b>a<span style="font-weight: 400">b</span>c</b>` | `a` and `c` bold, `b` plain |
| `<strong style="font-weight: 500">a</strong>` | `a` plain |
| `<strong style="font-weight: var(--w, 600)">a</strong>` | `a` bold, because the weight is unreadable |
| `<span style="font-weight: bolder">a</span>` inside 300 text | `a` plain, because bolder than 300 is 400 |
| `<h1>a<span style="font-weight: 400">b</span>c</h1>` | `abc` with no mark, so `b` draws in the heading's weight. Bold cannot store text lighter than its heading or table header. |

## API Reference

| API | Package | Use |
|-----|---------|-----|
| `BaseBoldPlugin` | `platejs` | Headless bold plugin. |
| `BoldPlugin` | `platejs/react` | React bold plugin with shortcut defaults. |
| `BoldRules.markdown(options)` | `platejs` | Creates a bold mark input rule. |
| `tx.bold.toggle()` | `platejs` | Toggles the bold mark at the selection. |
