`SelectEditor` 是一个单行编辑器，它的值是一组标签。每个选中的标签都是行内标签元素，因此光标可以在标签之间移动，Backspace 会删除一个标签，标签也能像文本一样复制和粘贴。菜单会按输入的搜索文本筛选 `items`。

## 安装

<ComponentInstallation name="select-editor" inline />

安装该组件会添加两个文件：`select-editor.tsx`（字段及其标签规则）和 `tag.tsx`（`tag` 元素及其标签样式）。

## 使用

```tsx
import * as React from 'react';

import { type SelectItem, SelectEditor } from '@/components/editor/select-editor';

const ITEMS: SelectItem[] = [
  { value: 'React' },
  { value: 'TypeScript' },
  { value: 'JavaScript' },
];

export function LabelsField() {
  const [value, setValue] = React.useState<SelectItem[]>([ITEMS[0]]);

  return (
    <SelectEditor
      aria-label="Labels"
      items={ITEMS}
      placeholder="Select labels..."
      value={value}
      onValueChange={setValue}
    />
  );
}
```

`onValueChange` 必须同步更新 `value`。只要 `value` 与标签不同，字段就会把 `value` 写回，所以稍后设置的值（例如在 transition 中设置）会先撤销这次修改。非受控字段请传入 `defaultValue` 而不是 `value`。

## 行为

- 输入文本进行搜索。`ArrowUp` 和 `ArrowDown` 移动当前选项，`Enter` 选中它。
- 两个或更多字符的搜索如果没有匹配的标签，菜单会提供创建它的选项。
- `Escape`、`mod+Enter` 或点击外部会关闭菜单并清除搜索。
- 只有大小写不同的标签视为同一个。第一个标签保留，因此表单值中重复的标签只显示一次。
- 撤销和重做快捷键已关闭，选中的标签不会被撤销。
- 只读字段仅在 [`getLinkHref`](/cn/docs/link#getlinkhref) 接受标签的 `url` 时把标签渲染为链接。`url` 被拒绝的标签（例如 `javascript:` 地址或只有 `https://`）显示为没有链接的标签。
- 把标签拖到另一个标签之前会移动它。把标签放到另一个标签之后不会产生任何变化。

要修改这些规则，请编辑复制的 `select-editor.tsx` 中的 `SelectTagPlugin`；要修改按键，请编辑字段的按键处理函数。

## API 参考

### SelectEditor

接收可编辑区域的属性，例如 `placeholder`、`readOnly`、`onBlur` 和 `aria-*`，但不包括字段自己设置的 combobox 属性。

<API name="SelectEditor">
<APIProps>
  <APIItem name="items" type="readonly SelectItem[]" optional>
    菜单提供的标签。
  </APIItem>
  <APIItem name="value" type="readonly SelectItem[]" optional>
    受控字段的标签。
  </APIItem>
  <APIItem name="defaultValue" type="readonly SelectItem[]" optional>
    非受控字段的初始标签。
  </APIItem>
  <APIItem name="onValueChange" type="(items: SelectItem[]) => void" optional>
    字段中每次修改后，以当前标签调用。
  </APIItem>
</APIProps>
</API>

### SelectItem

<API name="SelectItem">
<APIAttributes>
  <APIItem name="value" type="string">
    标签文本。
  </APIItem>
  <APIItem name="url" type="string" optional>
    [`getLinkHref`](/cn/docs/link#getlinkhref) 接受时，只读标签渲染的链接。
  </APIItem>
</APIAttributes>
</API>
