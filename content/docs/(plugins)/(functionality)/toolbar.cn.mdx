## 功能特性

- **固定工具栏**: 位于编辑器可滚动内容上方的持久工具栏
- **浮动工具栏**: 文本选中时出现的上下文工具栏
- **可定制按钮**: 添加、删除和重新排序工具栏按钮
- **响应式设计**: 适配不同屏幕尺寸和内容
- **插件集成**: 使用 Plate 插件和复制的 UI 组件

</PackageInfo>

## 套件使用

<Steps>

### 安装

最快捷的方式是使用`FixedToolbarKit`和`FloatingToolbarKit`，它们包含预配置的工具栏插件及其[Plate UI](/docs/installation/plate-ui)组件。

<ComponentSource name="fixed-toolbar" />
<ComponentSource name="floating-toolbar" />

- [`FixedToolbar`](/docs/components/fixed-toolbar): 在编辑器上方渲染固定工具栏
- [`FixedToolbarButtons`](/docs/components/fixed-toolbar): 固定工具栏的预配置按钮集
- [`FloatingToolbar`](/docs/components/floating-toolbar): 文本选中时渲染浮动工具栏
- [`FloatingToolbarButtons`](/docs/components/floating-toolbar): 浮动工具栏的预配置按钮集

### 添加套件

```tsx
import { createEditor } from 'platejs/react';
import { FixedToolbarKit } from '@/components/editor/fixed-toolbar';
import { FloatingToolbarKit } from '@/components/editor/floating-toolbar';

const editor = createEditor({
  plugins: [
    // ...其他插件
    ...FixedToolbarKit,
    ...FloatingToolbarKit,
  ],
});
```

</Steps>

## 手动配置

<Steps>

### 创建插件

```tsx
import { definePlugin } from 'platejs/react';
import { FixedToolbar } from '@/components/editor/fixed-toolbar';
import { FixedToolbarButtons } from '@/components/editor/fixed-toolbar';
import { FloatingToolbar } from '@/components/editor/floating-toolbar';

const fixedToolbarPlugin = definePlugin('fixedToolbar', {
  slots: {
    beforeContainer: () => (
      <FixedToolbar>
        <FixedToolbarButtons />
      </FixedToolbar>
    ),
  },
});

const floatingToolbarPlugin = definePlugin('floatingToolbar', {
  slots: {
    afterEditable: FloatingToolbar,
  },
});

const editor = createEditor({
  plugins: [
    // ...其他插件
    fixedToolbarPlugin,
    floatingToolbarPlugin,
  ],
});
```

- `slots.beforeContainer`: 在编辑器滚动容器前渲染[`FixedToolbar`](/docs/components/fixed-toolbar)
- `slots.afterEditable`: 在编辑器后渲染[`FloatingToolbar`](/docs/components/floating-toolbar)作为覆盖层

将编辑器容器放在 `EditorFrame` 中。固定工具栏和滚动容器会在同一个有界布局中占据不同的行。

```tsx
<EditorFrame className="h-[650px]">
  <EditorContainer>
    <Editor />
  </EditorContainer>
</EditorFrame>
```

### 自定义固定工具栏按钮

`FixedToolbarButtons`组件包含固定工具栏的默认按钮集。

<ComponentSource name="fixed-toolbar" />

可以通过编辑`components/editor/fixed-toolbar.tsx`来自定义。

### 自定义浮动工具栏按钮

同样地，可以通过编辑`components/editor/floating-toolbar.tsx`来自定义浮动工具栏。

<ComponentSource name="floating-toolbar" />

### 创建自定义按钮

这个示例展示了一个向编辑器插入自定义文本的按钮。

```tsx
import { useEditor } from 'platejs/react';
import { CustomIcon } from 'lucide-react';
import { ToolbarButton } from '@/components/editor/toolbar';

export function CustomToolbarButton() {
  const editor = useEditor();

  return (
    <ToolbarButton
      onClick={() => {
        // 自定义操作
        editor.update((tx) => {
          tx.text.insert('自定义文本');
        });
      }}
      tooltip="自定义操作"
    >
      <CustomIcon />
    </ToolbarButton>
  );
}
```

### 创建标记按钮

对于切换粗体或斜体等标记，可以使用[`MarkToolbarButton`](/docs/components/mark-toolbar-button)组件。它会自动处理切换状态和操作。

这个示例创建了一个"粗体"按钮。

```tsx
import { BoldIcon } from 'lucide-react';
import { BoldPlugin } from 'platejs/react';

import { MarkToolbarButton } from '@/components/editor/mark-toolbar-button';

export function BoldToolbarButton() {
  return (
    <MarkToolbarButton plugin={BoldPlugin} tooltip="粗体 (⌘+B)">
      <BoldIcon />
    </MarkToolbarButton>
  );
}
```

- `plugin`: 指定要切换的标记插件（例如 `BoldPlugin`）
- `tooltip`: 为按钮提供提示信息
- `MarkToolbarButton` 直接在组件中读取标记状态并处理切换。

### 转换工具栏按钮

[`TurnIntoToolbarButton`](/docs/components/turn-into-toolbar-button)提供用于叶格式和结构化块操作的下拉菜单。

<ComponentSource name="turn-into-toolbar-button" />

每个菜单项直接调用对应功能。文本、标题和列表等互斥格式放在单选组中；包装器和布局操作单独渲染，并检查各自支持的选择范围。

```tsx
const quote = editor.plugin(BaseBlockquotePlugin);

if (quote.installed) {
  editor.update((tx) => {
    tx.plugin(BaseBlockquotePlugin).toggle();
  });
}
```

### 插入工具栏按钮

[`InsertToolbarButton`](/docs/components/insert-toolbar-button)提供下拉菜单插入各种元素(块、列表、媒体、内联元素)。

<ComponentSource name="insert-toolbar-button" />

要添加可插入项，请在`getGroups`中定义它的类型化操作。本地`value`只标识菜单项，不负责分派编辑操作。

```tsx
{
  icon: <Heading2Icon />,
  label: '标题 2',
  value: 'heading-2',
  onSelect: () => {
    const heading = editor.plugin(BaseHeadingPlugin);

    if (!heading.installed || editor.read.view.isReadOnly()) return;

    editor.update((tx) => {
      insertBlock(tx, {
        matches: (block) =>
          !block.listType &&
          block.type === heading.schema.type &&
          block.level === 2,
        insert: (options) => {
          tx.plugin(BaseHeadingPlugin).insert({ level: 2 }, options);
        },
      });
    });
  },
}
```

</Steps>

## 插件

### `FixedToolbarKit`

在编辑器滚动容器前渲染固定工具栏的插件。

<API name="FixedToolbarKit">
<APIOptions>
  <APIItem name="slots.beforeContainer" type="ContainerSiblingComponent">
    在编辑器滚动容器前渲染固定工具栏。默认包含FixedToolbarButtons。
  </APIItem>
</APIOptions>
</API>

### `FloatingToolbarKit`

在文本选中时渲染浮动工具栏的插件。

<API name="FloatingToolbarKit">
<APIOptions>
  <APIItem name="slots.afterEditable" type="EditableSiblingComponent">
    在编辑器后作为覆盖层渲染浮动工具栏。默认包含FloatingToolbarButtons。
  </APIItem>
</APIOptions>
</API>
