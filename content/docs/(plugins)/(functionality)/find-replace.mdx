Find highlights matching text in editor blocks. `FindReplacePlugin` owns the
mutable search state and decorations; your UI owns the search input and any
replace command.

<ComponentPreview name="find-replace-demo" />

<PackageInfo>

## Features

- Case-insensitive search highlighting.
- Multiple matches inside the same block.
- Matches split across adjacent text leaves.
- App-controlled search state through plugin state.
- Registry highlight leaf for visible matches.

</PackageInfo>

## Fast Path

<Steps>

### Add The Plugin

Configure `FindReplacePlugin` with a leaf renderer for highlighted ranges.

```tsx
import { FindReplacePlugin } from '@platejs/find-replace';
import { createPlateEditor } from 'platejs/react';

import { SearchHighlightLeaf } from '@/components/editor/search-highlight';

export const editor = createPlateEditor({
  plugins: [
    FindReplacePlugin.configure({ component: SearchHighlightLeaf }),
  ],
});
```

### Control The Search

Update the `search` state from your toolbar and refresh the editor decorations.

```tsx title="components/find-toolbar.tsx" showLineNumbers
import { FindReplacePlugin } from '@platejs/find-replace';
import { useEditor, useEditorPlugin, usePluginStore } from 'platejs/react';

export function FindToolbar() {
  const editor = useEditor();
  const { store } = useEditorPlugin(FindReplacePlugin);
  const search = usePluginStore(FindReplacePlugin, 'search');

  return (
    <input
      type="search"
      value={search}
      onChange={(event) => {
        store.set({ search: event.target.value });
        editor.api.react.refreshDecorations();
      }}
    />
  );
}
```

## Ownership

| Surface | Owner | What It Does |
|---------|-------|--------------|
| `FindReplacePlugin` | `@platejs/find-replace` | Stores `initialState.search`, registers a leaf node, and decorates matching text ranges. |
| `SearchHighlightLeaf` | Registry UI | Renders decorated ranges with a yellow background. |
| `FindToolbar` | App or registry example | Updates `search` and calls `editor.api.react.refreshDecorations()`. |
| Replace actions | App code | Perform text replacement with editor transforms. The package does not replace content for you. |

The package is headless. The registry gives you a visible highlight leaf and a demo toolbar.

## Search Behavior

| Behavior | Source |
|----------|--------|
| Empty `search` | Returns no ranges. |
| Case handling | Text and query are lowercased before matching. |
| Match scope | Block text and text inside direct inline children contribute to the same search string. |
| Multiple matches | Each match becomes one or more ranges. |
| Split text leaves | A match crossing adjacent leaves is split into per-leaf ranges. |
| Range payload | Each range includes `[editor.plugin(FindReplacePlugin).schema.key]: true` and the matched `search` slice. |

`FindReplacePlugin` searches the concatenated text for one element, then maps each match back to the original child text paths.

## Search Highlight Leaf

Install the registry leaf when you want the default yellow highlight.

```bash
npx shadcn@latest add @plate/search-highlight
```

The copied component is intentionally small:

```tsx title="components/editor/search-highlight.tsx"
import type { FindReplacePlugin } from '@platejs/find-replace';
import { type PlateLeafProps, PlateLeaf } from 'platejs/react';

export function SearchHighlightLeaf(
  props: PlateLeafProps<typeof FindReplacePlugin>
) {
  return <PlateLeaf {...props} className="bg-yellow-100" />;
}
```

Change the class name when your design system needs a different search color.

## API Reference

| API | Package | Use |
|-----|---------|-----|
| `FindReplacePlugin` | `@platejs/find-replace` | Main plugin for search highlighting. |
| `search` | `string` | Mutable plugin state containing the query text. Defaults to `''`. |
