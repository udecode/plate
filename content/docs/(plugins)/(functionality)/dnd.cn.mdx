## 功能特性

- 通过手柄拖拽区块。选中的区块，或列表项及其嵌套项，会一起移动。
- 每个视图在放置位置的边缘绘制一条放置指示线。
- 在同一文档内拖拽会移动区块，拖到另一个编辑器会复制区块。按住 Option（macOS）或 Ctrl（其他平台）可改为复制。
- 点击手柄可使用“上移”“下移”和“剪切”。`Mod+Shift+ArrowUp` 和 `Mod+Shift+ArrowDown` 移动光标所在的区块。
- 区块可以放到 schema 允许的任何位置，例如引用块、详情正文、分栏或表格单元格内。表格行、分栏、列表、详情摘要和上传保留各自的规则，指示线只显示可以放置的边缘。
- `UploadPlugin` 接受原生拖放时，拖入的文件会变成上传。

</PackageInfo>

## 套件使用

<Steps>

### 安装

`DndKit` 为任意层级的每个可选中区块添加手柄，例如引用块、详情、分栏和表格单元格内的区块，并且只显示最内层悬停区块的手柄。表格行、单元格、分栏项和详情摘要没有手柄。它还绘制放置指示线，并绑定键盘移动。拖放使用浏览器原生事件，不需要 provider 或额外依赖。

<ComponentSource name="dnd" />

### 添加套件

```tsx
import { createEditor } from 'platejs/react';
import { DndKit } from '@/components/editor/dnd';

const editor = createEditor({
  plugins: [
    // ...otherPlugins,
    ...DndKit,
  ],
});
```

## 示例

### 多个编辑器

<ComponentPreview name="dnd-multi-editor-demo" />

同一个编辑器上的两个 `EditorRoot` 是同一文档的两个视图，因此在它们之间拖拽会移动区块。挂载第二个视图时传入 `suppressInstanceWarning`。拖放到另一个编辑器会复制，源编辑器保留原区块。

### 表格与分栏

<ComponentPreview name="dnd-table-demo" />

复制的 `table` 和 `column` 组件会添加各自的行手柄和分栏手柄。行只能落在同一表格的行旁边，表格会拒绝会拆分合并单元格的拖放。分栏只在所属分栏组内重新排序。其他区块可以拖入单元格或分栏。

### 文件拖放

`nativeDrop` 为 `true` 时，React 版 `UploadPlugin` 会放置拖入的文件；复制的 [Upload](/docs/upload) 套件已启用它。文件拖放显示相同的指示线，只会落在上传区块可以放置的位置。被拒绝的拖放不会插入任何内容。

## 自定义拖拽手柄

编辑器自己处理每个 `dragover` 和 `drop`。它解析放置位置、发布指示线并执行转移。手柄只负责开始拖拽，组件负责绘制指示线。

```tsx
import {
  definePlugin,
  type RenderNodeWrapperProps,
  useDropIndicator,
} from 'platejs/react';

function DragHandle({ children, editor, element }: RenderNodeWrapperProps) {
  return (
    <div className="relative [&>[data-editor-dragging]]:opacity-50">
      <button
        aria-label="Drag block"
        className="absolute -left-6 cursor-grab"
        contentEditable={false}
        draggable
        type="button"
        onDragStart={(event) => {
          if (!editor.api.dom.drag.start(event.nativeEvent, { node: element })) {
            event.preventDefault();
          }
        }}
      >
        ⠿
      </button>
      {children}
    </div>
  );
}

function DropIndicator() {
  const indicator = useDropIndicator();

  if (!indicator) return null;

  const { line } = indicator;

  return (
    <div
      aria-hidden
      className="pointer-events-none fixed top-0 left-0 h-0.5 bg-blue-500"
      style={{
        transform: `translate(${line.x}px, ${line.y - 1}px)`,
        width: line.width,
      }}
    />
  );
}

export const DragHandlePlugin = definePlugin('dragHandle', {
  slots: {
    afterEditable: DropIndicator,
    wrapNode: {
      component: DragHandle,
      match: ({ editor, element }) =>
        editor.read.schema.isBlockContent(element) &&
        editor.read.nodes.isSelectable(element),
    },
  },
});
```

这个 match 为任意层级的每个可选中区块添加手柄；只给顶层区块添加时匹配 `renderPath.length === 1`。没有可拖拽内容时，例如区块已被删除，`drag.start` 返回 `null`。拖拽期间，每个被拖拽的区块都带有 `data-editor-dragging`，上面的包装组件据此降低其不透明度。只读视图开始的拖拽只能复制。

指示线在每次 `dragover` 时移动，因此用 `transform` 定位，它不会触发布局。分栏项水平排列，其指示线为 `axis: 'x'`。用 `line.x`、`line.y` 和 `line.height` 绘制竖线。

### 拖拽图像

`drag.start` 还返回被拖拽区块的惰性克隆，以及指针相对第一个区块的偏移。套件的 `startBlockDrag` 将它们放在被拖拽区块上方，并交给浏览器作为拖拽图像：

```tsx
onDragStart={(event) => {
  const drag = editor.api.dom.drag.start(event.nativeEvent, { node: element });

  if (!drag) {
    event.preventDefault();
    return;
  }

  const rect = editor.api.dom.resolveDOMNode(element)?.getBoundingClientRect();
  const image = document.createElement('div');

  image.style.cssText = `position:fixed;pointer-events:none;left:${rect?.left ?? 0}px;top:${rect?.top ?? 0}px;width:${rect?.width ?? 0}px;`;
  image.append(...drag.previews);
  document.body.append(image);
  event.dataTransfer.setDragImage(image, drag.origin.x, drag.origin.y);
  // The browser snapshots the image during dragstart.
  requestAnimationFrame(() => image.remove());
}}
```

## 以代码移动区块

`editor.api.transfer` 执行与放置相同的规则。每次调用是一个撤销步骤，并返回其结果。

```tsx
const outcome = editor.api.transfer.move({
  nodes: [editor.key(element)],
  to: { edge: 'after', key: editor.key(target) },
});

if (outcome.status === 'refused') {
  console.warn(outcome.reason);
}
```

`to` 也接受 `'next'` 和 `'previous'`，在父级内将区块越过最近的同级区块并保留选区；位于不同父级下的区块会以 `policy` 拒绝。不传 `nodes` 时，转移携带 `editor.read.transfer.nodes()` 返回的区块。传入 `announce` 可在移动完成时向屏幕阅读器播报：

```tsx
editor.api.transfer.move({ announce: 'Moved down', to: 'next' });
```

传入另一个编辑器作为 `from`，即可从该编辑器移动或复制。在相互独立的编辑器之间，移动总是复制。

### 拒绝放置

区块落在目标 schema 接受它的任何位置。schema 允许但功能不允许的放置，例如把表格行放进另一个表格，由插件通过 `transferVeto` 贡献拒绝。它在列表等功能调整之后，对每次拖拽、键盘移动和 `editor.api.transfer` 调用的最终边缘运行。

```tsx
import { transferVeto } from 'platejs';
import { definePlugin } from 'platejs/react';

export const PinnedPlugin = definePlugin('pinned', {
  contributions: [
    transferVeto.of(({ edge, target: [node] }) => edge === 'before' && node.pinned === true),
  ],
});
```

输入还包含源视图（`from`）、`intent`（`move` 或 `copy`）、`payload` 以及文档之间的 `relation`。第二个参数是目标视图。

若要移动边缘，例如越过列表项的嵌套项，用读取中间件包裹 `editorReads.transfer.landing` 并返回另一个边缘，或返回 `next()` 保持原边缘。被移动的边缘必须映射到它自身；随后由 schema 和否决检查最终边缘。

## API 参考

### `editor.api.transfer.move`

        放置位置：某个区块旁、某个文本点，或越过一个同级区块。

      <APISubListItem parent="input" name="nodes" type="NodeKey[]" optional>
        要移动的区块，以 `from` 中的键表示。**默认值：** 选中的区块，或包含选区的区块。
      </APISubListItem>
      <APISubListItem parent="input" name="range" type="Range" optional>
        要移动的文本，代替区块。
      </APISubListItem>
      <APISubListItem parent="input" name="from" type="Editor" optional>
        源编辑器或视图。**默认值：** 执行转移的编辑器。
      </APISubListItem>
      <APISubListItem parent="input" name="announce" type="string" optional>
        转移完成时播报的屏幕阅读器消息。
      </APISubListItem>
    </APISubList>
  </APIItem>
</APIParameters>

<APIReturns type="TransferOutcome">
  <APIItem name="status" type="'moved' | 'copied' | 'refused'">
    `moved` 和 `copied` 以 `at` 给出放置后的选区。`copied` 给出其 `reason`，例如另一个编辑器对应 `independent`。`refused` 给出 `reason`：`inside-source`、`lossy`、`no-op`、`policy`、`read-only-target`、`schema` 或 `source-missing`。
  </APIItem>
</APIReturns>
</API>

### `editor.api.transfer.copy`

输入与 `move` 相同，并保留源内容。

### `editor.read.transfer.nodes`

`editor.read.transfer.nodes(options?: { node?: Element | NodeKey }): NodeKey[]` 返回转移携带的区块，例如列表项及其嵌套项。传入 `node` 时返回手柄的区块：选区包含 `node` 时为选中的区块，否则只有 `node`。不传时返回选中的区块，或包含选区的区块。把结果作为 `nodes` 传给 `editor.api.transfer.move`。

### `useDropIndicator`

`useDropIndicator(): DropIndicator | null` 读取当前视图的放置指示线。

<API name="DropIndicator">
<APIAttributes>
  <APIItem name="key" type="NodeKey">
    放置位置所在的区块。
  </APIItem>
  <APIItem name="edge" type="'before' | 'after'">
    该区块的哪一侧。
  </APIItem>
  <APIItem name="axis" type="'x' | 'y'">
    纵向堆叠的区块为 `y`，分栏等横向排列的项为 `x`。
  </APIItem>
  <APIItem name="line" type="{ x: number; y: number; width: number; height: number }">
    边缘在视口中的矩形：`y` 轴时高度为零，`x` 轴时宽度为零。
  </APIItem>
</APIAttributes>
</API>

### DOM 拖拽 API

[`editor.api.dom.drag.start`](/docs/api/dom#drag-and-drop)、`editor.api.dom.drag.indicate` 和 `editor.api.dom.resolveDropTarget` 用于以代码驱动拖拽，例如不是原生 draggable 的自定义手柄。
