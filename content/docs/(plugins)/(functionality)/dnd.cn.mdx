## 功能特性

- 通过拖拽区块实现内容移动和插入
- 拖拽至视窗边缘时自动滚动
- 支持文件拖放插入媒体区块
- 可视化拖放指示器和拖拽手柄

</PackageInfo>

## 套件使用

<Steps>

### 安装

最快捷的方式是使用 `DndKit` 套件，它包含预配置的 `DndPlugin`、React DnD 设置以及 [`BlockDraggable`](/docs/components/dnd) UI组件。

<ComponentSource name="dnd" />

- [`BlockDraggable`](/docs/components/dnd): 为区块渲染拖拽手柄和放置指示器

### 添加套件

```tsx
import { createEditor } from 'platejs/react';
import { DndKit } from '@/components/editor/dnd';

const editor = createEditor({
  plugins: [
    // ...其他插件
    ...DndKit,
  ],
});
```

### 渲染编辑器

`DndKit` 提供 HTML5 backend，并将清理绑定到每个已挂载的 Editable，包括禁用自动滚动时的清理。在 `Plate` 内渲染编辑器即可：

```tsx
import { Plate, useCreateEditor } from 'platejs/react';
import { DndKit } from '@/components/editor/dnd';
import { Editor, EditorContainer } from '@/components/editor/editor';

export function DraggableEditor() {
  const editor = useCreateEditor({ plugins: DndKit });

  return (
    <Plate editor={editor}>
      <EditorContainer>
        <Editor />
      </EditorContainer>
    </Plate>
  );
}
```

</Steps>

## 手动配置

<Steps>

### 安装依赖

```bash
npm install platejs @tanstack/react-virtual raf react-dnd react-dnd-html5-backend
```

### 配置工具包

安装 `DndKit`，并通过 `DndPlugin` 配置行为：

```tsx
import { DndPlugin } from 'platejs/dnd/react';
import { createEditor } from 'platejs/react';
import { DndKit } from '@/components/editor/dnd';

const editor = createEditor({
  plugins: [
    ...DndKit,
    DndPlugin.configure({
      initialState: { enableScroller: false },
    }),
  ],
});
```

若应用提供了 `DndProvider`，请将其放在编辑器的共同父组件中。每个 `DndKit` 都会使用该 manager；否则，工具包会提供默认的 HTML5 backend。

### 高级配置

添加自动滚动和文件拖放处理：

```tsx
import { DndPlugin } from 'platejs/dnd/react';
import { PlaceholderPlugin } from 'platejs/media/react';
import { BlockDraggable } from '@/components/editor/dnd';

DndPlugin.configure({
  initialState: {
    enableScroller: true,
    onDropFiles: ({ dragItem, editor, target }) => {
      editor
        .plugin(PlaceholderPlugin)
        .update.insertMedia(dragItem.files, { at: target });
    },
  },
  slots: {
    wrapNode: BlockDraggable,
  },
});
```

- `enableScroller`: 启用拖拽至视窗边缘时的自动滚动
- `onDropFiles`: 处理文件拖放，在目标位置插入媒体区块

</Steps>

## 钩子

## 拖拽准备

`editor.plugin(DndPlugin).read.dragEntries(element)` 读取当前拖拽区块及其嵌套列表项，不修改选择。
`api.prepareDrag(element)` 选择完整拖拽内容，并返回已挂载区块的 `{ node, domNode, preview }`。
预览副本为 inert、设置 `aria-hidden`，且不包含 Plite DOM 绑定；未挂载的选中区块仍保留在拖拽内容中。
预览的位置、间距和滚动补偿由组件负责。

`canDropNode` 对每个拖拽区块执行检查，并提供目标 `editor` 与 `sourceEditor`。
任何区块被拒绝时，不显示落点，也不调用 `onDropHandler`。

### `useDndPlugin`

`useDndPlugin(editableElement: HTMLElement | null): void` 将拖放清理监听器绑定到一个已挂载视图的 `ownerDocument`。传入该视图的实际 Editable 元素；挂载前和卸载后传入 `null`。元素变化或组件卸载时，钩子会移除旧文档上的监听器。

`DndKit` 会自动调用此钩子。只有在自行管理 Provider 和视图生命周期的自定义集成中，才需要直接使用它。

### `useDraggable`

使元素具备可拖拽行为的自定义钩子，提供可自定义或禁用的拖拽预览效果。

  </APIItem>
