## Features

- Drag and drop blocks for content movement and insertion within the editor.
- Automatic scrolling when dragging blocks near viewport edges.
- File drop support for inserting media blocks.
- Visual drop indicators and drag handles.

</PackageInfo>

## Kit usage

<Steps>

### Installation

The fastest way to add drag and drop functionality is with the `DndKit`, which includes the pre-configured `DndPlugin` along with React DnD setup and the [`BlockDraggable`](/docs/components/dnd) UI component.

<ComponentSource name="dnd" />

- [`BlockDraggable`](/docs/components/dnd): Renders drag handles and drop indicators for blocks.

### Add kit

```tsx
import { createEditor } from 'platejs/react';
import { DndKit } from '@/components/editor/dnd';

const editor = createEditor({
  plugins: [
    // ...otherPlugins,
    ...DndKit,
  ],
});
```

### Render the editor

`DndKit` provides the HTML5 backend and binds cleanup to each mounted Editable, including when automatic scrolling is disabled. Render the editor inside `Plate`:

```tsx
import { Plate, useCreateEditor } from 'platejs/react';
import { DndKit } from '@/components/editor/dnd';
import { Editor, EditorContainer } from '@/components/editor/editor';

export function DraggableEditor() {
  const editor = useCreateEditor({ plugins: DndKit });

  return (
    <Plate editor={editor}>
      <EditorContainer>
        <Editor />
      </EditorContainer>
    </Plate>
  );
}
```

</Steps>

## Manual usage

<Steps>

### Installation

```bash
npm install platejs @tanstack/react-virtual raf react-dnd react-dnd-html5-backend
```

### Configure the kit

Install `DndKit` and configure behavior through `DndPlugin`:

```tsx
import { DndPlugin } from 'platejs/dnd/react';
import { createEditor } from 'platejs/react';
import { DndKit } from '@/components/editor/dnd';

const editor = createEditor({
  plugins: [
    ...DndKit,
    DndPlugin.configure({
      initialState: { enableScroller: false },
    }),
  ],
});
```

To supply a shared or custom manager, place your `DndProvider` above the editors. Each `DndKit` inherits that manager; otherwise, the kit supplies the default HTML5 backend.

### Advanced configuration

Add automatic scrolling and file drop handling:

```tsx
import { DndPlugin } from 'platejs/dnd/react';
import { PlaceholderPlugin } from 'platejs/media/react';
import { BlockDraggable } from '@/components/editor/dnd';

DndPlugin.configure({
  initialState: {
    enableScroller: true,
    onDropFiles: ({ dragItem, editor, target }) => {
      editor
        .plugin(PlaceholderPlugin)
        .update.insertMedia(dragItem.files, { at: target });
    },
  },
  slots: {
    wrapNode: BlockDraggable,
  },
});
```

- `enableScroller`: Enables automatic scrolling when dragging blocks near the viewport edges.
- `onDropFiles`: Handles file drops by inserting them as media blocks at the target location.

</Steps>

## Plugins

### `DndPlugin`

Plugin for drag and drop functionality within the editor.

<API name="DndPlugin">
<APIOptions>
  <APIItem name="enableScroller" type="boolean" optional>
    Enables automatic scrolling when dragging blocks near viewport edges.
    - **Default:** `false`
  </APIItem>
  <APIItem name="scrollerProps" type="Partial<DndScrollerOptions>" optional>
    Automatic scrolling behavior when `enableScroller` is true.
  </APIItem>
  <APIItem name="onDropFiles" type="function" optional>
    Handler for file drop events.
    <APISubList>
      <APISubListItem parent="onDropFiles" name="key" type="NodeKey">
        Node key of the target element.
      </APISubListItem>
      <APISubListItem parent="onDropFiles" name="dragItem" type="FileDragItemNode">
        Object containing the dropped files.
      </APISubListItem>
      <APISubListItem parent="onDropFiles" name="editor" type="Editor">
        The editor instance.
      </APISubListItem>
      <APISubListItem parent="onDropFiles" name="target" type="Path">
        Path where files should be inserted.
      </APISubListItem>
    </APISubList>
  </APIItem>
  <APIItem name="dropTarget" type="{ key: NodeKey | null; line: DropLineDirection }" optional>
    The current drop target state containing its node key and drop line direction.
  </APIItem>
</APIOptions>
</API>

## Drag preparation

Use the plugin to prepare a custom drag handle:

```tsx
const dnd = editor.plugin(DndPlugin);
const entries = dnd.read.dragEntries(element);
const previews = dnd.api.prepareDrag(element);

for (const { domNode, preview } of previews) {
  preview.style.width = `${domNode.clientWidth}px`;
  previewContainer.append(preview);
}
```

`read.dragEntries(element)` returns the selected blocks when the element is in
the selection, or that element alone otherwise. Nested list items follow their
selected parent. The read does not change selection.

`api.prepareDrag(element)` selects that payload, records its drag keys and
returns `{ node, domNode, preview }` pairs for mounted blocks. Clones are inert,
hidden from accessibility and contain no Plite DOM bindings. Selected blocks
without mounted views stay in the payload. Read-only or removed elements do not
start preparation. The copied component owns preview placement and styling.

## Hooks

### `useDndPlugin`

`useDndPlugin(editableElement: HTMLElement | null): void` attaches drag cleanup to one mounted view's `ownerDocument`. Pass its exact Editable element, or `null` before attachment and after detach. The hook releases the old document's listeners when the element changes or the component unmounts.

`DndKit` calls this hook automatically. Use it directly only for custom integration that owns its own provider and view lifetime.

### `useDraggable`

A custom hook that enables draggable behavior for a given element. It provides a preview for the element, which can be customized or disabled.

<API name="useDraggable">
<APIOptions type="UseDraggableOptions">
  <APIItem name="element" type="Element">
    The element to make draggable.
  </APIItem>
  <APIItem name="orientation" type="'horizontal' | 'vertical'" optional>
    Orientation of drag and drop.
    - **Default:** `'vertical'`
  </APIItem>
  <APIItem name="type" type="string" optional>
    Type of drag item.
    - **Default:** `'block'`
  </APIItem>
  <APIItem name="onDropHandler" type="function" optional>
    Handler called after the landing passes the drop guards. Return `true` to handle the drop; otherwise the package performs the move.
  </APIItem>
  <APIItem name="canDropNode" type="CanDropCallback" optional>
    Checks every dragged element before a hover indicator or drop callback. Receives `dragEntry`, `dropEntry`, `dragItem`, the target `editor`, and `sourceEditor`. Return `false` to reject the entire payload.
  </APIItem>
</APIOptions>

<APIReturns type="object">
  <APIItem name="handleRef" type="(element: Element | React.ReactElement | React.RefObject<any> | null) => void">
    Drag source connector function.
  </APIItem>
  <APIItem name="isDragging" type="boolean">
    Whether element is being dragged.
  </APIItem>
  <APIItem name="previewRef" type="React.RefObject<HTMLDivElement>">
    Reference to draggable element.
  </APIItem>
</APIReturns>
</API>

### `useDropLine`

Returns the current drop line state for an element.

<API name="useDropLine">
<APIOptions type="object">
  <APIItem name="key" type="NodeKey" optional>
    Node key used to show the element's drop line.
    - **Default:** Current element node key
  </APIItem>
  <APIItem name="orientation" type="'horizontal' | 'vertical'" optional>
    Filter drop lines by orientation.
    - **Default:** `'vertical'`
  </APIItem>
</APIOptions>

<APIReturns type="object">
  <APIItem name="dropLine" type="'top' | 'bottom' | 'left' | 'right' | ''">
    Current drop line direction.
  </APIItem>
</APIReturns>
</API>
