`SelectEditor` is a one-line editor whose value is a list of chips. Each picked label is an inline chip, so the caret moves between chips, Backspace removes one and chips copy and paste like text. The menu filters `items` by the typed search.

## Installation

<ComponentInstallation name="select-editor" inline />

Installing the item adds two files: `select-editor.tsx`, with the field and its tag rules, and `tag.tsx`, with the `tag` element and its chip.

## Usage

```tsx
import * as React from 'react';

import { type SelectItem, SelectEditor } from '@/components/editor/select-editor';

const ITEMS: SelectItem[] = [
  { value: 'React' },
  { value: 'TypeScript' },
  { value: 'JavaScript' },
];

export function LabelsField() {
  const [value, setValue] = React.useState<SelectItem[]>([ITEMS[0]]);

  return (
    <SelectEditor
      aria-label="Labels"
      items={ITEMS}
      placeholder="Select labels..."
      value={value}
      onValueChange={setValue}
    />
  );
}
```

`onValueChange` must update `value` synchronously. The field writes `value` back whenever it differs from the chips, so a value set later, such as in a transition, first reverts the change. Pass `defaultValue` instead of `value` for an uncontrolled field.

## Behavior

- Type to search. `ArrowUp` and `ArrowDown` move the active option, and `Enter` picks it.
- A search of two or more characters that matches no label offers to create it.
- `Escape`, `mod+Enter` or a click outside closes the menu and clears the search.
- Labels that differ only in case count as one. The first chip wins, so a form value that repeats a label shows it once.
- Undo and redo keys are off, so a picked chip stays.
- A read-only field renders a chip as a link when [`getLinkHref`](/docs/link#getlinkhref) accepts its `url`. A chip whose `url` it refuses, such as a `javascript:` address or a bare `https://`, shows without a link.
- Dragging a chip before another chip moves it there. Dropping a chip after another chip does nothing.

Edit `SelectTagPlugin` in the copied `select-editor.tsx` to change these rules, and the field's key handler to change the keys.

## API Reference

### SelectEditor

Takes the editable's props, such as `placeholder`, `readOnly`, `onBlur` and `aria-*`, except the combobox attributes the field sets itself.

<API name="SelectEditor">
<APIProps>
  <APIItem name="items" type="readonly SelectItem[]" optional>
    The labels the menu offers.
  </APIItem>
  <APIItem name="value" type="readonly SelectItem[]" optional>
    The chips of a controlled field.
  </APIItem>
  <APIItem name="defaultValue" type="readonly SelectItem[]" optional>
    The starting chips of an uncontrolled field.
  </APIItem>
  <APIItem name="onValueChange" type="(items: SelectItem[]) => void" optional>
    Called with the chips after each change made in the field.
  </APIItem>
</APIProps>
</API>

### SelectItem

<API name="SelectItem">
<APIAttributes>
  <APIItem name="value" type="string">
    The label.
  </APIItem>
  <APIItem name="url" type="string" optional>
    The link a read-only chip renders when [`getLinkHref`](/docs/link#getlinkhref) accepts it.
  </APIItem>
</APIAttributes>
</API>
