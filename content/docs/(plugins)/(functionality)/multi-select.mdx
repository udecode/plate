`SelectEditor` is a one-line editor whose value is a list of chips. Each picked label is an inline chip, so the caret moves between chips, Backspace or each chip's remove button deletes one, `Cmd/Ctrl+Z` undoes chip changes, and chips copy, paste and drag like text. The menu filters `items` by the typed search.

## Installation

<ComponentInstallation name="select-editor" inline />

Installing the item adds `select-editor.tsx`, which exports `SelectEditor`, `SelectTagPlugin`, `TagPlugin`, `TagElement` and `SelectItem`.

## Usage

```tsx
import * as React from 'react';

import { type SelectItem, SelectEditor } from '@/components/editor/select-editor';

const ITEMS: SelectItem[] = [
  { value: 'React' },
  { value: 'TypeScript' },
  { value: 'JavaScript' },
];

export function LabelsField() {
  const [value, setValue] = React.useState<SelectItem[]>([ITEMS[0]]);

  return (
    <SelectEditor
      aria-label="Labels"
      items={ITEMS}
      placeholder="Select labels..."
      value={value}
      onValueChange={setValue}
    />
  );
}
```

`onValueChange` must update `value` synchronously. The field reconciles `value` back whenever it differs from the chips, so a value set later, such as in a transition, first reverts the change. Pass `defaultValue` instead of `value` for an uncontrolled field.

## Behavior

- Type to search. `ArrowUp` and `ArrowDown` move the active option, and `Enter` picks it at the caret while keeping the caret right after the inserted chip.
- Pass `creatable` to offer a create option when a search of two or more characters matches no existing label. Without `creatable`, typed searches with no match display an empty state (`No results found.`) while native chip copy, paste and drag stay active.
- The menu renders up to `limit` catalog options (100 by default), ranking matches by score and length before slicing when matches exceed `limit` and keeping the create option outside the cap.
- `Escape`, `mod+Enter` or a click outside closes the menu and clears the search.
- Labels that differ only in case count as one. The first chip wins, so a form value that repeats a label shows it once.
- Undo and redo (`Cmd/Ctrl+Z`, `Cmd/Ctrl+Shift+Z`, `Ctrl+Y`) apply to chip additions, removals and reorders while skipping search-only text edits.
- Click a chip's remove button to delete that chip without blurring the field or clearing an active search.
- `TagPlugin` validates stored `url` values with [`linkUrlValidation`](/docs/link#linkurlvalidation), and `SelectEditor` strips floor-refused URLs before inserting chips. A read-only field renders a chip as a link when [`getLinkHref`](/docs/link#getlinkhref) accepts its `url`.
- Dragging a chip before or after another chip moves it there.

Edit `SelectTagPlugin` in the copied `select-editor.tsx` to change these rules, and the field's key handler to change the keys.

## API Reference

### SelectEditor

Takes the editable's props, such as `placeholder`, `readOnly`, `onBlur` and `aria-*`, except the combobox attributes the field sets itself.

<API name="SelectEditor">
<APIProps>
  <APIItem name="items" type="readonly SelectItem[]" optional>
    The labels the menu offers.
  </APIItem>
  <APIItem name="value" type="readonly SelectItem[]" optional>
    The chips of a controlled field.
  </APIItem>
  <APIItem name="defaultValue" type="readonly SelectItem[]" optional>
    The starting chips of an uncontrolled field.
  </APIItem>
  <APIItem name="creatable" type="boolean" optional>
    Allow creating new labels from typed search in the menu. Defaults to `false`.
  </APIItem>
  <APIItem name="limit" type="number" optional>
    Maximum catalog options rendered in the menu. Defaults to `100`.
  </APIItem>
  <APIItem name="onValueChange" type="(items: SelectItem[]) => void" optional>
    Called with the chips after each change made in the field.
  </APIItem>
</APIProps>
</API>

### SelectItem

<API name="SelectItem">
<APIAttributes>
  <APIItem name="value" type="string">
    The label.
  </APIItem>
  <APIItem name="url" type="string" optional>
    The link a read-only chip renders when [`getLinkHref`](/docs/link#getlinkhref) accepts it. Stored values must pass [`linkUrlValidation`](/docs/link#linkurlvalidation).
  </APIItem>
</APIAttributes>
</API>
