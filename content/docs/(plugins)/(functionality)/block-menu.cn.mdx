块菜单是复制到应用中的 UI。它只在 React 中保存菜单显示状态，并对编辑器
选择中的节点执行操作。

<ComponentPreview name="block-menu-demo" />

## 添加 Kit

`BlockMenuKit` 会在 editable 上方渲染 `BlockContextMenu`。复制的 `Editor`
组件负责节点选择的视觉呈现。

<ComponentSource name="block-menu" />

```tsx
import { createPlateEditor } from "platejs/react";

import { BlockMenuKit } from "@/components/editor/block-menu";

export const editor = createPlateEditor({
  plugins: [...BlockMenuKit],
});
```

只有保留 Ask AI 操作时才需要安装 `@platejs/ai`。

## 选择行为

右键点击可选择元素时，如果该节点尚未选中，菜单会创建单节点编辑器选择。
如果节点已经属于多节点选择，菜单会保留该选择。

菜单关闭后会恢复 editable 焦点。触摸设备只渲染子元素；只读编辑器不会
打开菜单。

使用 `data-plate-open-context-menu={false}` 禁用特定区域的菜单：

```tsx
<PlateElement data-plate-open-context-menu={false} {...props}>
  {children}
</PlateElement>
```

## 操作

组件读取 `editor.read.selection.nodes()`，并把变更交给对应 owner：

| 操作           | Owner                       |
| -------------- | --------------------------- |
| Ask AI         | `AIChatPlugin`              |
| 删除和复制     | 编辑器节点 transforms       |
| 转换节点类型   | registry `applyBlockAction` |
| 缩进和减少缩进 | `IndentPlugin`              |
| 对齐           | 编辑器节点 transforms       |

`BlockContextMenu` 是可复制的公共组件。不存在菜单状态或块选择 package API。
