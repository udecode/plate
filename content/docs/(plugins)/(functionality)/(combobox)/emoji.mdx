Emoji adds two insertion paths. Typing `:` opens a popup that searches the
shortcode typed after it, and a toolbar picker browses and searches every emoji.
Both are copied registry components over [Emojibase](https://emojibase.dev) data,
and the picker grid is built on [frimousse](https://frimousse.liveblocks.io).
Both insert emoji as plain text.

<ComponentPreview name="emoji-demo" />

<PackageInfo>

## Features

- A popup over the shortcode typed after `:`, through [Combobox](/docs/combobox).
- GitHub shortcodes such as `:+1:`, `:tada:` and `:heart_eyes:`, ranked before label and tag matches.
- Shortcode queries, where a space closes the popup and a closing `:` stays in the query.
- No popup inside code blocks.
- Insertion as Unicode text.
- A toolbar picker with category browsing, search, keyboard navigation and a frequent row.
- Emojibase data loaded on first use and cached in the browser, with emoji the device cannot draw left out.
- Markdown shortcode deserialization to Unicode text.

</PackageInfo>

## Fast path

<Steps>

### Add the kit

`EmojiKit` installs `EmojiPlugin` and mounts the emoji popup.

<ComponentSource name="emoji" />

```tsx
import { createEditor } from 'platejs/react';

import { EmojiKit } from '@/components/editor/emoji';

export const editor = createEditor({
  plugins: EmojiKit,
});
```

### Load emoji data

`emoji-data` loads Emojibase through frimousse, joins GitHub shortcodes to it
and ranks searches. The popup and every picker share one load.

### Add toolbar picking

`emoji-picker` owns the picker popover, search and frequent picks.
`emoji-toolbar-button` inserts the picked emoji at the selection.

## Ownership

| Layer | Owner | What It Does |
|-------|-------|--------------|
| `emoji` | Registry | Defines `EmojiPlugin`, its trigger policy and code-block veto, and `EmojiCombobox`. |
| `emoji-data` | Registry | Loads Emojibase once, joins GitHub shortcodes and ranks searches. |
| `emoji-picker` | Registry UI | Owns the popover, search results, frimousse grid and frequent picks. |
| `emoji-toolbar-button` | Registry UI | Opens `EmojiPicker` from the toolbar and inserts the pick. |
| `inline-combobox` | Registry UI | Renders the listbox and popover primitives at the trigger. |
| `platejs/combobox/react` | Package | Exports `useCombobox`, which opens the popup on a typed `:`. |
| `platejs/markdown` | Package | Deserializes emoji shortcodes such as `:fire:` to Unicode text. |

`EmojiPlugin` is edit-only. Completion replaces the typed `:` and shortcode with
the emoji in one undo step.

## Manual setup

<Steps>

### Install packages

```bash
npm install platejs frimousse@0.4.0
```

### Add the registry items

Copy the popup, the data loader and the picker into your app.

```bash
npx shadcn@latest add @plate/emoji @plate/emoji-picker @plate/emoji-toolbar-button
```

### Add plugins

`EmojiPlugin` holds only the trigger policy. Mount the popup in its
`afterEditable` slot.

```tsx
import { createEditor } from 'platejs/react';

import { EmojiCombobox, EmojiPlugin } from '@/components/editor/emoji';

export const editor = createEditor({
  plugins: [EmojiPlugin.configure({ slots: { afterEditable: EmojiCombobox } })],
});
```

### Add a toolbar button

Render `EmojiToolbarButton` in your toolbar when users should browse emoji
without typing `:`.

```tsx
import { EmojiToolbarButton } from '@/components/editor/emoji-toolbar-button';

export function EditorToolbar() {
  return <EmojiToolbarButton />;
}
```

</Steps>

## Inline flow

The inline path is a [combobox](/docs/combobox) flow.

| Step | Source |
|------|--------|
| Type `:` | `EmojiPlugin` trigger. |
| Previous character must match `/^\s?$/` | Start of block or whitespace by default. |
| Not inside a code block | `triggerQuery` refuses the trigger when the selection is in a code block. |
| Type the shortcode | `queryPattern` admits letters, digits, `_`, `+`, `-` and `:`; a space closes the popup. |
| Search emoji data | The `:` popup calls `useEmojiSearch(query)`, which ignores a closing `:`. |
| Select a result | `InlineComboboxItem` replaces `:` and the shortcode and calls `tx.text.insert(emoji)`. |

Search ranks an exact shortcode first, then the shortest shortcode that starts
with the query, then a label word that starts with it, then any match in the
label, tags or shortcodes. It returns at most 60 results.

`EmojiCombobox` sets `filter={false}` because emoji search already returns
filtered results, and `hideWhenNoValue`, so the popup stays closed until the
user types after `:`. While the data loads, the popup shows a loading row and
holds Enter, so Enter keeps the typed shortcode. When the data cannot load,
the popup says so and retries on the next keystroke.

## Toolbar picker

`EmojiPicker` takes its trigger as its child and hands the picked emoji to
`onEmojiSelect`. It closes after a pick and returns focus to the editor.
`EmojiToolbarButton` inserts the pick; another component, such as a callout,
can use the emoji any other way.

```tsx
import { Button } from '@/components/ui/button';
import { EmojiPicker } from '@/components/editor/emoji-picker';

<EmojiPicker onEmojiSelect={setIcon}>
  <Button>Choose icon</Button>
</EmojiPicker>;
```

While the search box is empty, the picker shows a Frequently used row and the
frimousse category grid; press ArrowDown or Tab to move into the grid. Typing a
search shows the same ranked results as the popup, with arrow keys and Enter.
Enter that confirms an IME composition does not pick an emoji.

Frequent picks are counted per browser in `window.localStorage` under
`plate:emoji-frequent:v1`.

## Emoji data

`emoji-data` fetches `emojibase-data@17.0.0` from the jsDelivr CDN the first
time the popup or a picker needs it. frimousse caches the emoji in
`localStorage` and drops emoji the device cannot draw, and the GitHub shortcodes
are stored beside them, so later page loads also work offline.

To serve the data yourself, host `en/data.json`, `en/messages.json` and
`en/shortcodes/github.json` from the `emojibase-data` 17.0.0 package and point
`EMOJIBASE_URL` in `emoji-data` at that location.

## Markdown

`platejs/markdown` parses emoji shortcodes to Unicode text.

```md
Launch :fire: soon
```

Serializing the resulting value writes the Unicode emoji:

```md
Launch 🔥 soon
```

## API Reference

| API | Source | Use |
|-----|--------|-----|
| `EmojiPlugin` | `emoji` registry | Edit-only plugin whose state holds the `:` trigger policy. |
| `EmojiKit` | `emoji` registry | `EmojiPlugin` with `EmojiCombobox` in its `afterEditable` slot. |
| `useEmojiSearch(query)` | `emoji-data` registry | Starts the shared load for a non-null query and returns `{ results, status }`, where `status` is `'loading'`, `'ready'` or `'failed'`. |
| `searchEmojis(entries, query)` | `emoji-data` registry | Ranks entries for a query and returns at most 60. |
| `resolveEmojiData` | `emoji-data` registry | frimousse data source for pickers, shared with the popup. |
| `EmojiPicker` | `emoji-picker` registry UI | Popover picker; props are the trigger child and `onEmojiSelect(emoji)`. |
| `EmojiToolbarButton` | `emoji-toolbar-button` registry UI | Toolbar trigger that inserts the picked emoji at the selection. |
