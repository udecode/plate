## 功能特性

- 通过自动补全建议内联插入表情符号
- 通过输入`:`字符后跟表情名称触发（例如`:apple:` 🍎）
- 可自定义的表情数据源和渲染方式

## 套件使用方式

<Steps>

### 安装

最快捷的添加表情功能方式是使用`EmojiKit`，它包含预配置的`EmojiPlugin`以及它的[Plate UI](/docs/installation/plate-ui)弹出框。

```tsx

import { EmojiKit } from '@/components/editor/emoji';

const editor = createEditor({

    // ...其他插件,

  ],
});
```

## 手动配置方式

<Steps>

### 安装

```bash
npm install platejs @emoji-mart/data @tanstack/react-virtual
```

### 添加插件

`emojiPlugin` 使用完整的 emoji-mart 数据集配置包插件。在它的 `afterEditable` 插槽中挂载弹出框：

```tsx
import { createEditor } from 'platejs/react';
import { EmojiCombobox, emojiPlugin } from '@/components/editor/emoji';

const editor = createEditor({
  plugins: [
    // ...其他插件,
    emojiPlugin.configure({
      initialState: {
        trigger: ':',
        triggerPreviousCharPattern: /^\s?$/,
        createEmojiNode: (emoji) => ({ text: emoji.skins[0].native }),
      },
      slots: { afterEditable: EmojiCombobox },
    }),
  ],
});
```

- `initialState.data`: 来自@emoji-mart/data包的表情数据
- `initialState.trigger`: 打开表情弹出框的文本（默认：`:`）
- `initialState.triggerPreviousCharPattern`: 匹配触发字符前一个字符的正则表达式
- `initialState.createEmojiNode`: 选择表情时创建表情节点的函数。默认插入Unicode字符作为文本
- `slots.afterEditable`: 表情弹出框组件

### 添加工具栏按钮

您可以在[工具栏](/docs/toolbar)中添加[`EmojiToolbarButton`](/docs/components/emoji-toolbar-button)来插入表情符号。

`EmojiPicker` 自行管理弹出层、搜索、分类焦点、预览、选择和常用表情。`EmojiToolbarButton` 只提供工具栏触发器。

弹出框和工具栏共用 `platejs/emoji` 的 `createEmojiSearch(data)`。
为每个数据集创建一次搜索函数，再调用 `search(query, { limit: 60 })`。
搜索匹配 ID、名称和关键词，优先返回完全匹配的 ID。每次查询返回独立数组，
空查询返回空数组。分类、行布局、常用表情记录和结果数量由复制的 UI 管理。

```tsx
import { Button } from '@/components/ui/button';
import {
  EmojiPicker,
  EmojiPickerTrigger,
} from '@/components/editor/emoji-picker';

<EmojiPicker onSelectEmoji={setIcon}>
  <EmojiPickerTrigger>
    <Button>选择图标</Button>
  </EmojiPickerTrigger>
</EmojiPicker>;
```

## 插件说明

### EmojiPlugin

提供表情功能的核心插件。其状态包含 [ComboboxState](/docs/combobox#comboboxstate) 触发策略。

<API name="EmojiPlugin">
<APIOptions>
  <APIItem name="data" type="EmojiMartData" optional>
    来自@emoji-mart/data包的表情数据。
    - **默认值:** 内置表情库
  </APIItem>
  <APIItem name="createEmojiNode" type="(emoji: Emoji) => Descendant" optional>
    指定选择表情时插入节点的函数。
    - **默认行为:** 插入包含表情Unicode字符的文本节点
  </APIItem>
  <APIItem name="trigger" type="RegExp | readonly string[] | string" optional>
    打开表情弹出框的文本。
    - **默认值:** `':'`
  </APIItem>
  <APIItem name="triggerPreviousCharPattern" type="RegExp | null" optional>
    匹配触发字符前一个字符的模式。
    - **默认值:** `/^\s?$/`
  </APIItem>
  <APIItem name="queryPattern" type="RegExp | null" optional>
    逐个测试短代码字符；空格会关闭弹出框，结尾的 `:` 保留在查询中。
  </APIItem>
</APIOptions>
</API>
