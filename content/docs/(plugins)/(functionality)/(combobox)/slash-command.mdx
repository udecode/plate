## Features

- Quick access to various editor commands
- Triggered by `/` character
- Keyboard navigation and filtering
- Customizable command groups and options

</PackageInfo>

## Kit usage

<Steps>

### Installation

The fastest way to add slash command functionality is with the `SlashKit`, which includes a pre-configured `SlashPlugin` with its [Plate UI](/docs/installation/plate-ui) popup.

<ComponentSource name="slash" />

- [`SlashCombobox`](/docs/components/slash): Renders the slash command popup with predefined options

### Add kit

```tsx
import { createEditor } from 'platejs/react';
import { SlashKit } from '@/components/editor/slash';

const editor = createEditor({
  plugins: [
    // ...otherPlugins,
    ...SlashKit,
  ],
});
```

</Steps>

## Manual usage

<Steps>

### Installation

```bash
npm install platejs @tanstack/react-virtual
```

### Add plugins

Mount the popup in the plugin's `afterEditable` slot:

```tsx
import { SlashPlugin } from 'platejs/slash-command/react';
import { BaseCodeBlockPlugin } from 'platejs';
import { createEditor } from 'platejs/react';
import { SlashCombobox } from '@/components/editor/slash';

const editor = createEditor({
  plugins: [
    // ...otherPlugins,
    SlashPlugin.configure({
      initialState: {
        trigger: '/',
        triggerPreviousCharPattern: /^\s?$/,
        triggerQuery: (editor) => {
          const codeBlock = editor.plugin(BaseCodeBlockPlugin);

          return (
            !codeBlock.installed ||
            !editor.read.nodes.some({ type: codeBlock.schema.type })
          );
        },
      },
      slots: { afterEditable: SlashCombobox },
    }),
  ],
});
```

- `initialState.trigger`: Text that opens the slash command popup (default: `/`)
- `initialState.triggerPreviousCharPattern`: RegExp pattern for the character before the trigger
- `initialState.triggerQuery`: Function to determine when slash commands should be enabled
- `slots.afterEditable`: The popup component for the slash command menu

</Steps>

## Usage

How to use slash commands:

1. Type `/` at the start of a line or after a space to open the slash menu
2. Keep typing to filter options, or use the arrow keys to navigate
3. Press Enter, press Tab or click to run an option; it replaces the typed `/` and query
4. Press Escape to close the menu and keep the typed text

Available options include:
- Text blocks (paragraphs, headings)
- Lists (bulleted, numbered, to-do)
- Advanced blocks (tables, code blocks, callouts)
- Inline elements (dates, equations)

<Callout type="info">
  Use keywords to quickly find options. For example, type '/ul' for Bulleted List or '/h1' for Heading 1.
</Callout>

## Plugins

### SlashPlugin

Plugin for slash command functionality. Its state is a [ComboboxState](/docs/combobox#comboboxstate).

<API name="SlashPlugin">
<APIOptions>
  <APIItem name="trigger" type="RegExp | readonly string[] | string" optional>
    Text that opens the slash command popup.
    - **Default:** `'/'`
  </APIItem>
  <APIItem name="triggerPreviousCharPattern" type="RegExp | null" optional>
    RegExp to match the character before the trigger.
    - **Default:** `/^\s?$/`
  </APIItem>
  <APIItem name="triggerQuery" type="(editor: Editor) => boolean" optional>
    Function to determine when slash commands should be enabled. Useful for disabling in certain contexts like code blocks.
  </APIItem>
</APIOptions>
</API>
