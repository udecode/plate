## Features

- Quick access to various editor commands
- Triggered by `/` character
- Keyboard navigation and filtering
- Customizable command groups and options

</PackageInfo>

## Kit usage

<Steps>

### Installation

The fastest way to add slash command functionality is with the `SlashKit`, which includes a pre-configured `SlashPlugin` with its [Plate UI](/docs/installation/plate-ui) popup.

<ComponentSource name="slash" />

- [`SlashCombobox`](/docs/components/slash): Renders the slash command popup with predefined options

### Add kit

```tsx
import { createEditor } from 'platejs/react';
import { SlashKit } from '@/components/editor/slash';

const editor = createEditor({
  plugins: [
    // ...otherPlugins,
    ...SlashKit,
  ],
});
```

</Steps>

## Manual usage

<Steps>

### Installation

```bash
npm install platejs
npx shadcn@latest add @plate/slash
```

### Add plugins

The copied `slash` file defines `SlashPlugin`, which holds only the trigger policy. Mount the popup in its `afterEditable` slot:

```tsx
import { createEditor } from 'platejs/react';

import { SlashCombobox, SlashPlugin } from '@/components/editor/slash';

const editor = createEditor({
  plugins: [
    // ...otherPlugins,
    SlashPlugin.configure({ slots: { afterEditable: SlashCombobox } }),
  ],
});
```

Its state is a [`ComboboxState`](/docs/combobox#comboboxstate). A `/` opens the menu at the start of a line or after a space, and `triggerQuery` keeps a `/` typed in a code block as plain text. Edit `SlashPlugin` in the copied file to change either.

</Steps>

## Usage

How to use slash commands:

1. Type `/` at the start of a line or after a space to open the slash menu
2. Keep typing to filter options, or use the arrow keys to navigate
3. Press Enter, press Tab or click to run an option; it replaces the typed `/` and query
4. Press Escape to close the menu and keep the typed text

Available options include:
- Text blocks (paragraphs, headings)
- Lists (bulleted, numbered, to-do)
- Advanced blocks (tables, code blocks, callouts)
- Inline elements (dates, equations)

<Callout type="info">
  Use keywords to quickly find options. For example, type '/ul' for Bulleted List or '/h1' for Heading 1.
</Callout>

## API Reference

| API | Source | Use |
|-----|--------|-----|
| `SlashPlugin` | `slash` registry | Edit-only plugin whose state holds the `/` trigger policy and the code-block check. |
| `SlashKit` | `slash` registry | `SlashPlugin` with `SlashCombobox` in its `afterEditable` slot. |
| `SlashCombobox` | `slash` registry | The slash menu, built from the file's `groups` list. Edit that list to add, remove or reorder options. |
