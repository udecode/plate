## 功能特性

- 基于普通编辑器文本的自动补全：触发字符和查询直接输入到文档中
- 只有用户在该编辑器中输入触发字符时才会打开弹出框
- 补全在一个撤销步骤中替换触发字符和查询；撤销会恢复输入的文本
- IME 预编辑会过滤选项，但不会选中选项
- Escape 关闭弹出框并保留文本

</PackageInfo>

## 创建组合框插件

<Steps>

### 安装

```bash
npm install platejs
npx shadcn@latest add @plate/inline-combobox
```

### 创建插件

将触发策略放在插件状态中，将插入的节点放在插件 schema 中：

```tsx showLineNumbers
import { property } from 'platejs';
import type { ComboboxState } from 'platejs/combobox';
import { definePlugin } from 'platejs/react';

export const HashtagPlugin = definePlugin('hashtag', {
  initialState: (): ComboboxState => ({
    maxQueryLength: 50,
    queryPattern: /^[\p{L}\p{N}_-]$/u,
    trigger: '#',
    triggerPreviousCharPattern: /^\s?$/,
    triggerQuery: null,
  }),
  schema: {
    element: {
      properties: { value: property.string({ required: true }) },
      type: 'hashtag',
      void: 'inline',
    },
  },
});
```

- `trigger`：输入后打开弹出框的文本（`#`）。
- `triggerPreviousCharPattern`：必须匹配触发字符之前的字符。`/^\s?$/` 允许行首或空格之后。
- `queryPattern`：逐个检查查询字符。这里空格会结束标签查询。

### 创建弹出框

弹出框渲染在编辑器旁边，并从触发字符之后的文本读取查询：

```tsx showLineNumbers
import * as React from 'react';
import {
  type EditorElementProps,
  EditorElement,
} from 'platejs/react';
import {
  InlineCombobox,
  InlineComboboxContent,
  InlineComboboxEmpty,
  InlineComboboxItem,
} from '@/components/editor/inline-combobox';
import { HashtagPlugin } from './hashtag-plugin';

const tags = ['Frontend', 'Backend', 'Design', 'Urgent'];

export function HashtagCombobox({
  editableRef,
}: {
  editableRef: React.RefObject<HTMLDivElement | null>;
}) {
  return (
    <InlineCombobox editableRef={editableRef} plugin={HashtagPlugin}>
      <InlineComboboxContent>
        <InlineComboboxEmpty>未找到标签</InlineComboboxEmpty>
        {tags.map((tag) => (
          <InlineComboboxItem
            key={tag}
            value={tag}
            onSelect={(tx) => {
              tx.plugin(HashtagPlugin).insert({ value: tag });
            }}
          >
            #{tag}
          </InlineComboboxItem>
        ))}
      </InlineComboboxContent>
    </InlineCombobox>
  );
}

export function HashtagElement(props: EditorElementProps<typeof HashtagPlugin>) {
  return (
    <EditorElement
      {...props}
      as="span"
      className="inline-block rounded-md bg-primary/10 px-1.5 py-0.5 align-baseline font-medium text-primary text-sm"
    >
      #{props.element.value}
      {props.children}
    </EditorElement>
  );
}
```

### 添加到编辑器

在插件的 `afterEditable` 插槽中挂载弹出框，该插槽会收到每个编辑器的 `editableRef`：

```tsx showLineNumbers
import { createEditor } from 'platejs/react';
import { HashtagPlugin } from './hashtag-plugin';
import { HashtagCombobox, HashtagElement } from './hashtag-components';

const editor = createEditor({
  plugins: [
    HashtagPlugin.configure({
      component: HashtagElement,
      slots: { afterEditable: HashtagCombobox },
    }),
  ],
});
```

## 行为

- 用户输入触发字符时打开弹出框。把光标移到已有触发文本之后、撤销、粘贴和远程编辑都不会打开它。
- 查询是同一块内从触发字符到光标的文本，可以跨越标记。光标移到触发字符之前或越过已输入的文本、某个字符不匹配 `queryPattern`、查询以空白开头或长度超过 `maxQueryLength` 时，查询结束。
- Escape 关闭弹出框并保留输入的文本。继续输入不会重新打开；再次输入触发字符会重新打开。
- 补全在一个事务中删除触发字符和查询并执行插入。撤销会恢复输入的文本。
- IME 组字期间，查询会预览可见的预编辑文本。Enter 只确认组字，从不选中选项。

## 配置选项

### ComboboxState

保存在功能插件状态中的触发策略。使用 `.configure({ initialState })` 覆盖。

<API name="ComboboxState">
<APIOptions>
  <APIItem name="trigger" type="RegExp | readonly string[] | string">
    输入后打开弹出框的文本。字符串可以多于一个字符，例如 `'[^'`。正则表达式针对输入的字符进行测试。
  </APIItem>
  <APIItem name="triggerPreviousCharPattern" type="RegExp | null">
    针对触发字符之前的字符进行测试，在文本开头时为 `''`。`null` 允许任意字符。
  </APIItem>
  <APIItem name="triggerQuery" type="((editor: ComboboxEditor) => boolean) | null">
    返回 `false` 时将输入的触发字符保留为普通文本，例如在代码中。
  </APIItem>
  <APIItem name="queryPattern" type="RegExp | null">
    逐个测试查询字符；第一个不匹配的字符会关闭弹出框。`null` 允许除换行外的任意字符。
  </APIItem>
  <APIItem name="maxQueryLength" type="number">
    查询长度超过该值时关闭弹出框。
  </APIItem>
</APIOptions>
</API>

## Hooks

### useCombobox

把弹出框连接到一个编辑器。从 `platejs/combobox/react` 导入，并在 `afterEditable` 插槽组件中调用。

<API name="useCombobox">
<APIParameters>
  <APIItem name="editableRef" type="React.RefObject<HTMLDivElement | null>">
    弹出框服务的编辑器，即传给插槽的 ref。
  </APIItem>
  <APIItem name="plugin" type="PluginReference">
    状态中保存 `ComboboxState` 的功能插件。
  </APIItem>
  <APIItem name="activeOptionId" type="string | null" optional>
    当前选项的 id，同步为编辑器的 `aria-activedescendant`。
  </APIItem>
  <APIItem name="open" type="boolean" optional>
    弹出框是否正在显示。只有显示时才接管按键并写入 ARIA，因此没有结果而隐藏的弹出框会把方向键和 Escape 留给编辑器。
    - **默认值:** `true`
  </APIItem>
  <APIItem name="onKeyDown" type="(event: React.KeyboardEvent<HTMLDivElement>) => boolean" optional>
    弹出框打开时，在编辑器快捷键之前接收 Enter、Tab、ArrowUp、ArrowDown 和 Escape。处理后返回 `true`。未处理的 Escape 会关闭弹出框。
  </APIItem>
</APIParameters>
<APIReturns>
  <APIItem name="match" type="ComboboxMatch | null">
    当前打开的查询，关闭时为 `null`。`match.query` 是触发字符之后的文本，`match.range` 覆盖触发字符和查询，IME 预编辑期间 `match.composing` 为 true。
  </APIItem>
  <APIItem name="listboxId" type="string">
    弹出框列表的 id，同步为编辑器的 `aria-controls`。
  </APIItem>
  <APIItem name="complete" type="(match: ComboboxMatch, callback: (tx) => false | void) => boolean">
    通过一个同步事务替换触发字符和查询。传入提供该选项的 match。回调返回 `false` 表示拒绝并保留查询。更新的查询、进行中的组字或被拒绝的回调都不会产生更改并返回 `false`；回调抛出异常时会回滚全部更改。
  </APIItem>
  <APIItem name="dismiss" type="() => void">
    关闭弹出框并保留输入的文本。
  </APIItem>
</APIReturns>
</API>

## Registry UI

复制的 `inline-combobox` 组件用 Ariakit 列表封装 `useCombobox`。它负责过滤、当前选项以及在触发字符处定位弹出框。在 `InlineComboboxItem.onSelect` 中使用推断的事务插入所选功能，当选项不再可用时返回 `false`。在弹出框内使用 `useInlineComboboxQuery()` 读取查询。成功补全后的 UI 操作（例如打开另一个弹出框）放在 `onClick` 中。
