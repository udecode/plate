## 创建组合框插件

<Steps>

### 安装

```bash
npm install platejs
npx shadcn@latest add @plate/inline-combobox
```

### 创建输入插件

首先创建一个输入插件，当触发器激活时将被插入：

```tsx showLineNumbers
import { property } from 'platejs';
import { BaseComboboxPlugin } from 'platejs/combobox';
import { definePlatePlugin } from 'platejs/react';

export const TagInputPlugin = definePlatePlugin('tagInput', {
  dependencies: [BaseComboboxPlugin],
  editOnly: true,
  schema: {
    element: {
      type: 'tag_input',
      void: 'inline',
      properties: {
        trigger: property.string(),
        userId: property.string(),
      },
    },
  },
});
```

### 创建主插件

使用触发器元数据创建主插件：

```tsx showLineNumbers
import { property } from 'platejs';
import { triggerCombobox, type TriggerComboboxPluginState } from 'platejs/combobox';
import { definePlatePlugin } from 'platejs/react';
import { TagInputPlugin } from './tag-input-plugin';

const initialState: TriggerComboboxPluginState = {
  trigger: '#',
  triggerPreviousCharPattern: /^\s?$/,
  createComboboxInput: () => ({
    children: [{ text: '' }],
    type: 'tag_input',
  }),
};

export const TagPlugin = definePlatePlugin('customTag', {
  dependencies: [TagInputPlugin],
  initialState,
  schema: {
    element: {
      type: 'tag',
      void: 'inline',
      properties: { value: property.string({ required: true }) },
    },
  },
  update: ({ tx, schema: { type } }) => ({
    insert: (value: string) => {
      tx.nodes.insert({ children: [{ text: '' }], type, value });
      tx.selection.move({ unit: 'offset' });
    },
  }),
}).extend(({ editor, store }) => ({
  commands: (context) => triggerCombobox(context, {
    editor,
    getState: () => store.get(),
    type: editor.plugin(TagInputPlugin).schema.type,
  }),
}));
```

- `schema.element`: 定义插件的元素模型行为
- `schema.element.void: 'inline'`: 将标签定义为行内 void，并防止编辑其内部内容
- `initialState.trigger`: 触发组合框的字符(本例为`#`)
- `initialState.triggerPreviousCharPattern`: 必须匹配触发器前字符的正则表达式。`/^\s?$/`允许在行首或空白后触发
- `initialState.createComboboxInput`: 触发器激活时创建输入元素节点的函数

### 创建组件

使用`InlineCombobox`创建输入元素组件：

```tsx showLineNumbers
import {
  type PlateElementProps,
  PlateElement,
  useEditorFocused,
  useEditorReadOnly,
  useElementSelected,
} from 'platejs/react';
import {
  InlineCombobox,
  InlineComboboxContent,
  InlineComboboxEmpty,
  InlineComboboxInput,
  InlineComboboxItem,
} from '@/components/editor/inline-combobox';
import { cn } from '@/lib/utils';
import { TagInputPlugin } from './tag-input-plugin';
import { TagPlugin } from './tag-plugin';

const tags = ['Frontend', 'Backend', 'Design', 'Urgent'];

export function TagInputElement(props: PlateElementProps<typeof TagInputPlugin>) {
  return (
    <PlateElement {...props} as="span">
      <InlineCombobox element={props.element} trigger="#">
        <InlineComboboxInput />
        <InlineComboboxContent>
          <InlineComboboxEmpty>No tags found</InlineComboboxEmpty>
          {tags.map((tag) => (
            <InlineComboboxItem
              key={tag}
              value={tag}
              onSelect={(tx) => tx.plugin(TagPlugin).insert(tag)}
            >
              #{tag}
            </InlineComboboxItem>
          ))}
        </InlineComboboxContent>
      </InlineCombobox>
      {props.children}
    </PlateElement>
  );
}

export function TagElement(props: PlateElementProps<typeof TagPlugin>) {
  const selected = useElementSelected();
  const focused = useEditorFocused();
  const readOnly = useEditorReadOnly();

  return (
    <PlateElement
      {...props}
      as="span"
      className={cn(
        'inline-block rounded-md bg-primary/10 px-1.5 py-0.5 align-baseline text-sm font-medium text-primary',
        !readOnly && 'cursor-pointer',
        selected && focused && 'ring-2 ring-ring'
      )}
    >
      #{props.element.value}
      {props.children}
    </PlateElement>
  );
}
```

### 添加到编辑器

```tsx showLineNumbers
import { BaseCodeBlockPlugin } from 'platejs';
import { createEditor } from 'platejs/react';
import { TagPlugin } from './tag-plugin';
import { TagInputPlugin } from './tag-input-plugin';
import { TagElement, TagInputElement } from './tag-components';

const editor = createEditor({
  plugins: [
    TagPlugin.configure({
      component: TagElement,
      initialState: {
        triggerQuery: (editor) => {
          const codeBlock = editor.plugin(BaseCodeBlockPlugin);
          return !codeBlock.installed || !editor.read.nodes.some({ type: codeBlock.schema.type });
        },
      },
    }),
    TagInputPlugin.configure({ component: TagInputElement }),
  ],
});
```

- `initialState.triggerQuery`: 根据编辑器状态有条件启用/禁用触发器的可选函数

## 配置选项

### TriggerComboboxPluginState

基于触发器的组合框插件的配置选项。

<API name="TriggerComboboxPluginState">
<APIOptions>
  <APIItem name="createComboboxInput" type="(trigger: string) => Element">
    触发器激活时创建输入节点的函数。
  </APIItem>
  <APIItem name="trigger" type="RegExp | string[] | string">
    触发组合框的字符。可以是：
    - 单个字符(如'@')
    - 字符数组
    - 正则表达式
  </APIItem>
  <APIItem name="triggerPreviousCharPattern" type="RegExp" optional>
    匹配触发器前字符的模式。
    - **示例:** `/^\s?$/` 匹配行首或空格
  </APIItem>
  <APIItem name="triggerQuery" type="(editor: TriggerComboboxEditor) => boolean" optional>
    控制触发器何时激活的自定义查询函数。
  </APIItem>
</APIOptions>
</API>

## 输入命令

提及、斜杠、表情和脚注输入依赖 `BaseComboboxPlugin`。自定义输入插件也应声明
此依赖。使用 `editor.key(element)` 获取已挂载输入的 `NodeKey`，并在事件回调中
保留该键。

| 方法 | 行为 |
| --- | --- |
| `read.canEdit(input)` | 检查输入是否存在、可编辑且属于当前用户。 |
| `api.cancel(input, { text, select })` | 在一次历史记录中删除输入并恢复原始文本。Backspace 可省略 `text`；`select` 可为 `'start'`、`'end'`，或省略以保留外部选区。 |
| `api.commit(input, callback)` | 删除输入、选中其当前位置并运行同步事务回调。回调抛出异常时回滚整个更改。 |
| `api.undo(input)` / `api.redo(input)` | 仅为可编辑输入执行可用的历史操作。 |

输入键已失效或属于其他用户时，完成命令返回 `false`。命令不会把文本恢复到
无关的当前选区；节点键也适用于命名文档根中的输入。

## Registry UI

复制的 `inline-combobox` 组件负责查询状态、过滤、弹出框导航、输入法事件和 DOM
聚焦。在 `InlineComboboxItem.onSelect` 中使用自动推断的事务插入所选内容。
`onClick` 适用于成功完成后执行的界面操作，例如打开另一个弹出框。
