## 套件使用

<Steps>

### 安装

添加斜杠命令功能最快的方式是使用 `SlashKit`，它包含预配置的 `SlashPlugin` 以及它的 [Plate UI](/docs/installation/plate-ui) 弹出框。

<ComponentSource name="slash" />

- [`SlashCombobox`](/docs/components/slash)：渲染带有预定义选项的斜杠命令弹出框

### 添加套件

```tsx
import { createEditor } from 'platejs/react';
import { SlashKit } from '@/components/editor/slash';

const editor = createEditor({
  plugins: [
    // ...其他插件
    ...SlashKit,
  ],
});
```

</Steps>

## 手动使用

<Steps>

### 安装

```bash
npm install platejs
npx shadcn@latest add @plate/slash
```

### 添加插件

复制的 `slash` 文件定义了 `SlashPlugin`，它保存触发策略和应用添加的选项。在它的 `afterEditable` 插槽中挂载弹出框：

```tsx
import { createEditor } from 'platejs/react';

import { SlashCombobox, SlashPlugin } from '@/components/editor/slash';

const editor = createEditor({
  plugins: [
    // ...其他插件
    SlashPlugin.configure({ slots: { afterEditable: SlashCombobox } }),
  ],
});
```

它的状态是 [`ComboboxState`](/docs/combobox#comboboxstate) 加上 `items`。在行首或空格后输入 `/` 会打开菜单，`triggerQuery` 会让代码块中输入的 `/` 保持为普通文本。要修改这两点，请编辑复制文件中的 `SlashPlugin`。

</Steps>

## 添加应用选项

<ComponentPreview name="slash-command-items-demo" />

通过 `initialState.items` 传入自己的选项，不用编辑复制的文件。每个选项写明一个 `group`。它会加入同名的内置分组，例如 `Basic blocks`，或者在内置分组之后新建一个分组。

```tsx
import { PenLineIcon } from 'lucide-react';
import { createEditor } from 'platejs/react';

import { SlashCombobox, SlashPlugin } from '@/components/editor/slash';

const editor = createEditor({
  plugins: [
    // ...其他插件
    SlashPlugin.configure({
      initialState: {
        items: [
          {
            group: 'Basic blocks',
            icon: () => <PenLineIcon />,
            isAvailable: () => true,
            keywords: ['sign'],
            label: 'Signature',
            onSelect: (_editor, tx) => {
              tx.text.insert('Signed by the review team.');
            },
          },
        ],
      },
      slots: { afterEditable: SlashCombobox },
    }),
  ],
});
```

选项的字段和内置选项相同：`label`、`icon`、`isAvailable`、可选的 `keywords`，以及 `onSelect` 或 `onClick`。`icon` 是返回图标的函数，如 `() => <PenLineIcon />`，因为插件状态只放数据和函数，不放元素。`onSelect` 在菜单的事务里运行，并替换输入的 `/` 和查询；返回 `false` 会保留它们。

## 使用方式

如何使用斜杠命令：

1. 在行首或空格后输入 `/` 打开斜杠菜单
2. 继续输入以缩小选项范围，最佳匹配排在最前，或使用方向键导航
3. 按回车、Tab 或点击执行选项；它会替换输入的 `/` 和查询
4. 按 Escape 关闭菜单并保留输入的文本

可用选项包括：
- 文本块（段落、标题）
- 列表（项目符号、编号、待办事项）
- 高级块（表格、代码块、标注）
- 行内元素（日期、公式）

<Callout type="info">
  使用关键词快速查找选项。例如输入 '/ul' 查找项目符号列表，或 '/h1' 查找一级标题。
</Callout>

## API 参考

| API | 来源 | 用途 |
|-----|------|------|
| `SlashPlugin` | `slash` registry | 仅在编辑时启用的插件，其状态保存 `/` 触发策略、代码块检查和应用的 `items`。 |
| `SlashItem` | `slash` registry | 一个应用选项：内置选项的字段（`icon` 为函数），加上它加入的 `group`。 |
| `SlashKit` | `slash` registry | 在 `afterEditable` 插槽中挂载 `SlashCombobox` 的 `SlashPlugin`。 |
| `SlashCombobox` | `slash` registry | 斜杠菜单，先由文件中的 `groups` 列表构建，再加上插件的 `items`。编辑 `groups` 来移除或重新排序内置选项。输入查询时，菜单把最佳匹配排在最前，只在同等匹配之间保留列表顺序。 |
