## 功能特性

- **提供者边界：** 应用负责 Hocuspocus、WebSocket、WebRTC、IndexedDB 或自定义传输代码。`@platejs/yjs` 负责把 `Y.Doc`、提供者生命周期、Awareness、选择状态和撤销/重做接入编辑器。
- **自定义提供者：** 将提供者包包装成 `YjsProviderLike`，然后通过 `YjsPlugin.configure` 配置。
- **Awareness 与光标：** 集成 Yjs Awareness 协议，用于在用户之间共享光标位置和临时状态。远程光标 UI 使用 [`RemoteCursorOverlay`](/docs/components/remote-cursor-overlay)。
- **多根文档：** 通过同一个编辑器扩展和 Yjs 事务边界同步主 `children`、命名 `roots` 和带根信息的 Awareness。
- **自定义光标：** 通过 `tx.yjs.sendSelection` 发送光标名称、颜色和其他元数据。
- **显式命令：** 插件会安装 Plite Yjs 扩展，并添加 `state.yjs` 读取和 `tx.yjs` 命令，用于连接、Awareness、选择、撤销和重做。

</PackageInfo>

## 手动使用

<Steps>

### 安装

安装 Yjs 插件包。

```bash
npm install @platejs/yjs
```

如果应用使用 Hocuspocus：

```bash
npm install @hocuspocus/provider
```

如果应用使用 WebRTC：

```bash
npm install y-webrtc
```

### 添加插件

同一房间内的所有节点必须使用相同的编译后 schema 身份。派生 schema 通过指纹匹配。
持久房间使用显式的 `id` 和 `version` 作为谱系；递增版本前先迁移房间。

```tsx
import { YjsPlugin } from "@platejs/yjs/react";
import { createPlateEditor } from "platejs/react";

const editor = createPlateEditor({
  schema: { id: "yjs-example", version: 1 },
  plugins: [
    YjsPlugin.configure({
      options: {
        clientId: "local-user",
        doc,
        provider,
        rootName: roomId,
      },
    }),
  ],
  initialValue,
});
```

<Callout type="warning" title="提供者边界">
  应用代码负责提供者包、房间名、认证、持久化和服务扩容。`YjsPlugin` 负责 Plate
  组合并安装 Plite/Yjs 同步扩展。
</Callout>

### 配置提供者和光标

把你的提供者包装成 `YjsProviderLike`，然后通过插件的 `options` 配置。远程光标 hooks 从同一个 React 子路径导入。

```tsx
import { useYjsRemoteCursors, YjsPlugin } from "@platejs/yjs/react";
import { RemoteCursorOverlay } from "@/components/ui/remote-cursor-overlay";

export const yjsPlugin = YjsPlugin.configure({
  options: {
    clientId: user.id,
    doc,
    provider,
    rootName: roomId,
  },
});
```

- `provider`: 应用拥有的传输包装器，类型为 `YjsProviderLike`。
- `doc`: 共享的 `Y.Doc`。
- `rootName`: 协作文档的命名空间。主根和命名根一起同步。
- 本地选择变化时，通过 `tx.yjs.sendSelection(...)` 发送光标数据。

一次同时修改主根和命名根的 Plate 提交会生成一个 Yjs 事务和一个撤销步骤。
命名根无需挂载 `PlateContent` 也会同步；远程选区保留其根 key，且一个选区不能跨越
两个根。

### 添加编辑器容器

`RemoteCursorOverlay` 需要编辑器内容外层有定位容器。使用 [`EditorContainer`](/docs/components/editor) 组件，或使用 `platejs/react` 中的 `PlateContainer`。

```tsx
import { Plate } from "platejs/react";
import { EditorContainer } from "@/components/ui/editor";

return (
  <Plate editor={editor}>
    <EditorContainer>
      <Editor />
    </EditorContainer>
  </Plate>
);
```

### 读取和控制连接状态

插件会在 `editor.read` 和 `editor.update` 中安装 `yjs` 组。

```tsx
const connected = editor.read((state) => state.yjs.connected());
const providerStatus = editor.read((state) => state.yjs.providerStatus());

editor.update((tx) => {
  tx.yjs.connect();
  tx.yjs.sendSelection(selection, { name: "Ada", color: "#aabbcc" });
});
```

插件安装的扩展会在清理时销毁编辑器拥有的监听器。提供者是否销毁，取决于提供者包装器是否声明自己由编辑器拥有。

### 监听连接状态（可选）

读取提供者状态，给 UI 显示同步状态。

```tsx
import React from "react";
import { useYjsProviderStatus, useYjsProviderSynced } from "@platejs/yjs/react";

function EditorStatus() {
  const status = useYjsProviderStatus(editor);
  const synced = useYjsProviderSynced(editor);

  return (
    <div>
      {status} {synced ? "Synced" : "Syncing"}
    </div>
  );
}
```

## 提供者边界

提供者包留在应用边界。把 Hocuspocus、WebSocket、WebRTC、IndexedDB 或其他传输包装成 `YjsProviderLike`，再通过 `YjsPlugin.configure` 配置。包装器负责网络连接状态，插件负责安装 Plite/Yjs 同步扩展。

| 关注点                                 | 所有者                  |
| -------------------------------------- | ----------------------- |
| `Y.Doc` 和根名                         | 应用加 `YjsPlugin` 配置 |
| 提供者包安装                           | 应用                    |
| 房间命名和认证                         | 应用                    |
| 持久化和服务扩容                       | 应用                    |
| 编辑器操作、选择、Awareness、撤销/重做 | `@platejs/yjs`          |

## 连接命令

用 `editor.read` 读取提供者状态，用 `editor.update` 执行命令。

```tsx
const connected = editor.read((state) => state.yjs.connected());
const synced = editor.read((state) => state.yjs.providerSynced());

editor.update((tx) => {
  tx.yjs.connect();
  tx.yjs.sendSelection(selection, { name: "Ada", color: "#aabbcc" });
});
```

| 命令                                | 用途                        |
| ----------------------------------- | --------------------------- |
| `tx.yjs.connect()`                  | 连接提供者。                |
| `tx.yjs.disconnect()`               | 断开连接，但不销毁编辑器。  |
| `tx.yjs.reconnect()`                | 提供者中断后重新连接。      |
| `tx.yjs.sendSelection(range, data)` | 发布本地选择和光标元数据。  |
| `tx.yjs.clearSelection()`           | 清空本地 Awareness 选择。   |
| `tx.yjs.undo()` / `tx.yjs.redo()`   | 执行 Yjs 感知的撤销和重做。 |

## 后端设置

### Hocuspocus

在应用代码中安装并配置 `@hocuspocus/provider`。把共享的 `Y.Doc` 和提供者包装器传给 `YjsPlugin.configure`。认证令牌、房间名和服务器 URL 不属于 Plate 包。

### WebRTC

需要点对点协作时，在应用代码中安装 `y-webrtc`。生产环境要使用自己的信令和 TURN 基础设施。编辑器包只需要包装后的提供者和共享的 `Y.Doc`。

### IndexedDB

如果想在远程同步完成前恢复本地文档，可以在应用层使用 `y-indexeddb`。IndexedDB 本身不传输远程 Awareness 或光标。

## 排错

- 确认所有协作者使用相同的 `Y.Doc` 根名。
- 在应用日志中暴露提供者连接错误。
- 编辑器挂载时，不要绕过编辑器直接修改共享 `Y.Doc`。
- 临时断开连接用 `tx.yjs.disconnect()`，卸载清理交给扩展生命周期。
- 如果远程光标错误，确认应用通过 `tx.yjs.sendSelection(...)` 发送光标元数据，并渲染 `@platejs/yjs/react` 中的 React 光标 hooks。
