## Features

- **Text Comments:** Add comments as text marks with inline annotations
- **Overlapping Comments:** Support multiple comments on the same text
- **Draft Comments:** Create draft comments before finalizing
- **State Tracking:** Track comment state and user interactions
- **Discussion Integration:** Works with discussion plugin for complete collaboration

</PackageInfo>

## Kit Usage

<Steps>

### Installation

The fastest way to add comment functionality is with the `CommentKit`, which includes pre-configured `commentPlugin` and related components along with their [Plate UI](/docs/installation/plate-ui) components.

<ComponentSource name="comment" />

- [`CommentLeaf`](/docs/components/comment): Renders comment text marks
- [`BlockDiscussion`](/docs/components/block-discussion): Renders discussion UI with comments integration

### Add Kit

```tsx
import { createEditor } from 'platejs/react';
import { CommentKit } from '@/components/editor/comment';

const editor = createEditor({
  plugins: [
    // ...otherPlugins,
    ...CommentKit,
  ],
});
```

</Steps>

### Extend Comment Plugin

Create the comment plugin with extended configuration for state management:

```tsx
import { isString } from 'platejs/dom';
import { TextApi, type Path } from 'platejs';
import { BaseCommentPlugin, getDraftCommentKey } from 'platejs/comment';
import { CommentLeaf } from '@/components/editor/comment';

const initialState: {
  activeId: string | null;
  commentingBlock: Path | null;
  hoverId: string | null;
} = {
  activeId: null,
  commentingBlock: null,
  hoverId: null,
};

export const commentPlugin = BaseCommentPlugin.configure({
  component: CommentLeaf,
  initialState,
});
```

- `initialState.activeId`: Currently active comment ID for visual highlighting
- `initialState.commentingBlock`: Path of the block currently being commented
- `initialState.hoverId`: Currently hovered comment ID for hover effects
- `component: CommentLeaf`: Renders comment text marks with
  [`CommentLeaf`](/docs/components/comment)

### Add Click Handler

Add click handling to manage active comment state:

```tsx
export const commentPlugin = toPlatePlugin(BaseCommentPlugin, {
    initialState,
    on: {
      // Set active comment when clicking on comment marks
      click: ({ api, event, store, type }) => {
        let leaf = event.target as HTMLElement;
        let isSet = false;

        const unsetActiveComment = () => {
          store.set({ activeId: null });
          isSet = true;
        };

        if (!isString(leaf)) unsetActiveComment();

        while (leaf.parentElement) {
          if (leaf.classList.contains(`plite-${type}`)) {
            const commentsEntry = api.node();

            if (!commentsEntry) {
              unsetActiveComment();
              break;
            }

            const id = api.id(commentsEntry[0]);
            store.set({ activeId: id ?? null });
            isSet = true;
            break;
          }

          leaf = leaf.parentElement;
        }

        if (!isSet) unsetActiveComment();
      },
    },
    // ... render
});
```

The click handler tracks which comment is currently active:

- **Detects comment clicks**: Traverses DOM to find comment elements
- **Sets active state**: Updates `activeId` when clicking on comments
- **Clears state**: Unsets `activeId` when clicking outside comments
- **Visual feedback**: Enables hover/active styling in comment components

### Extend Transforms

Extend the `setDraft` transaction command for enhanced functionality:

```tsx
export const commentPlugin = toPlatePlugin(BaseCommentPlugin, {
  initialState,
})
  .extend(({ schema, store }) => ({
    update: ({ tx }) => ({
      setDraft: (options = {}) => {
        const commentingBlock =
          tx.selection()?.focus.path.slice(0, 1) ?? null;

        if (tx.selection.isCollapsed()) {
          const blockEntry = tx.nodes.block();

          if (blockEntry) {
            tx.selection.set(blockEntry[1]);
          }
        }

        tx.nodes.set(
          {
            [getDraftCommentKey()]: true,
            [schema.key]: true,
          },
          { match: TextApi.isText, split: true, ...options }
        );

        tx.selection.collapse();
        store.set({ activeId: getDraftCommentKey() });
        store.set({ commentingBlock });
      },
    }),
  }))
  .configure({
    component: CommentLeaf,
    shortcuts: {
      setDraft: { keys: 'mod+shift+m' },
    },
  });
```

## Plugins

### `CommentPlugin`

Plugin for creating and managing text comments with state tracking and discussion integration.

<API name="CommentPlugin">
  <APIOptions>
    <APIItem name="activeId" type="string | null">
      Currently active comment ID for visual highlighting. Used internally to
      track state.
    </APIItem>
    <APIItem name="commentingBlock" type="Path | null">
      Path of the block currently being commented on.
    </APIItem>
    <APIItem name="hoverId" type="string | null">
      Currently hovered comment ID for hover effects.
    </APIItem>
  </APIOptions>
</API>

## API

### `editor.read.comment.has`

Checks if a comment with the given ID exists in the editor.

<API name="editor.read.comment.has">
  <APIParameters>
    <APIItem name="options" type="{ id: string }">
      Options containing the comment ID to check.
    </APIItem>
  </APIParameters>
  <APIReturns type="boolean">Whether the comment exists.</APIReturns>
</API>

### `editor.read.comment.node`

Gets a comment node entry.

<API name="editor.read.comment.node">
  <APIOptions
    type="object & { id?: string; isDraft?: boolean }"
    optional
  >
    Options for finding the node.
  </APIOptions>
  <APIReturns type="NodeEntry<CommentText> | undefined">
    The comment node entry if found.
  </APIReturns>
</API>

### `editor.api.comment.id`

Gets the ID of a comment from a leaf node.

<API name="editor.api.comment.id">
  <APIParameters>
    <APIItem name="leaf" type="CommentText">
      The comment leaf node.
    </APIItem>
  </APIParameters>
  <APIReturns type="string | undefined">The comment ID if found.</APIReturns>
</API>

### `editor.read.comment.nodes`

Gets all comment node entries matching the options.

<API name="editor.read.comment.nodes">
  <APIOptions
    type="object & { id?: string; isDraft?: boolean }"
    optional
  >
    Options for finding the nodes.
  </APIOptions>
  <APIReturns type="NodeEntry<CommentText>[]">
    Array of comment node entries.
  </APIReturns>
</API>

## Transforms

### `tx.comment.removeMark`

Removes the comment mark from the current selection or a specified location.

<API name="removeMark" />

### `tx.comment.unsetMark`

Unsets comment nodes with the specified ID from the editor.

<API name="unsetMark">
<APIParameters>
  <APIItem name="options" type="{ id: string; transient?: boolean }">
    Options for unsetting comment marks.
  </APIItem>
</APIParameters>

<APIOptions type="object">
  <APIItem name="id" type="string">
    The comment ID to unset.
  </APIItem>
  <APIItem name="transient" type="boolean" optional>
    When true, removes all AI comments at once.
    - **Default:** `false`
  </APIItem>
</APIOptions>
</API>
