建议记录待审阅的文档修改。接受或拒绝建议会修改编辑器内容，因此建议数据保留在文档中；[评论](/docs/comment)位于文档之外，[讨论](/docs/discussion)把两者呈现在同一个审阅视图中。

<PackageInfo>

## 功能

- 用内联注解记录文本建议
- 记录整个区块的插入和删除建议
- 跟踪建议状态与当前用户
- 支持撤销和重做
- 在复制的 Discussion UI 中接受、拒绝并讨论建议

</PackageInfo>

## 套件用法

<Steps>

### 安装

`SuggestionKit` 是最快的接入方式。它包含预配置的 `SuggestionPlugin`、渲染组件以及相关的 [Plate UI](/docs/installation/plate-ui) 组件。

<ComponentSource name="suggestion" />

- [`SuggestionLeaf`](/docs/components/suggestion)：渲染文本建议标记
- `VoidRemoveSuggestionOverlay`：渲染已删除区块的建议遮罩
- [`SuggestionLineBreak`](/docs/components/suggestion)：处理建议中的换行

### 添加套件

```tsx
import { createEditor } from "platejs/react";

import { SuggestionKit } from "@/components/editor/suggestion";

const editor = createEditor({
  plugins: [...SuggestionKit],
});
```

</Steps>

## 手动用法

<Steps>

### 安装

```bash
npm install platejs @tanstack/react-virtual
```

### 配置 Suggestion 插件

```tsx
import { SuggestionPlugin } from "platejs/suggestion/react";

import {
  SuggestionLeaf,
  SuggestionLineBreak,
  VoidRemoveSuggestionOverlay,
} from "@/components/editor/suggestion";

export const suggestionPlugin = SuggestionPlugin.configure({
  component: SuggestionLeaf,
  initialState: {
    currentUserId: "alice",
  },
  slots: {
    afterNodeChildren: VoidRemoveSuggestionOverlay,
    wrapNodeChildren: SuggestionLineBreak,
  },
});
```

`SuggestionPlugin` 管理渲染器使用的激活和悬停状态。`slots.afterNodeChildren` 渲染区块删除遮罩，`slots.wrapNodeChildren` 渲染建议换行。

### 添加插件

```tsx
import { createEditor } from "platejs/react";

const editor = createEditor({
  plugins: [suggestionPlugin],
});
```

### 控制建议模式

```tsx
import { useEditor, usePluginStore } from "platejs/react";

function SuggestionToolbar() {
  const editor = useEditor();
  const isSuggesting = usePluginStore(suggestionPlugin, "isSuggesting");

  return (
    <button
      onClick={() =>
        editor
          .plugin(suggestionPlugin)
          .store.set({ isSuggesting: !isSuggesting })
      }
    >
      {isSuggesting ? "停止建议" : "开始建议"}
    </button>
  );
}
```

[`SuggestionToolbarButton`](/docs/components/suggestion-toolbar-button) 提供相同的工具栏操作。

</Steps>

## Discussion 审阅

复制的 Discussion UI 从编辑器读取建议，并为每个当前建议渲染一张卡片。卡片包含作者、时间、添加/删除/替换/属性更新摘要、接受与拒绝操作，以及附加到该建议的应用评论线程。

安装方法请参阅[讨论](/docs/discussion)。`editor.update.suggestion.accept` 与 `editor.update.suggestion.reject` 是文档修改的唯一所有者；Discussion UI 只调用这些更新并渲染当前状态。

## 插件

### `SuggestionPlugin`

`SuggestionPlugin` 创建和管理文本与区块建议。

<API name="SuggestionPlugin">

## 插件 API

建议查询和值辅助方法位于已安装的插件上，因此编辑器类型、插件状态和 schema 会保留在类型推断路径中。

```tsx
const { api, read } = editor.plugin(BaseSuggestionPlugin);
const suggestions = read.nodes();
const reviews = read.reviews();
```

| 方法 | 说明 |
| --- | --- |
| `read.reviews()` | 返回当前建议分组、ID、操作类型、范围与变更数据 |
| `api.createFragment(fragment, identity)` | 为片段添加显式的插入建议身份 |
| `api.createIdentity(options?)` | 创建建议 ID 和时间戳 |
| `api.dataList(node)` | 返回文本节点上的全部内联建议记录 |
| `read.findIdentity(options)` | 查找已有建议身份 |
| `api.getProps(node, options?)` | 构建节点的建议属性 |
| `api.inlineData(node)` | 返回当前内联建议记录 |
| `api.isBlockSuggestion(node)` | 将节点收窄为区块建议 |
| `api.isCurrentUser(node)` | 根据 `currentUserId` 检查建议归属 |
| `api.isTracking(tags)` | 检查建议中间件是否追踪某次更新 |
| `api.key(id?)` / `api.keyId(node)` / `api.keys(node)` | 读取和构建内联建议键 |
| `read.node(options?)` / `read.nodes(options?)` | 查找一个或全部建议条目 |
| `read.nodeEntries(id, options?)` | 查找建议 ID 对应的内联条目 |
| `api.id(node)` | 返回节点的建议 ID |
| `api.skipDeletes(node)` | 返回不包含删除建议的文本 |
| `api.suggestionData(node)` | 返回内联或区块建议数据 |
| `api.untracked(fn)` | 同步运行操作且不递归创建建议 |
| `api.userId(node)` / `api.userIds(node)` | 返回建议作者 ID |

## 建议分组

`read.reviews()` 返回 `SuggestionReview`：`id`、数字时间戳 `createdAt`、
`userId`、操作类型 `type`、`range` 与 `changes`。每个变更包含当前节点、路径
和建议数据。React 组件使用 `platejs/suggestion/react` 中的
`useSuggestionReviews()` 订阅这些分组。日期、标签与活动卡片状态保留在视图中。

## 更新方法

接受和拒绝操作安装在编辑器的 `update.suggestion` 命名空间中。

```tsx
editor.update.suggestion.accept(id);
editor.update.suggestion.reject(id);
```

| 更新方法 | 说明 |
| --- | --- |
| `accept(id)` | 应用建议的修改 |
| `reject(id)` | 丢弃建议的修改 |
| `addMark(key, value)` | 以建议形式添加标记 |
| `removeMark(key, previousValue?)` | 以建议形式移除标记 |
| `delete(at, options?)` | 记录范围删除 |
| `deleteFragment(options?)` | 记录当前选区删除 |
| `insertFragment(fragment, insertContent?)` | 插入建议片段 |
| `insertText(text)` | 插入建议文本 |
| `removeNodes(nodes)` | 记录节点删除 |
| `setNodes(options?)` | 记录节点属性更新 |

## 更新策略

`SuggestionUpdatePolicy.skip` 在不创建建议标记的情况下运行更新。直接或原子更新应使用包提供的预设。

```tsx
import { SuggestionUpdatePolicy } from "platejs/suggestion";

editor.update(SuggestionUpdatePolicy.skip, (tx) => {
  tx.text.insert("Accepted text");
});
```

## 类型

| 类型 | 用途 |
| --- | --- |
| `SuggestionText` | 包含 `suggestion_<id>` 内联记录的文本节点 |
| `SuggestionElement` | 包含区块级 `suggestion` 数据的元素 |
| `InlineSuggestionData` | `insert`、`remove` 或 `update` 建议的 ID、用户、时间和属性 |
| `SuggestionData` | 区块级 `insert` 或 `remove` 建议数据 |
