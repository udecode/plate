## 安装

```bash
npm install platejs @excalidraw/excalidraw
```

## 使用方式

```tsx
import { ExcalidrawPlugin } from 'platejs/excalidraw/react';

const plugins = [
  // ...其他插件
  ExcalidrawPlugin,
];
```

### 插入工具栏按钮

菜单项直接调用已安装的 Excalidraw 功能：

```tsx
import { BaseExcalidrawPlugin } from 'platejs/excalidraw';

const insertItem = {
  icon: <PenToolIcon />,
  label: 'Excalidraw',
  value: 'excalidraw',
  onSelect: () => {
    const excalidraw = editor.plugin(BaseExcalidrawPlugin);

    if (!excalidraw.installed || editor.read.view.isReadOnly()) return;

    excalidraw.update.insert({}, { select: true });
  },
};
```

## 插件

### `ExcalidrawPlugin`

Excalidraw 空元素插件。

## API 接口

### `editor.plugin(BaseExcalidrawPlugin).update.insert`

向编辑器中插入 Excalidraw 元素。

```tsx
import { BaseExcalidrawPlugin } from 'platejs/excalidraw';

editor.plugin(BaseExcalidrawPlugin).update.insert(
  { data: { elements: [], state: {} } },
  { at: [1], select: true }
);
```

传入 `at` 时使用该精确位置；否则插入到当前选区所在块之后。既没有选区也没有
`at` 时不执行操作。

## UI 行为

复制的 registry 元素负责动态加载、初始视图、控件和布局，并在只读模式启用
`viewModeEnabled`。`useExcalidrawSync({ api, excalidraw })` 负责当前元素与画布同步：
保存绘图、持久状态和引用的图片文件，忽略平移、缩放及选区变化。文档更新和
撤销会反映到画布，并清除不再适用的画布撤销记录。该 hook 返回 `void`；加载期间
`api` 和 `excalidraw` 可以为 `null`。

撤销和重做快捷键即使在画布获得焦点时也会运行文档历史记录，hook 会把结果重新绘制到画布；
只读模式下它们不执行任何操作。画布自带的撤销按钮撤销 Excalidraw 的本地步骤，hook 会把结果保存到节点。

### 自定义组件

自定义画布组件需要保留 registry 元素的三个部分：

- 带有 `contentEditable={false}` 和 `data-editor-root-chrome-ignore="true"` 的包裹元素，让画布自行处理输入。参见[嵌入式组件](/cn/docs/plugin-components#嵌入式组件)。
- `viewModeEnabled={readOnly}`，其中 `readOnly` 来自 `useEditorReadOnly()`，使只读文档保持 Excalidraw 的查看模式。
- `@excalidraw/excalidraw/index.css` 样式导入。
