## 安装

```bash
npm install platejs @excalidraw/excalidraw @tanstack/react-virtual
```

## 使用方式

```tsx
import { ExcalidrawPlugin } from 'platejs/excalidraw/react';

const plugins = [
  // ...其他插件
  ExcalidrawPlugin,
];
```

### 插入工具栏按钮

可以将此项添加到[插入工具栏按钮](/docs/toolbar#insert-toolbar-button)来插入 Excalidraw 元素：

```tsx
{
  icon: <PenToolIcon />,
  label: 'Excalidraw',
  value: PLUGINS.excalidraw,
}
```

## 插件

### `ExcalidrawPlugin`

Excalidraw 空元素插件。

## API 接口

### `editor.plugin(BaseExcalidrawPlugin).update.insert`

向编辑器中插入 Excalidraw 元素。

```tsx
import { BaseExcalidrawPlugin } from 'platejs/excalidraw';

editor.plugin(BaseExcalidrawPlugin).update.insert(
  { data: { elements: [], state: {} } },
  { at: [1], select: true }
);
```

传入 `at` 时使用该精确位置；否则插入到当前选区所在块之后。既没有选区也没有
`at` 时不执行操作。

## UI 行为

复制的 registry 元素负责动态加载、初始视图、控件和布局，并在只读模式启用
`viewModeEnabled`。`useExcalidrawSync({ api, excalidraw })` 负责当前元素与画布同步：
保存绘图、持久状态和引用的图片文件，忽略平移、缩放及选区变化。文档更新和
撤销会反映到画布，并清除不再适用的画布撤销记录。该 hook 返回 `void`；加载期间
`api` 和 `excalidraw` 可以为 `null`。
