- 集成 Excalidraw 库用于创建绘图和图表

## 安装

```bash
npm install @platejs/excalidraw
```

## 使用方式

```tsx
import { ExcalidrawPlugin } from '@platejs/excalidraw/react';

const plugins = [
  // ...其他插件
  ExcalidrawPlugin,
];
```

### 插入工具栏按钮

可以将此项添加到[插入工具栏按钮](/docs/toolbar#insert-toolbar-button)来插入 Excalidraw 元素：

```tsx
{
  icon: <PenToolIcon />,
  label: 'Excalidraw',
  value: PLUGINS.excalidraw,
}
```

## 插件

### `ExcalidrawPlugin`

Excalidraw 空元素插件。

## API 接口

### `editor.plugin(BaseExcalidrawPlugin).update.insert`

向编辑器中插入 Excalidraw 元素。

```tsx
import { BaseExcalidrawPlugin } from '@platejs/excalidraw';

editor.plugin(BaseExcalidrawPlugin).update.insert(
  { data: { elements: [], state: {} } },
  { at: [1], select: true }
);
```

传入 `at` 时使用该精确位置；否则插入到当前选区所在块之后。既没有选区也没有
`at` 时不执行操作。

<API name="editor.plugin(BaseExcalidrawPlugin).update.insert">
<APIParameters>
  <APIItem name="props" type="NodeProps<ExcalidrawElement>" optional>
    Excalidraw 元素的属性参数
  </APIItem>
  <APIItem name="options" type="object" optional>
    插入 Excalidraw 元素的配置选项
  </APIItem>
</APIParameters>
</API>

## UI 行为

复制的 registry 元素直接拥有 Excalidraw React 集成。它动态导入 canvas，
从元素数据构建 `initialData`，在编辑模式保存变化，并在只读模式启用
`viewModeEnabled`。
