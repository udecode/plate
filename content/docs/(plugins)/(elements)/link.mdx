## Features

- Insert, edit, and remove hyperlinks.
- Markdown shortcut: type `[text](url)` and close with `)` to turn it into a link.
- Plain URL autolink: paste a URL, or type a URL then press space or `Enter`.

</PackageInfo>

## Kit usage

<Steps>

### Installation

The fastest way to add link functionality is with the `LinkKit`, which includes pre-configured `LinkPlugin` with floating toolbar, autolink rules, and [Plate UI](/docs/installation/plate-ui) components.

<ComponentSource name="link" />

- [`LinkElement`](/docs/components/link): Renders link elements.
- [`LinkFloatingToolbar`](/docs/components/link): Provides floating toolbar for link editing.

### Add kit

Add the kit to your plugins:

```tsx
import { createEditor } from 'platejs/react';
import { LinkKit } from '@/components/editor/link';

const editor = createEditor({
  plugins: [
    // ...otherPlugins,
    ...LinkKit,
  ],
});
```

</Steps>

## Manual usage

<Steps>

### Installation

```bash
npm install platejs
```

### Add plugin

Include `LinkPlugin` in your Plate plugins array when creating the editor.

```tsx
import { LinkRules } from 'platejs';
import { LinkPlugin } from 'platejs/react';
import { createEditor } from 'platejs/react';

const editor = createEditor({
  plugins: [
    // ...otherPlugins,
    LinkPlugin,
  ],
});
```

### Configure plugin

Configure the plugin with floating toolbar and custom components.

```tsx
import { LinkPlugin } from 'platejs/react';
import { createEditor } from 'platejs/react';
import { LinkElement } from '@/components/editor/link';
import { LinkFloatingToolbar } from '@/components/editor/link';

const editor = createEditor({
  plugins: [
    // ...otherPlugins,
    LinkPlugin.configure({
      component: LinkElement,
      slots: {
        afterEditable: LinkFloatingToolbar,
      },
    }),
  ],
});
```

- `slots.afterEditable`: Renders [`LinkFloatingToolbar`](/docs/components/link) after the editable area for link editing.
- `.configure({ component: LinkElement })`: Renders link elements with
  [`LinkElement`](/docs/components/link).

### Input rules

Configure `LinkPlugin` to enable the built-in link input presets:

```tsx
import { LinkPlugin } from 'platejs/react';

const editor = createEditor({
  plugins: [
    LinkPlugin.configure({
      inputRules: [
        LinkRules.markdown(),
        LinkRules.autolink({ variant: 'paste' }),
        LinkRules.autolink({ variant: 'space' }),
        LinkRules.autolink({ variant: 'break' }),
      ],
    }),
  ],
});
```

- `LinkRules.autolink({ variant: 'paste' | 'space' | 'break' })`: Enables plain URL autolink. A pasted or typed token becomes a link when `parseUrl` recognizes it and `allowedSchemes` allows the result; otherwise the paste, space or `Enter` goes on as usual.
- `LinkRules.markdown()`: Enables `[text](url)` source-entry conversion on the closing `)`. Image source, `![alt](src)`, stays text.

### Add toolbar button

You can add [`LinkToolbarButton`](/docs/components/link-toolbar-button) to your [Toolbar](/docs/toolbar) to insert and edit links.

The floating toolbar saves a new or changed address that starts with `http://` or `https://`, has another scheme such as `mailto:`, or starts with `/`, `./`, `../`, `#` or `?`. It stays open on any other draft, such as `www.example.com` or `https:www.example.com`, and when `allowedSchemes` refuses the address. Editing only the link text keeps the stored address, even one `allowedSchemes` no longer allows.

</Steps>

## Plugins

### `LinkPlugin`

Plugin for link formatting.

URL parsing and headless interaction behavior share one state contract:

```tsx
LinkPlugin.configure({
  initialState: {
    allowedSchemes: ['http', 'https', 'mailto', 'tel'],
  },
});
```

<API name="LinkPlugin">

Options:

- `allowedSchemes?: string[]` — URL schemes the link feature accepts when it
  inserts, types, pastes or imports a link, and that a rendered link may use.
  Relative URLs are always allowed. Add a scheme such as `vscode` for app deep links. Script-capable
  destinations, such as `javascript:`, `vbscript:`, and `data:`, are never
  allowed, and a stored link URL must pass that floor. HTML and Markdown import
  keep the label of a link whose destination is not allowed and report the
  removed destination. A stored link whose scheme is no longer allowed keeps
  its URL, renders without an `href`, and exports its stored URL, and so does
  a link pasted as an exact editor fragment. Default:
  `['http', 'https', 'mailto', 'tel']`.

<APIOptions type="object">
<APIItem name="rangeBeforeOptions" type="RangeBeforeOptions" optional>
Allows custom configurations for rangeBeforeOptions.
- **Default:**
```ts
{
  matchString: ' ',
  skipInvalid: true,
  afterMatch: true,
}
```
</APIItem>
<APIItem name="defaultLinkAttributes" type="AnchorHTMLAttributes&lt;HTMLAnchorElement&gt;" optional>
Default HTML attributes for link elements.
- **Default:** **`{}`**
</APIItem>
<APIItem name="keepSelectedTextOnPaste" type="boolean" optional>
Keeps selected text on pasting links by default.
- **Default:** **`true`**
</APIItem>
<APIItem name="parseUrl" type="(text: string, defaultParseUrl: (text: string) => string | undefined) => string | undefined" optional>
Returns the href for typed or pasted text, or `undefined` when the text is not a link. The autolink rules call it; `upsert`, the toolbar and imports do not. `defaultParseUrl` accepts a whole token with an explicit scheme, such as `https://example.com` or `tel:+15551234`, so typed `#top`, `/docs` and `www.example.com` stay text. With Markdown paste installed, a pasted `www.example.com` can still become a link. The result still has to pass `allowedSchemes`.
- **Default:** **`(text, defaultParseUrl) => defaultParseUrl(text)`**

```tsx
LinkPlugin.configure({
  initialState: {
    parseUrl: (text, defaultParseUrl) =>
      text === 'example' ? 'https://example.com' : defaultParseUrl(text),
  },
});
```
</APIItem>
</APIOptions>
</API>

## Updates

`LinkPlugin` installs link updates on the editor. Types are inferred from the
configured editor, so no editor argument or transaction helper is required.

```tsx
editor.update.link.upsert({ url: 'https://platejs.org', text: 'EditorRoot' });
editor.update.link.unwrap({ split: true });
```

| Update | Description |
| --- | --- |
| `editor.update.link.insert(node, options?)` | Inserts a link node; returns `true`, or `undefined` when the URL is not allowed or the node cannot be inserted. |
| `editor.update.link.unwrap(options?)` | Unwraps matching links; with `split`, unlinks only the selected text, or the whole link at a caret; returns `true`, or `undefined` when no link was removed. |
| `editor.update.link.upsert(options)` | Prepares URL input, then inserts or updates a link at the selection. Over selected text that crosses or touches a link's edge or covers whole links, it unlinks only the selected part of each link and links the selection; a selection inside one link updates that link. Returns `true` when the link lands, or `undefined` when the editor refuses the update, the URL is not allowed, there is no selection, an expanded selection outside a link holds no text, or a link cannot go there, such as in a code block or over a mention. A call that returns `undefined` over selected text may still have unlinked the selected part of an old link. |
| `editor.update.link.upsertText(options)` | Replaces the text of the link above the selection. |
| `editor.update.link.wrap(options)` | Wraps the selected text in a link; returns `true`, or `undefined` when the URL is not allowed or nothing was wrapped. |

`insert`, `upsert` and `wrap` encode unescaped URI characters and check the result against `allowedSchemes` before changing the document. They keep valid percent escapes and store a URL without a scheme as a relative link.

```tsx
if (!editor.update.link.upsert({ url })) {
  // The URL is not allowed, there is no selection, or a link cannot go there.
}
```

### `CreateLinkNodeOptions`

Options for creating a new link node.

<API name="CreateLinkNodeOptions">
<APIOptions type="object">
  <APIItem name="url" type="string">
    The URL of the link node that is being created.
  </APIItem>
  <APIItem name="text" type="string" optional>
    The text that is displayed for the link node. If not provided, the URL is used as the display text.
  </APIItem>
  <APIItem name="target" type="string" optional>
    Specifies where to open the URL:
    - `_blank`: new tab
    - `_self`: same frame
    - `_parent`: parent frame
    - `_top`: full window
  </APIItem>
  <APIItem name="children" type="Text[]" optional>
    An array of text nodes that represent the link content.
  </APIItem>
</APIOptions>
</API>

## API Reference

### `getLinkHref`

Returns the href a link may navigate to. The link feature runs the same check before it renders an `href`. Copied UI that renders a stored address as a link, such as a tag chip, calls it to link only what a link would.

```tsx
import { getLinkHref } from 'platejs';
import { LinkPlugin, usePluginStore } from 'platejs/react';

const allowedSchemes = usePluginStore(LinkPlugin, 'allowedSchemes');
const href = getLinkHref(url, { allowedSchemes });
```

`usePluginStore` throws when the editor does not install `LinkPlugin`. Code that may run without it checks `editor.plugin(LinkPlugin).installed` first. When link is installed, it reads the store in a child component, because a hook cannot run conditionally. Otherwise it calls `getLinkHref(url)` for the default schemes.

<API name="getLinkHref">
<APIParameters>
  <APIItem name="url" type="string">
    The stored or typed address. Surrounding spaces are trimmed. An address that starts with `//` or holds a backslash or a control character, such as a tab, is refused.
  </APIItem>
  <APIItem name="options.allowedSchemes" type="readonly string[]" optional>
    Schemes allowed besides relative URLs. Defaults to `['http', 'https', 'mailto', 'tel']`. Pass `LinkPlugin`'s `allowedSchemes` when the editor installs it. Script-capable schemes such as `javascript:` and `data:` are always refused.
  </APIItem>
</APIParameters>
<APIReturns type="string | undefined">
  The trimmed href, or `undefined` when the address is refused or malformed, such as `https://` with no host.
</APIReturns>
</API>

## Registry link UI

The copied `link` item owns floating state, positioning, hotkeys,
outside clicks, URL input, and toolbar commands. It exports the app-local
`linkPlugin` descriptor and `LinkFloatingToolbar` component.

<ComponentSource name="link" />

Use that exact descriptor when another copied UI surface opens the toolbar.

```tsx
import { linkPlugin } from '@/components/editor/link';

const link = editor.plugin(linkPlugin);

link.api.trigger({ focused: true });
link.api.triggerEdit();
link.api.triggerInsert({ focused: true });
link.api.submit();
```
