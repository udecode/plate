## Features

- Support for PlantUML, Graphviz, Flowchart, and Mermaid diagram languages
- Inline code editing with code-block-like styling
- Real-time preview with debounced rendering (500ms)
- Three persisted views: split, code, and preview
- Responsive layout: horizontal on desktop (code left, preview right), vertical on mobile (preview top, code bottom)
- Border separator between code editor and preview in Both mode
- Toolbar controls: language selector and view mode selector (always visible on mobile, hover to show on desktop)
- Download rendered diagrams as images
- Floating toolbar with delete and download actions

</PackageInfo>

## Kit Usage

<Steps>

### Installation

The fastest way to add code drawing functionality is with the `CodeDrawingKit`, which includes the pre-configured `CodeDrawingPlugin` with its [Plate UI](/docs/installation/plate-ui) components.

<ComponentSource name="code-drawing" />

- [`CodeDrawingElement`](/docs/components/code-drawing): Renders code drawing elements with inline editing and preview.

### Add Kit

Add the kit to your plugins:

```tsx
import { createPlateEditor } from 'platejs/react';
import { CodeDrawingKit } from '@/components/editor/code-drawing';

const editor = createPlateEditor({
  plugins: [
    // ...otherPlugins,
    ...CodeDrawingKit,
  ],
});
```

</Steps>

## Manual Usage

<Steps>

### Installation

```bash
npm install @platejs/code-drawing
```

### Add Plugin

Include `CodeDrawingPlugin` in your Plate plugins array when creating the editor.

```tsx
import { CodeDrawingPlugin } from '@platejs/code-drawing/react';
import { createPlateEditor } from 'platejs/react';

const editor = createPlateEditor({
  plugins: [
    // ...otherPlugins,
    CodeDrawingPlugin,
  ],
});
```

### Configure Plugin

Configure the code drawing plugin with custom components.

```tsx
import { CodeDrawingPlugin } from '@platejs/code-drawing/react';
import { createPlateEditor } from 'platejs/react';
import { CodeDrawingElement } from '@/components/editor/code-drawing';

const editor = createPlateEditor({
  plugins: [
    // ...otherPlugins,
    CodeDrawingPlugin.configure({ component: CodeDrawingElement }),
  ],
});
```

- `component`: Assigns [`CodeDrawingElement`](/docs/components/code-drawing) to render code drawing elements.

### Add Toolbar Button

You can add a toolbar button to insert code drawing elements. Add this item to the [Insert Toolbar Button](/docs/toolbar#insert-toolbar-button):

```tsx
import { PLUGINS } from 'platejs';

const insertItem = {
  icon: <Code2Icon />,
  label: 'Code Drawing',
  value: PLUGINS.codeDrawing,
};
```

</Steps>

## Plugins

### CodeDrawingPlugin

Plugin for rendering code drawings with inline editing and preview capabilities.

## API

### `editor.plugin(BaseCodeDrawingPlugin).update.insert`

Inserts a code drawing element at the current selection.

<API name="editor.plugin(BaseCodeDrawingPlugin).update.insert">
<APIParameters>
<APIItem name="input" type="Partial<Pick<CodeDrawingElement, 'code' | 'language' | 'view'>>" optional>
Construction values for the code drawing element. Schema defaults make every canonical field present.
<APISubList>
<APISubListItem parent="input" name="language" type="CodeDrawingLanguage" optional>
The diagram language.

- **Default:** `'mermaid'`

- **Options:** `'flowchart'`, `'graphviz'`, `'mermaid'`, `'plantuml'`

</APISubListItem>
<APISubListItem parent="input" name="view" type="CodeDrawingView" optional>
The persisted presentation view.

- **Default:** `'split'`

- **Options:** `'code'`, `'preview'`, `'split'`

</APISubListItem>
<APISubListItem parent="input" name="code" type="string" optional>
The code content for the diagram.

- **Default:** `''`

</APISubListItem>
</APISubList>
</APIItem>
<APIItem name="options" type="object" optional>
Use `after?: NodeTarget` to choose a reference block and `select?: boolean` to
select the drawing. Without a reference or selection, the command appends the
drawing to the document.
</APIItem>
</APIParameters>
</API>

## Types

### `CodeDrawingElement`

The code drawing element type.

<API name="CodeDrawingElement">
<APIAttributes>
<APIItem name="type" type="string">
The serialized element type. Its default is `codeDrawing`; read the installed
value from `editor.plugin(BaseCodeDrawingPlugin).schema.type`.
</APIItem>
<APIItem name="code" type="string">
The diagram source. Defaults to an empty string.
</APIItem>
<APIItem name="language" type="CodeDrawingLanguage">
The lowercase diagram-language identifier. Defaults to `mermaid`.
</APIItem>
<APIItem name="view" type="CodeDrawingView">
The persisted presentation view. Defaults to `split`.
</APIItem>
</APIAttributes>
</API>

### `CodeDrawingLanguage`

The type of diagram supported.

<API name="CodeDrawingLanguage">
<APIReturns>
<APIItem type="'flowchart' | 'graphviz' | 'mermaid' | 'plantuml'">
The persisted diagram language.
</APIItem>
</APIReturns>
</API>

### `CodeDrawingView`

The view mode for code drawing elements.

<API name="CodeDrawingView">
<APIReturns>
<APIItem type="'code' | 'preview' | 'split'">
The view mode.

- `'split'`: Shows code and preview together.
- `'code'`: Shows only the code editor.
- `'preview'`: Shows only the rendered preview.

</APIItem>
</APIReturns>
</API>
