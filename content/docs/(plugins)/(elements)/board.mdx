## Features

- A void `board` block that owns its own list of shapes. Each shape is a top-level block of that list, so sync, suggestions, undo and copy and paste work per shape.
- Six shape types: sticky notes and geo shapes that hold rich text, image shapes that hold a picture, arrows whose ends bind to shapes, frames that hold shapes, and pen lines.
- Styles stored on each shape: fill, outline color, line style, outline width, opacity and text size, each with a default for its shape type. One pick restyles the selected shapes as one undo step, or the next shape while a drawing tool is picked.
- Commands to insert, move, resize, restack and remove shapes. Undo never splits a call, and in Suggesting mode each call is one suggestion.
- Copy, paste and duplicate with fresh shape ids. A copied arrow binds the copied shapes. The copies land on top, with frames still behind the other shapes. They land at the pointer when it is over the board, and step 24px down and right off any shape already at their place.
- Paste an image link or a picture copied from a web page, and it lands as an image shape at the pointer, at the picture's proportions.
- A camera, a tool, a tool lock and a next style for each mounted view, which the document never stores.
- Tab and Mod with an arrow move between shapes, Shift+Enter reaches the toolbar, and keys zoom, pan and fit. Enter places a note, shape or frame, and connects two shapes with an arrow. A screen reader hears the selected shape, the picked tool, the zoom, each removal and each step of a connect, in words your app passes.
- Only the shapes near the camera mount, so the work each keystroke does stays the same as the board grows.

</PackageInfo>

## Kit usage

<Steps>

### Installation

`BoardKit` installs `BoardPlugin` and the five shape plugins with the copied board UI: the board surface with its toolbar and a renderer for each of those five shape types.

<ComponentSource name="board" />

- `BoardElement`: renders the board surface and its toolbar.
- `BoardPageElement`: renders a board that fills its container. `BoardPageKit` installs it in place of `BoardElement`.
- `BoardNoteElement`, `BoardGeoElement`, `BoardArrowElement`, `BoardFrameElement` and `BoardStrokeElement`: render each shape type.
- `BoardImageElement`: renders an image shape. `BoardImageKit` installs it apart from `BoardKit`, as [Images](#images) shows.
- `BoardToolbar`: picks the select, hand, note, shape, arrow, frame, pen or eraser tool, and its shape menu picks a rectangle, ellipse, diamond or triangle for the next shape. The lock button after them turns the tool lock on or off, as Q does, and shows pressed while the lock is on. Zoom out and zoom in move one zoom step, the zoom level between them shows the zoom as a percentage and goes back to 100% when clicked, and the fit button brings every shape into view. With a frame selected, an icon button removes the frame and keeps the frame's shapes.
- `BoardStylePanel`: docks at the board's top right and styles the selected shapes, or the next shape while a drawing tool is picked, as [Style panel](#style-panel) shows.

### Add kit

```tsx
import { createEditor } from 'platejs/react';

import { BoardKit } from '@/components/editor/board';

const editor = createEditor({
  plugins: [
    // ...otherPlugins,
    ...BoardKit,
  ],
});
```

</Steps>

## Style panel

Select shapes, or pick a drawing tool, and the panel at the board's top right shows a row for each style they take: Shape, which turns a geo shape into a rectangle, ellipse, diamond or triangle, then Fill, Outline, Line, Width and Text size. A pick writes every selected shape that takes the style, and the shape you are typing in, as one undo step that teammates in a shared room see. With a drawing tool picked, a pick styles only the next shape. The panel hides while no shape it targets takes a style, and in a read-only view. It has no opacity row, and a shape keeps the `opacity` it stores. On a board narrower than 36rem the panel folds behind a Styles button. A pick keeps the caret in the shape you are typing in, except in that folded panel, whose Styles button moves focus into the panel.

The copied `board.tsx` renders the panel in the surface's `toolbar`, next to `BoardToolbar`, and defines the class constants it uses, such as `BOARD_COLORS`:

```tsx
const boardToolbar = (
  <>
    <BoardToolbar />
    <BoardStylePanel />
  </>
);

export function BoardElement(props: EditorElementProps<typeof BoardPlugin>) {
  return (
    <BoardSurface
      {...props}
      attributes={{
        ...props.attributes,
        className: cn(
          '@container my-4 rounded-lg border data-selected:ring-2 data-selected:ring-ring',
          BOARD_COLORS,
          BOARD_ERASING,
          BOARD_FOCUS_RING,
          BOARD_GRID
        ),
      }}
      messages={boardMessages}
      toolbar={boardToolbar}
    />
  );
}
```

The panel needs two of those classes. Without `@container` it stays folded behind the Styles button at every width, and without `BOARD_COLORS` its named swatches show no color.

`BoardStylePanel` places itself at the board's top right and marks its root with `data-board-dock="right"`. The mark tells `fit` and Shift+1 which side the panel covers, so they fit shapes into the room beside it. When that room cannot hold the shapes at 10 percent zoom, they use the board's whole width. The mark moves nothing, so place a panel of your own at a side and mark it with `"left"` or `"right"`. Every other top-level element of `toolbar` counts as a row at the board's top or bottom.

To build your own row, render it inside `toolbar`, read its style from `styles` and write it with `setStyle`. A style that no target takes has no entry in `styles`, so the row hides. Prevent the default of a press on the row, so a shape being edited keeps its caret:

```tsx
import { useBoardActions, useBoardView } from 'platejs/board/react';

const SIZES = ['s', 'm', 'l', 'xl'] as const;

function TextSizeRow() {
  const textSize = useBoardView((view) => view.styles.textSize);
  const { setStyle } = useBoardActions();

  if (!textSize) return null;

  return (
    <div aria-label="Text size" role="group">
      {SIZES.map((size) => (
        <button
          key={size}
          aria-pressed={!textSize.mixed && textSize.value === size}
          type="button"
          onClick={() => setStyle({ textSize: size })}
          onMouseDown={(event) => event.preventDefault()}
        >
          {size.toUpperCase()}
        </button>
      ))}
    </div>
  );
}
```

## Images

`BoardImageKit` adds the image shape, a box that holds one picture. Its one child is the document's own image element, so `ImagePlugin` keeps the picture's link, alt text, HTML and Markdown. Install the kit in an editor that installs `ImagePlugin`, such as one with the [media kit](/docs/media). The demo at the top of this page gets it from `EditorKit`.

```tsx
import { createEditor } from 'platejs/react';

import { BoardImageKit, BoardKit } from '@/components/editor/board';
import { MediaKit } from '@/components/editor/media';

const editor = createEditor({
  plugins: [
    // ...otherPlugins,
    ...MediaKit,
    ...BoardKit,
    ...BoardImageKit,
  ],
});
```

Paste an image link, or a picture copied from a web page, while the board has focus, such as after a click on its empty space. With the caret in the page's text, the page takes the paste at the caret, even while the pointer is over the board. A link counts as an image link when `ImagePlugin` would embed it, such as one whose path ends in `.png` or `.jpg`. Pasted HTML counts when every block in it that is not empty is a picture.

- The pictures of one paste land as image shapes in a row 16px apart, centered on the pointer, or on the view's center when the pointer is off the board. They land as one undo step, and the board selects them.
- Each shape keeps its picture's proportions, shrunk so its longest side is at most 480px and never enlarged. A picture that fails to load lands at 320 by 240.
- The paste waits for each picture to load. Any of these drops a waiting paste: a key or a press on the board, another paste, focus leaving the board, an edit or selection change such as an undo, or the view turning read-only.
- While a shape's text is being edited, a paste goes into that text, and no image shape appears.

Every resize of an image shape keeps its proportions, with or without Shift. A shrink stops when the short edge reaches 8px, and a shape whose short edge is already under 8px can only grow. An image shape has no text to edit, so Enter and a double-click keep it selected. It takes no style, so the style panel hides while the select tool is picked and only image shapes are selected. With a drawing tool picked, the panel targets the next shape that tool draws instead, as [Style panel](#style-panel) says. The copied `BoardImageElement` fits the picture to the shape's box and draws no caption.

To add a picture from code, pass the image element as the shape's one child. The shape is 320 by 240 unless `width` and `height` say otherwise.

```ts
import { BaseBoardImagePlugin } from 'platejs/board';

editor.update((tx) => {
  tx.plugin(BaseBoardImagePlugin).insert(
    {
      children: [
        {
          children: [{ text: '' }],
          type: 'image',
          url: 'https://example.com/plan.png',
        },
      ],
      height: 320,
      width: 480,
      x: 300,
      y: 40,
    },
    { board }
  );
});
```

## Manual usage

<Steps>

### Installation

```bash
npm install platejs
```

### Add plugins

Install the board and each shape type it holds. Configure each plugin with the component that draws it.

```tsx
import {
  BoardArrowPlugin,
  BoardFramePlugin,
  BoardGeoPlugin,
  BoardNotePlugin,
  BoardPlugin,
  BoardStrokePlugin,
} from 'platejs/board/react';
import { createEditor } from 'platejs/react';

import {
  BoardArrowElement,
  BoardElement,
  BoardFrameElement,
  BoardGeoElement,
  BoardNoteElement,
  BoardStrokeElement,
} from '@/components/editor/board';

const editor = createEditor({
  plugins: [
    BoardPlugin.configure({ component: BoardElement }),
    BoardNotePlugin.configure({ component: BoardNoteElement }),
    BoardGeoPlugin.configure({ component: BoardGeoElement }),
    BoardArrowPlugin.configure({ component: BoardArrowElement }),
    BoardFramePlugin.configure({ component: BoardFrameElement }),
    BoardStrokePlugin.configure({ component: BoardStrokeElement }),
  ],
});
```

For pictures, also install `ImagePlugin` and `BoardImagePlugin.configure({ component: BoardImageElement })`.

</Steps>

## Keyboard and pointer

Mod is Command on a Mac and Control elsewhere. The board has one Tab stop, its focus target, which holds focus while you move between shapes.

| Input | Result |
| --- | --- |
| A press on a shape with the select tool | Selects it. Shift adds it to the selection. |
| A click with the note, shape or frame tool | Places that shape at its default size, centered on the click, over empty board or over another shape. It selects the new shape and picks the select tool, or keeps the tool while the tool lock is on. |
| A drag with the note, shape or frame tool | Draws that shape over the dragged box, over empty board or over another shape, and shows the picked outline while you drag. Shift keeps a square, and Alt centers the box where the drag started. It selects the new shape and picks the select tool, or keeps the tool while the tool lock is on. |
| A drag on a selected shape's corner handle, which shows only with the select tool | Resizes the shape once the pointer has gone 8 px, down to 8 a side, with the opposite corner in place. Shift keeps its proportions, and Alt resizes it around its center. An image shape keeps its proportions with or without Shift. A resize that keeps proportions stops when the short edge reaches 8, and a shape whose short edge is already under 8 can only grow. Each edge the drag moves lines up with the nearest edge or center of another shape or frame in view within 8 screen px, and a line shows each edge that lines up. The shape never lines up with arrows or pen lines. Hold Control or Command to resize it freely. |
| Enter on the selected board, or on the focused board with nothing selected and any tool but the note, shape, frame and arrow tools | Selects its first shape. On an empty selected board, it focuses the board, so the tool letters work. |
| Tab and Shift+Tab | Move between shapes in the order the board stores them, and leave the board after the last one. A shape outside the view comes into it. |
| Mod with an arrow | Selects the nearest shape in that direction and brings it into view. With nothing selected, it starts from the view's center. With no shape that way, the selection stays and the board says it again. |
| Double click with the select tool, or Enter on one selected note, shape or arrow with any tool but the note, shape, frame and arrow tools, or on one selected arrow with the arrow tool | Edits its text. An image shape has no text, so both keep it selected. |
| Escape | Ends a drag, a connect, a resize or picking in flight and keeps the tool. Otherwise it climbs from the text to its shape. On the focused board or its selected shapes, it then picks the select tool when another tool is picked, or climbs to the board when the select tool is picked. |
| Shift+Enter on the focused board or its selected shapes | Moves focus to the toolbar. Escape or Shift+Tab moves it back. |
| `V`, `H`, `N`, `R`, `A`, `F`, `P`, `E` | Pick the select, hand, note, shape, arrow, frame, pen and eraser tools. |
| `Q` on the focused board or its selected shapes | Turns the tool lock on or off. While it is on, the note, shape, frame and arrow tools stay picked after each shape they add, so you can add several in a row. Escape and the tool letters change the tool and keep the lock. A held Q turns it once, and Q in a shape's text types a q. |
| Enter with the note or shape tool, on the focused board or its selected shapes | Places a note or shape of the default size 24 px to the right of the selection, or at the view's center with nothing selected. It selects the new shape and picks the select tool, so the next Enter edits its text. While the tool lock is on, it keeps the tool, so the next Enter places another one beside it. When another shape that is not an arrow has its top-left corner where the new shape's top-left corner would go, it tries 24 px down and right, then 48 px, and so on. When no point it tries is free, or a coordinate it would store is not a finite number, Enter places nothing and says the selection again. |
| Enter with the frame tool, on the focused board or its selected shapes | Places a frame around the selected shapes, padded by 24 px. The frame takes in each shape wholly inside it that no frame holds yet and no suggestion removes. It never takes in an arrow or a frame. With nothing selected, Enter places a frame of the default size at the view's center. It selects the new frame and picks the select tool, or keeps the frame tool while the tool lock is on. When a coordinate the frame would store is not a finite number, or a frame around the selection would take in no shape, Enter places nothing and says the selection again. |
| Enter with the arrow tool and one shape selected that is not an arrow | Starts connecting that shape. Tab and Shift+Tab aim the arrow's end at the middle of the other shapes that are not arrows, wrapping at either end, and Mod with an arrow aims it at the nearest one that way from the end. The arrow keys move the end by 1, or 10 with Shift. It binds where it sits in the frontmost shape under it that is not an arrow or the start, counting a frame only on its edge and a pen line only on its line, and stays free off every such shape. Enter draws the arrow from the start's middle to the end, selects it and picks the select tool, or keeps the arrow tool while the tool lock is on. Escape, a left or middle press on the board, another tool, an undo or redo, Mod+D, removing the shape it started from, the view turning read-only, or focus leaving the board ends the connect without drawing. |
| Enter with the arrow tool and nothing selected | Starts an arrow at the view's center. The arrow keys move its start by 1, or 10 with Shift. At the center and after each move, the start binds where it sits in the frontmost shape under it that is not an arrow, counting a frame only on its edge and a pen line only on its line, and stays free off every such shape. Tab, Shift+Tab and Mod with an arrow aim it at a shape's middle. Enter keeps the start and connects from there, as the row above does from a selected shape, and the end can bind to any shape but the start's. The same keys and events end it without drawing, and removing the shape the start binds to ends it too. |
| Enter with the arrow tool and several shapes selected | Says the selection again through `shapes` and draws nothing. |
| S with one shape selected that is not an arrow | Starts resizing the shape from its bottom-right corner. Tab moves to the next corner clockwise and Shift+Tab to the one before. The arrow keys move the corner by 1, or 10 with Shift, down to 8 a side, and the opposite corner stays where it is. An image shape keeps its proportions, so it stops when the short edge reaches 8, and one whose short edge is already under 8 can only grow. Each key shows the new box, with the arrows bound to the shape following it, and writes nothing. Enter writes the box as one undo step when it changed. Escape, a pointer press, the view turning read-only, removing the shape or focus leaving the board puts the box back and writes nothing, and so does any other key, which then does what it does. |
| Space on the focused board | Starts picking shapes. The cursor starts on the first selected shape in stored order, or on the first shape with nothing selected, and the copied board rings it with a dashed line. Tab and Shift+Tab move the cursor through every shape in stored order and wrap, and Mod with an arrow moves it to the nearest shape that way. Neither changes the selection. Space adds the cursor's shape to the selection or takes it out. Enter or Escape keeps the selection and ends picking. A pointer press, focus leaving the board or removing the cursor's shape ends it too, and so does any other key, which then does what it does. The board acts when Space comes up, and only for a press that went down on the focused board with no modifier and met no other key or pointer press before it came up, so a drag with Space held still pans. During a resize, Space only ends it, as any other key does. During a connect or a pointer gesture, or on a board with no shapes, Space does nothing. |
| Arrow keys | Nudge the selected shapes by 1 point, or 10 with Shift. During a connect they move the end being placed instead. For an arrow begun with nothing selected, that is the start until Enter keeps it, then the end. During a resize they move its corner. |
| `]` and `[` | Bring the selected shapes forward or send them backward one step. |
| Mod+Shift+Up and Mod+Shift+Down | Bring the selected shapes to the front or send them to the back. |
| Delete or Backspace | Removes the selected shapes. A frame goes with the shapes in it. |
| Mod+A with a shape selected | Selects every shape of the board. |
| Mod+D on the focused board or its selected shapes | Copies the selected shapes, with the shapes in a selected frame, as one undo step, and selects the copies. As with a paste, the copies land 24 px down and right of their sources, or further while another shape sits at their place. A held Mod+D copies once. With nothing selected, a writable board says the selection again. A read-only board copies nothing and says nothing, as with the other keys that write. With shapes selected in a writable view, Mod+D first ends a drag or a connect in flight. In a shape's text, the board leaves Mod+D to the text. |
| Mod+Z, and Mod+Shift+Z or Control+Y | Undo and redo. Control+Y redoes only off a Mac. Focus follows the shapes the undo selects. |
| `=` or `+`, and `-` | Zoom in or out to the next of 10, 25, 50, 100, 200, 400 and 800 percent. |
| Shift+0 | Zooms to 100 percent. |
| Shift+1 | Fits every shape in the view. |
| PageDown and PageUp | Pan down or up by 80 percent of the view, or right and left with Shift. |
| A drag on a shape with the select tool | Moves the selected shapes, and the shapes in a selected frame, once the pointer has gone 8 px, so a click moves nothing. On each axis the selected shapes line up with the nearest edge or center of another shape or frame in view within 8 screen px, and a line shows each edge or center they share. They never line up with arrows or pen lines. They also space evenly with the nearest shapes beside them, within the same 8 screen px: halfway between two, or at the gap the next two already have. A line with a tick at each end marks each equal gap. Hold Control or Command to move them freely. The move is one undo step. |
| A drag with the select tool and Alt held | Copies the dragged shapes, lined up as a move lines them up. A copy that lands at another shape's place moves 24 px down and right, as with a paste. |
| A click or drag with the eraser | Marks every note, shape, arrow and pen line it passes over, and removes them on release as one undo step. A shape with no fill and no label is marked only where the path passes near its outline, so a pen line inside an empty rectangle goes alone. A frame is never marked; select it and press Delete to remove it. Escape or another tool picked mid-drag removes nothing. |
| A drag on the empty board with the select tool | Draws a selection box and selects every shape wholly inside it. Shift keeps the shapes already selected. A touch drag pans instead. |
| A drag with the hand | Pans, from any point and over shapes and the text being edited too. It selects, moves and edits nothing. While the hand is picked, the pointer is an open hand, except over an element with its own cursor. |
| Wheel, or a drag with Space held or with the middle button | Pans, from any point and over shapes too. Mod with the wheel zooms. |

On a read-only board, the keys that change nothing still work: Tab and Shift+Tab, Mod with an arrow, Mod+A, Enter on the board, Space picking, Escape, Shift+Enter, the tool letters, Q, and the zoom, fit and pan keys. The keys that write do nothing and say nothing. With the note, shape, frame or arrow tool, Enter does what it does with the select tool. After the last shape, Tab clears the selection and the browser moves focus out of the board.

Backspace at the start of the block after a board, or Delete at the end of the block before it, selects the board. The next Backspace or Delete removes it with every shape, and one undo puts it back.

## Screen readers

The board says what happens through the editor's one status region, in the words your copied board passes as `messages`. The prop is required, and the package ships no English word. Only the view that holds focus says anything, so a second view of the same board stays silent. A member that returns an empty string says nothing. Moves, restacks and pans say nothing.

| Member | Use |
| --- | --- |
| `label` | The board's name, on its focus target and on the region of its shapes. |
| `instructions` | The focus target's description, which a screen reader says when the board takes focus. |
| `aim(shape, { anchor, position, side, total })` | Said when the arrow end the keys move binds to `shape`: when Tab, Shift+Tab or Mod with an arrow aims it at the shape's middle, when an arrow key moves it into or within the shape, and again when Mod with an arrow finds no shape that way. `anchor` is where the end sits in the shape in whole percents, `across` from its left edge and `down` from its top, so the middle is 50 and 50. `side` is `'start'` while the keys place the start of an arrow begun with nothing selected, and `'end'` while they move its end. `position` and `total` give the shape's place in stored order among all shapes. |
| `connecting(from)` | Said when Enter with the arrow tool starts connecting `from`, the one selected shape, and when Enter keeps the start of an arrow begun with nothing selected, with `from` as the shape that start binds to, or `null` for a start on no shape. While the keys place the end and the connect has none, before an arrow key or an aim key places one and after the shape it binds to is removed, Enter and an aim key that finds no shape say it again. Enter also says it again, and draws no arrow, when the arrow would have no length, as with the end back at the start's point. |
| `free(place, { side })` | Said when an arrow key moves the arrow end the keys move onto no shape it can bind to, with the board point it sits at in whole units, and again when Tab, Shift+Tab or Mod with an arrow finds no shape. `side` is that end, as in `aim`. |
| `starting(place, { from })` | Said when Enter with the arrow tool and nothing selected starts an arrow at `place`, the view's center in whole units. The start binds to the shape under that point as an arrow key move binds it, and sits free where that move would bind it to no shape. `from` is the shape the start binds to, or `null` for a free start. |
| `resizing(shape, { corner, width, height })` | Said when S starts resizing `shape` from `corner`, its bottom-right corner, with its size in whole units. When Enter, Escape or any other end that says nothing of its own ends the resize, the board says the shape again through `shape`. A pointer press ends it without saying anything, so the board says only what the press itself does. |
| `resize({ corner, width, height })` | Said when Tab or Shift+Tab moves a resize to another corner, and when an arrow key moves the corner, with the box's size in whole units. |
| `picking(shape, { count, position, selected, total })` | Said when Space starts picking, with `shape` under the cursor. `selected` says whether that shape is selected, `count` how many shapes are selected, and `position` and `total` give the shape's place in stored order among all shapes. When Enter, Escape or any other end that says nothing of its own ends picking, the board says the selection again through `shape` or `shapes`. A pointer press ends it without saying anything, so the board says only what the press itself does. |
| `pick(shape, { count, position, selected, total })` | Said when Tab, Shift+Tab or Mod with an arrow moves the cursor to `shape`, again when Mod with an arrow finds no shape that way, and when Space adds the cursor's shape to the selection or takes it out, with the same state as `picking`. |
| `shape(shape, { position, total })` | Said when the selection becomes one shape, with its place in stored order, such as `Ship it, Shape. 3 of 5`. |
| `shapes(count)` | Said when the selection becomes several shapes, and with 0 when the board says the selection again while no shape is selected, such as after Mod with an arrow on a board with no shapes. |
| `tool(tool)` | Said when a letter or the toolbar picks a tool. |
| `toolLock(locked)` | Said when Q or `setToolLocked` turns the tool lock on or off, with whether it is now on. |
| `zoom(percent)` | Said when a zoom key, `zoomIn`, `zoomOut`, `resetZoom` or `fit` changes the zoom. A wheel zoom says nothing. |
| `removed(count)` | Said when a removal lands, with the number of shapes it took off the board, a removed frame's shapes included. |

`shape`, `aim`, `connecting`, `starting`, `resizing`, `picking` and `pick` get a `BoardShapeDescription`. Its `kind` is `note`, `geo`, `arrow`, `frame`, `stroke`, or `shape` for an image shape or a shape your app defines, and its `text` is the shape's text or a frame's name. An arrow's `ends` describe the shapes its ends attach to, or `null` for a free end. A resize's `corner` is a `BoardCorner`, one of `topLeft`, `topRight`, `bottomRight` and `bottomLeft`, and `picking` and `pick` also get a `BoardPickState`. The copied board passes:

```tsx
const boardMessages: BoardMessages = {
  label: 'Board',
  instructions:
    'Enter selects the first shape. Tab moves between shapes and leaves them after the last. Command with an arrow on a Mac, or Control with an arrow elsewhere, picks the nearest shape. With the note, shape or frame tool, Enter places one, and with the arrow tool and one shape selected that is not an arrow, Enter connects it to another, whose end the arrow keys then move. With the arrow tool and nothing selected, Enter starts an arrow whose start the arrow keys move until a second Enter keeps it. With one shape selected that is not an arrow, S resizes it: Tab picks a corner, the arrow keys move it and Enter keeps the new size. Space starts picking shapes: Tab moves, Space adds or removes the shape and Enter keeps the selection. Q keeps the drawing tool picked after each shape until a second Q, and Command+D on a Mac, or Control+D elsewhere, copies the selected shapes. Shift+Enter reaches the toolbar.',
  aim: (shape, { anchor, position, side, total }) =>
    `${side === 'start' ? 'From' : 'To'} ${nameOf(shape)}${anchor.across === 50 && anchor.down === 50 ? '' : `, ${anchor.across}% across, ${anchor.down}% down`}. ${position} of ${total}`,
  connecting: (from) =>
    `Connecting ${from ? nameOf(from) : 'a free point'}. Tab picks a shape, arrow keys move the end, Enter draws the arrow and Escape stops.`,
  free: ({ x, y }, { side }) =>
    `${side === 'start' ? 'Start' : 'End'} free at ${x}, ${y}`,
  starting: ({ x, y }, { from }) =>
    `Drawing an arrow from ${from ? nameOf(from) : `${x}, ${y}`}. Arrow keys move its start, Tab picks a shape, Enter keeps the start and Escape stops.`,
  resizing: (shape, { corner, height, width }) =>
    `Resizing ${nameOf(shape)} from its ${CORNERS[corner]} corner, ${width} by ${height}. Tab picks a corner, arrow keys resize, Enter keeps it and Escape stops.`,
  resize: ({ corner, height, width }) =>
    `${CORNERS[corner]}, ${width} by ${height}`,
  picking: (shape, state) =>
    `Picking shapes. ${pickOf(shape, state)}. Tab moves, Space adds or removes, Enter finishes.`,
  pick: (shape, state) => pickOf(shape, state),
  shape: (shape, { position, total }) =>
    `${nameOf(shape)}. ${position} of ${total}`,
  shapes: (count) =>
    count === 0 ? 'No shapes selected' : `${count} shapes selected`,
  tool: (tool) => TOOL_NAMES[tool],
  toolLock: (locked) => (locked ? 'Tool lock on' : 'Tool lock off'),
  zoom: (percent) => `Zoom ${percent}%`,
  removed: (count) =>
    count === 1 ? 'Shape deleted' : `${count} shapes deleted`,
};
```

## Insert shapes from code

Every board command runs inside `editor.update` with no selection, so a Node agent on the same Yjs document uses the same calls as the toolbar. A board insert returns the board's key, and a shape insert names its board and returns the new shape's id. Shape ids are unique in the whole document, so later commands name a shape by its id alone.

```ts
import {
  BaseBoardArrowPlugin,
  BaseBoardGeoPlugin,
  BaseBoardNotePlugin,
  BaseBoardPlugin,
} from 'platejs/board';

editor.update((tx) => {
  const board = tx.plugin(BaseBoardPlugin).insert({ height: 480 }, { at: [1] });

  if (!board) return;

  const note = tx.plugin(BaseBoardNotePlugin).insert(
    {
      children: [{ children: [{ text: 'Launch' }], type: 'paragraph' }],
      x: 120,
      y: 80,
    },
    { board }
  );
  const rect = tx
    .plugin(BaseBoardGeoPlugin)
    .insert({ geo: 'rectangle', x: 480, y: 80 }, { board });

  if (note && rect) {
    tx.plugin(BaseBoardArrowPlugin).insert({ end: rect, start: note });
  }
});
```

Move, resize, restack and remove shapes by id:

```ts
editor.update((tx) => {
  const boards = tx.plugin(BaseBoardPlugin);

  boards.move([noteId], { x: 40, y: 0 });
  boards.resize(noteId, { height: 240, width: 240, x: 160, y: 80 });
  boards.restack([noteId], 'front');
  boards.remove([rectId]);
});
```

A style change is a plain property write on the shape's key, with a style its shape type takes, as [Value shape](#value-shape) lists:

```ts
editor.update((tx) => {
  const shape = tx.plugin(BaseBoardPlugin).shape(rectId);

  if (shape) {
    tx.nodes.set({ fill: 'blue', strokeWidth: 'l' }, { at: shape.key });
  }
});
```

In a toolbar, `setStyle` writes the selected shapes, as [Style panel](#style-panel) shows.

## Add your own shape

`defineBoardShape` defines a shape that holds text, with its own properties and default size. List it in the board's `targetPlugins`, beside the shape types you keep. The shape then gets its id, place and size, stacking, frames, arrow ends, copy and paste, suggestions and sync from the board.

```tsx
import { property } from 'platejs';
import {
  BaseBoardGeoPlugin,
  BaseBoardNotePlugin,
  BaseBoardPlugin,
  defineBoardShape,
} from 'platejs/board';

const BaseCardPlugin = defineBoardShape('card', {
  properties: { status: property.enum(['todo', 'doing', 'done'], { default: 'todo' }) },
  size: { height: 160, width: 240 },
  styles: { fill: 'blue', opacity: 1, textSize: 'm' },
});

const plugins = [
  BaseBoardPlugin.configure({
    targetPlugins: [BaseBoardNotePlugin, BaseBoardGeoPlugin, BaseCardPlugin],
  }),
  BaseBoardNotePlugin,
  BaseBoardGeoPlugin,
  BaseCardPlugin,
];
```

`tx.plugin(BaseCardPlugin).insert({ status: 'doing', x: 0, y: 0 }, { board })` adds a card. HTML serialize refuses a board that holds your own shape, so persist the Plate value for such a board.

## Value shape

A board block sits in its document like any other block and holds one empty text. Its shapes sit in the content root that `childRoots.shapes` names, as that root's top-level blocks. The board's `insert` creates the block and its root in one change and names the root, so app code never names a root.

```ts
const value = {
  children: [
    {
      childRoots: { shapes: 'board:k3f9' },
      children: [{ text: '' }],
      height: 480,
      type: 'board',
    },
  ],
  roots: {
    'board:k3f9': [
      {
        children: [{ children: [{ text: 'Launch' }], type: 'paragraph' }],
        place: { x: 40, y: 30 },
        shapeId: 'n1',
        size: { height: 160, width: 200 },
        type: 'boardNote',
        zIndex: 'a1',
      },
    ],
  },
};
```

| Property | Shapes | Notes |
| --- | --- | --- |
| `shapeId` | All | Unique in the whole document. Every paste, drop and duplicate gives its copy a fresh id. |
| `zIndex` | All | A fractional key that sets the paint order. Frames paint behind the other shapes. |
| `place` | All but arrows | `{ x, y }`. Inside a frame it also holds `frame` and `frameOrigin`, and `x` and `y` are measured from the frame. A frame's own `place` holds its `origin`. |
| `size` | All but arrows | `{ width, height }`. |
| `start`, `end` | Arrows | `{ shape, anchor, x, y }` for an end bound to a shape, or `{ x, y }` for a free end. `x` and `y` hold the point the end last drew at. |
| `points` | Pen lines | Flat `[x, y, pressure]` triples, each a fraction of the line's box. |
| `fill` | Notes and geo shapes | `'none'`, a color name or any CSS color. Defaults to `'yellow'` on a note and `'none'` on a geo shape. |
| `strokeColor` | Geo shapes, arrows and pen lines | A color name or any CSS color. Defaults to `'currentColor'`, the text color. |
| `dash` | Geo shapes and arrows | `'solid'`, `'dashed'` or `'dotted'`. Defaults to `'solid'`. |
| `strokeWidth` | Geo shapes and arrows | `'s'`, `'m'`, `'l'` or `'xl'`. Defaults to `'m'`. |
| `opacity` | All but frames and image shapes | A number from 0.1 to 1. Defaults to 1. |
| `textSize` | Notes, geo shapes and arrows | `'s'`, `'m'`, `'l'` or `'xl'`. Defaults to `'m'`, or `'s'` on an arrow. |
| `geo` | Geo shapes | One of `'rectangle'`, `'ellipse'`, `'diamond'` or `'triangle'`. |
| `name` | Frames | Shown above the frame. |
| `children` | Image shapes | At most one `image` element, whose `url` and `alt` `ImagePlugin` keeps, or an upload draft when the editor installs `UploadPlugin`. |

The copied board paints the color names `blue`, `green`, `grey`, `orange`, `red`, `violet` and `yellow` with a light and a dark value, and any other string as a CSS color. HTML keeps each style in a `data-board-` attribute, such as `data-board-stroke-width`.

The camera, the tool, the tool lock, the next style, the selection handles and a gesture in progress are never stored.

## Collaboration

Each shape is a block of the document, so `YjsPlugin` syncs boards with no extra setup. When two people change different properties of one shape, such as a move and a recolor, both changes stay. A drag reaches teammates as one change when it is dropped.

### Add the board to an app with Yjs rooms

Adding the board adds element types, so it changes the app's schema identity. A Yjs room keeps the schema identity it was created with, so an editor with the board refuses to join a room written before it. It throws a `Yjs schema mismatch` error, or `Yjs derived schema mismatch` when the app declares no `schema`. Move each room's document to a new room:

<Steps>

### Bump the schema version

Add a migration step for the new version. A step that only adds element types returns the document unchanged. Register the version 3 fingerprint in `sourceFingerprints` from the migration scaffold, as [document migrations](/docs/editor#document-migrations) shows.

```ts title="src/editor.ts"
import { defineDocumentMigrations } from 'platejs/migrations';

import { BoardKit } from '@/components/editor/board';
import { EditorKit } from '@/components/editor/plugins';

import { fingerprint as v3Fingerprint } from './migrations/v4-add-board/from';

export const EditorPlugins = [...EditorKit, ...BoardKit];

export const EditorSchema = { id: 'acme-document', version: 4 } as const;

export const EditorMigrations = defineDocumentMigrations({
  plugins: EditorPlugins,
  schema: EditorSchema,
  sourceFingerprints: { 3: v3Fingerprint },
  steps: { 4: ({ document }) => ({ document }) },
});
```

### Migrate the old room's document

Read the document and its schema identity from an editor bound to the old room, with the old plugins and schema, then migrate it.

```ts
import { migrateDocument } from 'platejs/migrations';

const current = migrateDocument(
  {
    document: oldEditor.read.value(),
    schema: oldEditor.read.schema.identity(),
  },
  { migrations: EditorMigrations }
).output;
```

### Seed a new room

Create the new room's editor from the migrated document. Give `seed: true` to one editor only, the one your app picked to fill the new empty room.

```tsx
import { createEditor } from 'platejs/react';
import { YjsPlugin } from 'platejs/yjs/react';

const editor = createEditor({
  initialValue: current,
  plugins: [
    ...EditorPlugins,
    YjsPlugin.create({
      doc: newRoomDocument,
      initialReady: true,
      rootName: newRoomId,
      seed: true,
    }),
  ],
  schema: EditorSchema,
});
```

</Steps>

Every other peer joins the new room with the new plugins and schema, and without `seed`. See [Yjs](/docs/yjs) and [document migrations](/docs/editor#document-migrations).

## Limits

- Find searches only the page, not the text of notes. Word export leaves out a comment on note text and reports a `comment-range` warning.
- Over note text, the copied toolbars' mark, color, highlight and comment buttons and the AI menu act on the note, as [Toolbar](/docs/toolbar#act-on-the-view-that-holds-the-selection) describes. Other buttons, such as Insert, Turn into, lists and links, act on the page.
- Moving a paragraph inside a note is refused. Moving the whole shape keeps its text.
- Undo of a move puts back your old place, even over a teammate's later move of the same shape.
- A long note gets slower, because a note's lines sync as one unit.
- Each keystroke does some work for every board in the document, so keep a document to 100 boards or fewer.
- Markdown keeps the text and pictures of the shapes in stored order and reports what it drops, such as places and arrow ends. Persist the Plate value, or HTML when the board holds only built-in shape types, to keep a board whole.
- A picture file pasted or dropped on a board does not become an image shape. Paste the picture's link, or insert it from code.
- A shape property named after a style mark's key, such as `color`, `backgroundColor`, `fontSize` or `fontFamily`, also styles the shape's text while that mark's plugin is installed. Give the property another name, the way the note uses `fill`.
- A board inside a note, rotation and cropping a picture are not supported, and the copied board draws no caption under a picture.
- Drawing with the pen needs a pointer. A keyboard resize keeps the proportions of an image shape only, and cannot resize around the center, which Shift and Alt do on a corner drag.
- No key or pointer gesture moves a bound arrow end off its shape, or resizes several shapes at once. Moving a selected arrow moves its free ends, and each bound end stays on its shape.
- On a board page, the board is still a block of the document. Delete or Backspace with the board selected removes it with its shapes, and Undo brings it back. With [exit break](/docs/exit-break) installed, Mod+Enter with the caret on the board, where Mod+A can put it, adds a paragraph after the board, out of sight.

## Plugins

### `BoardPlugin`

The board block, a void element that owns a content root of shapes. `targetPlugins` lists the shape types the board holds, by default the six below.

### `BoardNotePlugin`, `BoardGeoPlugin`, `BoardArrowPlugin`, `BoardFramePlugin`, `BoardStrokePlugin`

The shape types: `boardNote`, `boardGeo`, `boardArrow`, `boardFrame` and `boardStroke`. Frames and pen lines are voids; notes, geo shapes and arrows hold blocks.

### `BoardImagePlugin`

The image shape, `boardImage`: an object block that holds at most one `image` element or upload draft. Install `ImagePlugin` with it. An editor that installs it with neither `ImagePlugin` nor `UploadPlugin` throws an error naming both.

| `BaseBoardPlugin`, `BaseBoardNotePlugin`, `BaseBoardGeoPlugin`, `BaseBoardImagePlugin`, `BaseBoardArrowPlugin`, `BaseBoardFramePlugin`, `BaseBoardStrokePlugin` | `platejs/board` | Headless board and shape plugins. |
| `defineBoardShape(name, { properties, size, styles })` | `platejs/board` | Defines an app shape that holds text, with the default of each board style it takes. |

| `tx.plugin(BaseBoardNotePlugin).insert(props, { board })` | Each shape plugin | Adds a shape above every shape of `board` and returns its id. An image shape takes `{ children: [image] }` and is 320 by 240 unless `width` and `height` say otherwise. |
| `move(ids, delta)` | `BaseBoardPlugin` | Moves shapes. A shape joins the frontmost frame under its middle or leaves its frame. |
| `resize(id, { x, y, width, height })` | `BaseBoardPlugin` | Sets a shape's place and size together. On an image shape the height follows `width`. A shrink stops at a short edge of 8, and one whose short edge is already under 8 can only grow. |
| `restack(ids, direction)` | `BaseBoardPlugin` | `'front'`, `'back'`, `'forward'` or `'backward'`, in paint order only. |
| `remove(ids)` | `BaseBoardPlugin` | Removes shapes, each frame with its shapes. An arrow bound to a removed shape keeps a loose end where it drew it. |
| `removeFrame(id)` | `BaseBoardPlugin` | Removes a frame and keeps its shapes where they are. |
| `insertCopy(slice, { board, place? })` | `BaseBoardPlugin` | Pastes a copy of the shapes in `slice` into `board`, with fresh ids, and returns the copies' ids. |
| `shapes(board)`, `shape(id)`, `arrowEnds(id)`, `slice(ids)` | `BaseBoardPlugin` | Read the shapes of a board, one shape by id in any board, where an arrow draws its ends, and the slice a copy of shapes carries. Call them on `tx.plugin(BaseBoardPlugin)`. |
| `BoardSurface`, `BoardShape` | `platejs/board/react` | The board's mounted view and a shape's positioned wrapper, for copied renderers. The surface's required `messages` holds every word the board says, as [Screen readers](#screen-readers) lists. Its `height` sets its view's height and defaults to the board's stored `height`. A shape the eraser will remove shows `data-erasing`, which the copied board fades, and the shape under the picking cursor shows `data-board-cursor`, which the copied board rings. A plain wheel over a toolbar element that can still scroll in the wheel's main direction scrolls that element instead of panning the board. |
| `data-board-dock` | `platejs/board/react` | Marks an element at the top level of the surface's `toolbar` that sits at the board's `"left"` or `"right"` side. Every other top-level toolbar element counts as a row at the board's top or bottom. `fit` and Shift+1 fit the shapes into the room the toolbar leaves clear. Where that room's width or height cannot hold them at 10 percent, they use the board's whole width or height. Both zoom between 10 and 100 percent, so shapes the board cannot hold at 10 percent run past its edges. |
| `BoardMessages`, `BoardShapeDescription`, `BoardCorner`, `BoardPickState` | `platejs/board/react` | The type of `messages`, the shape that `messages.shape` describes, the corner a resize moves, and where picking stands when the board says `picking` or `pick`. |
| `useBoardView(selector)`, `useBoardActions()` | `platejs/board/react` | Inside the surface's `toolbar`, read the view's `tool`, `toolLocked`, `camera` and `nextStyle`, its board's selected shapes as `selectedShapes`, each style a pick would set as `styles`, and whether it can write as `writable`. A camera `zoom` of 1 is 100 percent. Call `setTool`, `setToolLocked`, `setStyle`, `fit`, `zoomIn`, `zoomOut`, `resetZoom`, `removeFrame` and `focus`. From any zoom, `zoomIn` and `zoomOut` go to the next step the `=` or `+` and `-` keys use, and stop at 800 and 10 percent. `resetZoom` zooms to 100 percent, as Shift+0 does. All three work in a read-only view too. `toolLocked` says whether the note, shape, frame and arrow tools stay picked after they add a shape. It is off when the view mounts and is never stored, and `setToolLocked` turns it on or off, as Q does, without changing the tool or the selection. `focus` moves focus back to the board and keeps its selection, such as after a toolbar menu closes. A shape whose text is being edited ends its edit and stays selected. `setStyle` merges into the next style. With the select tool it also writes each style to every selected shape that takes it and to the shape whose text is being edited, as one undo step that keeps the caret. With a drawing tool it styles only the next shape. Each entry of `styles` is `{ mixed: false, value }` when its targets share a value and `{ mixed: true }` when they differ, and a style no target takes has no entry. A read-only view's `setStyle` changes nothing. |
| `useArrowPath(element)`, `useStrokePath(element)` | `platejs/board/react` | The drawn path of an arrow or a pen line. |
