## 功能特性

### 媒体支持
- **文件类型**: 
  - 图片
  - 视频
  - 音频
  - 其他 (PDF, Word等)
- **视频平台**: 
  - 本地视频文件
  - YouTube, Vimeo, Dailymotion, Youku, Coub
- **嵌入支持**: 
  - 推特推文

### 媒体功能
- 可编辑的标题说明
- 可调整大小的元素

### 上传功能
- **多种上传方式**:
  - 工具栏按钮文件选择器
  - 从文件系统拖放
  - 从剪贴板粘贴(图片)
  - 外部媒体URL嵌入
- **上传体验**:
  - 实时进度跟踪
  - 上传过程中预览
  - 使用同一个节点身份将草稿位替换为完成的图片、视频、音频或文件
  - 错误处理
  - 文件大小验证
  - 类型验证

</PackageInfo>

## 套件使用

<Steps>

### 安装

最快捷的媒体支持方式是使用 `MediaKit`。它包含预配置的 `ImagePlugin`、
`VideoPlugin`、`AudioPlugin`、`FilePlugin`、`MediaEmbedPlugin`，以及
对应的 [Plate UI](/docs/installation/plate-ui) 组件。需要上传本地文件时，再添加
`UploadKit`，由它负责草稿渲染和上传控件；`MediaKit` 负责已完成的媒体。

<ComponentSource name="media" />
<ComponentSource name="upload" />

- [`ImageElement`](/docs/components/media-image): 渲染图片元素
- [`VideoElement`](/docs/components/media-video): 渲染视频元素
- [`AudioElement`](/docs/components/media-audio): 渲染音频元素
- [`FileElement`](/docs/components/media-file): 渲染文件元素
- [`MediaEmbedElement`](/docs/components/media-embed): 渲染嵌入媒体
- [`UploadElement`](/cn/docs/upload): 渲染 UploadKit 中未绑定、上传中和失败的媒体草稿位
- [`MediaPreviewDialog`](/docs/components/media-preview-dialog): 提供媒体预览功能

### 添加套件

将套件添加到你的插件中:

```tsx
import { createEditor } from 'platejs/react';
import { MediaKit } from '@/components/editor/media';
import { UploadKit } from '@/components/editor/upload';

const editor = createEditor({
  plugins: [
    // ...其他插件
    ...MediaKit,
    ...UploadKit,
  ],
});
```

### 配置上传

安装 Files 网关，并为 `UploadKit` 配置 `FilesClient` 和持久 URL 解析函数。
客户端、路由、访问策略和环境变量见[上传文件](/cn/docs/upload)。

</Steps>

## 手动使用

<Steps>

### 安装

```bash
npm install platejs @tanstack/react-virtual
```

### 添加插件

在创建编辑器时将媒体插件包含到Plate插件数组中。

```tsx
import { AudioPlugin, FilePlugin, ImagePlugin, MediaEmbedPlugin, VideoPlugin } from 'platejs/media/react';
import { createEditor } from 'platejs/react';

const editor = createEditor({
  plugins: [
    // ...其他插件
    ImagePlugin,
    VideoPlugin,
    AudioPlugin,
    FilePlugin,
    MediaEmbedPlugin,
  ],
});
```

### 配置插件

使用自定义渲染组件配置媒体插件。

```tsx
import { AudioPlugin, FilePlugin, ImagePlugin, MediaEmbedPlugin, VideoPlugin } from 'platejs/media/react';
import { createEditor } from 'platejs/react';
import { AudioElement } from '@/components/editor/media-audio';
import { FileElement } from '@/components/editor/media-file';
import { ImageElement } from '@/components/editor/media-image';
import { MediaEmbedElement } from '@/components/editor/media-embed';
import { VideoElement } from '@/components/editor/media-video';

const editor = createEditor({
  plugins: [
    // ...其他插件
    ImagePlugin.configure({ component: ImageElement }),
    VideoPlugin.configure({ component: VideoElement }),
    AudioPlugin.configure({ component: AudioElement }),
    FilePlugin.configure({ component: FileElement }),
    MediaEmbedPlugin.configure({ component: MediaEmbedElement }),
  ],
});
```

- `component`: 为每种媒体类型分配自定义渲染组件

本地文件上传需单独添加 `UploadPlugin`，配置方法见[上传文件](/cn/docs/upload)。

### 标题

每个图片、音频、视频、文件和嵌入都是非 void、隔离且可通过键盘选择的元素。
媒体元素的直接行内 children 就是标题；媒体插件负责 schema 和行为，不需要单独的
标题插件、节点类型或 content root。

只需配置媒体插件及其渲染组件：

```tsx
import { ImagePlugin } from 'platejs/media/react';
import { ImageElement } from '@/components/editor/media-image';

export const MediaKit = [
  ImagePlugin.configure({ component: ImageElement }),
];
```

让资源 DOM 保持不可编辑，并把媒体元素的普通 children slot 渲染为标题：

```tsx
<figure>
  <div contentEditable={false}>{/* 媒体界面 */}</div>
  <figcaption>{props.children}</figcaption>
</figure>
```

通过仅用于构造的 `caption` 字段传入字符串或行内 children：

```tsx
editor.plugin(ImagePlugin).update.insert({
  url: 'https://example.com/image.png',
  caption: 'Plain caption',
});

editor.plugin(ImagePlugin).update.insert({
  url: 'https://example.com/diagram.png',
  caption: [
    { text: 'Rich ' },
    { text: 'caption', bold: true },
  ],
});
```

插入命令会把 `caption` 编译成直接 children。文档中只持久化生成的媒体元素：

```ts
{
  type: 'image',
  url: 'https://example.com/image.png',
  children: [{ text: 'Plain caption' }],
}
```

空文本 child 是标题缺失时的规范状态：

```ts
{
  type: 'image',
  url: 'https://example.com/image.png',
  children: [{ text: '' }],
}
```

渲染组件可以在媒体资源未获得焦点时隐藏空标题。占位符是否可见属于 UI 状态，
不会改变持久化的元素。

资源焦点和标题编辑使用不同的 selection 状态：

| Selection | 行为 |
| --- | --- |
| 媒体路径上的 Plate `NodeSelection` | 聚焦资源，显示选中边框和空标题占位符；`ArrowDown` 进入标题，Delete 删除整个媒体节点。 |
| 媒体 children 内的 Plate `TextSelection` | 编辑标题；光标位于标题开头时，`ArrowUp` 返回资源焦点。 |

### 上传本地文件

[`UploadPlugin`](/cn/docs/upload) 使用 `files-sdk/client` 的 `FilesClient` 上传
本地文件。它验证整个批次、创建带 key 的草稿位，并在文档事务提交后启动请求。
应用通过同步 `getUrl` 将 SDK 上传结果映射为持久的绝对 URL。上传完成后，
已安装的媒体插件会把草稿位变为图片、视频、音频或文件节点。

使用 `editor.plugin(UploadPlugin).update.submit(files)` 提交新批次；
`{ slot: key }` 填充现有草稿；`{ after: key }` 等选项指定块位置。
使用 `editor.plugin(UploadPlugin).api.cancel(key)` 取消单个任务。失败的实时任务
保留本地 `File` 以便显式重试；重新加载的草稿需要重新选择文件。客户端、进度和
网关访问策略见[上传文件](/cn/docs/upload)。

### 添加工具栏按钮

你可以将[`MediaToolbarButton`](/docs/components/media-toolbar-button)添加到[Toolbar](/docs/toolbar)以上传和插入媒体。

### 插入工具栏按钮

你可以将这些项添加到[插入工具栏按钮](/docs/toolbar#insert-toolbar-button)来插入媒体元素:

```tsx
{
  icon: <ImageIcon />,
  label: '图片',
  value: PLUGINS.image,
}
```

用于非 void、隔离且可通过键盘选择的图片元素。其直接行内 children 存储标题。

  </APIItem>

`UploadPlugin` 处理粘贴的图片文件；`ImagePlugin` 处理图片 URL。

### `VideoPlugin`

用于非 void、隔离且可通过键盘选择的视频元素。其直接行内 children 存储标题。
扩展 `MediaPluginState`。

### `AudioPlugin`

用于非 void、隔离且可通过键盘选择的音频元素。其直接行内 children 存储标题。
扩展 `MediaPluginState`。

### `FilePlugin`

用于非 void、隔离且可通过键盘选择的文件元素。其直接行内 children 存储标题。
扩展 `MediaPluginState`。

### `MediaEmbedPlugin`

用于非 void、隔离且可通过键盘选择的媒体嵌入元素。其直接行内 children 存储标题。
扩展 `MediaPluginState`。

### `UploadPlugin`

管理持久化媒体草稿位和编辑器上传任务。`platejs/upload` 中的
`BaseUploadPlugin` 拥有无 React 的相同状态机；React 插件增加可选的原生 DOM 拖放适配器。

<API name="UploadPlugin">
<APIOptions type="UploadPluginState">
  <APIItem name="client" type="FilesClient | null">
    由 `files-sdk/client` 的 `createFilesClient` 创建。**默认：** `null`。
  </APIItem>
  <APIItem name="getUrl" type="((file: UploadOutcome) => string) | null">
    同步地将 SDK 上传结果映射为持久的绝对 URL。**默认：** `null`。
  </APIItem>
  <APIItem name="rules" type="UploadRules">
    将 `audio | blob | image | pdf | text | video` 映射到必需的草稿 `kind`，
    以及可选的 `minFiles`、`maxFiles`、`maxBytes`。
  </APIItem>
  <APIItem name="maxFiles" type="number">
    一个提交批次的最大文件数。**默认：** `Number.POSITIVE_INFINITY`。
  </APIItem>
  <APIItem name="onError" type="((failure: UploadFailure) => void) | null">
    每个被拒批次或失败任务只通知一次。**默认：** `null`。
  </APIItem>
</APIOptions>
</API>

React 版 `UploadPlugin` 还接受 `nativeDrop: boolean`（默认 `false`）。
由 `DndPlugin` 指定文件位置时保持关闭。

## API

### 上传任务

| 操作 | 契约 |
| --- | --- |
| `editor.plugin(UploadPlugin).update.submit(files, options)` | 验证并插入整个批次，提交后启动 SDK 请求。 |
| `editor.plugin(UploadPlugin).api.cancel(key)` | 中止该实时草稿 key 拥有的任务。 |
| `editor.plugin(UploadPlugin).store.get('task', key)` | 返回 `UploadTask` 或 `undefined`；通过 `file`、`getSnapshot` 和 `subscribe` 构建进度与重试 UI。 |

只要 `NodeKey`、草稿类型和 `kind` 仍然有效，任务就保留权限。移动草稿不会取消任务；
删除、改类型、改 `kind`、替换整个文档、重试或清理插件会取消任务。只读模式会阻止新提交，
但不会取消已经提交的请求。

`UploadFailure` 区分接收、配置、上传和 URL 结果错误。上传错误保留 SDK 的
`unknown` 错误；无效的 URL 或抛错的 `getUrl` 属于结果错误。任务快照直接使用
SDK 的 `AggregateProgress`（`loaded`、`total`、`fraction`），不是百分比数值。

### `api.insertUrl`

选定的媒体插件会在应用解析 URL 输入期间保留插入目标。图片、媒体嵌入、音频、视频和文件插件均提供此 API。
该操作调用已安装的 `update.insert`，包括 URL 验证和应用覆盖逻辑。
取消输入、URL 无效或目标已删除时返回 `false`；URL 解析 Promise 的错误会传递给调用方。

```tsx
const inserted = await editor.plugin(BaseImagePlugin).api.insertUrl(
  getUrlFromDialog,
  { caption: 'An optional caption', select: true }
);
```

`getUrlFromDialog` 由应用提供，返回 URL、`null` 或相应的 Promise。
选项支持插入位置 `at`、来源区块 `after`、`replaceEmpty`、`caption` 和 `select`。
设置 `replaceEmpty: true` 时，仅在 URL 解析完成后来源区块仍为空时替换它。
区块移动或期间的文本编辑不会改变目标身份或丢失内容。应用负责 URL 对话框并选择媒体插件。

## 类型

### 媒体元素类型

```tsx
import type { AudioElement, FileElement, ImageElement, MediaEmbedElement, VideoElement } from 'platejs/media';
```

每个别名都从其所属插件的 schema 派生。`Element.children` 存储标题的直接行内内容。标题缺失时使用
`[{ text: '' }]`。

### `UploadElement`

```tsx
import type { UploadElement } from 'platejs/upload';
```

`UploadElement` 从 `BaseUploadPlugin` 派生，并且需要严格的
`kind`：`'audio' | 'file' | 'image' | 'video'`。

### `EmbedUrlData`

```tsx
export interface EmbedUrlData {
  id?: string;
  provider?: string;
  sourceKind?: 'allowlisted_snippet' | 'iframe' | 'url';
  sourceUrl?: string;
  url?: string;
}
```
