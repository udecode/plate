## 功能特性

### 媒体支持
- **文件类型**: 
  - 图片
  - 视频
  - 音频
  - 其他 (PDF, Word等)
- **视频平台**: 
  - 本地视频文件
  - YouTube, Vimeo, Dailymotion, Youku, Coub
- **嵌入支持**: 
  - 推特推文

### 媒体功能
- 可编辑的标题说明
- 可调整大小的元素

### 上传功能
- **多种上传方式**:
  - 工具栏按钮文件选择器
  - 从文件系统拖放
  - 从剪贴板粘贴(图片)
  - 外部媒体URL嵌入
- **上传体验**:
  - 实时进度跟踪
  - 上传过程中预览
  - 上传或嵌入完成后自动将占位符转换为相应的媒体元素(图片/视频/音频/文件)
  - 错误处理
  - 文件大小验证
  - 类型验证

## 手动使用

<Steps>

### 安装

```bash
npm install platejs @tanstack/react-virtual
```

### 添加插件

在创建编辑器时将媒体插件包含到Plate插件数组中。

```tsx
import { AudioPlugin, FilePlugin, ImagePlugin, MediaEmbedPlugin, PlaceholderPlugin, VideoPlugin } from 'platejs/media/react';
import { createEditor } from 'platejs/react';

const editor = createEditor({
  plugins: [
    // ...其他插件
    ImagePlugin,
    VideoPlugin,
    AudioPlugin,
    FilePlugin,
    MediaEmbedPlugin,
    PlaceholderPlugin,
  ],
});
```

### 配置插件

使用自定义组件和上传设置配置插件。

```tsx
import { AudioPlugin, FilePlugin, ImagePlugin, MediaEmbedPlugin, PlaceholderPlugin, VideoPlugin } from 'platejs/media/react';
import { createEditor } from 'platejs/react';
import { AudioElement } from '@/components/editor/media-audio';
import { FileElement } from '@/components/editor/media-file';
import { ImageElement } from '@/components/editor/media-image';
import { MediaEmbedElement } from '@/components/editor/media-embed';
import { PlaceholderElement } from '@/components/editor/media-placeholder';
import { VideoElement } from '@/components/editor/media-video';
import { MediaUploadToast } from '@/components/editor/media';

const editor = createEditor({
  plugins: [
    // ...其他插件
    ImagePlugin.configure({ component: ImageElement }),
    VideoPlugin.configure({ component: VideoElement }),
    AudioPlugin.configure({ component: AudioElement }),
    FilePlugin.configure({ component: FileElement }),
    MediaEmbedPlugin.configure({ component: MediaEmbedElement }),
    PlaceholderPlugin.configure({
      component: PlaceholderElement,
      initialState: { disableEmptyPlaceholder: true },
      slots: { afterEditable: MediaUploadToast },
    }),
  ],
});
```

- `component`: 为每种媒体类型分配自定义渲染组件
- `initialState.disableEmptyPlaceholder`: 插入上传占位符时创建独立的撤销批次
- `slots.afterEditable`: 在编辑器外部渲染上传进度提示

### 标题

每个图片、音频、视频、文件和嵌入都是非 void、隔离且可通过键盘选择的元素。
媒体元素的直接行内 children 就是标题；媒体插件负责 schema 和行为，不需要单独的
标题插件、节点类型或 content root。

只需配置媒体插件及其渲染组件：

```tsx
import { ImagePlugin } from 'platejs/media/react';
import { ImageElement } from '@/components/editor/media-image';

export const MediaKit = [
  ImagePlugin.configure({ component: ImageElement }),
];
```

让资源 DOM 保持不可编辑，并把媒体元素的普通 children slot 渲染为标题：

```tsx
<figure>
  <div contentEditable={false}>{/* 媒体界面 */}</div>
  <figcaption>{props.children}</figcaption>
</figure>
```

通过仅用于构造的 `caption` 字段传入字符串或行内 children：

```tsx
editor.plugin(ImagePlugin).update.insert({
  url: 'https://example.com/image.png',
  caption: 'Plain caption',
});

editor.plugin(ImagePlugin).update.insert({
  url: 'https://example.com/diagram.png',
  caption: [
    { text: 'Rich ' },
    { text: 'caption', bold: true },
  ],
});
```

插入命令会把 `caption` 编译成直接 children。文档中只持久化生成的媒体元素：

```ts
{
  type: 'image',
  url: 'https://example.com/image.png',
  children: [{ text: 'Plain caption' }],
}
```

空文本 child 是标题缺失时的规范状态：

```ts
{
  type: 'image',
  url: 'https://example.com/image.png',
  children: [{ text: '' }],
}
```

渲染组件可以在媒体资源未获得焦点时隐藏空标题。占位符是否可见属于 UI 状态，
不会改变持久化的元素。

资源焦点和标题编辑使用不同的 selection 状态：

| Selection | 行为 |
| --- | --- |
| 媒体路径上的 Plite `NodeSelection` | 聚焦资源，显示选中边框和空标题占位符；`ArrowDown` 进入标题，Delete 删除整个媒体节点。 |
| 媒体 children 内的 Plite `TextSelection` | 编辑标题；光标位于标题开头时，`ArrowUp` 返回资源焦点。 |

### 自定义上传实现

通过 `initialState.upload` 配置上传函数。占位符插件负责取消、进度和替换原始
节点。你的接口接收文件并返回公开的 `url`。

```ts
import { PlaceholderPlugin } from 'platejs/media/react';

PlaceholderPlugin.configure({
  initialState: {
    upload: async (file, { signal, onProgress }) => {
      const body = new FormData();
      body.append('file', file);
      const response = await fetch('/api/upload', {
        body,
        method: 'POST',
        signal,
      });
      if (!response.ok) throw new Error('Upload failed.');
      const result: unknown = await response.json();
      if (
        !result || typeof result !== 'object' ||
        !('url' in result) || typeof result.url !== 'string'
      ) {
        throw new Error('The upload returned no URL.');
      }
      onProgress(100);
      return { name: file.name, url: result.url };
    },
  },
});
```

将 `signal` 传给上传服务，并报告 0 到 100 的进度。返回值可以包含 `name`、
`naturalWidth` 和 `naturalHeight`。图片替换不依赖预览组件的加载事件。
上传失败时保留占位符并提供错误，不会生成替代 URL。未配置上传函数也会产生失败任务。

调用 `editor.plugin(PlaceholderPlugin).api.upload(key, file)` 上传到现有占位符，
使用 `api.cancelUpload(key)` 取消。通过 `editor.key(element)` 获取当前节点的
`NodeKey`。插入文件的上传只在文档事务提交后启动。

复制的 `PlaceholderElement` 已订阅上传任务。自定义 React 组件可以结合
`platejs/react` 的 `usePluginStore` 和 `React.useSyncExternalStore`：

```tsx
const task = usePluginStore(PlaceholderPlugin, 'uploadTask', editor.key(element));
const upload = React.useSyncExternalStore(
  React.useCallback((notify) => task?.subscribe(notify) ?? (() => {}), [task]),
  React.useCallback(() => task?.getSnapshot() ?? null, [task]),
  () => null
);
```

`task.file` 表示本次上传的文件，快照包含 `status`、`progress` 和 `error`。
取消订阅或重新挂载视图不会重新启动上传。无 React 的调用方可以从
`platejs/media` 使用 `BasePlaceholderPlugin` 的相同上传操作；上传与任务类型也从该路径导出。

## API

### 上传任务

| 操作 | 契约 |
| --- | --- |
| `editor.plugin(PlaceholderPlugin).api.upload(key, file)` | 启动当前占位符的上传，替换之前的请求。 |
| `editor.plugin(PlaceholderPlugin).api.cancelUpload(key)` | 中止请求并移除任务，迟到的回调不能替换节点。 |
| `editor.plugin(PlaceholderPlugin).store.get('uploadTask', key)` | 返回 `MediaUpload` 或 `undefined`；通过 `file`、`getSnapshot` 和 `subscribe` 显示进度。 |

`key` 是运行时的 `NodeKey`，不是持久化元素 ID 或路径。上传完成后只替换原始占位符。
节点被删除、媒体类型发生变化或编辑器变为只读时，迟到的结果不会写入文档。
失败任务保留到取消、重试或删除占位符为止。

### `api.insertUrl`

选定的媒体插件会在应用解析 URL 输入期间保留插入目标。图片、媒体嵌入、音频、视频和文件插件均提供此 API。
该操作调用已安装的 `update.insert`，包括 URL 验证和应用覆盖逻辑。
取消输入、URL 无效或目标已删除时返回 `false`；URL 解析 Promise 的错误会传递给调用方。

```tsx
const inserted = await editor.plugin(BaseImagePlugin).api.insertUrl(
  getUrlFromDialog,
  { caption: 'An optional caption', select: true }
);
```

`getUrlFromDialog` 由应用提供，返回 URL、`null` 或相应的 Promise。
选项支持插入位置 `at`、来源区块 `after`、`replaceEmpty`、`caption` 和 `select`。
设置 `replaceEmpty: true` 时，仅在 URL 解析完成后来源区块仍为空时替换它。
区块移动或期间的文本编辑不会改变目标身份或丢失内容。应用负责 URL 对话框并选择媒体插件。

## 类型

### 媒体元素类型

```tsx
import type { AudioElement, FileElement, ImageElement, MediaEmbedElement, VideoElement } from 'platejs/media';
```

每个别名都从其所属插件的 schema 派生。`Element.children` 存储标题的直接行内内容。标题缺失时使用
`[{ text: '' }]`。

### `PlaceholderElement`

```tsx
import type { PlaceholderElement } from 'platejs/media';
```

`PlaceholderElement` 从 `BasePlaceholderPlugin` 派生，并且需要字符串
`mediaType`。

### `EmbedUrlData`

```tsx
export interface EmbedUrlData {
  id?: string;
  provider?: string;
  sourceKind?: 'allowlisted_snippet' | 'iframe' | 'url';
  sourceUrl?: string;
  url?: string;
}
```
