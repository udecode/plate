## 功能特性

- 代码块的语法高亮显示
- 支持多种编程语言
- 可自定义语言选择
- 正确处理缩进
- 通过 `CodeBlockRules.markdown({ on })` 支持 Markdown 代码围栏快捷输入
- 代码块内输入的快捷语法保持原样，Markdown 也不会转换粘贴的纯文本

</PackageInfo>

## 套件使用

<Steps>

### 安装

最快捷添加代码块功能的方式是使用 `CodeBlockKit`。它组合了 `CodeBlockPlugin` 和可移除的 `CodeHighlightPlugin`，并带上三反引号 input rule 和 [Plate UI](/docs/installation/plate-ui) 组件。

<ComponentSource name="code-block" />

- [`CodeBlockElement`](/docs/components/code-block): 渲染代码块容器

### 添加套件

将套件添加到你的插件中：

```tsx
import { createEditor } from 'platejs/react';
import { CodeBlockKit } from '@/components/editor/code-block';

const editor = createEditor({
  plugins: [
    // ...其他插件,
    ...CodeBlockKit,
  ],
});
```

</Steps>

## 大型代码块

`CodeBlockKit` 将代码保留在原生编辑器 DOM 中。当单个代码块的文本或语法标记使 DOM 变得昂贵时，请显式使用 `CodeBlockCodeMirrorElement`。Plate 仍然拥有规范文本、选择、历史记录、装饰和协作状态；CodeMirror 只拥有代码块挂载后的 DOM 和输入界面。

## 图表 [#diagrams]

图表语言的代码块可以在源码下方绘制图片。

<ComponentPreview name="code-block-diagram-demo" />

添加图表包装组件，并为每个要绘制的引擎添加一个渲染器条目：

```bash
npx shadcn@latest add @plate/code-block-diagram @plate/code-block-diagram-mermaid @plate/code-block-diagram-graphviz
```

<ComponentSource name="code-block-diagram" />

| 条目 | 渲染器 | 语言 | 依赖包 |
| --- | --- | --- | --- |
| `code-block-diagram-mermaid` | `mermaidRenderer` | `mermaid` | `pele` |
| `code-block-diagram-graphviz` | `graphvizRenderer` | `graphviz`、`dot` | `viz.js`、`@types/viz.js` |
| `code-block-diagram-flowchart` | `flowchartRenderer` | `flowchart` | `flowchart.js` |
| `code-block-diagram-plantuml` | `createPlantUmlRenderer({ server })` | `plantuml`、`puml` | `plantuml-encoder`、`@types/plantuml-encoder` |

包装代码块组件，并替换套件中的代码块插件：

```tsx title="components/editor/diagram-editor-kit.tsx"
import { CodeBlockPlugin } from 'platejs/react';

import {
  CodeBlockElement,
  createCodeBlockPlugin,
} from '@/components/editor/code-block';
import { withDiagrams } from '@/components/editor/code-block-diagram';
import { graphvizRenderer } from '@/components/editor/code-block-diagram-graphviz';
import { mermaidRenderer } from '@/components/editor/code-block-diagram-mermaid';
import { EditorKit } from '@/components/editor/plugins';

const diagramCodeBlockPlugin = createCodeBlockPlugin(
  withDiagrams(CodeBlockElement, {
    renderers: [mermaidRenderer, graphvizRenderer],
  })
);

export const DiagramEditorKit = EditorKit.map((plugin) =>
  plugin.name === CodeBlockPlugin.name ? diagramCodeBlockPlugin : plugin
);
```

`withDiagrams` 也能以同样方式包装 `CodeBlockCodeMirrorElement`。每个渲染器都会把自己的
标签加入语言选择器；两个渲染器声明同一种语言时，`withDiagrams` 会抛出错误。Mermaid
渲染器使用 [Pele](https://pele.run/) 绘制：它读取 Mermaid 语法，并按自己的方式布局和
配色。它绘制 Mermaid 内置的图表类型，不支持 ZenUML 等外部类型。无论通过
`mermaid.initialize` 还是 `%%{init}%%` 指令设置，Mermaid 主题都不会生效。

### PlantUML 服务器

PlantUML 通过你的应用运行的服务器绘制。渲染器只把每个代码块的源码发送到该服务器，
请求地址为 `<server>/svg/<encoded source>`，遇到重定向时直接失败而不跟随。

```tsx
import { createPlantUmlRenderer } from '@/components/editor/code-block-diagram-plantuml';

const plantUmlRenderer = createPlantUmlRenderer({
  server: 'https://plantuml.example.com',
});
```

### 视图

图表代码块的工具栏在 Code 和 Both 之间切换：Code 只显示源码，Both 在源码下方显示图片。
可编辑和只读编辑器中默认都是 Both。视图保存在组件中，文档只存储代码块的文本和语言。
Export PNG 会把已绘制的图片保存为 `diagram.png`。

代码块接近视口且浏览器空闲时才开始绘制。每个代码块同时只运行一次渲染，只有最新的源码
会等待下一次渲染。

- 图片是渲染器输出的 SVG 图像，以语言作为替代文本。Export PNG 按 SVG 声明的尺寸绘制；
  SVG 未声明尺寸时，采用浏览器的默认尺寸。
- Mermaid 图片不绘制背景，因此在深色主题下，它的深色线条直接显示在页面上。
- 渲染失败时，错误显示在源码下方；不是 SVG 的输出也显示为错误。
- 没有渲染器声明的语言仍是普通代码块。
- 图表代码块与其他块一样删除。

### 插入菜单

共享的插入菜单和斜杠菜单没有 Diagram 条目，因为默认编辑器套件不安装任何渲染器。绘制
图表的应用在自己的插入菜单副本中添加一个条目：

```tsx
import { BaseCodeBlockPlugin } from 'platejs';

const insertItem = {
  icon: <WorkflowIcon />,
  label: 'Diagram',
  value: 'diagram',
  onSelect: () => {
    const codeBlock = editor.plugin(BaseCodeBlockPlugin);

    if (!codeBlock.installed || editor.read.view.isReadOnly()) return;

    codeBlock.update.insert({ language: 'mermaid' }, { select: true });
  },
};
```

### 静态与导出输出

静态渲染和 Markdown 导出不绘制图片。图表代码块的源码保持为普通代码块，Markdown 将其
写为带语言的代码围栏，例如 `mermaid`。

## 手动使用

<Steps>

### 安装

```bash
npm install platejs lowlight
```

### 添加插件

加入 `CodeBlockPlugin` 即可获得代码块编辑行为；需要 Lowlight 语法高亮时，再单独加入 `CodeHighlightPlugin`。

```tsx
import { CodeBlockPlugin } from 'platejs/react';
import { createEditor } from 'platejs/react';

const editor = createEditor({
  plugins: [
    // ...其他插件,
    CodeBlockPlugin,
  ],
});
```

### 配置插件

在各自的能力所有者上配置：`CodeBlockPlugin` 负责多行文本和编辑行为，`CodeHighlightPlugin` 负责高亮。

**包含所有语言的基础设置：**

```tsx
import { CodeBlockRules } from 'platejs';
import { CodeBlockPlugin, CodeHighlightPlugin } from 'platejs/react';
import { createEditor } from 'platejs/react';
import { CodeBlockElement } from '@/components/editor/code-block';
import { createCodeBlockLowlight } from '@/components/editor/code-block-lowlight';

const lowlight = createCodeBlockLowlight();

const editor = createEditor({
  plugins: [
    // ...其他插件,
    CodeBlockPlugin.configure({
      component: CodeBlockElement,
      inputRules: [CodeBlockRules.markdown({ on: 'match' })],
      shortcuts: { toggle: { keys: 'mod+alt+8' } },
    }),
    CodeHighlightPlugin.configure({
      initialState: { lowlight },
    }),
  ],
});
```

**自定义语言设置（优化包体积）：**

为了优化包体积，你可以只注册特定语言：

```tsx
import { createLowlight } from 'lowlight';
import css from 'highlight.js/lib/languages/css';
import js from 'highlight.js/lib/languages/javascript';
import ts from 'highlight.js/lib/languages/typescript';
import html from 'highlight.js/lib/languages/xml';

// 创建 lowlight 实例
const lowlight = createLowlight();

// 只注册需要的语言
lowlight.register('html', html);
lowlight.register('css', css);
lowlight.register('js', js);
lowlight.register('ts', ts);

const editor = createEditor({
  plugins: [
    // ...其他插件,
    CodeBlockPlugin.configure({
      component: CodeBlockElement,
      inputRules: [CodeBlockRules.markdown({ on: 'match' })],
      shortcuts: { toggle: { keys: 'mod+alt+8' } },
    }),
    CodeHighlightPlugin.configure({
      initialState: {
        lowlight,
        defaultLanguage: 'js', // 设置默认语言（可选）
      },
    }),
  ],
});
```

- `CodeBlockPlugin.configure({ component })`：使用
  [`CodeBlockElement`](/docs/components/code-block) 渲染代码块容器
- `inputRules`：注册三反引号围栏规则。`on: 'match'` 表示围栏完成时立即提交，`on: 'break'` 表示围栏完成后按 `Enter` 再提交。
- `CodeHighlightPlugin.initialState.lowlight`：用于语法高亮的 lowlight 实例。插件只读取传入的实例，不会修改语言注册表。复制组件提供的 `createCodeBlockLowlight()` 会预先注册兼容浏览器的 Python 语法及 `py`、`gyp`、`ipython` 别名。
- `CodeHighlightPlugin.initialState.defaultLanguage`: 未指定语言时使用的默认语言
- `shortcuts.toggle`: 定义切换代码块的键盘[快捷键](/docs/plugin-shortcuts)

每个 `codeBlock` 只包含一个文本子节点。换行符定义物理行；编辑和高亮行为由文本偏移量推导。

代码块内不会运行任何[输入规则](/docs/plugin-input-rules#where-rules-run)，因此 `# `、`**x**`、`->` 和 URL 都按输入原样保留。Markdown 和输入规则都不会转换粘贴的纯文本。

需要纯文本代码块时，省略 `CodeHighlightPlugin`：

```tsx
import { CodeBlockPlugin } from 'platejs/react';
import { createEditor } from 'platejs/react';

const editor = createEditor({
  plugins: [CodeBlockPlugin],
});
```

完整运行时模型请参阅 [Plugin Input Rules](/docs/plugin-input-rules)。

### 转换为工具栏按钮

添加一个直接调用`BaseCodeBlockPlugin`的结构化操作。只有连续的同级选择具有一致的激活状态时才启用它。

```tsx
import { BaseCodeBlockPlugin, PLUGINS } from 'platejs';

const turnIntoItem = {
  icon: <FileCodeIcon />,
  label: '代码',
  value: PLUGINS.codeBlock,
  onSelect: () => {
    const codeBlock = editor.plugin(BaseCodeBlockPlugin);

    if (!codeBlock.installed || editor.read.view.isReadOnly()) return;

    codeBlock.update.toggle();
  },
};
```

### 插入工具栏按钮

添加一个回调直接调用已安装代码块功能的菜单项：

```tsx
import { BaseCodeBlockPlugin, PLUGINS } from 'platejs';

const insertItem = {
  icon: <FileCodeIcon />,
  label: '代码',
  value: PLUGINS.codeBlock,
  onSelect: () => {
    const codeBlock = editor.plugin(BaseCodeBlockPlugin);

    if (!codeBlock.installed || editor.read.view.isReadOnly()) return;

    codeBlock.update.insert({}, { select: true });
  },
};
```

</Steps>

## 插件

### `CodeBlockPlugin`

负责代码块 schema、多行编辑行为、input rule、快捷键和命令。

### `CodeHighlightPlugin`

负责 `codeSyntax` mark、Lowlight decoration 流程和高亮 token 渲染。把这个描述符作为普通插件数组的一项加入或省略。

<API name="CodeHighlightPlugin">
<APIOptions>
  <APIItem name="defaultLanguage" type="string | null" optional>
    未指定语言时使用的默认语言。设为 null 可默认禁用语法高亮。
  </APIItem>
  <APIItem name="lowlight" type="ReturnType<typeof createLowlight> | null" optional>
    用于高亮的 lowlight 实例。如果未提供，将禁用语法高亮。
  </APIItem>
</APIOptions>
</API>

## 命令

安装 `CodeBlockPlugin` 后，通过命令组修改代码块：

```tsx
editor.update.codeBlock.insert();
editor.update.codeBlock.toggle();
editor.update.codeBlock.tab();
editor.update.codeBlock.untab();
editor.update.codeBlock.resetBlock();
editor.update.codeBlock.selectAll();
```

- `insert()` 原地转换选中的空块；对于非空或展开选区，在选区末尾块之后插入段落并转换。无选区时不执行操作。
- `toggle()` 在普通块和代码块之间切换，并返回是否修改了文档。在 Details 标题上，它只转换标题，正文保留在代码块之后。选区包含标题和其他块，或者选区位于运行它的编辑器或视图不编辑的命名根中时，返回 `false`。
- `tab()` 与 `untab()` 将选中的物理行缩进或减少两个空格。
- `resetBlock()` 将代码块解包为段落。
- `selectAll()` 选择当前代码块。
