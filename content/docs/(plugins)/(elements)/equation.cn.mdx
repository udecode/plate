## 功能特性

- 支持LaTeX语法编写复杂数学表达式
- 提供行内公式和块级公式两种格式
- 使用KaTeX实时渲染公式
- 便捷的公式编辑和导航功能

编辑弹出框保留本地草稿。按 Enter 或点击 Done 后，以一个撤销批次提交；
按 Escape 或关闭弹出框则丢弃草稿，不写入文档。外部公式更新会替换当前草稿。

</PackageInfo>

## 套件使用

<Steps>

### 安装

最快捷的方式是使用`MathKit`套件，它包含预配置的`EquationPlugin`和`InlineEquationPlugin`、对应的 `$...$` 与 `$$` input rules，以及[Plate UI](/docs/installation/plate-ui)组件。

<ComponentSource name="math" />

- [`EquationElement`](/docs/components/math): 渲染块级公式元素
- [`InlineEquationElement`](/docs/components/math): 渲染行内公式元素

### 添加套件

将套件添加到插件中:

```tsx
import { createEditor } from 'platejs/react';
import { MathKit } from '@/components/editor/math';

const editor = createEditor({
  plugins: [
    // ...其他插件,
    ...MathKit,
  ],
});
```

</Steps>

## 分层归属

| 层 | 归属 | 作用 |
|----|------|------|
| `platejs/math` | 包 | 导出基础公式插件族、其 Markdown `math` 与 `inlineMath` 映射，以及 `MathRules`。 |
| `platejs/math/react` | 包 | 导出 React 公式插件描述符。 |
| `math` | Registry | 添加带 input rules 的块级与行内 React 插件，以及可编辑的公式元素。 |
| `math-static` | Registry | 添加用于只读渲染的静态公式元素。 |
| `equation-toolbar-button` | Registry UI | 从工具栏插入行内公式。 |
| `platejs/markdown` | 包 | 当 `MarkdownPlugin` 配置了 `remark-math` 时，运行公式插件的 Markdown 映射。 |
| `platejs/docx/export` | 包 | 将公式导出为 Word 公式。参阅 [DOCX](/docs/docx)。 |

`platejs/math` 和 `platejs/math/react` 不加载 KaTeX。`math` 和 `math-static` 组件以及 `platejs/docx/export` 会导入 `katex`，因此在运行其中任何一个的地方安装 `katex`。

块级公式和行内公式共享 `EquationElement` 结构，但它们是不同的节点类型，插件名称也不同。

## 手动配置

<Steps>

### 安装

```bash
npm install platejs katex@0.16.22 lucide-react react-textarea-autosize
```

`math` 和 `math-static` 组件会导入 KaTeX 样式表 `katex/dist/katex.min.css`，以及 `lucide-react` 的图标。`math` 还会导入 `react-textarea-autosize` 作为公式源码输入框。

`math-static` 导入了 KaTeX 样式表，因此只能在能加载 CSS 导入的打包工具中运行。纯 Node 遇到该导入会抛出错误。只转换公式、不渲染公式的 Node 进程使用 `platejs/math` 中的 `BaseEquationPlugin` 和 `BaseInlineEquationPlugin`。

### 添加插件

在创建编辑器时将公式插件包含到Plate插件数组中。

```tsx
import { MathRules } from 'platejs/math';
import { EquationPlugin, InlineEquationPlugin } from 'platejs/math/react';
import { createEditor } from 'platejs/react';

const editor = createEditor({
  plugins: [
    // ...其他插件,
    EquationPlugin,
    InlineEquationPlugin,
  ],
});
```

### 配置插件

使用自定义组件和 input rules 配置插件来渲染公式元素。

```tsx
import { MathRules } from 'platejs/math';
import { EquationPlugin, InlineEquationPlugin } from 'platejs/math/react';
import { createEditor } from 'platejs/react';
import { EquationElement, InlineEquationElement } from '@/components/editor/math';

const editor = createEditor({
  plugins: [
    // ...其他插件,
    InlineEquationPlugin.configure({
      component: InlineEquationElement,
      inputRules: [MathRules.markdown({ variant: '$' })],
    }),
    EquationPlugin.configure({
      component: EquationElement,
      inputRules: [MathRules.markdown({ on: 'break', variant: '$$' })],
    }),
  ],
});
```

- `.configure({ component })`：使用
  [`EquationElement`](/docs/components/math) 渲染块级公式，使用
  [`InlineEquationElement`](/docs/components/math) 渲染行内公式。
- `MathRules.markdown({ variant: '$' })`：启用行内公式 Markdown 快捷输入。
- `MathRules.markdown({ variant: '$$', on: 'break' | 'match' })`：启用块级公式 Markdown 快捷输入，并显式选择提交时机。

完整运行时模型请参阅 [Plugin Input Rules](/docs/plugin-input-rules)。

### 添加工具栏按钮

您可以在[工具栏](/docs/toolbar)中添加[`EquationToolbarButton`](/docs/components/equation-toolbar-button)来插入公式。

</Steps>

## 渲染

Registry 组件使用 KaTeX 渲染公式，并在弹出框中编辑源码。

| 场景 | 行为 |
|------|------|
| 可编辑块级公式 | `math` 使用 display mode 选项调用 `katex.render`。 |
| 可编辑行内公式 | `math` 以 inline mode 调用 `katex.render`，公式与周围文字同样大小。选中行内 void 节点且选区折叠时打开弹出框。 |
| 弹出框输入 | 保留本地草稿。外部公式更新会替换该草稿。 |
| `Enter` 或 Done | 以一个撤销批次提交草稿并关闭输入框。输入法组合中的 Enter 不会提交。 |
| `Escape` 或在外部关闭 | 丢弃草稿，不写入文档。 |
| 行内公式左右边缘的方向键 | 提交草稿，并将选区移出行内公式。 |
| 静态渲染 | `math-static` 以与 `math` 相同的模式调用 `katex.renderToString`。 |

Registry UI 中的 KaTeX 配置为 `throwOnError: false`、`strict: 'warn'` 和 `trust: false`。

## Markdown

Markdown 映射由公式插件负责。`BaseEquationPlugin` 将 `equation` 映射为 `math` 节点，`BaseInlineEquationPlugin` 将 `inlineEquation` 映射为 `inlineMath`。当 `remark-math` 位于 `platejs/markdown` 的 `MarkdownPlugin` 的 remark 插件中时，`MarkdownPlugin` 会运行这些映射；registry 的 `MarkdownKit` 就是这样配置的。

```mdx
Inline $x+1$ math
```

```mdx
$$
x+1
$$
```

行内公式解析为 `inlineEquation`，块级公式解析为 `equation`。序列化时从 `latex` 写回相同的 Markdown 公式结构。

import type { EquationElement } from 'platejs/math';
