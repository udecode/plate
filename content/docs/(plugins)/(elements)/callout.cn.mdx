## 功能特性

- 可自定义的提示框区块，用于突出显示重要信息
- 支持不同类型的提示框变体（如信息、警告、错误）
- 可为提示框设置自定义图标或表情符号

</PackageInfo>

## 套件使用

<Steps>

### 安装

最快添加提示框插件的方式是使用 `CalloutKit`，它包含预配置的 `CalloutPlugin` 和 [Plate UI](/docs/installation/plate-ui) 组件。

<ComponentSource name="callout" />

- [`CalloutElement`](/docs/components/callout): 渲染提示框元素

### 添加套件

将套件添加到你的插件中：

```tsx
import { createEditor } from 'platejs/react';
import { CalloutKit } from '@/components/editor/callout';

const editor = createEditor({
  plugins: [
    // ...其他插件
    ...CalloutKit,
  ],
});
```

</Steps>

## 手动使用

<Steps>

### 安装

```bash
npm install platejs @tanstack/react-virtual
```

### 添加插件

在创建编辑器时，将 `CalloutPlugin` 包含到 Plate 插件数组中。

```tsx
import { CalloutPlugin } from 'platejs/callout/react';
import { createEditor } from 'platejs/react';

const editor = createEditor({
  plugins: [
    // ...其他插件
    CalloutPlugin,
  ],
});
```

### 配置插件

你可以通过自定义组件来配置 `CalloutPlugin` 以渲染提示框元素。

```tsx
import { CalloutPlugin } from 'platejs/callout/react';
import { createEditor } from 'platejs/react';
import { CalloutElement } from '@/components/editor/callout';

const editor = createEditor({
  plugins: [
    // ...其他插件
    CalloutPlugin.configure({ component: CalloutElement }),
  ],
});
```

- `component`: 指定 [`CalloutElement`](/docs/components/callout) 来渲染提示框元素

</Steps>

## 转换器

### `editor.plugin(BaseCalloutPlugin).update.insert`

向编辑器中插入提示框元素。

<API name="editor.plugin(BaseCalloutPlugin).update.insert">
<APIParameters>
<APIItem name="props" type="NodeProps<CalloutElement>" optional>
  <APIItem name="variant" type="string" optional>
    要插入的提示框变体类型
  </APIItem>
  <APIItem name="icon" type="string" optional>
    提示框图标。默认值为 `💡`
  </APIItem>
  <APIItem name="backgroundColor" type="string" optional>
    提示框背景颜色
  </APIItem>
</APIItem>
<APIItem name="options" type="NodeInsertNodesOptions" optional>
  标准节点插入选项，例如 `at` 和 `select`
</APIItem>
</APIParameters>
</API>

## 类型

### `CalloutElement`

```typescript
import type { CalloutElement } from 'platejs/callout';
```

`CalloutElement` 从 `BaseCalloutPlugin` 派生。其 schema 提供可选的
`backgroundColor`、`icon` 和 `variant` 属性。
