## Kit Usage

<Steps>

### Installation

The fastest way to add column functionality is with the `ColumnKit`, which includes pre-configured `ColumnPlugin` and `ColumnItemPlugin` with [Plate UI](/docs/installation/plate-ui) components.

<ComponentSource name="column" />

- [`ColumnGroupElement`](/docs/components/column): Renders column group containers.
- [`ColumnElement`](/docs/components/column): Renders individual column items.

### Add Kit

Add the kit to your plugins:

```tsx
import { createEditor } from 'platejs/react';
import { ColumnKit } from '@/components/editor/column';

const editor = createEditor({
  plugins: [
    // ...otherPlugins,
    ...ColumnKit,
  ],
});
```

</Steps>

## Manual Usage

<Steps>

### Installation

```bash
npm install platejs @tanstack/react-virtual
```

### Add Plugins

Add `ColumnPlugin` to the editor. It installs `ColumnItemPlugin` as the required structural dependency.

```tsx
import { ColumnPlugin } from 'platejs/layout/react';
import { createEditor } from 'platejs/react';

const editor = createEditor({
  plugins: [
    // ...otherPlugins,
    ColumnPlugin,
  ],
});
```

### Configure Plugins

Configure the group and add a complete `ColumnItemPlugin` descriptor when you need to replace the dependency's render component.

```tsx
import { ColumnPlugin, ColumnItemPlugin } from 'platejs/layout/react';
import { createEditor } from 'platejs/react';
import { ColumnGroupElement, ColumnElement } from '@/components/editor/column';

const editor = createEditor({
  plugins: [
    // ...otherPlugins,
    ColumnPlugin.configure({ component: ColumnGroupElement }),
    ColumnItemPlugin.configure({ component: ColumnElement }),
  ],
});
```

- `component`: Assigns [`ColumnGroupElement`](/docs/components/column) to render column group containers and [`ColumnElement`](/docs/components/column) to render individual columns.

### Turn Into Toolbar Button

You can add this item to the [Turn Into Toolbar Button](/docs/toolbar#turn-into-toolbar-button) to convert blocks into column layouts:

```tsx
{
  icon: <Columns3Icon />,
  label: '3 columns',
  value: 'action_three_columns',
}
```

</Steps>

## Plugins

### `ColumnPlugin`

Owns column groups and requires `ColumnItemPlugin`.

### `ColumnItemPlugin`

Owns the structural column item installed by `ColumnPlugin`. Add it directly only to replace its default configuration or component.

## Types

### `ColumnGroupElement`

Extends `Element`.

### `ColumnElement`

Extends `Element`.

## Capabilities

The group plugin owns group operations. The item plugin owns item operations:

```tsx
const columnGroup = editor.plugin(ColumnPlugin);
const column = editor.plugin(ColumnItemPlugin);

columnGroup.update.insert({ columns: 3 }, { select: true });
columnGroup.update.setColumns({ at: columnGroupPath, widths: ['33%', '67%'] });
columnGroup.update.toggle({ columns: 2 });
column.update.moveMiddle(columnGroupEntry, { direction: 'left' });
column.update.selectAll();
```

Group commands are also available through `editor.update.columnGroup`; item
commands are available through `editor.update.column`.

- `insert` inserts a group of equal-width column items.
- `setColumns` changes the count and widths of an existing group.
- `toggle` converts the active block to a column group or updates its layout.
- `moveMiddle` moves the middle column's content into the first column.
- `selectAll` expands a selection inside a column to the column group.
