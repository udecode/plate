## Features

- Add 2-column and 3-column layouts to your document, or up to five columns by adding columns or dropping blocks side by side.
- Drag the divider between adjacent columns to resize their relative flex weights in one undoable step, or pick presets and unwrap columns from the floating toolbar.
- Stack columns vertically on narrow mobile viewports while preserving side-by-side weights on wider screens.
- With [Drag & Drop](/docs/dnd), drop a block beside another block, on its inline-end edge or in the editor's side padding next to a top-level block, to place both in a new column group, or beside a block in a column to add a column, up to five.

</PackageInfo>

## Kit usage

<Steps>

### Installation

The fastest way to add column functionality is with the `ColumnKit`, which includes pre-configured `ColumnGroupPlugin` and `ColumnItemPlugin` with [Plate UI](/docs/installation/plate-ui) components.

<ComponentSource name="column" />

- [`ColumnGroupElement`](/docs/components/column): Renders column group containers.
- [`ColumnElement`](/docs/components/column): Renders individual column items.

### Add kit

Add the kit to your plugins:

```tsx
import { createEditor } from 'platejs/react';
import { ColumnKit } from '@/components/editor/column';

const editor = createEditor({
  plugins: [
    // ...otherPlugins,
    ...ColumnKit,
  ],
});
```

</Steps>

## Manual usage

<Steps>

### Installation

```bash
npm install platejs
```

### Add plugins

Add `ColumnGroupPlugin` to the editor. It installs `ColumnItemPlugin` as the required structural dependency.

```tsx
import { ColumnGroupPlugin } from 'platejs/column/react';
import { createEditor } from 'platejs/react';

const editor = createEditor({
  plugins: [
    // ...otherPlugins,
    ColumnGroupPlugin,
  ],
});
```

### Configure plugins

Configure the group and add a complete `ColumnItemPlugin` descriptor when you need to replace the dependency's render component.

```tsx
import { ColumnGroupPlugin, ColumnItemPlugin } from 'platejs/column/react';
import { createEditor } from 'platejs/react';
import { ColumnGroupElement, ColumnElement } from '@/components/editor/column';

const editor = createEditor({
  plugins: [
    // ...otherPlugins,
    ColumnGroupPlugin.configure({ component: ColumnGroupElement }),
    ColumnItemPlugin.configure({ component: ColumnElement }),
  ],
});
```

- `component`: Assigns [`ColumnGroupElement`](/docs/components/column) to render column group containers and [`ColumnElement`](/docs/components/column) to render individual columns.

### Turn into toolbar button

Add a structural action that calls `BaseColumnGroupPlugin` directly. Enable it only when exactly one eligible block outside a column is selected.

```tsx
import { BaseColumnGroupPlugin } from 'platejs/column';

const turnIntoItem = {
  icon: <Columns3Icon />,
  label: '3 columns',
  value: 'action_three_columns',
  onSelect: () => {
    const column = editor.plugin(BaseColumnGroupPlugin);

    if (!column.installed || editor.read.view.isReadOnly()) return;

    column.update.toggle({ columns: 3 });
  },
};
```

</Steps>

## Plugins

### `ColumnGroupPlugin`

Owns column groups and requires `ColumnItemPlugin`.

### `ColumnItemPlugin`

Owns the structural column item installed by `ColumnGroupPlugin`. Add it directly only to replace its default configuration or component.

## Types

### `ColumnGroupElement`

Extends `Element`.

### `ColumnElement`

Extends `Element`.

## Capabilities

The group plugin owns group operations. The item plugin owns item operations:

```tsx
const columnGroup = editor.plugin(ColumnGroupPlugin);
const column = editor.plugin(ColumnItemPlugin);

columnGroup.update.insert({ columns: 3 }, { select: true });
columnGroup.update.setColumns({ at: columnGroupPath, widths: [1, 2] });
columnGroup.update.resizeColumns({
  columns: [leftColumnKey, rightColumnKey],
  widths: [1.5, 0.5],
});
columnGroup.update.insertColumn({ at: columnPath, side: 'after' });
columnGroup.update.removeColumn({ at: columnPath });
columnGroup.update.unwrap({ at: columnGroupPath });
columnGroup.update.toggle({ columns: 2 });
column.update.selectAll();
```

Group commands are also available through `editor.update.columnGroup`; item
commands are available through `editor.update.column`.

- `insert` inserts a group of column items after the current block (refusing nested placement inside a column).
  `select: true` selects its first paragraph; `replaceEmpty: true` replaces an
  empty source in the same history step. Use `after` to identify another source
  block or `at` for explicit node-insertion placement.
- `setColumns` changes the count and numeric flex weights of an existing group while keeping locked columns' weights intact.
- `resizeColumns` updates the numeric flex weights of two adjacent content columns by their live `NodeKey`s without mutating other siblings.
- `insertColumn` inserts a sibling column before or after a column with the group's average weight, up to five content columns.
- `removeColumn` deletes a column from groups of three or more, or drops the column and structurally unwraps the surviving column in a two-column group.
- `unwrap` structurally lifts every column's inner blocks into the parent container in order.
- `toggle` converts the active block to a column group or updates an existing group's layout.
- `selectAll` expands a selection inside a column to the column group.

Pressing Backspace at the start of a column whose only content block is an empty plain paragraph removes that column (unwrapping a two-column group) while yielding to headings, lists, indented paragraphs, and inline content such as mentions.

`ColumnGroupPlugin` also builds side drops through
`editorReads.transfer.side`, so
`editor.api.transfer.move({ nodes, to: { key, side: 'end' } })` places blocks
beside a top-level block in a new group, or beside a block in a column as a new
column of up to five. Adding a column gives it the group's mean flex weight without rewriting sibling widths. See [Build beside a block](/docs/dnd#build-beside-a-block).
