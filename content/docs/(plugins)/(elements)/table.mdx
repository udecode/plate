## Features

- Enables creation and editing of tables with advanced behaviors.
- Arrow navigation (up/down).
- Grid cell selection.
- Cell selection expansion with `Shift+Arrow` keys.
- Copying and pasting cells.
- Row drag-and-drop reordering
- Row selection via drag handle

</PackageInfo>

## Kit Usage

<Steps>

### Installation

The fastest way to add table functionality is with the `TableKit`, which includes pre-configured `TablePlugin`, `TableRowPlugin`, and `TableCellPlugin` descriptors with their [Plate UI](/docs/installation/plate-ui) components.

<ComponentSource name="table" />

- [`TableElement`](/docs/components/table): Renders table containers.
- [`TableRowElement`](/docs/components/table): Renders table rows.
- [`TableCellElement`](/docs/components/table): Renders `tableCell` nodes as `<td>` or `<th>` from the node's `header` property.

### Add Kit

Add the kit to your plugins:

```tsx
import { createEditor } from 'platejs/react';
import { TableKit } from '@/components/editor/table';

const editor = createEditor({
  plugins: [
    // ...otherPlugins,
    ...TableKit,
  ],
});
```

</Steps>

## Manual Usage

<Steps>

### Installation

```bash
npm install platejs @tanstack/react-virtual
```

### Add Plugin

Include `TablePlugin` in your Plate plugins array when creating the editor.

`TablePlugin` installs `TableRowPlugin` and `TableCellPlugin` as required structural dependencies.

```tsx
import { TablePlugin } from 'platejs/table/react';
import { createEditor } from 'platejs/react';

const editor = createEditor({
  plugins: [
    // ...otherPlugins,
    TablePlugin,
  ],
});
```

### Configure Plugins

Configure the table owner and add complete row or cell descriptors when you need to replace a dependency's component or configuration.

```tsx
import { TableCellPlugin, TablePlugin, TableRowPlugin } from 'platejs/table/react';
import { createEditor } from 'platejs/react';
import {
  TableCellElement,
  TableElement,
  TableRowElement,
} from '@/components/editor/table';

const editor = createEditor({
  plugins: [
    // ...otherPlugins,
    TablePlugin.configure({
      component: TableElement,
      initialState: {
        initialTableWidth: 600,
        disableMerge: false,
        minColumnWidth: 48,
      },
    }),
    TableRowPlugin.configure({ component: TableRowElement }),
    TableCellPlugin.configure({ component: TableCellElement }),
  ],
});
```

- `.configure({ component })`: Assigns [`TableElement`](/docs/components/table) to render table containers.
- `component`: Assigns components for table rows and cells. `TableCellElement` reads `element.header` to render header cells.
- `initialState.initialTableWidth`: Sets the initial width for new tables.
- `initialState.disableMerge`: Disables cell merging functionality.
- `initialState.minColumnWidth`: Sets the minimum width for table columns.

Column widths are stored once on the table's `columnWidths`. Table renderers read
that vector in the table renderer; `null` preserves an unknown imported width
without treating it as zero pixels. Pointer previews use transient
overrides, then commit through
`editor.plugin(TablePlugin).update.setColumnWidth`. Row resizing follows the
same pattern with each row's `height`.

## Plugins

### TablePlugin

Owns the table schema and behavior. Requires the row and cell plugins.

<API name="TablePlugin">
<APIOptions>
  <APIItem name="disableMerge" type="boolean" optional>
    Disables the merging behavior of cells.
  </APIItem>
  <APIItem name="disableExpandOnInsert" type="boolean" optional>
    Disables the expansion of the table when inserting cells.
  </APIItem>
  <APIItem name="disableMarginLeft" type="boolean" optional>
    Disables the left resizer of the first column in the table.
  </APIItem>
  <APIItem name="enableUnsetSingleColSize" type="boolean" optional>
    Disables unsetting the width of the first column when the table has only one column. Set this to `true` if you want to resize the table width when there's only one column. Leave it `false` if you have a full-width table.
  </APIItem>
  <APIItem name="initialTableWidth" type="number" optional>
    If defined, a normalizer will set each undefined table `columnWidths` to this value divided by the number of columns. Note that merged cells are not yet supported.
  </APIItem>
  <APIItem name="minColumnWidth" type="number" optional>
    The minimum width of a column in the table.
    - **Default:** `48`
  </APIItem>
</APIOptions>
</API>

### TableRowPlugin

Required structural plugin for table rows. Add it directly only to replace its default configuration or component.

### TableCellPlugin

Required structural plugin for all table cells. Header cells use the same `tableCell` type with `header: true`; add the plugin directly only to replace its default configuration or component.

### `editor.plugin(TablePlugin).update.merge`

Merges multiple selected cells into one.

The merged cell will:
- Have a colSpan equal to the number of columns spanned by the selected cells
- Have a rowSpan equal to the number of rows spanned by the selected cells
- Contain the combined content of all merged cells (non-empty cells only)
- Inherit the header status from the first selected cell

### `editor.plugin(TablePlugin).update.split`

Splits a merged cell back into individual cells.

The split operation will:
- Create new cells for each column and row that was spanned
- Copy the header status from the original merged cell
- Place the original cell's content in the first cell
- Create empty cells for the remaining spaces

## Hooks

### `useTableSelectionDOM`

Synchronizes structural cell selection with a custom table renderer. The hook
updates selected-cell attributes, hides the caret in the anchor cell, and
restores the caret when the selection changes or the renderer unmounts.

Compose column sizing, cell layout, and pointer handlers directly in your
renderer with `TablePlugin` reads and Core selector hooks.

<API name="useTableSelectionDOM">
<APIParameters>
  <APIItem name="tableRef" type="React.RefObject&lt;HTMLTableElement | null&gt;">
    Ref for the rendered `<table>` that contains `data-table-cell-key`
    attributes.
  </APIItem>
</APIParameters>
<APIReturns type="void" />
</API>

### `editor.plugin(TablePlugin).read.canMerge()`

Returns whether the current editable selection is a complete rectangular
multi-cell selection.

### `editor.plugin(TablePlugin).read.canSplit()`

Returns whether the current editable selection is inside one cell with a row
or column span. Registry controls also apply the live `disableMerge` option.
