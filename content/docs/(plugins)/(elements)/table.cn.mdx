## 功能特性

- 插入和删除表格、行与列。
- 使用指针选择单元格，或通过 `Shift+方向键` 扩展选区。
- 合并和拆分单元格，同时保留富文本内容。
- 复制和粘贴矩形单元格区域。
- 调整列宽和行高，设置单元格背景与边框。
- 使用复制到项目中的行拖拽手柄调整行顺序或选择整行。

</PackageInfo>

## 使用方法

通过已安装的表格描述符插入表格、读取选区和修改内容：

```tsx
import { createEditor } from 'platejs/react';
import { TablePlugin } from 'platejs/table/react';

const editor = createEditor({ plugins: [TablePlugin] });
const table = editor.plugin(TablePlugin);

table.update.insert({ rows: 3, columns: 4, header: true }, { select: true });
table.update.insertColumn({ before: true });

if (table.read.canMerge()) {
  table.update.merge();
}
```

无界面用法从 `platejs` 导入 `createEditor`，从 `platejs/table` 导入 `BaseTablePlugin`。

### 指定目标单元格

省略 `at` 时，操作使用调用方编辑器视图的选区。传入 `at` 可指定独立于当前选区的目标：

```tsx
const selected = table.read.selection();

if (selected) {
  table.update.insertRow({ at: selected.focus, before: true });

  const cell = table.read.cell({ at: selected.anchor });
  if (cell) {
    table.update.setCellBackground({ at: cell.entry[0], color: '#fef9c3' });
  }
}
```

`TableTargetOptions.at` 接受表格、行或单元格目标，也接受 `NodeSelection`。节点目标可以是路径、点、范围、当前文档中的节点或 `NodeKey`。已删除的键或不属于当前文档的节点不会回退到当前选区。路径相对于调用方的根；带根信息的目标保留该根。

`read.cell` 接受单元格目标，仅在目标解析为一个单元格时返回结果，否则返回 `null`。多单元格选区使用 `read.selection`。返回的 `cells` 精确保留所选节点；`bounds` 不会填补非矩形选区中的空隙。

### 设置选中单元格的格式

在一次更新中组合相关操作：

```tsx
editor.update((tx) => {
  const table = tx.plugin(TablePlugin);

  table.setCellBackground({ color: '#fef9c3' });
  table.setBorders({
    border: 'outer',
    value: { color: '#334155', style: 'solid', width: 2 },
  });
});
```

`color: null` 清除背景。边框 `value` 替换对应边的格式；`null` 清除覆盖值，`{ width: 0 }` 隐藏边框。省略的边框字段使用渲染器默认值。

`read.borders()` 为每个边框状态返回 `true`、`false` 或 `'mixed'`。控件需显式处理 `'mixed'`。`toggleBorders` 隐藏全部可见的边框，显示关闭或混合状态的边框；`border: 'none'` 切换无边框状态。

### 插件配置

`TablePlugin` 会安装必需的行和单元格描述符。需要配置组件时，直接添加这些描述符。复制的行渲染器需要 `DndKit`。

```tsx
import { createEditor } from 'platejs/react';
import { TableCellPlugin, TablePlugin, TableRowPlugin } from 'platejs/table/react';

import { DndKit } from '@/components/editor/dnd';
import {
  TableCellElement,
  TableElement,
  TableRowElement,
} from '@/components/editor/table';

const editor = createEditor({
  plugins: [
    ...DndKit,
    TablePlugin.configure({
      component: TableElement,
      initialState: {
        allowCellSpanEditing: true,
        defaultTableWidth: 600,
        expandOnPaste: true,
        minColumnWidth: 48,
      },
    }),
    TableRowPlugin.configure({ component: TableRowElement }),
    TableCellPlugin.configure({ component: TableCellElement }),
  ],
});
```

在[工具栏](/docs/toolbar)中添加 [`TableToolbarButton`](/docs/components/table-toolbar-button) 来插入表格。

## 编辑行为

`TablePlugin` 处理键盘导航、选区、删除和剪贴板输入。`Tab` 和 `Shift+Tab` 在单元格间移动；在最后一个单元格按 `Tab` 可插入行。同一单元格内的文本拖选使用原生文本选区。清空结构化单元格选区会保留其精确成员和方向。

合并按行优先顺序保留所选单元格的完整富文本内容，包括只有媒体的内容及其拥有的根。目标单元格和保留节点的身份不变。拆分将原始内容留在锚点单元格中，其余位置创建空单元格。

结构化表格粘贴要求 `ContentSlice` 两端闭合，且顶层恰好包含一个表格。开放切片、行或单元格列表、带兄弟节点的表格均作为完整普通内容进行适配。普通内容可以分别粘贴到每个选中的单元格。

将表格粘贴到矩形选区时，只允许完整重复的源区域。不完整的重复区域，以及跨出目标覆盖范围的已有合并单元格都会被拒绝；被完整覆盖的跨行或跨列单元格可以替换。`expandOnPaste: false` 时，超出表格范围的粘贴会被拒绝，而不是裁剪。适配失败不会修改文档或选区。

结构化单元格复制和剪切要求矩形选区完整覆盖其中的跨行、跨列单元格。非矩形选区仍支持删除、格式设置和普通内容粘贴。剪切仅在剪贴板写入成功后清空单元格。精确切片保留富文本及其可达的拥有根；CSV 和 TSV 仅表示文本。

## 自定义尺寸调整

列宽存储在表格的 `columnWidths` 中；`null` 表示导入时未知的宽度。`api.columnWidths(table)` 为每个逻辑列解析数值宽度，不会将回退值写入文档。渲染器负责临时尺寸覆盖值，每一行在自身的 `height` 中存储行高。

`api.createResize(table, target)` 捕获起始尺寸，返回一个把像素偏移转换为 `TableResize` 的函数。计算预览不会修改文档：

```tsx
import { TablePlugin } from 'platejs/table/react';

const selected = editor.plugin(TablePlugin).read.selection();

if (selected) {
  const preview = editor.plugin(TablePlugin).api.createResize(selected.table[0], {
    edge: 'right',
    colIndex: 0,
  });

  editor.plugin(TablePlugin).update.resize({
    at: selected.tableKey,
    resize: preview(24),
  });
}
```

目标可以是 `{ edge: 'right', colIndex }`、`{ edge: 'left' }` 或 `{ edge: 'bottom', rowIndex, height }`。底边目标需要实测起始行高。内部列边界保持相邻两列的总宽度；左边界在首列宽度和表格缩进之间分配空间。导入宽度小于 `minColumnWidth` 时，以其起始宽度作为此次拖动的下限。

横向调整的提交必须包含非空 `columns` 数组，每项为 `{ colIndex, width }`。左边界提交还必须包含 `marginLeft`，右边界提交不包含缩进。底边提交包含 `rowIndex` 和 `height`。

### TableRowPlugin

必需的行结构描述符。当前行被前面行的跨行单元格完整覆盖时，可以没有直接子单元格。

### TableCellPlugin

所有单元格共用的必需结构描述符。表头单元格使用 `type: 'tableCell'` 和 `header: true`。`colSpan` 与 `rowSpan` 必须为正安全整数；省略时跨度为一。

## API 参考

以下 `table` 指 `editor.plugin(TablePlugin)`。公开的表格类型从 `platejs/table` 导出。

| 纯计算 API | 返回值 | 用途 |
| --- | --- | --- |
| `table.api.columnWidths(tableElement)` | `readonly number[]` | 解析每个逻辑列的宽度；数组长度即列数。 |
| `table.api.createResize(tableElement, target)` | `(delta: number) => TableResize` | 计算受尺寸约束的预览。 |

| 读取方法 | 返回值 | 用途 |
| --- | --- | --- |
| `table.read.selection(options?)` | `TableSelection \| null` | 精确的单元格成员、方向、表格身份与边界。 |
| `table.read.cell(options?)` | `TableCellInfo \| null` | 单个单元格的节点条目、逻辑坐标、跨度、边框与尺寸。 |
| `table.read.borders(options?)` | `TableBorderStates \| null` | 将 `top`、`right`、`bottom`、`left`、`none`、`outer` 汇总为 `true \| false \| 'mixed'`。 |
| `table.read.canMerge(options?)` | `boolean` | 当前策略与视图权限是否允许合并完整覆盖跨度的矩形多单元格目标。 |
| `table.read.canSplit(options?)` | `boolean` | 当前策略与视图权限是否允许拆分一个跨行或跨列单元格。 |

读取选项使用 `TableTargetOptions`，但 `cell` 使用 `{ at?: TableCellTarget }`。

`TableSelection` 包含 `table`、`tableKey`、`cells`、`anchor`、`focus`、`bounds`、`rectangular` 和可选的 `root`。`table` 与 `cells` 是当前文档中的元素条目；`tableKey`、`anchor` 和 `focus` 为 `NodeKey`。`rectangular` 表示选区完整覆盖一个矩形区域及其单元格跨度。

`TableCellInfo` 包含 `entry`、`row`、`col`、`rowSpan`、`colSpan`、`borders`、`size` 和可选的 `root`。`size` 包含 `width` 和 `minHeight`。解析后的边框包含 `color`、`style`、`width`：始终提供底边和右边，在对应表格边缘还提供顶边或左边。这两种读取结果省略 `root` 时均表示主根。

## 转换操作

所有表格更新均返回 `boolean`：接受变更返回 `true`；目标不可用、操作被拒绝或内容不变时返回 `false`。无效尺寸和数值选项会在提交前抛出错误。即使已经读取过可用性，执行命令时仍会重新检查。

| 更新方法 | 选项 | 用途 |
| --- | --- | --- |
| `table.update.insert(options?, placement?)` | `TableCreateOptions`、`TableInsertPlacement` | 插入表格，默认为两行两列。 |
| `table.update.insertColumn(options?)` | `TableAxisInsertOptions` | 在逻辑列边界插入列。 |
| `table.update.insertRow(options?)` | `TableAxisInsertOptions` | 在逻辑行边界插入行。 |
| `table.update.removeColumn(options?)` | `TableTargetOptions` | 删除目标列；没有剩余列时删除表格。 |
| `table.update.removeRow(options?)` | `TableTargetOptions` | 删除目标行；没有剩余行时删除表格。 |
| `table.update.remove(options?)` | `TableTargetOptions` | 删除所在表格。 |
| `table.update.merge(options?)` | `TableTargetOptions` | 合并完整的矩形选区。 |
| `table.update.split(options?)` | `TableTargetOptions` | 拆分一个跨行或跨列单元格。 |
| `table.update.setCellBackground(options)` | `{ at?, color: string \| null }` | 为精确选中的单元格设置或清除背景。 |
| `table.update.setBorders(options)` | `{ at?, border, value: TableCellBorder \| null }` | 替换或清除边框格式。 |
| `table.update.toggleBorders(options)` | `{ at?, border }` | 统一切换边框状态。 |
| `table.update.resize(options)` | `TableResizeOptions` | 提交 `{ at?, resize }`。 |
| `table.update.setColumnWidth(options)` | `TableColumnWidthOptions` | 设置 `{ at?, colIndex, width }`。 |
| `table.update.setRowHeight(options)` | `TableRowHeightOptions` | 设置 `{ at?, rowIndex, height }`。 |

`TableCreateOptions` 包含 `rows`、`columns` 和 `header`。行列数必须为正安全整数；`header: true` 将首行设为表头。`TableInsertPlacement` 中，`at` 指定精确插入位置，`after` 指定当前文档中的块，两者不能同时使用。其他块插入选项（包括 `select` 和 `replaceEmpty`）仍可使用。省略位置时，表格插入在当前所在的表格或块之后。

`TableAxisInsertOptions` 包含 `at`、`before`、`header` 和 `select`。目标为跨行或跨列单元格时，插入使用其逻辑起始或结束边界；目标为表格时，在开头或结尾插入。尺寸调整中的行列索引从零开始，宽度和高度必须为有限正数。

背景与边框更新接受 `TableTargetOptions.at`，包括精确的非矩形单元格选区。`setBorders.border` 可以是 `'top'`、`'right'`、`'bottom'`、`'left'`、`'all'` 或 `'outer'`；`toggleBorders.border` 接受四个方向、`'none'` 或 `'outer'`。`TableCellBorder` 包含可选的 `color`、`style`，以及非负有限数值 `width`。

尺寸更新接受 `at?: TableNodeTarget`。在 `editor.update` 回调中，直接通过 `tx.plugin(TablePlugin)` 调用相同的更新方法。

`TablePlugin` 会在渲染后的单元格宿主上绘制结构化单元格选区。自定义 `TableCellPlugin` 组件必须将 `props.attributes`（包括其中的 `ref`）绑定到唯一的标准 `<td>` 或 `<th>` 元素。

## Hooks

### `useTableResize`

从 `platejs/table/react` 导入并调用 `useTableResize({ element, tableRef, onResize, onResizeEnd })`。返回的函数接受指针事件和 `TableResizeHandle`。底边手柄提供 `rowIndex`，由 hook 测量起始高度。

在本地渲染 `onResize` 的预览，并在 `onResizeEnd` 清除覆盖值。主指针释放时提交一次；取消操作、窗口失焦、只读状态变化、表格替换或组件卸载都会丢弃当前手势。
