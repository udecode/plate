## 套件使用

<Steps>

### 安装

最快捷的方式是使用 `ColumnKit`，它包含预配置的 `ColumnPlugin` 和 `ColumnItemPlugin` 以及 [Plate UI](/docs/installation/plate-ui) 组件。

<ComponentSource name="column" />

- [`ColumnGroupElement`](/docs/components/column): 渲染分栏组容器
- [`ColumnElement`](/docs/components/column): 渲染单个分栏项

### 添加套件

将套件加入插件列表：

```tsx
import { createPlateEditor } from 'platejs/react';
import { ColumnKit } from '@/components/editor/column';

const editor = createPlateEditor({
  plugins: [
    // ...其他插件,
    ...ColumnKit,
  ],
});
```

</Steps>

## 手动配置

<Steps>

### 安装

```bash
npm install @platejs/layout
```

### 添加插件

将 `ColumnPlugin` 加入编辑器。它会把 `ColumnItemPlugin` 作为必需的结构依赖安装。

```tsx
import { ColumnPlugin } from '@platejs/layout/react';
import { createPlateEditor } from 'platejs/react';

const editor = createPlateEditor({
  plugins: [
    // ...其他插件,
    ColumnPlugin,
  ],
});
```

### 配置插件

配置分栏组；需要替换依赖的渲染组件时，再加入完整的 `ColumnItemPlugin` 描述符。

```tsx
import { ColumnPlugin, ColumnItemPlugin } from '@platejs/layout/react';
import { createPlateEditor } from 'platejs/react';
import { ColumnGroupElement, ColumnElement } from '@/components/editor/column';

const editor = createPlateEditor({
  plugins: [
    // ...其他插件,
    ColumnPlugin.configure({ component: ColumnGroupElement }),
    ColumnItemPlugin.configure({ component: ColumnElement }),
  ],
});
```

- `component`: 指定 [`ColumnGroupElement`](/docs/components/column) 渲染分栏组容器，[`ColumnElement`](/docs/components/column) 渲染单个分栏。

### 转换为工具栏按钮

可将此功能添加至 [转换为工具栏按钮](/docs/toolbar#turn-into-toolbar-button) 来将区块转为分栏布局：

```tsx
{
  icon: <Columns3Icon />,
  label: '3栏布局',
  value: 'action_three_columns',
}
```

</Steps>

## 插件

### `ColumnPlugin`

负责分栏组，并要求安装 `ColumnItemPlugin`。

### `ColumnItemPlugin`

负责由 `ColumnPlugin` 安装的结构分栏项。仅在替换其默认配置或组件时直接加入。

## 类型定义

### `ColumnGroupElement`

继承自 `Element`。

### `ColumnElement`

继承自 `Element`。

<API name="ColumnElement">
<APIAttributes>
  <APIItem name="width" type="string" optional>
    分栏宽度（必须以 `%` 结尾）
  </APIItem>
</APIAttributes>

## 能力

分栏组插件负责组操作，分栏项插件负责项操作：

```tsx
const columnGroup = editor.plugin(ColumnPlugin);
const column = editor.plugin(ColumnItemPlugin);

columnGroup.update.insert({ columns: 3 }, { select: true });
columnGroup.update.setColumns({ at: columnGroupPath, widths: ['33%', '67%'] });
columnGroup.update.toggle({ columns: 2 });
column.update.moveMiddle(columnGroupEntry, { direction: 'left' });
column.update.selectAll();
```

组命令也可通过 `editor.update.columnGroup` 使用；项命令通过
`editor.update.column` 使用。

- `insert` 插入一组等宽分栏项。
- `setColumns` 修改现有分栏组的数量和宽度。
- `toggle` 将当前区块转换为分栏组，或更新其布局。
- `moveMiddle` 将中间栏内容移动到第一栏。
- `selectAll` 将栏内选区扩展到整个分栏组。
