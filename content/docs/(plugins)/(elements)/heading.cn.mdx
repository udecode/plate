标题使用一个元素类型和一个插件。必填的 level 属性决定 H1 到 H6 的渲染和 Markdown 深度。

<ComponentPreview name="basic-blocks-demo" />

<PackageInfo>

## 功能

- 一个 HeadingPlugin 和 BaseHeadingPlugin。
- 必填 level，范围为 1 到 6。
- 一个 HTML 和 MDAST Codec。
- # 到 ###### 的 Markdown 快捷输入。
- mod+alt+1 到 mod+alt+6 的 Registry 快捷键。

</PackageInfo>

## Kit 用法

~~~tsx
import { BasicBlocksKit } from '@/components/editor/plugins/basic-blocks-kit';
import { createPlateEditor } from 'platejs/react';

const editor = createPlateEditor({
  plugins: [...BasicBlocksKit],
});
~~~

## 手动用法

~~~tsx
import { HeadingRules } from '@platejs/basic-nodes';
import { HeadingPlugin } from '@platejs/basic-nodes/react';

const plugins = [
  HeadingPlugin.configure({
    component: HeadingElement,
    inputRules: [HeadingRules.markdown()],
  }),
];
~~~

组件读取 element.level 并选择对应标签。

~~~tsx
export function HeadingElement(props) {
  const tag = `h${props.element.level}`;
  return <PlateElement as={tag} {...props} />;
}
~~~

## 值

~~~ts
const value = [
  {
    type: 'heading',
    level: 2,
    children: [{ text: '文档模型' }],
  },
];
~~~

HTML Codec 将 level 映射到 h1 到 h6 标签。Markdown Codec 将它映射到 MDAST depth。

## 命令

~~~ts
editor.plugin(HeadingPlugin).update.toggle({ level: 2 });
~~~

使用当前级别会把标题重置为根默认块；使用其他级别会修改同一标题类型的 level。

## API

| API | 用途 |
| --- | --- |
| BaseHeadingPlugin | 无 React 的标题 Schema、行为、Codec 和更新。 |
| HeadingPlugin | BaseHeadingPlugin 的 React 适配器。 |
| HeadingRules.markdown() | 处理 # 到 ###### 的单个输入规则。 |
| HeadingLevel | 1、2、3、4、5 或 6。 |
