## 功能特性

- 一个 void `board` 块，拥有自己的图形列表。每个图形都是该列表的顶层块，因此同步、建议、撤销以及复制粘贴都以图形为单位。
- 六种图形：可容纳富文本的便签和几何图形、容纳一张图片的图片图形、两端可绑定到图形的箭头、可容纳图形的框架，以及笔迹。
- 每个图形存储自己的样式：填充、轮廓颜色、线型、轮廓粗细、不透明度和文字大小，每种图形类型各有默认值。一次选取把选中的图形改为新样式，作为一步撤销；选中绘制工具时，只设置下一个图形的样式。
- 插入、移动、缩放、调整层级和删除图形的命令。撤销不会拆开一次调用，在建议模式下每次调用是一条建议。
- 复制、粘贴和创建副本时图形获得新 id。复制的箭头绑定到复制出的图形。副本落在最上层，框架仍在其他图形之后。指针位于白板上时，副本落在指针处。若该位置已有图形，副本每次向右下方错开 24px，直到所在位置没有图形。
- 粘贴图片链接或从网页复制的图片，它会作为图片图形落在指针处，并保持图片的比例。
- 每个挂载的视图各自拥有相机、工具、工具锁定和下一个样式，文档从不存储它们。
- Tab 和 Mod 加方向键在图形之间移动，Shift+Enter 进入工具栏，按键可以缩放、平移和适配视图。Enter 可以放置便签、图形或框架，也可以用箭头连接两个图形。屏幕阅读器会听到选中的图形、选择的工具、缩放比例、每次删除和连接的每一步，使用你的应用传入的文字。
- 只挂载相机附近的图形，因此每次按键的工作量不会随白板变大而增加。

</PackageInfo>

## 套件用法

<Steps>

### 安装

`BoardKit` 安装 `BoardPlugin` 和五个图形插件，并配好复制的白板 UI：带工具栏的白板表面，以及这五种图形各自的渲染组件。

<ComponentSource name="board" />

- `BoardElement`：渲染白板表面及其工具栏。
- `BoardPageElement`：渲染填满容器的白板。`BoardPageKit` 用它代替 `BoardElement`。
- `BoardNoteElement`、`BoardGeoElement`、`BoardArrowElement`、`BoardFrameElement` 和 `BoardStrokeElement`：渲染各类图形。
- `BoardImageElement`：渲染图片图形。`BoardImageKit` 在 `BoardKit` 之外单独安装它，见[图片](#图片)。
- `BoardToolbar`：选择选择、抓手、便签、图形、箭头、框架、笔或橡皮擦工具，图形菜单为下一个图形选择矩形、椭圆、菱形或三角形。其后的锁定按钮像 Q 一样开启或关闭工具锁定，锁定开启时显示为按下状态。缩小和放大按钮各缩放一级，两者之间的缩放比例以百分比显示，点击它会回到 100%；适应按钮让所有图形进入视图。选中框架时，一个图标按钮可以删除框架并保留其中的图形。
- `BoardStylePanel`：停靠在白板右上角，为选中的图形设置样式；选中绘制工具时，为下一个图形设置样式，见[样式面板](#样式面板)。

### 添加套件

```tsx
import { createEditor } from 'platejs/react';

import { BoardKit } from '@/components/editor/board';

const editor = createEditor({
  plugins: [
    // ...其他插件
    ...BoardKit,
  ],
});
```

</Steps>

## 示例

### 白板页面

在这个示例中，白板是页面中唯一的块，就像白板应用一样。它在这里填满预览框，在[自己的页面](/blocks/board-page-demo)中填满整个窗口。在空白处拖动会绘制选择框。滚动滚轮、用抓手拖动、按住 Space 拖动或用中键拖动可平移，按住 Mod 并滚动滚轮可缩放。

<ComponentPreview name="board-page-demo" />

`BoardPageKit` 用 `BoardPageElement` 绘制白板，它向 `BoardSurface` 传入 `height="100%"`。这个 `height` 在此视图中替代白板存储的 `height`，且不会改变文档，因此白板取其外层编辑器的高度。请给编辑器设置高度，就像示例在一个设定了高度的容器中使用 `<Editor className="h-full" variant="none" />` 那样。去掉包裹每个块或在最后一个块后添加段落的套件，例如 `EditorKit` 的拖动手柄和末尾块。示例安装了 `ImagePlugin` 和 `BoardImageKit`，因此粘贴的图片会按[图片](#图片)一节所述落在白板上。

## 样式面板

选中图形或选择绘制工具后，白板右上角的面板会为这些图形接受的每种样式显示一行：图形（把几何图形改为矩形、椭圆、菱形或三角形）、填充、轮廓、线型、粗细和文字大小。一次选取会写入每个接受该样式的选中图形，以及你正在输入文字的图形，作为一步撤销，共享房间中的协作者也会看到。选中绘制工具时，一次选取只设置下一个图形的样式。没有目标图形接受任何样式时，以及在只读视图中，面板会隐藏。面板没有不透明度一行，图形保留它存储的 `opacity`。白板窄于 36rem 时，面板收进一个 Styles 按钮。一次选取会让光标留在你正在输入文字的图形中，但收起的面板除外，因为 Styles 按钮会把焦点移进面板。

复制的 `board.tsx` 在画板表面的 `toolbar` 中渲染面板，放在 `BoardToolbar` 旁边，并定义了它用到的类名常量，例如 `BOARD_COLORS`：

```tsx
const boardToolbar = (
  <>
    <BoardToolbar />
    <BoardStylePanel />
  </>
);

export function BoardElement(props: EditorElementProps<typeof BoardPlugin>) {
  return (
    <BoardSurface
      {...props}
      attributes={{
        ...props.attributes,
        className: cn(
          '@container my-4 rounded-lg border data-selected:ring-2 data-selected:ring-ring',
          BOARD_COLORS,
          BOARD_ERASING,
          BOARD_FOCUS_RING,
          BOARD_GRID
        ),
      }}
      messages={boardMessages}
      toolbar={boardToolbar}
    />
  );
}
```

面板依赖其中两个类名。没有 `@container`，面板在任何宽度下都收在 Styles 按钮后面；没有 `BOARD_COLORS`，命名颜色的色块不显示颜色。

`BoardStylePanel` 自己定位在白板右上角，并在其根元素上标记 `data-board-dock="right"`。这个标记告诉 `fit` 和 Shift+1 面板遮挡哪一侧，它们会把图形放进面板旁边的空间。如果这块空间在 10% 缩放下放不下这些图形，它们就改用白板的整个宽度。标记不会移动元素，所以你自己的面板要先放在白板一侧，再用 `"left"` 或 `"right"` 标记。`toolbar` 的其他顶层元素都算作白板顶部或底部的一行。

要自己做一行，把它渲染在 `toolbar` 中，从 `styles` 读取样式，用 `setStyle` 写入。没有目标接受的样式在 `styles` 中没有对应项，因此这一行会隐藏。在这一行上阻止按下的默认行为，正在编辑的图形就能保留光标：

```tsx
import { useBoardActions, useBoardView } from 'platejs/board/react';

const SIZES = ['s', 'm', 'l', 'xl'] as const;

function TextSizeRow() {
  const textSize = useBoardView((view) => view.styles.textSize);
  const { setStyle } = useBoardActions();

  if (!textSize) return null;

  return (
    <div aria-label="Text size" role="group">
      {SIZES.map((size) => (
        <button
          key={size}
          aria-pressed={!textSize.mixed && textSize.value === size}
          type="button"
          onClick={() => setStyle({ textSize: size })}
          onMouseDown={(event) => event.preventDefault()}
        >
          {size.toUpperCase()}
        </button>
      ))}
    </div>
  );
}
```

## 图片

`BoardImageKit` 添加图片图形，即容纳一张图片的方框。它唯一的子节点是文档自己的图片元素，因此由 `ImagePlugin` 保存图片的链接、替代文字、HTML 和 Markdown。请在安装了 `ImagePlugin` 的编辑器中安装这个套件，例如使用了[媒体套件](/docs/media)的编辑器。本页顶部的示例通过 `EditorKit` 获得它。

```tsx
import { createEditor } from 'platejs/react';

import { BoardImageKit, BoardKit } from '@/components/editor/board';
import { MediaKit } from '@/components/editor/media';

const editor = createEditor({
  plugins: [
    // ...其他插件
    ...MediaKit,
    ...BoardKit,
    ...BoardImageKit,
  ],
});
```

在白板获得焦点时，例如点击白板空白处之后，粘贴图片链接或从网页复制的图片。光标位于页面文字中时，即使指针在白板上，也由页面在光标处接收这次粘贴。`ImagePlugin` 会嵌入的链接才算图片链接，例如路径以 `.png` 或 `.jpg` 结尾的链接。粘贴的 HTML 只有其中每个非空块都是图片时才算。

- 一次粘贴的图片作为图片图形排成一行，间隔 16px，以指针为中心；指针不在白板上时，以视图中心为中心。它们作为一步撤销落下，白板会选中它们。
- 每个图形保持图片的比例，缩小到最长边不超过 480px，从不放大。加载失败的图片以 320 × 240 落下。
- 粘贴会等待每张图片加载完成。以下任一情况都会放弃等待中的粘贴：在白板上按键或按下指针、再次粘贴、焦点离开白板、编辑或选区变化（例如撤销），或视图变为只读。
- 正在编辑图形的文字时，粘贴的内容进入该文字，不会出现图片图形。

调整图片图形大小时总是保持比例，无论是否按住 Shift。缩小到短边为 8px 时停止；短边已不足 8px 的图形只能放大。图片图形没有可编辑的文字，因此 Enter 和双击只让它保持选中。它不接受任何样式，因此选中选择工具且只选中图片图形时，样式面板会隐藏。选中绘制工具时，面板改为针对该工具将绘制的下一个图形，见[样式面板](#样式面板)。复制的 `BoardImageElement` 把图片缩放到适合图形的方框，不绘制图注。

要用代码添加图片，把图片元素作为图形唯一的子节点传入。除非 `width` 和 `height` 另有指定，图形大小为 320 × 240。

```ts
import { BaseBoardImagePlugin } from 'platejs/board';

editor.update((tx) => {
  tx.plugin(BaseBoardImagePlugin).insert(
    {
      children: [
        {
          children: [{ text: '' }],
          type: 'image',
          url: 'https://example.com/plan.png',
        },
      ],
      height: 320,
      width: 480,
      x: 300,
      y: 40,
    },
    { board }
  );
});
```

## 手动用法

<Steps>

### 安装

```bash
npm install platejs
```

### 添加插件

安装白板及其容纳的每种图形，并为每个插件配置绘制它的组件。

```tsx
import {
  BoardArrowPlugin,
  BoardFramePlugin,
  BoardGeoPlugin,
  BoardNotePlugin,
  BoardPlugin,
  BoardStrokePlugin,
} from 'platejs/board/react';
import { createEditor } from 'platejs/react';

import {
  BoardArrowElement,
  BoardElement,
  BoardFrameElement,
  BoardGeoElement,
  BoardNoteElement,
  BoardStrokeElement,
} from '@/components/editor/board';

const editor = createEditor({
  plugins: [
    BoardPlugin.configure({ component: BoardElement }),
    BoardNotePlugin.configure({ component: BoardNoteElement }),
    BoardGeoPlugin.configure({ component: BoardGeoElement }),
    BoardArrowPlugin.configure({ component: BoardArrowElement }),
    BoardFramePlugin.configure({ component: BoardFrameElement }),
    BoardStrokePlugin.configure({ component: BoardStrokeElement }),
  ],
});
```

如需图片，还要安装 `ImagePlugin` 和 `BoardImagePlugin.configure({ component: BoardImageElement })`。

</Steps>

## 键盘和指针

Mod 在 Mac 上是 Command，在其他系统上是 Control。白板只有一个 Tab 停靠点，即它的焦点目标，在图形之间移动时焦点停在这里。

| 输入 | 结果 |
| --- | --- |
| 使用选择工具时按下图形 | 选中它。按住 Shift 会把它加入选区。 |
| 使用便签、图形或框架工具点击 | 在点击位置居中放置一个默认大小的该图形，在白板空白处或其他图形上方都可以。然后选中新图形并选择选择工具；工具锁定开启时保留当前工具。 |
| 使用便签、图形或框架工具拖动 | 按拖出的方框绘制该图形，在白板空白处或其他图形上方都可以，拖动时显示所选图形的轮廓。按住 Shift 保持正方形，按住 Alt 从拖动起点向四周扩展。然后选中新图形并选择选择工具；工具锁定开启时保留当前工具。 |
| 拖动选中图形的角手柄（只在使用选择工具时显示） | 指针移动超过 8 px 后调整图形大小，每边最小 8 个单位，对角保持不动。按住 Shift 保持比例，按住 Alt 围绕中心调整。图片图形无论是否按住 Shift 都保持比例。保持比例的调整在短边达到 8 时停止；短边已不足 8 的图形只能放大。拖动移动的每条边会与视图中 8 个屏幕像素以内最近的其他图形或框架的边缘或中心对齐，并用一条线标出每条对齐的边。图形不会与箭头或笔画对齐。按住 Control 或 Command 可自由调整大小。 |
| 在被选中的白板上，或没有选中图形、使用便签、图形、框架和箭头以外的任何工具时在获得焦点的白板上按 Enter | 选中它的第一个图形。在被选中的空白板上，它让白板获得焦点，这样工具字母就能用。 |
| Tab 和 Shift+Tab | 按白板存储图形的顺序在图形之间移动，最后一个图形之后离开白板。视图外的图形会移入视图。 |
| Mod 加方向键 | 选中该方向上最近的图形，并把它移入视图。没有选中图形时，从视图中心开始。该方向没有图形时，选区不变，白板会再播报一次选中的图形。 |
| 使用选择工具时双击；或使用便签、图形、框架和箭头以外的任何工具时，在选中的一个便签、几何图形或箭头上按 Enter；或使用箭头工具时，在选中的一个箭头上按 Enter | 编辑其文字。图片图形没有文字，因此两者都只让它保持选中。 |
| Escape | 结束进行中的拖动、连接、调整大小或挑选，并保留当前工具。否则，它从文字上升到所在图形。在获得焦点的白板或其选中的图形上，选择了其他工具时它选择选择工具，使用选择工具时它上升到白板。 |
| 在获得焦点的白板或其选中的图形上按 Shift+Enter | 把焦点移到工具栏。按 Escape 或 Shift+Tab，焦点回到白板。 |
| `V`、`H`、`N`、`R`、`A`、`F`、`P`、`E` | 选择选择、抓手、便签、图形、箭头、框架、笔和橡皮擦工具。 |
| 在获得焦点的白板或其选中的图形上按 `Q` | 开启或关闭工具锁定。锁定开启时，便签、图形、框架和箭头工具在每次添加图形后保持选中，因此可以连续添加多个。Escape 和工具字母会切换工具，但保留锁定。按住 Q 只切换一次，在图形的文字中按 Q 会输入 q。 |
| 使用便签或图形工具时，在获得焦点的白板或其选中的图形上按 Enter | 在选区右侧 24 px 处放置一个默认大小的图形，没有选中图形时放在视图中心，然后选中它并选择选择工具，所以下一次 Enter 会编辑它的文字。工具锁定开启时保留当前工具，所以下一次 Enter 会在它旁边再放置一个。其他不是箭头的图形的左上角正好在新图形左上角要放的位置时，依次尝试向右下方 24 px、48 px，以此类推。尝试的点都不空闲，或要存储的坐标不是有限数时，Enter 不放置任何东西，并再次播报选区。 |
| 使用框架工具时，在获得焦点的白板或其选中的图形上按 Enter | 在选中的图形周围放置一个外扩 24 px 的框架，框架会收纳完全位于其中、不在任何框架里、也没有被建议删除的每个图形（箭头和框架除外）。没有选中图形时，在视图中心放置一个默认大小的框架。然后选中新框架并选择选择工具；工具锁定开启时保留框架工具。框架要存储的坐标不是有限数，或围绕选区的框架不会收纳任何图形时，Enter 不放置任何东西，并再次播报选区。 |
| 使用箭头工具且选中一个不是箭头的图形时按 Enter | 开始连接这个图形。Tab 和 Shift+Tab 把箭头终点对准其他不是箭头的图形的中心并循环，Mod 加方向键从终点出发，把它对准该方向上最近的这类图形。方向键把终点移动 1 个单位，按住 Shift 时移动 10 个单位。终点绑定到它下方最前面的、既不是箭头也不是起始图形的图形，绑定在它所在的位置；框架只在边框上可绑定，画笔线只在线条上可绑定；不在任何这类图形上时，终点保持自由。Enter 从起始图形的中心向终点绘制箭头，选中它并选择选择工具；工具锁定开启时保留箭头工具。按 Escape、用左键或中键在白板上按下、换用其他工具、撤销或重做、按 Mod+D、删除起始图形、视图变为只读或焦点离开白板，都会停止连接且不绘制。 |
| 使用箭头工具且未选中任何图形时按 Enter | 开始绘制一个箭头，起点位于视图中心。方向键把起点移动 1 个单位，按住 Shift 时移动 10 个单位。在视图中心以及每次移动之后，起点都绑定到它下方最前面的、不是箭头的图形，绑定在它所在的位置；框架只在边框上可绑定，画笔线只在线条上可绑定；不在任何这类图形上时，起点保持自由。Tab、Shift+Tab 和 Mod 加方向键把起点对准图形的中心。Enter 保留起点并从那里开始连接，与上一行从选中图形开始连接相同，终点可以绑定到起点所在图形以外的任何图形。同样的按键和事件会停止绘制且不写入，删除起点绑定的图形也会停止。 |
| 使用箭头工具且选中多个图形时按 Enter | 通过 `shapes` 再播报一次选择，不绘制任何内容。 |
| 选中一个不是箭头的图形时按 S | 从图形的右下角开始调整大小。Tab 按顺时针移到下一个角，Shift+Tab 移到上一个角。方向键把这个角移动 1 个单位，按住 Shift 时移动 10 个单位，每边最小 8 个单位，对角保持不动。图片图形保持比例，因此在短边达到 8 时停止；短边已不足 8 的图片图形只能放大。每次按键都会显示新的方框，绑定到该图形的箭头跟随移动，但不写入。方框有变化时，Enter 把它写入，作为一步撤销。Escape、按下指针、视图变为只读、删除该图形或焦点离开白板，都会恢复原来的方框且不写入；其他任何按键也是如此，然后再执行它本来的操作。 |
| 在获得焦点的白板上按 Space | 开始挑选图形。光标从按存储顺序的第一个选中图形开始，没有选中图形时从第一个图形开始，复制的白板用虚线环标出它。Tab 和 Shift+Tab 按存储顺序在所有图形之间移动光标并循环，Mod 加方向键把它移到该方向上最近的图形，两者都不改变选区。Space 把光标所在的图形加入选区或移出选区。Enter 或 Escape 保留选区并结束挑选。按下指针、焦点离开白板或删除光标所在的图形也会结束挑选，其他任何按键也是如此，然后再执行它本来的操作。白板在 Space 松开时才响应，而且只响应在获得焦点的白板上按下、没有按住修饰键、松开前没有按过其他键也没有按下过指针的 Space，所以按住 Space 拖动仍会平移。调整大小期间，Space 只会像其他按键一样结束调整。连接或指针手势进行期间，或白板上没有图形时，Space 不做任何事。 |
| 方向键 | 把选中的图形移动 1 个单位，按住 Shift 时移动 10 个单位。连接期间，方向键改为移动正在放置的那一端。对于未选中任何图形时开始的箭头，Enter 保留起点之前移动起点，之后移动终点。调整大小期间，方向键移动正在调整的那个角。 |
| `]` 和 `[` | 把选中的图形上移或下移一层。 |
| Mod+Shift+Up 和 Mod+Shift+Down | 把选中的图形置于顶层或底层。 |
| Delete 或 Backspace | 删除选中的图形。框架会连同其中的图形一起删除。 |
| 选中图形时按 Mod+A | 选中白板上的所有图形。 |
| 在获得焦点的白板或其选中的图形上按 Mod+D | 复制选中的图形，连同选中框架中的图形，作为一个撤销步骤，并选中副本。与粘贴相同，副本落在原图形右下方 24 px 处；该位置已有其他图形时继续向右下移动。按住 Mod+D 只复制一次。没有选中图形时，可写的白板会再播报一次选区。只读白板不复制，也不播报，与其他会写入的按键相同。在可写视图中选中图形时，Mod+D 会先结束进行中的拖动或连接。在图形的文字中按 Mod+D 交给文字处理。 |
| Mod+Z，以及 Mod+Shift+Z 或 Control+Y | 撤销和重做。Control+Y 只在 Mac 以外的系统上重做。焦点跟随撤销所选中的图形。 |
| `=` 或 `+`，以及 `-` | 放大或缩小到 10、25、50、100、200、400、800 百分比中的下一级。 |
| Shift+0 | 缩放到 100%。 |
| Shift+1 | 让所有图形适配到视图中。 |
| PageDown 和 PageUp | 向下或向上平移视图的 80%，按住 Shift 时向右或向左平移。 |
| 使用选择工具拖动图形 | 指针移动超过 8 px 后，移动选中的图形以及选中框架中的图形，所以点击不会移动任何图形。在每个轴上，选中的图形会与视图中 8 个屏幕像素以内最近的其他图形或框架的边缘或中心对齐，并用一条线标出它们共有的每条边缘或中心。它们不会与箭头或笔画对齐。它们还会在同样的 8 个屏幕像素以内与旁边最近的图形等距排列：位于两个图形正中间，或与相邻两个图形已有的间距相同。两端带刻度的线标出每个相等的间距。按住 Control 或 Command 可自由移动。一次移动是一个撤销步骤。 |
| 使用选择工具时按住 Alt 拖动 | 复制被拖动的图形，副本像移动时一样对齐。副本落在其他图形所在的位置时，会像粘贴一样向右下移动 24 px。 |
| 用橡皮擦点击或拖动 | 标记经过的每个便签、图形、箭头和笔画，松开时作为一个撤销步骤删除它们。没有填充也没有标签的图形，只有路径经过其轮廓附近时才会被标记，所以空矩形里的笔画可以单独擦掉。框架永远不会被标记；要删除框架，请选中它并按 Delete。拖动中按 Escape 或换用其他工具不会删除任何内容。 |
| 使用选择工具时在白板空白处拖动 | 绘制选择框，并选中完全位于框内的所有图形。按住 Shift 会保留已选中的图形。触摸拖动则会平移。 |
| 用抓手拖动 | 从任意位置平移，在图形和正在编辑的文字上方也可以。它不会选中、移动或编辑任何内容。选中抓手时，指针显示为张开的手，自带光标的元素除外。 |
| 滚轮，或按住 Space 拖动，或用中键拖动 | 从任意位置平移，在图形上方也可以。按住 Mod 滚动滚轮会缩放。 |

在只读白板上，不改变内容的按键照常可用：Tab 和 Shift+Tab、Mod 加方向键、Mod+A、在白板上按 Enter、用 Space 挑选、Escape、Shift+Enter、工具字母、Q，以及缩放、适配和平移按键。会写入的按键不做任何事，也不播报。使用便签、图形、框架或箭头工具时，Enter 的行为与使用选择工具时相同。最后一个图形之后，Tab 会清除选区，由浏览器把焦点移出白板。

在白板之后那个块的开头按 Backspace，或在白板之前那个块的末尾按 Delete，会选中白板。再按一次 Backspace 或 Delete 会删除白板及其所有图形，一次撤销即可恢复。

## 屏幕阅读器

白板通过编辑器唯一的状态区域播报，使用你复制的白板通过 `messages` 传入的文字。这个属性是必填的，包本身不带任何英文文字。只有持有焦点的视图会播报，因此同一个白板的第二个视图不出声。返回空字符串的成员不播报。移动、调整层级和平移都不播报。

| 成员 | 用途 |
| --- | --- |
| `label` | 白板的名称，用在它的焦点目标和图形区域上。 |
| `instructions` | 焦点目标的描述，白板获得焦点时屏幕阅读器会读出它。 |
| `aim(shape, { anchor, position, side, total })` | 按键移动的箭头端点绑定到 `shape` 时播报：Tab、Shift+Tab 或 Mod 加方向键把该端点对准它的中心时，方向键把该端点移入它或在它内部移动时，以及 Mod 加方向键在该方向上找不到图形时再播报一次。`anchor` 是终点在图形中的位置，用整数百分比表示，`across` 从左边缘算起，`down` 从上边缘算起，中心为 50 和 50。在未选中图形时开始的箭头放置起点期间，`side` 为 `'start'`；按键移动箭头终点时为 `'end'`。`position` 和 `total` 给出该图形在所有图形的存储顺序中的位置。 |
| `connecting(from)` | 使用箭头工具按 Enter 开始从 `from`（唯一选中的图形）连接时播报；在未选中图形时开始的箭头中按 Enter 保留起点时也会播报，此时 `from` 是起点绑定的图形，起点不在任何图形上时为 `null`。按键放置终点期间，在方向键或目标键放下终点之前，以及终点绑定的图形被删除之后，连接都没有终点，此时按 Enter 或按下找不到图形的目标键会再播报一次。箭头长度会为零时，例如终点回到起点的位置，按 Enter 也会再播报一次，且不绘制箭头。 |
| `free(place, { side })` | 方向键把按键移动的箭头端点移到没有可绑定图形的位置时播报，带上该端点所在的白板坐标（取整）；Tab、Shift+Tab 或 Mod 加方向键找不到图形时再播报一次。`side` 是该端点，与 `aim` 相同。 |
| `starting(place, { from })` | 使用箭头工具且未选中任何图形时按 Enter 开始绘制箭头时播报，起点位于 `place`，即视图中心的白板坐标（取整）。起点绑定到该点下方的图形，与方向键移动时的绑定相同；若该移动不会绑定到任何图形，起点保持自由。`from` 是起点绑定的图形，起点自由时为 `null`。 |
| `resizing(shape, { corner, width, height })` | 按 S 从 `corner`（即右下角）开始调整 `shape` 的大小时播报，附带取整后的尺寸。按 Enter、Escape 或以其他不另行播报的方式结束调整时，白板通过 `shape` 再次播报该图形。指针按下结束调整时不播报，白板只播报这次按下本身的结果。 |
| `resize({ corner, width, height })` | 调整大小期间，Tab 或 Shift+Tab 移到另一个角时，以及方向键移动这个角时播报，附带取整后的方框尺寸。 |
| `picking(shape, { count, position, selected, total })` | 按 Space 开始挑选时播报，`shape` 是光标所在的图形。`selected` 表示该图形是否已选中，`count` 是已选中的图形数，`position` 和 `total` 给出该图形在所有图形的存储顺序中的位置。按 Enter、Escape 或以其他不另行播报的方式结束挑选时，白板通过 `shape` 或 `shapes` 再次播报选区。指针按下结束挑选时不播报，白板只播报这次按下本身的结果。 |
| `pick(shape, { count, position, selected, total })` | Tab、Shift+Tab 或 Mod 加方向键把光标移到 `shape` 时播报，Mod 加方向键在该方向上找不到图形时再播报一次，Space 把光标所在的图形加入选区或移出选区时也会播报，状态与 `picking` 相同。 |
| `shape(shape, { position, total })` | 选区变成一个图形时播报，带上它在存储顺序中的位置，例如 `Ship it, Shape. 3 of 5`。 |
| `shapes(count)` | 选区变成多个图形时播报；没有选中图形而白板再次播报选区时，以 0 调用，例如在没有图形的白板上按 Mod 加方向键之后。 |
| `tool(tool)` | 用字母键或工具栏选择工具时播报。 |
| `toolLock(locked)` | 按 Q 或调用 `setToolLocked` 开启或关闭工具锁定时播报，`locked` 表示锁定现在是否开启。 |
| `zoom(percent)` | 缩放键、`zoomIn`、`zoomOut`、`resetZoom` 或 `fit` 改变缩放比例时播报。滚轮缩放不播报。 |
| `removed(count)` | 删除完成时播报，带上从白板上移除的图形数，被删除框架中的图形也计算在内。 |

`shape`、`aim`、`connecting`、`starting`、`resizing`、`picking` 和 `pick` 收到一个 `BoardShapeDescription`。它的 `kind` 是 `note`、`geo`、`arrow`、`frame`、`stroke`，或者表示图片图形或应用自定义图形的 `shape`；它的 `text` 是图形的文字或框架的名称。箭头的 `ends` 描述两端连接的图形，自由端为 `null`。调整大小的 `corner` 是一个 `BoardCorner`，取值为 `topLeft`、`topRight`、`bottomRight` 或 `bottomLeft`；`picking` 和 `pick` 还收到一个 `BoardPickState`。复制的白板传入：

```tsx
const boardMessages: BoardMessages = {

};
```

## 用代码插入图形

每个白板命令都在 `editor.update` 内运行，不需要选区，因此同一 Yjs 文档上的 Node 代理与工具栏使用相同的调用。插入白板返回白板的 key；插入图形时指定所属白板，并返回新图形的 id。图形 id 在整个文档中唯一，所以后续命令只用 id 指定图形。

```ts
import {
  BaseBoardArrowPlugin,
  BaseBoardGeoPlugin,
  BaseBoardNotePlugin,
  BaseBoardPlugin,
} from 'platejs/board';

editor.update((tx) => {
  const board = tx.plugin(BaseBoardPlugin).insert({ height: 480 }, { at: [1] });

  if (!board) return;

  const note = tx.plugin(BaseBoardNotePlugin).insert(
    {
      children: [{ children: [{ text: 'Launch' }], type: 'paragraph' }],
      x: 120,
      y: 80,
    },
    { board }
  );
  const rect = tx
    .plugin(BaseBoardGeoPlugin)
    .insert({ geo: 'rectangle', x: 480, y: 80 }, { board });

  if (note && rect) {
    tx.plugin(BaseBoardArrowPlugin).insert({ end: rect, start: note });
  }
});
```

按 id 移动、缩放、调整层级和删除图形：

```ts
editor.update((tx) => {
  const boards = tx.plugin(BaseBoardPlugin);

  boards.move([noteId], { x: 40, y: 0 });
  boards.resize(noteId, { height: 240, width: 240, x: 160, y: 80 });
  boards.restack([noteId], 'front');
  boards.remove([rectId]);
});
```

修改样式就是在图形的 key 上写普通属性，写入的样式须是该图形类型接受的，见[值结构](#值结构)：

```ts
editor.update((tx) => {
  const shape = tx.plugin(BaseBoardPlugin).shape(rectId);

  if (shape) {
    tx.nodes.set({ fill: 'blue', strokeWidth: 'l' }, { at: shape.key });
  }
});
```

在工具栏中，`setStyle` 写入选中的图形，见[样式面板](#样式面板)。

## 添加自定义图形

`defineBoardShape` 定义一种容纳文字的图形，带有自己的属性和默认尺寸。把它和你保留的图形类型一起列入白板的 `targetPlugins`。这样它就从白板获得 id、位置和尺寸、层级、框架、箭头端点、复制粘贴、建议和同步。

```tsx
import { property } from 'platejs';
import {
  BaseBoardGeoPlugin,
  BaseBoardNotePlugin,
  BaseBoardPlugin,
  defineBoardShape,
} from 'platejs/board';

const BaseCardPlugin = defineBoardShape('card', {
  properties: { status: property.enum(['todo', 'doing', 'done'], { default: 'todo' }) },
  size: { height: 160, width: 240 },
  styles: { fill: 'blue', opacity: 1, textSize: 'm' },
});

const plugins = [
  BaseBoardPlugin.configure({
    targetPlugins: [BaseBoardNotePlugin, BaseBoardGeoPlugin, BaseCardPlugin],
  }),
  BaseBoardNotePlugin,
  BaseBoardGeoPlugin,
  BaseCardPlugin,
];
```

`tx.plugin(BaseCardPlugin).insert({ status: 'doing', x: 0, y: 0 }, { board })` 会添加一张卡片。HTML 序列化会拒绝包含自定义图形的白板，因此这样的白板请持久化 Plate 值。

## 值结构

白板块和其他块一样位于文档中，只包含一个空文本。它的图形位于 `childRoots.shapes` 指定的内容根中，是该根的顶层块。白板的 `insert` 在一次变更中创建块及其根，并为根命名，因此应用代码从不需要为根命名。

```ts
const value = {
  children: [
    {
      childRoots: { shapes: 'board:k3f9' },
      children: [{ text: '' }],
      height: 480,
      type: 'board',
    },
  ],
  roots: {
    'board:k3f9': [
      {
        children: [{ children: [{ text: 'Launch' }], type: 'paragraph' }],
        place: { x: 40, y: 30 },
        shapeId: 'n1',
        size: { height: 160, width: 200 },
        type: 'boardNote',
        zIndex: 'a1',
      },
    ],
  },
};
```

| 属性 | 图形 | 说明 |
| --- | --- | --- |
| `shapeId` | 全部 | 在整个文档中唯一。每次粘贴、拖放和复制都会给副本新 id。 |
| `zIndex` | 全部 | 决定绘制顺序的分数键。框架绘制在其他图形之后。 |
| `place` | 除箭头外 | `{ x, y }`。在框架内时还包含 `frame` 和 `frameOrigin`，`x` 和 `y` 从框架起算。框架自己的 `place` 包含它的 `origin`。 |
| `size` | 除箭头外 | `{ width, height }`。 |
| `start`、`end` | 箭头 | 绑定到图形的端点是 `{ shape, anchor, x, y }`，自由端点是 `{ x, y }`。`x` 和 `y` 保存该端点上次绘制的位置。 |
| `points` | 笔迹 | 扁平的 `[x, y, pressure]` 三元组，每个值都是笔迹框内的比例。 |
| `fill` | 便签和几何图形 | 表示无填充的 `'none'`、颜色名称或任意 CSS 颜色。便签默认 `'yellow'`，几何图形默认 `'none'`。 |
| `strokeColor` | 几何图形、箭头和笔迹 | 颜色名称或任意 CSS 颜色。默认 `'currentColor'`，即文字颜色。 |
| `dash` | 几何图形和箭头 | `'solid'`、`'dashed'` 或 `'dotted'`。默认 `'solid'`。 |
| `strokeWidth` | 几何图形和箭头 | `'s'`、`'m'`、`'l'` 或 `'xl'`。默认 `'m'`。 |
| `opacity` | 除框架和图片图形外 | 0.1 到 1 之间的数。默认 1。 |
| `textSize` | 便签、几何图形和箭头 | `'s'`、`'m'`、`'l'` 或 `'xl'`。默认 `'m'`，箭头默认 `'s'`。 |
| `geo` | 几何图形 | 取值为 `'rectangle'`、`'ellipse'`、`'diamond'` 或 `'triangle'`。 |
| `name` | 框架 | 显示在框架上方。 |
| `children` | 图片图形 | 最多一个 `image` 元素，其 `url` 和 `alt` 由 `ImagePlugin` 保存；编辑器安装了 `UploadPlugin` 时，也可以是一个上传草稿。 |

复制的白板用一个浅色值和一个深色值绘制颜色名称 `blue`、`green`、`grey`、`orange`、`red`、`violet` 和 `yellow`，其他字符串按 CSS 颜色绘制。HTML 把每种样式保存在一个 `data-board-` 属性中，例如 `data-board-stroke-width`。

相机、工具、工具锁定、下一个样式、选区控制点和进行中的手势都不会被存储。

## 协作

每个图形都是文档中的块，因此 `YjsPlugin` 无需额外配置即可同步白板。两人修改同一图形的不同属性时，例如一人移动、一人改色，两项修改都会保留。拖动在松开时作为一次变更发给协作者。

### 在已有 Yjs 房间的应用中添加白板

添加白板会增加元素类型，因此会改变应用的 schema identity。Yjs 房间保留其创建时的 schema identity，所以带白板的编辑器会拒绝加入在此之前写入的房间。它会报 `Yjs schema mismatch` 错误；如果应用没有声明 `schema`，则报 `Yjs derived schema mismatch`。把每个房间的文档迁移到新房间：

<Steps>

### 提升 schema 版本

为新版本添加一个迁移步骤。只增加元素类型的步骤原样返回文档。按[文档迁移](/docs/editor#document-migrations)所示，把迁移脚手架给出的版本 3 指纹登记到 `sourceFingerprints`。

```ts title="src/editor.ts"
import { defineDocumentMigrations } from 'platejs/migrations';

import { BoardKit } from '@/components/editor/board';
import { EditorKit } from '@/components/editor/plugins';

import { fingerprint as v3Fingerprint } from './migrations/v4-add-board/from';

export const EditorPlugins = [...EditorKit, ...BoardKit];

export const EditorSchema = { id: 'acme-document', version: 4 } as const;

export const EditorMigrations = defineDocumentMigrations({
  plugins: EditorPlugins,
  schema: EditorSchema,
  sourceFingerprints: { 3: v3Fingerprint },
  steps: { 4: ({ document }) => ({ document }) },
});
```

### 迁移旧房间的文档

从绑定到旧房间、使用旧插件和旧 schema 的编辑器读取文档及其 schema identity，然后迁移。

```ts
import { migrateDocument } from 'platejs/migrations';

const current = migrateDocument(
  {
    document: oldEditor.read.value(),
    schema: oldEditor.read.schema.identity(),
  },
  { migrations: EditorMigrations }
).output;
```

### 为新房间写入初始内容

用迁移后的文档创建新房间的编辑器。只把 `seed: true` 交给一个编辑器，即应用选定来填充这个新空房间的那个。

```tsx
import { createEditor } from 'platejs/react';
import { YjsPlugin } from 'platejs/yjs/react';

const editor = createEditor({
  initialValue: current,
  plugins: [
    ...EditorPlugins,
    YjsPlugin.create({
      doc: newRoomDocument,
      initialReady: true,
      rootName: newRoomId,
      seed: true,
    }),
  ],
  schema: EditorSchema,
});
```

</Steps>

其他协作者使用新插件和新 schema 加入新房间，且不传 `seed`。参见 [Yjs](/cn/docs/yjs) 和[文档迁移](/cn/docs/editor#文档迁移)。

## 限制

- 查找只搜索页面，不搜索便签中的文字。Word 导出会略去便签文字上的评论，并报告 `comment-range` 警告。
- 在便签文字上，复制的工具栏里的标记、颜色、高亮和评论按钮以及 AI 菜单作用于便签，见[工具栏](/docs/toolbar#act-on-the-view-that-holds-the-selection)。其他按钮（例如插入、转换、列表和链接）作用于页面。
- 不能在便签内移动段落。移动整个图形会保留其文字。
- 撤销移动会放回你原来的位置，即使协作者之后移动过同一图形。
- 便签很长时会变慢，因为一个便签的所有行作为一个单元同步。
- 每次按键都要为文档中的每个白板做一些工作，因此一个文档最好不超过 100 个白板。
- Markdown 按存储顺序保留图形的文字和图片，并报告它丢弃的内容，例如位置和箭头端点。要完整保存白板，请持久化 Plate 值；白板只含内置图形时，也可以持久化 HTML。
- 粘贴或拖放到白板上的图片文件不会成为图片图形。请粘贴图片的链接，或用代码插入。
- 图形属性若与样式标记的键同名，例如 `color`、`backgroundColor`、`fontSize` 或 `fontFamily`，安装该标记的插件后也会改变图形文字的样式。请给属性换个名字，就像便签用 `fill` 一样。
- 不支持便签内的白板、旋转和裁剪图片，复制的白板也不会在图片下方绘制图注。
- 用画笔绘制需要指针。用键盘调整大小时只有图片图形保持比例，也不能围绕中心调整，而拖动角时按住 Shift 和 Alt 可以做到。
- 任何按键或指针手势都不能把箭头已绑定的端点移离它的图形，也不能同时调整多个图形的大小。移动选中的箭头会移动它的自由端点，每个已绑定的端点仍留在它的图形上。
- 在白板页面中，白板仍是文档中的一个块。选中白板时按 Delete 或 Backspace 会删除它及其图形，撤销可以恢复白板。安装了[退出块结构](/docs/exit-break)时，光标在白板上（Mod+A 可能把光标放在那里）按 Mod+Enter 会在白板后添加一个段落，它在视野之外。

## 插件

### `BoardPlugin`

白板块，一个拥有图形内容根的 void 元素。`targetPlugins` 列出白板容纳的图形类型，默认是下面六种。

### `BoardNotePlugin`、`BoardGeoPlugin`、`BoardArrowPlugin`、`BoardFramePlugin`、`BoardStrokePlugin`

各图形类型：`boardNote`、`boardGeo`、`boardArrow`、`boardFrame` 和 `boardStroke`。框架和笔迹是 void；便签、几何图形和箭头容纳块。

### `BoardImagePlugin`

图片图形 `boardImage`：最多容纳一个 `image` 元素或上传草稿的对象块。请同时安装 `ImagePlugin`。编辑器安装它却既没有 `ImagePlugin` 也没有 `UploadPlugin` 时，会抛出一个同时提到两者的错误。
