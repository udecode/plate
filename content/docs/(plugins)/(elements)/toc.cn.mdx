## 功能特性

- 自动从文档标题生成目录
- 按标题级别 1 到 6 缩进每个条目
- 平滑滚动至标题位置

TOC 使用 editor 作用域内的 `NodeKey` 跟踪标题。它不需要持久化元素 ID，
也不会安装 `ElementIdPlugin`。

</PackageInfo>

## 套件使用

<Steps>

### 安装

最快捷的目录功能添加方式是使用 `TocKit`，它已预配置了 [Plate UI](/docs/installation/plate-ui) 组件的 `TocPlugin`。

<ComponentSource name="toc" />

- [`TocElement`](/docs/components/toc): 渲染目录元素

### 添加套件

将套件加入插件列表：

```tsx
import { createEditor } from 'platejs/react';
import { TocKit } from '@/components/editor/toc';

const editor = createEditor({
  plugins: [
    // ...其他插件
    ...TocKit,
  ],
});
```

</Steps>

## 手动配置

<Steps>

### 安装

```bash
npm install platejs
```

### 添加插件

在创建编辑器时，将 `TocPlugin` 和 `HeadingPlugin` 加入 Plate 插件数组。

```tsx
import { TocPlugin } from 'platejs/toc/react';
import { HeadingPlugin } from 'platejs/react';
import { createEditor } from 'platejs/react';

const editor = createEditor({
  plugins: [
    // ...其他插件
    HeadingPlugin,
    TocPlugin,
  ],
});
```

### 配置插件

使用自定义组件和滚动选项配置 `TocPlugin`。

```tsx
import { TocPlugin } from 'platejs/toc/react';
import { HeadingPlugin } from 'platejs/react';
import { createEditor } from 'platejs/react';
import { TocElement } from '@/components/editor/toc';
import { HeadingElement } from '@/components/editor/heading';

const editor = createEditor({
  plugins: [
    // ...其他插件
    HeadingPlugin.configure({ component: HeadingElement }),
    TocPlugin.configure({
      component: (props) => <TocElement {...props} topOffset={80} isScroll />,
    }),
  ],
});
```

- `.configure({ component })`: 指定渲染目录元素的 [`TocElement`](/docs/components/toc)
- `TocElement.topOffset`: 设置滚动至标题时的顶部偏移量
- `TocElement.isScroll`: 启用滚动至标题的行为

### 添加工具栏按钮

可将此项加入[插入工具栏按钮](/docs/toolbar#insert-toolbar-button)来插入目录元素：

```tsx
{
  icon: <TableOfContentsIcon />,
  label: '目录',
  value: PLUGINS.toc,
}
```

### 滚动容器设置

使用 [EditorContainer](/docs/components/editor) 作为编辑器的滚动区域。
对于自定义布局，在 `<EditorRoot>` 内渲染 `EditorContainer` 并为其添加滚动样式。
`EditorContainer` 会将该区域注册到编辑器。

```tsx
import { EditorContainer, EditorContent } from 'platejs/react';

function Layout() {
  return (
    <EditorContainer className="h-[600px] overflow-y-auto">
      <EditorContent />
    </EditorContainer>
  );
}
```

</Steps>

## 自定义标题列表

复制的 `TocElement`、静态的 `TocElementStatic` 和 Word 导出都渲染插件的
[`read.headings()`](#editorplugintocpluginreadheadings)。要改变它们列出的标题，扩展插件的
read，并过滤插件自身的标题查找函数 [`readTocHeadings`](#readtocheadings)。这样一个应用插件就能同时用于实时套件、静态套件和 Word 导出。把它放在只导入
`platejs/toc` 的模块里，这样服务端渲染的静态套件也能导入它。

```ts title="components/editor/app-toc-plugin.ts"
import { BaseTocPlugin, readTocHeadings } from 'platejs/toc';

export const AppTocPlugin = BaseTocPlugin.extend({
  read: ({ editor, state }) => ({
    headings: () =>
      readTocHeadings({ editor, state }).filter((heading) => heading.level <= 3),
  }),
});
```

在客户端 `toc` 文件中用它替换 `TocPlugin`：

```tsx title="components/editor/toc.tsx"
import { toReactPlugin } from 'platejs/react';
import { AppTocPlugin } from '@/components/editor/app-toc-plugin';

export const TocKit = [
  toReactPlugin(AppTocPlugin).configure({ component: TocElement }),
];
```

在 `toc-static` 中用它替换 `BaseTocPlugin`：

```tsx title="components/editor/toc-static.tsx"
import { AppTocPlugin } from '@/components/editor/app-toc-plugin';

export const BaseTocKit = [
  AppTocPlugin.configure({ component: TocElementStatic }),
];
```

把 read 收到的 `editor` 和 `state` 传给 `readTocHeadings`，这样静态渲染或文档视图会列出它自己的标题。查找函数遍历
`state`，但通过 `editor` 的标题插件读取每个级别，所以两者必须来自同一次 read。

## 插件

### `TocPlugin`

目录元素插件。它没有选项；它的
[`read.headings()`](#editorplugintocpluginreadheadings) 列出标题，
[read 覆盖](#自定义标题列表)可以改变它们。

### `TocElement`

滚动选项由复制的视图配置；标题列表由 `TocPlugin` 提供。

<API name="TocElement">
<APIOptions>
  <APIItem name="isScroll" type="boolean" optional>
    启用滚动行为
    - **默认值:** `true`
  </APIItem>
  <APIItem name="topOffset" type="number" optional>
    滚动至标题时的顶部偏移量
    - **默认值:** `80`
  </APIItem>
</APIOptions>
</API>

## API 参考

### `editor.plugin(TocPlugin).read.headings`

按文档顺序列出文档中的标题。复制的 TOC 渲染这个列表，静态 TOC 和 Word 导出通过 `BaseTocPlugin` 读取它。

<API name="editor.plugin(TocPlugin).read.headings">
<APIReturns type="Heading[]">
  每个有文本的标题对应一个条目。
</APIReturns>
</API>

### `readTocHeadings`

插件自身的标题查找函数，导出后 read 覆盖可以过滤它。未安装标题插件时返回
`[]`，并跳过没有文本的标题。

```ts
import { readTocHeadings } from 'platejs/toc';
```

<API name="readTocHeadings">
<APIParameters>
  <APIItem name="editor" type="Editor">
    用其标题插件读取每个级别的编辑器，与 `state` 来自同一次 read。
  </APIItem>
  <APIItem name="state" type="EditorStateView">
    要遍历的文档，即插件 read 收到的 `state`。
  </APIItem>
</APIParameters>
<APIReturns type="Heading[]">
  每个有文本的标题对应一个条目，按文档顺序排列。
</APIReturns>
</API>

### `Heading`

一个目录条目。

<API name="Heading">
<APIAttributes>
  <APIItem name="key" type="NodeKey">
    标题在 editor 作用域内的 key，从不随文档保存。
  </APIItem>
  <APIItem name="level" type="HeadingLevel">
    标题级别，`1` 到 `6`。
  </APIItem>
  <APIItem name="title" type="string">
    标题的文本。
  </APIItem>
</APIAttributes>
</API>

## 转换器

### `editor.plugin(BaseTocPlugin).update.insert`

插入目录元素。

```ts
import { BaseTocPlugin } from 'platejs/toc';

editor.plugin(BaseTocPlugin).update.insert();
```

<API name="editor.plugin(BaseTocPlugin).update.insert">
<APIOptions type="object<Editor>">
    节点插入选项
</APIOptions>
</API>

## Registry UI

复制的 [`toc`](/docs/components/toc) 组件负责滚动和导航反馈。
这些面向产品的交互选择放在 renderer 旁边；package plugin 通过
`editor.plugin(TocPlugin).read.headings()` 负责标题发现。
