## 功能

- 清理并规范化从 Microsoft Word 粘贴的 HTML 和 RTF
- 导入 `.docx` 文件，并返回批注和转换警告
- 使用调用方提供的样式、页面设置、表格、列表和图片导出 DOCX

<Callout type="info" title="客户端边界">
  粘贴、文件导入和文件下载都使用浏览器 API，请在客户端代码中执行。DOCX
  导出还使用 React 静态渲染，因此应传入定义文档输出的相同插件描述符和静态组件。

## 所有权

| API | 导入路径 | 用途 |
| --- | --- | --- |
| `DocxPlugin` | `platejs/docx` | 内联粘贴的 CSS，并规范化 Word HTML/RTF |
| `importDocx` | `platejs/docx/import` | 将 DOCX 缓冲区转换为节点、批注和警告 |
| `exportToDocx` | `platejs/docx/export` | 将 Plate 节点转换为 DOCX Blob |
| Registry `DocxKit` | 应用内复制代码 | 安装粘贴插件 |
| Registry `DocxExportKit`、`DOCX_EXPORT_STYLES` | 应用内复制代码 | 提供 DOCX 静态渲染器和视觉样式 |

粘贴入口需要 `juice` 和 `validator`；文件导入需要 `mammoth` 和 `validator`；文件导出需要 HTML-to-DOCX 转换依赖。可在用户选择文件操作时动态加载导入和导出函数。

## Kit 用法

应用内的 `DocxKit` 安装 `DocxPlugin`，在 Plate 解码前内联粘贴内容中的 CSS。文件导入和导出使用独立函数。

## 从 Word 粘贴

添加 `DocxPlugin` 来处理剪贴板输入。它会保留 Word 和普通 HTML 粘贴中的 CSS，再规范化 Word 特有的结构。

```bash
npm install platejs @tanstack/react-virtual juice validator
```

```tsx title="components/editor/editor.tsx"
import { DocxPlugin } from "platejs/docx";
import { createEditor } from "platejs/react";

const editor = createEditor({
  plugins: [DocxPlugin],
});
```

安装后，`DocxPlugin` 会检测剪贴板中的 Word HTML，清理 HTML 和 RTF，再交由已安装的 Plate codecs 解码。

## 导入 DOCX

`importDocx` 将 DOCX `ArrayBuffer` 转换为节点、批注和警告，不会修改编辑器。编辑器中已安装的 HTML codecs 决定最终的 Plate 节点；无需安装 DOCX 插件。

```bash
npm install platejs @tanstack/react-virtual mammoth validator
```

```tsx title="components/editor/editor.tsx"
import { importDocx } from "platejs/docx/import";
import { createEditor } from "platejs/react";
import { BaseEditorKit } from "@/components/editor/plugins-static";

const editor = createEditor({
  plugins: BaseEditorKit,
});

export async function importFile(file: File) {
  const result = await importDocx(editor, await file.arrayBuffer());

  editor.update.fragment.replace(result.nodes);

  return {
    comments: result.comments,
    warnings: result.warnings,
  };
}
```

每条批注都包含 Word 批注 `id`、提取的 `text`，以及指向返回节点快照的 `references`。

## 导出 DOCX

向 `exportToDocx` 传入文档快照和静态渲染选项。应用负责下载文件名和浏览器下载操作。

```bash
npm install platejs @tanstack/react-virtual color-name html-to-vdom jszip juice mime-types virtual-dom xmlbuilder2
```

```tsx title="components/editor/export-docx.tsx"
import { exportToDocx } from "platejs/docx/export";
import { createEditor } from "platejs/react";
import { BaseEditorKit } from "@/components/editor/plugins-static";
import {
  DOCX_EXPORT_STYLES,
  DocxExportKit,
} from "@/components/editor/docx-export";

const editor = createEditor({ plugins: BaseEditorKit });

export async function downloadEditorDocx() {
  const blob = await exportToDocx(editor.read.value().children, {
    editorPlugins: [...BaseEditorKit, ...DocxExportKit],
    orientation: "portrait",
    stylesheet: DOCX_EXPORT_STYLES,
    title: "Document",
  });
  const url = URL.createObjectURL(blob);
  const link = document.createElement("a");
  link.href = url;
  link.download = "document.docx";
  document.body.append(link);
  link.click();
  link.remove();
  URL.revokeObjectURL(url);
}
```

### DOCX Export Kit

应用内的 `DocxExportKit` 为代码块、分栏、公式、Callout、标题和目录提供静态渲染器。`DOCX_EXPORT_STYLES` 是复制到应用内的展示样式预设；省略 `stylesheet` 时，转换器仅使用文档格式默认值，不应用 Plate 主题。

## API 参考

### `platejs/docx`

此入口导出 `DocxPlugin`。转换函数及其选项和结果类型分别位于 `platejs/docx/import` 和 `platejs/docx/export`。

### `importDocx`

`importDocx(editor, arrayBuffer, options?)` 返回 `nodes`、`comments` 和 `warnings`。`options.rtf` 可接收与文件内容匹配的 RTF 数据。

### `exportToDocx`

`exportToDocx(value, options?)` 根据传入的文档快照返回 DOCX `Blob`。选项包括 `allowRemoteImages`、`editorPlugins`、`editorStaticComponent`、`fontFamily`、`margins`、`orientation`、`pageSize`、`stylesheet` 和 `title`。`stylesheet` 是转换前应用的完整 CSS 样式表。

`allowRemoteImages` 默认为 `false`；只有显式启用时才会获取远程 HTTP 图片。
