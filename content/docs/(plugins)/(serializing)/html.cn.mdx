使用 `renderStaticHtml` 把配置好的静态 Plate React tree 渲染为 HTML。使用 `editor.api.html.deserialize(...)` 把 HTML 解析为 Plate content。这两个方向由不同的 API 负责。

## 套件使用

<Steps>

### 安装

启用HTML序列化的最快方式是使用`BaseEditorKit`，它包含预配置的基础插件，支持大多数常见元素和标记的HTML转换。

<ComponentSource name="editor-base-kit" />

### 添加套件

```tsx
import { createBaseEditor } from 'platejs';
import { renderStaticHtml } from 'platejs/static';
import { BaseEditorKit } from '@/components/editor/editor-base-kit';

const editor = createBaseEditor({
  plugins: BaseEditorKit,
  initialValue: [
    { type: 'h1', children: [{ text: 'Hello World' }] },
    { type: 'p', children: [{ text: '此内容将被序列化为HTML。' }] },
  ],
});

// 序列化为HTML
const html = await renderStaticHtml(editor);
```

## Plate转HTML

将Plate编辑器内容（Plate节点）转换为HTML字符串。这通常在服务端完成。

[查看服务端示例](/docs/examples/plate-to-html)

<Callout type="warning" title="关键服务端限制">
  在服务端环境（Node.js, RSC）中使用`renderStaticHtml`或其他Plate工具时，**不得**从任何`platejs*`包的`/react`子路径导入。始终使用基础导入（例如使用`@platejs/basic-nodes`而非`@platejs/basic-nodes/react`）。

  这意味着服务端编辑器实例应使用`platejs`中的`createBaseEditor`，而非`platejs/react`中的`usePlateEditor`或`createPlateEditor`。
</Callout>

<Steps>

### 基础用法

提供服务端编辑器实例并在编辑器创建时配置Plate组件。

```tsx title="lib/generate-html.ts"
import { createBaseEditor } from 'platejs';
import { renderStaticHtml } from 'platejs/static'; // 静态导入
// 导入服务端安全的 registry kit（不从 /react 包路径导入）
import { BaseBasicBlocksKit } from '@/components/editor/plugins/basic-blocks-base-kit';
// 导入用于渲染的静态组件
import { ParagraphElementStatic } from '@/components/ui/paragraph-node-static';
import { HeadingElementStatic } from '@/components/ui/heading-node-static';
// 对于带样式的静态输出，可以使用像EditorStatic这样的包装器
import { EditorStatic } from '@/components/ui/editor-static';

// 将插件键映射到其静态渲染组件
const components = {
  p: ParagraphElementStatic, // 'p'是段落的默认键
  h1: HeadingElementStatic,
  // ... 为所有元素和标记添加映射
};

// 创建带组件的服务端编辑器实例
const editor = createBaseEditor({
  plugins: [
    ...BaseBasicBlocksKit, // 段落、标题、引用和分隔线基础插件
    // ... 添加与内容相关的所有其他基础插件
  ],
  components,
  initialValue: [
    { type: 'h1', children: [{ text: '我的标题' }] },
    { type: 'p', children: [{ text: '我的内容。' }] },
  ],
});

async function getMyHtml() {
  const html = await renderStaticHtml(editor, {
    // 可选：使用像EditorStatic这样的自定义包装器进行样式设置
    // editorComponent: EditorStatic,
    // props: { variant: 'none', className: 'p-4 m-4 border' },
  });

  return html;
}
```

### 序列化HTML的样式设置

`renderStaticHtml`仅返回静态 React tree 渲染出的HTML。如果使用带样式的组件（如`EditorStatic`或具有特定类的自定义静态组件），必须确保最终显示HTML的上下文中包含必要的CSS。

这通常意味着将序列化的HTML包装在包含样式表的完整HTML文档中：

```tsx title="lib/generate-full-html-document.ts"
// ...（来自generate-html.ts的先前设置）

async function getFullHtmlDocument() {
  const editorHtmlContent = await getMyHtml(); // 来自之前的示例

  const fullHtml = `<!DOCTYPE html>
  <html>
    <head>
      <meta charset="UTF-8">
      <meta name="viewport" content="width=device-width, initial-scale=1.0">
      <link rel="stylesheet" href="/path/to/your-global-styles.css" />
      <link rel="stylesheet" href="/path/to/tailwind-or-component-styles.css" />
      <title>序列化内容</title>
    </head>
    <body>
      <div class="my-document-wrapper prose dark:prose-invert">
        ${editorHtmlContent}
      </div>
    </body>
  </html>`;
  return fullHtml;
}
```

<Callout type="info" title="仅静态输出">
  序列化过程将Plate节点转换为静态HTML。交互功能（React事件处理程序、客户端钩子）或依赖浏览器API的组件在序列化输出中将无法工作。
</Callout>

### 使用静态组件

对于服务端序列化，**必须**使用组件的静态版本（无仅客户端代码，无React钩子如`useEffect`或`useState`）。

参考[静态渲染指南](/docs/static)获取为Plate元素和标记创建服务端安全静态组件的详细说明。

```tsx title="components/ui/paragraph-node-static.tsx"
import React from 'react';
import type { PliteElementProps } from 'platejs/static';

// 示例静态段落组件
export function ParagraphElementStatic(props: PliteElementProps) {
  return (
    <PliteElement {...props} className={cn('m-0 px-0 py-1')}>
      {props.children}
    </PliteElement>
  );
}
```

</Steps>

## HTML转Plate

HTML反序列化器允许将HTML内容（字符串或DOM元素）转换回Plate格式。这支持往返转换，在存在对应插件规则的情况下保留结构、格式和属性。

<Steps>

### 基础用法

在客户端 Plate 编辑器中调用根级 HTML API。

```tsx title="components/my-html-importer.tsx"
import { usePlateEditor } from 'platejs/react';
// 导入表示HTML内容所需的所有Plate插件
import { BasicBlocksKit } from '@/components/editor/plugins/basic-blocks-kit';
// ... 以及粗体、斜体、表格、列表等的插件

function MyHtmlImporter({ htmlString }: { htmlString: string }) {
  const editor = usePlateEditor({
    plugins: [
      ...BasicBlocksKit, // 用于段落、标题、引用和分隔线
      // ... 包含与预期解析的HTML对应的所有插件
    ],
  });

  const handleImport = () => {
    const value = editor.api.html.deserialize({ element: htmlString });

    if (!value) return;

    editor.update.value.replace({ children: value });
  };

  // ... 渲染编辑器及触发handleImport的按钮 ...
  return <button onClick={handleImport}>导入HTML</button>;
}
```

<Callout type="warning" title="客户端操作">
  使用 `editor.api.html.deserialize` 的HTML反序列化通常是客户端操作，因为它使用已编译的 Plate plugin model。
</Callout>

Context-bound `defineCodecs` 返回的同一个 `'text/html'` map 同时负责 decode
和 encode。

### `defineCodecs`

包作者在应用最终调用 `.configure()` 之前，通过 constructor 的 `codecs`
callback 声明节点级 HTML 含义。解构 context-bound 的 `defineCodecs`，并传入
MIME-keyed map。它是插件 schema 和 codec callback 唯一的 inline inference anchor：

- `match` 是非空的标签、class、attribute 或 style matcher 数组。
- `decode` 只返回插件拥有的值或属性。Element codec 不返回 `type`；
  Plate 使用已安装插件解析后的类型。
- `encode` 为 mark 返回 wrapper，为 element 返回完整 node spec，
  为 element property 返回 attribute/style patch。
- 仅导入的映射显式设置 `decodeOnly: true`。
- `priority` 处理有意的重叠。相同优先级的排他声明会让 model 编译失败，
  不依赖插件数组顺序。
- 一个插件拥有多个 HTML 表示时，可以提供非空有序 rule tuple。该 tuple 保持在
  同一个 codec map 中。

下面的 element codec 把 `<aside>` 映射为 callout，并保留应用配置的存储类型：

```tsx title="lib/callout-plugin.ts"
import { property, schema } from 'platejs';
import { createPlatePlugin } from 'platejs/react';

const CalloutPlugin = createPlatePlugin({
  codecs: ({ defineCodecs }) =>
    defineCodecs({
      'text/html': {
        decode: ({ element }) => ({
          variant: element.dataset.variant || undefined,
        }),
        encode: ({ content, node }) => ({
          attributes: { 'data-variant': node.variant },
          children: content,
          tag: 'aside',
        }),
        match: [{ tag: 'aside' }],
      },
    }),
  key: 'callout',
  schema: {
    element: {
      content: schema.content.text({ default: 'text', min: 1 }),
      properties: {
        variant: property.string(),
      },
    },
  },
  type: 'callout',
});

export const NotePlugin = CalloutPlugin.configure({ type: 'note' });
```

`NotePlugin` 将 `<aside>` 解码为 `note` element，因为 codec 指向已安装的
descriptor，而不是硬编码的类型字符串。

Self/product codec 使用 `defineCodecs(map)`。向另一个 descriptor 贡献 HTML
行为时使用 `defineCodecs(TargetPlugin, map)`；helper 会把 target 注入每个
rule。不要在 rule 中手动添加 `target`。一个插件的多个 HTML 表示应保留在同一个
map 的非空有序 `'text/html'` tuple 中。

### 完整输入 HTML 钩子

需要整个输入 payload 时，使用扁平的 `parsers.html.query`、
`transformData` 和 `transformFragment`。这些钩子在节点 decode 前后运行，
不声明节点 matcher。

```ts title="lib/html-cleanup-plugin.ts"
const HtmlCleanupPlugin = createPlatePlugin({
  key: 'htmlCleanup',
  parsers: {
    html: {
      query: ({ source }) => source.types.includes('text/html'),
      transformData: ({ data }) =>
        data.replaceAll(/<!--(?:Start|End)Fragment-->/g, ''),
    },
  },
});
```

## API 参考

### `renderStaticHtml(editor, options)`

将 `editor.children`（或提供的 `value`）中的 Plate 节点转换为 HTML 字符串。此函数通常在服务端使用。

<API name="renderStaticHtml">
<APIParameters>
  <APIItem name="editor" type="PlateEditor">
    通过 `createBaseEditor` 创建的服务端 Plate 编辑器实例，已配置组件。
  </APIItem>
  <APIItem name="options" type="RenderStaticHtmlOptions" optional>
    静态 React 渲染选项。
  </APIItem>
</APIParameters>
<APIOptions type="RenderStaticHtmlOptions<P = PlateStaticProps>">
  <APIItem name="editorComponent" type="React.ComponentType<P>" optional>
    用于在静态渲染期间包装整个编辑器内容的 React 组件。默认为 `PlateStatic`。
    该组件接收 `editor` 以及此处传递的任何 `props`。
  </APIItem>
  <APIItem name="props" type="Partial<P>" optional>
    传递给 `editorComponent` 的 props。`P` 默认为 `PlateStaticProps`。
  </APIItem>
  <APIItem name="preserveClassNames" type="string[]" optional>
    `stripClassNames` 为 true 时保留的 class name 前缀。
  </APIItem>
  <APIItem name="stripClassNames" type="boolean" optional>
    如果为 `true`，则从输出 HTML 中删除所有类名，但保留 `preserveClassNames` 中列出的前缀。默认值：`false`。
  </APIItem>
  <APIItem name="stripDataAttributes" type="boolean" optional>
    如果为 `true`，则从输出 HTML 中删除所有 `data-*` 属性。默认值：`false`。
  </APIItem>
</APIOptions>
<APIReturns>
  <APIItem type="Promise<string>">
    解析为序列化 HTML 字符串的 Promise。
  </APIItem>
</APIReturns>
</API>

### `editor.api.html.deserialize(options)`

将 HTML 字符串或 `HTMLElement` 解析为 Plate `Value`（`Descendant` 节点数组）。这通常在客户端与完全配置的 Plate 编辑器一起使用。

<API name="editor.api.html.deserialize">
<APIParameters>
  <APIItem
    name="options"
    type="{ element: HTMLElement | string; collapseWhiteSpace?: boolean }"
  >
    反序列化选项。
  </APIItem>
</APIParameters>
<APIOptions>
  <APIItem name="element" type="HTMLElement | string">
    要反序列化的 HTML 字符串或 `HTMLElement`。
  </APIItem>
  <APIItem name="collapseWhiteSpace" type="boolean" optional>
    如果为 `true`（默认值），则像浏览器处理 HTML 中的空白一样折叠文本节点中的空白。设置为 `false` 以保留所有空白。默认值：`true`。
  </APIItem>
</APIOptions>
<APIReturns>
  <APIItem type="Descendant[] | null">
    反序列化的 Plate `Value`；当编译后的 HTML decoder 拒绝无效或不支持的
    结果时返回 `null`。
  </APIItem>
</APIReturns>
</API>
