Paste Word content with `DocxPlugin`, import files with `importDocx`, and export document snapshots with `exportToDocx`. Each operation has its own entrypoint.

<PackageInfo>

## Features

- Normalize HTML and RTF pasted from Microsoft Word
- Import `.docx` files with comments and conversion warnings
- Export Plate content with an application stylesheet, page settings, tables, lists, and images

</PackageInfo>

<Callout type="info" title="Client boundary">
  Paste, file import, and file download use browser APIs. Keep these operations
  in client code. DOCX export also uses React static rendering, so pass the same
  plugin descriptors and static components that define your document output.
</Callout>

## Ownership

| Surface | Import path | Use it for |
| --- | --- | --- |
| `DocxPlugin` | `platejs/docx` | Inline pasted CSS and normalize Word HTML/RTF |
| `importDocx` | `platejs/docx/import` | Convert a DOCX buffer into nodes, comments, and warnings |
| `exportToDocx` | `platejs/docx/export` | Convert Plate nodes into a DOCX blob |
| Registry `DocxKit` | App-local copied code | Install the paste plugin |
| Registry `DocxExportKit`, `DOCX_EXPORT_STYLES` | App-local copied code | Provide DOCX static renderers and presentation |

The paste entrypoint requires `juice` and `validator`. File import requires `mammoth` and `validator`; file export requires its HTML-to-DOCX dependencies. Import and export can be loaded dynamically when the user chooses a file action.

## Kit usage

The app-local `DocxKit` installs `DocxPlugin`, which inlines pasted CSS before Plate decodes it. File import and export are standalone functions.

## Paste from Word

Add `DocxPlugin` for clipboard input. It preserves CSS from both Word and ordinary HTML paste, then normalizes Word-specific structure.

```bash
npm install platejs @tanstack/react-virtual juice validator
```

```tsx title="components/editor/editor.tsx"
import { DocxPlugin } from "platejs/docx";
import { createEditor } from "platejs/react";

const editor = createEditor({
  plugins: [DocxPlugin],
});
```

Once installed, `DocxPlugin` detects Word HTML in clipboard data, cleans the HTML and RTF, and lets the installed Plate codecs decode the result.

## Import DOCX

`importDocx` converts a DOCX `ArrayBuffer` into nodes, comments, and warnings without modifying the editor. The editor's installed HTML codecs determine the resulting Plate nodes; no DOCX plugin is required.

```bash
npm install platejs @tanstack/react-virtual mammoth validator
```

```tsx title="components/editor/editor.tsx"
import { importDocx } from "platejs/docx/import";
import { createEditor } from "platejs/react";
import { BaseEditorKit } from "@/components/editor/plugins-static";

const editor = createEditor({
  plugins: BaseEditorKit,
});

export async function importFile(file: File) {
  const result = await importDocx(editor, await file.arrayBuffer());

  editor.update.fragment.replace(result.nodes);

  return {
    comments: result.comments,
    warnings: result.warnings,
  };
}
```

Each imported comment contains its Word comment `id`, extracted `text`, and `references` into the returned node snapshot.

## Export DOCX

Pass a document snapshot and its static rendering options to `exportToDocx`. The application owns the download filename and browser action.

```bash
npm install platejs @tanstack/react-virtual color-name html-to-vdom jszip juice mime-types virtual-dom xmlbuilder2
```

```tsx title="components/editor/export-docx.tsx"
import { exportToDocx } from "platejs/docx/export";
import { createEditor } from "platejs/react";
import { BaseEditorKit } from "@/components/editor/plugins-static";
import {
  DOCX_EXPORT_STYLES,
  DocxExportKit,
} from "@/components/editor/docx-export";

const editor = createEditor({ plugins: BaseEditorKit });

export async function downloadEditorDocx() {
  const blob = await exportToDocx(editor.read.value().children, {
    editorPlugins: [...BaseEditorKit, ...DocxExportKit],
    orientation: "portrait",
    stylesheet: DOCX_EXPORT_STYLES,
    title: "Document",
  });
  const url = URL.createObjectURL(blob);
  const link = document.createElement("a");
  link.href = url;
  link.download = "document.docx";
  document.body.append(link);
  link.click();
  link.remove();
  URL.revokeObjectURL(url);
}
```

### DOCX export kit

The app-local `DocxExportKit` supplies static renderers for code blocks, columns, equations, callouts, headings, and tables of contents. `DOCX_EXPORT_STYLES` is the copied presentation preset; omit `stylesheet` to use the converter's document defaults without a Plate theme.

## API Reference

### `platejs/docx`

The entrypoint exports `DocxPlugin`. The conversion functions and their options/result types live in `platejs/docx/import` and `platejs/docx/export`.

### `importDocx`

`importDocx(editor, arrayBuffer, options?)` returns:

| Field      | Type            | Description                                      |
| ---------- | --------------- | ------------------------------------------------ |
| `nodes`    | `Descendant[]`  | Plate nodes decoded by the installed HTML codecs |
| `comments` | `DocxComment[]` | Comment text and references into `nodes`         |
| `warnings` | `string[]`      | Conversion and decode warnings                   |

`options.rtf` accepts matching RTF clipboard data when the caller has it.

### `exportToDocx`

`exportToDocx(value, options?)` returns a DOCX `Blob` for the provided document snapshot.

| Option                  | Type                                    | Description                                         |
| ----------------------- | --------------------------------------- | --------------------------------------------------- |
| `allowRemoteImages`     | `boolean`                               | Fetch remote HTTP images during export; defaults to `false`              |
| `editorPlugins`         | `readonly BasePluginInput[]`            | Descriptors used for static HTML rendering          |
| `editorStaticComponent` | `React.ComponentType<PlateStaticProps>` | Static editor wrapper                               |
| `fontFamily`            | `string`                                | Document body font                                  |
| `margins`               | `Margins`                     | Page margins in twentieths of a point               |
| `orientation`           | `'landscape' \| 'portrait'`             | Page orientation                                    |
| `pageSize`              | `PageSize`                              | Page width and height in twentieths of a point      |
| `stylesheet`            | `string`                                | Exact CSS stylesheet applied before DOCX conversion |
| `title`                 | `string`                                | Document metadata title                             |
