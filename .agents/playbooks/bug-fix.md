# bug fix

- **In** "Reproduce it yourself on the matching surface via the driver skill": load `verify`, preserve the reporter's exact route, setup, gesture and follow-up. Use `video-transcripts` for a recording. A main regression needs a detached base control.
- **After** "Binary-search the cause": an explicit diagnose-only request ends with the cause and evidence.
- **In** "Plan the fix": repair the owning package invariant or copied UI interaction. Keep browser-only menu, focus and renderer behavior with its UI owner. A defect reproducing in plain Slate belongs upstream. Public call-shape questions use `best-api`.
- **After** "Verify on the same surface": revoke a disproven green, classify product, host, input-delivery and oracle failures before another attempt. On the second failed fix or cross-layer compensation, run `verdict` on ownership. Preserve every unresolved acceptance item. Run applicable `changeset`.
- **Replace** "Stage the commits so the failing repro lands before the fix": land a cheap failing test together with its fix, never as a red commit. Delivery follows `AGENTS.md`.
- **Replace** "Run **Opening a PR**": run the requested project delivery after writing, applicable review and final proof.
