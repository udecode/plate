# babysit

- **Before** "Declare the mode and resolve the forge before any poll": reviewing another person's PR is review-only. Run the panel on its diff with body, issue and plan (reviews: external-pr), return findings and make no edits or public review submission.
- **Before** "Declare the mode and resolve the forge before any poll": read the requested PR or current-tree candidate, establish its intended behavior and repair accepted defects at their owners. Keep the PR description true to the final diff and prove through `verify`. Public comments, reviews, merges and history rewrites need the user's authority.
