# Autopilot

This file says which calls the lead takes on its own, which stops wait on the owner, and when a finding pivots a run. The pstack block in `AGENTS.md` points here. The `sync-pstack` skill renders this file from its shared source in `udecode/dotai`, so change it there.

- **Autopilot.** Work runs to its close without waiting for the owner. Each call the owner could make gets an attention level, as the `plan-page` skill's memo rules define it: `safe` when the pick is easy to undo and the lead is sure, `look` when it is costly or hard to undo or the lead is unsure, and `answer` when it cannot be taken back or has no clear pick. The lead takes the pick of every call, records it as a Defaults row, or in a planless run's reply, with the word that reverses it, and keeps going; a call with no clear pick takes its most reversible option. A call few would notice, such as where to push, gets at most a decision-log row, never a Defaults row or a line in the reply. Only these stop the run under Open questions, whatever their level: a production deploy or release, a push to `main`, a force-push to a shared branch, deleting data the run did not create, a sign-in a product the run explores needs, and a models-sheet model that cannot run, except a seat the Panel review rule skips, such as one whose provider refused its prompt, a Codex seat whose usage limit ran out or an agy seat that failed. A third plan on a topic stops it too, as long-runs.md says. What the `cleanup` skill's scan marks safe is not data, and the skill deletes it without asking: an idle Next.js cache folder, a run or `.tmp` folder it strips or expires, and a worktree an agent made that no running session, process or recent session transcript uses, after saving its uncommitted changes as a patch. A message anyone outside the team can read waits as a draft, as the Messages rule says, while the run keeps going. A pending external gate, such as a staging release, a quota reset or a running seat, is not a stop either, and neither is a status question from the owner, which never counts as go. Unless the run is paused, held or at a stop it has reached, whoever or whatever set it, the lead keeps working on ready work and schedules a wakeup for a gate with a known time, chaining wakeups past the scheduler's limit. A prototype, an arena or `architect` picks its winner and keeps going, and the page names the other options. A finding that the accepted design cannot meet a requirement pivots the run when it is found. Such findings include a conclusive miss of a frozen budget, except a timing miss that time.md lands, and a cost that only a new owner or stored shape removes. A hillclimb expects most iterations to miss. A miss there is such a finding only when the loop stops with its stop predicate unmet, such as when only marginal ideas remain, or when a proven cause shows that only a change to a stored shape or an owner, which no iteration can make, closes the gap. A profile alone proves no cause, and one noisy or partial iteration never counts. The lead runs `architect` on the finding, writes the plan that adopts the winner and builds that next. Under "fast", the lead's own design pass replaces `architect`. Until it lands, steps that only finish, document or prove the design it replaces wait, and independent work goes on. Such a finding never waits in Open work, in a suggested task or in a deferred row, unless the owner kept that row until a date in their own words. A suggested task holds only side work outside the run's target or a measurement the Time budget rule sends there, and its ledger row names what it waits for, such as this run, so `chips` shows when the owner can start it. A request that asks only for a plan or a prototype ends there and builds nothing, a pivot plan included, and the page shows its picks. The owner adds a stop for one request with "stop at plan", which waits once the plan is written, "stop at design", which waits for the owner's pick among the design options, or "stop before ship", which waits before delivery. "panel" and "hold" work at any point. A project's standing stop goes in its own rules outside this block.
