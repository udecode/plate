# Time budget

This file says how long a command, proof, seat or wait may run, and where a measurement that cannot fit goes. The pstack block in `AGENTS.md` points here. The `sync-pstack` skill renders this file from its shared source in `udecode/dotai`, so change it there.

- **Time budget.** No command, proof or seat that a run starts takes more than an hour, so development stays fast (owner's word, 2026-10-16); only a stress run, below, takes longer. Nothing waits for the host's load to drop (owner's word, 2026-10-19). The lead runs a gate or proof now. When it fails only because the host is loaded, the lead reruns it now, or does other ready work and reruns it when that work is done. Host load alone never makes a time-sensitive measurement inconclusive; only its own measured noise does, such as the gap between interleaved same-code arms. When that noise makes it inconclusive, the lead logs it `inconclusive` with `proof:` its log, names its next probe and goes on. A rerun that cannot fit the hour goes to a suggested task, as below. In the owner's Claude Code, the user-scope hook `~/.claude/hooks/block-load-waits.mjs` refuses a shell loop that sleeps until the load average drops. The budget keeps a lead from holding long work while other chips wait to land, so long work runs in a dedicated chip. Before a proof that may run long, the lead times one sample and narrows the proof to fit. It never runs one protocol as pieces that together pass the hour. A measurement that a decision waits on, such as a probe before a design is accepted, narrows to fit as well, and an inconclusive narrowed result leaves that decision open with its next probe named. Any other measurement that cannot fit, such as a soak, a large-cohort sweep, a multi-round interleaved timing protocol or a final rerun of built code, never blocks the run or its close. When it is still worth running, the lead offers it as a suggested task through the `chips` skill's Offer mode. The offer names the command, the source identity it must measure, its budget, what a miss triggers and the plan step it settles, and says that its measurement lands no patch. When the change is not yet on the branch a card's worktree starts from, the task waits `pr:<number>` on the PR that carries it. When no PR carries it, the offer names the absolute path of a patch of it saved in the run directory. The task goes to `## Open work` with `owner:` the owner and `stop:` that task landing or being dropped. This hand-off is the owner's word that the narrower exit condition counts as done. The lead takes the close rule's accepted route: a `look` Defaults row whose word runs the measurement in the run, a labeled `partial` row and then an `accepted` row on the last log the run wrote for that measurement, such as its timed sample, and the step's box closed citing the task. The Close claims only what the run measured. The lead can then mark the plan done, which frees the task's `run:` wait. The task's session confirms that its tree holds that source identity before it runs, because a card's worktree lacks uncommitted work. It applies the named patch when its tree lacks the change, and stops and tells the owner when the patch does not apply. It writes its proof logs with `proof.mjs --dir` set to the checkout's run directory, appends its verdict to that plan's decision log from the checkout with `decisions-check.mjs append`, and delivers that row by the project's Delivery rule. Its measurement lands no patch, so its `landed` row names no `patch:`. A conclusive miss it finds is a pivot finding, which that session logs in the plan's decision log and leads as the Autopilot rule says. Only that session, or the run once the owner says the Defaults row's word, passes `--stress`. Without `--stress`, `proof.mjs` stops a command after 3,600 seconds or its shorter `--timeout`, kills every process still in the command's process group and logs the run as timed out. `proof.mjs` and `cross.mjs` refuse a longer `--timeout` without `--stress`, except a `cross.mjs --bypass` coding run, which the Codex workers rule gives six hours, and `mutate.mjs` refuses a spec timeout over 3,600 seconds and stops its whole run at an hour.
