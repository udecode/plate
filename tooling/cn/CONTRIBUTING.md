# 贡献指南

完整的指南（英文）位于 [../../CONTRIBUTING.md](../../CONTRIBUTING.md)。

- Plate 发布的代码（包括 Plite）以 MIT 许可证存放在本仓库中。
- 测试、计划和研究资料存放在团队的私有仓库中，因此本仓库的克隆只包含代码，不包含测试。
- 您可以通过提交附带复现的 issue 来参与贡献。所有修复都由团队编写，团队会关闭来自团队以外的拉取请求。

## 如何参与

1. **错误**：提交一个附带真实复现的错误报告。团队优先修复附带公开复现的错误。
2. **功能**：提交功能请求；较大的想法请先在 [GitHub Discussions](https://github.com/udecode/plate/discussions) 中讨论。
3. **问题**：请使用 [Discussions](https://github.com/udecode/plate/discussions) 或 [Discord](https://discord.gg/mAZRuBzGM3)。
4. **安全问题**：请通过[安全公告](https://github.com/udecode/plate/security/advisories/new)私下报告漏洞。
