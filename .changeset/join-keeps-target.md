An Editing deletion now applies in its own commit, even beside a pending suggested join, and every accepted join lands with the type of the line it merges into. Settling an accepted deletion of an inline element, such as a link, or of a whole block now removes it with its text, as accepting it does, and a level that needs a block, such as a quote or a document's title, keeps an empty one. Collaborative peers that each settle the same update write the result to Yjs as deletions and attribute writes, never insertions, so the room stores one copy and a letter another peer types into a kept line survives. Undoing an edit inside two sibling lines a peer joined, a mark change included, now restores it in the joined line and keeps the join, through `DocumentChange.transform` too. The Yjs binding now sends a join as a move of the second line's children, so the receiving peer reads it as a join, not as text retyped. Lines the undo restores between the two come back after the joined line. A join whose own lines move in the same update, a change outside Yjs that replaces the two lines whole, a join across a container's edge, such as Backspace at the start of the line after a quote, a line with no text that a join removes, and a join that leaves an inline element at a line's edge or beside another element still rebase by position. When a diff of two documents writes a join, the letters it retypes beside the boundary count as typed, so a peer's typing where the lines meet can land among them, as on base. A peer that removes a line and retypes its text after the line above in one commit no longer sends a join, so the undo keeps that peer's typing. A peer's commit that replaces both lines with their joined text now reads as a join, so undoing a letter it retyped removes the retyped copy too. Backspace from an external text view, an input method composition over a selection and the empty inline a cut leaves now go through the editor's commands, so a plugin's command handlers see them. Backspace from an external text view at the start of an empty line after a block void therefore removes the empty line and keeps the void, as Backspace in the editor does. A document or a peer's update that stores an Editing deletion claim is now refused, as one that stores an Editing insertion already is.
