Fix commands over a line that someone moved between the two halves of a pending join. A Backspace at the start of such a line now merges it the way a plain editor does, where it used to delete the wrong letter and drop the moved line from the saved document. Typing, deleting and joining around it land where the editor shows them, in Suggesting and Editing. Select-all covers every line the editor shows, a moved last line included. The editor refuses an edit that the review marks cannot record next to such a line, and saves none of it. That includes an edit whose selected letters show only away from the selection. A format beside a moved line formats what the proposed preview shows between the selection's ends, so it can format saved text outside the selection or leave a moved line inside it plain. The editor does not refuse a command that names a place of its own, such as a link inserted at a given point, for the selection it started with, so it can change text outside the selection. Its edits at the places it names still refuse this way. A refused edit reaches `subscribeRefusals` as `unrepresentable`. Its `reasons` list `crosses`, `reordered` or `unaligned`, except a Suggesting Backspace that would give a content root two owners, which carries none.
