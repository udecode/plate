- Fix a teammate's letter being lost when a Yjs peer, in one commit, wraps a paragraph twice, or changes one of its properties other than its type and wraps it. The peer now writes the wraps and the property change without rewriting the paragraph's letters, so concurrent typing in it survives.
- Fix a teammate's removal from a set-valued property coming back after a Yjs peer wraps, unwraps or moves its element, when the property merges per member only under some parents. Such a property now keeps both its per-member form and its whole-value form, and reads the same wherever its element sits, so a removal sticks after a later wrap, unwrap or move, also when the peer's move sets the property or sorts the list in the same commit. Each write still merges the way the element's current parent asks. A removal still comes back when the peer, in one commit, moves the element and edits its text, or moves it among its siblings and sets the property. It also comes back when the peer's one commit moves the element and sets the property while it adds, removes or moves another element with the same content, such as a second line with the same text. A whole value holding a member the new parent rejects, set while a teammate moves the element there and edits the property, stops both peers with a schema error. A text mark that merges as a set only under some parents still makes the peer rewrite the line.
- Fix a Yjs peer's editor disagreeing with its own Yjs document about an empty list in such a property under a parent that merges it per member. The editor and the document now agree when a teammate clears or removes the list while the peer moves the element there, when a teammate adds and removes all of its members in one commit, and when the peer splits an element that holds an empty list there.
- A room whose schema has such a property now uses schema metadata format 7. This version refuses a room of that schema saved by an earlier version, so start a fresh room, and an earlier version refuses any Yjs document that holds a format-7 room.
