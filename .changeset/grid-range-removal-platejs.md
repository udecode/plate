- Keep every row and cell of a table when an expanded range runs from inside the table to outside it. A cell the range covers whole keeps only its first block, emptied, when that block is an editable text block, and otherwise becomes one empty paragraph, as a cell that starts with an image, an atom or a read-only block does. A cell at the range's edge loses only the covered text, and text outside the table never joins a cell. Before, the covered cells and rows were dropped, the text after the table joined a cell, or a one-cell table was left. This holds for delete, typing, Enter, paste, node insert, split and merge over a range passed as `at` or set with `tx.selection.set` inside a transaction, except that a node insert or split whose range ends at the start of a table's first cell still lands in that cell. A mouse drag from a paragraph into a cell keeps its exact range, so Delete now keeps the table too. `editor.update.selection.set` over the same range still selects the whole table, so Delete after it still removes the table
- Remove a table whole when the range covers it and reaches past one of its edges. Select-all then Delete or Enter on a document that starts with a table now empties it instead of leaving a one-cell table. A delete over a selection that spans a table exactly keeps the table and clears its cells. `editor.update.fragment.delete({ at })` over such a range still removes the table, and typing over it still replaces the table with a paragraph holding the typed text, as before
- Stop a selection that `editor.update.selection.set` makes from a document's first table to past its end at the table's end, as it does for any other table. Select-all keeps its whole-document range
- Change the schema fingerprint of an editor that includes `BaseTablePlugin`, because it declares its grid roles. Such an editor refuses snapshots, persisted history and authored comparisons written with the old fingerprint, and old and new clients cannot share a Yjs room. A named schema needs a higher version before `plate migrate` scaffolds its migration
